¿Qué patrón de diseño aplica este código?

#include <iostream>
#include <string>

class Impresora {
public:
    virtual ~Impresora() {}
    virtual void imprimir(const std::string& texto) const = 0;
};

class TermicaX200 {
public:
    void enviarBytes(const std::string& datos) const {
        std::cout << "[X200] " << datos << "\n";
    }
};

class PuestoX200 : public Impresora {
private:
    TermicaX200* termica_;

public:
    PuestoX200(TermicaX200* termica) : termica_(termica) {}
    void imprimir(const std::string& texto) const override {
        termica_->enviarBytes(texto);
    }
};

int main() {
    TermicaX200 termica;
    Impresora* impresora = new PuestoX200(&termica);
    impresora->imprimir("Ticket 001");
    delete impresora;
    return 0;
}

Inventada · estilo Parcial 2025, Práctica 2

  • Adapter
  • Facade
  • Factory Method
  • Composite

PuestoX200 hereda de la interfaz que el sistema ya usa (Impresora) y guarda adentro un objeto de la clase incompatible (TermicaX200). Su único trabajo es traducir: recibe imprimir() y llama a enviarBytes(). Es Adapter: Impresora es la interfaz con el cliente (Target), TermicaX200 el servicio (Adaptee) y PuestoX200 el adaptador.

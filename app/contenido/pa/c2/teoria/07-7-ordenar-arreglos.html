Arreglos

7. Ordenar arreglos: sort, asort, rsort, arsort, ksort y krsort

Para qué sirve

Para poner los elementos de un arreglo en orden (alfabético o numérico). PHP trae varias funciones que se diferencian en dos preguntas:

  1. ¿Ordena por el valor o por la clave?
  2. ¿Qué pasa con las claves? ¿Cada valor se queda con su clave, o se tiran las claves y se numera de nuevo desde 0?
FunciónOrdena porSentidoLas claves
sort()ValorAscendente (A→Z, 0→9)Se pierden: renumera 0, 1, 2…
rsort()ValorDescendente (Z→A, 9→0)Se pierden: renumera 0, 1, 2…
asort()ValorAscendenteSe mantienen: cada valor sigue con su clave
arsort()ValorDescendenteSe mantienen
ksort()ClaveAscendenteSe mantienen
krsort()ClaveDescendenteSe mantienen

Cómo acordarse de los nombres:

  • r = reverse, al revés (descendente).
  • a = associative, respeta la asociación clave-valor.
  • k = key, ordena por la clave.

Sintaxis

Todas tienen la misma forma 
sort($arreglo);
sort($arreglo, SORT_STRING);   // con el segundo parámetro opcional

Qué es cada parte

ParteQué es
$arregloEl arreglo a ordenar. La función lo modifica a él mismo: no hace una copia
Lo que devuelveSolo true (que todo salió bien). No devuelve el arreglo ordenado
SORT_REGULAR(opcional, es el que se usa si no ponés nada) Compara sin transformar: los números como números y los textos como textos
SORT_NUMERICConvierte cada elemento a número antes de comparar
SORT_STRINGTrata todos los elementos como texto, carácter por carácter

Qué hace sort() con las claves, con precisión

La cátedra lo explica así:

"sort() ordena el arreglo que le pasamos como parámetro, modificando al mismo a nivel de claves. Esto quiere decir que destruirá todas las claves que contenga y generará un nuevo arreglo numerando los elementos a partir del 0."

Paso a paso, sort():

  1. Toma solo los valores del arreglo.
  2. Los ordena de menor a mayor.
  3. Tira todas las claves viejas, sean números o textos.
  4. Les pone claves nuevas 0, 1, 2… en el orden nuevo.

Por eso "modificando a nivel de claves" quiere decir que las claves cambian: después de sort(), un arreglo asociativo deja de serlo. Si necesitás conservar las claves, se usa asort().

Ejemplo 1 — sort(), antes y después (teoría de la cátedra)

<?php
$arreglo = array('a' => 'aab', 'b' => 'bbb', 'c' => 'aaa');
print_r($arreglo);
sort($arreglo);
print_r($arreglo);
?>

print_r($arreglo);Muestra el arreglo antes(igual)
sort($arreglo);Ordena los valores: aaa < aab (en la tercera letra, a va antes que b) < bbb. Tira las claves a, b, c y numera desde 00 => aaa · 1 => aab · 2 => bbb
print_r($arreglo);Muestra el arreglo después(igual)

    [a] => aab
    [b] => bbb
    [c] => aaa
)

Qué mirar: los valores quedaron en orden, y las claves [a] [b] [c] desaparecieron: ahora son [0] [1] [2]. El valor aaa, que estaba en la clave c, ahora está en la 0.

Ejemplo 2 — asort(): el mismo orden, sin perder las claves

<?php
$arreglo = array('a' => 'aab', 'b' => 'bbb', 'c' => 'aaa');
asort($arreglo);
print_r($arreglo);
?>

$arreglo = array(...);El mismo arregloa => aab · b => bbb · c => aaa

print_r($arreglo);Lo muestra(igual)
Array
(
    [c] => aaa
    [a] => aab
    [b] => bbb

La salida del apunte de la cátedra está mal

El apunte muestra ['c'] => aaa, ['b'] => aab, ['a'] => bbb: con las claves en orden inverso, como si se hubieran separado de sus valores. Justamente asort() no separa claves y valores: aab estaba en la clave a y sigue ahí. La salida real es la de arriba (y print_r no pone comillas en las claves).

Ejemplo 4 — Por clave: ksort() y krsort()

<?php
$arreglo = array('d' => 'aab', 'c' => 'bbb', 'a' => 'aaa');
ksort($arreglo);
print_r($arreglo);
krsort($arreglo);
print_r($arreglo);
?>

$arreglo = array(...);Claves d, c, ad => aab · c => bbb · a => aaa
ksort($arreglo);Ordena por clave de la A a la Z; cada clave con su valora => aaa · c => bbb · d => aab
krsort($arreglo);Por clave, de la Z a la Ad => aab · c => bbb · a => aaa

    [c] => bbb
    [d] => aab

Array
(
    [d] => aab
    [c] => bbb
    [a] => aaa
)

Los valores quedaron "desordenados" (aaa, bbb, aab) porque acá lo que se ordena son las claves.

Ejemplo 5 — El segundo parámetro: números guardados como texto

<?php
$s = array('10', '9', '2', '1');
$t = $s;
sort($s);
sort($t, SORT_STRING);
foreach ($s as $v) { echo $v . ' '; }
echo '<br>';
foreach ($t as $v) { echo $v . ' '; }
?>

Ejemplo 6 — La pregunta del parcial

Enunciado (Parcial PHP, pregunta 10)

Verdadero o falso: "¿La función sort() nos brinda la posibilidad de ordenar un arreglo que le pasamos como parámetro, modificando al mismo a nivel de claves?"

  • Es, palabra por palabra, la definición de sort() de la guía práctica de la cátedra.
  • Y es lo que se ve en el ejemplo 1: el arreglo que se pasa se modifica él mismo, y sus claves cambian (se tiran y se numera desde 0).
Respuesta: Verdadero

La trampa sería leer "a nivel de claves" como "ordena por clave": eso hace ksort(). sort() ordena por valor y reasigna las claves.

Errores y trampas

sort() no devuelve el arreglo

$ordenado = sort($q); deja en $ordenado el valor true, no el arreglo. El arreglo ordenado es $q mismo.

Las mayúsculas van antes que todas las minúsculas

Los textos se comparan por el código de cada carácter, y todas las mayúsculas (A–Z) tienen códigos menores que las minúsculas. Por eso sort() de ('pera', 'banana', 'Manzana') da Manzana, banana, pera. Lo mismo pasa con la práctica: los días ordenados quedan Domingo, Jueves, Lunes, Martes, Miércoles, Sábado, Viernes (ejercicio 4).

Definiciones

2. DDL y DML

Para escribir en la hoja

Son los dos lenguajes que trae el SGBD para comunicarse con el motor, uno por cada una de sus funciones principales: la de definición y la de manipulación.

DDL (Data Definition Language, lenguaje de definición de datos): sirve para definir la estructura de la base: crear la base, las tablas, sus atributos, sus relaciones y sus índices. Las definiciones quedan en el diccionario de datos. Tiene tres palabras reservadas: CREATE (crear un objeto), ALTER (modificar la estructura de un objeto) y DROP (eliminar un objeto).

DML (Data Manipulation Language, lenguaje de manipulación de datos): sirve para trabajar con los datos guardados. Tiene cuatro palabras reservadas: SELECT (obtener información), INSERT (agregar registros), UPDATE (actualizarlos) y DELETE (eliminarlos).

Cada sentencia, en una línea

LenguajeSentenciaQué haceEjemplo corto
DDLCREATECrea un objeto: una base, una tabla, una vistaCREATE TABLE Raza (...)
ALTERModifica la estructura de un objeto que ya existeALTER TABLE Animal ADD Color VARCHAR(20)
DROPElimina el objeto entero, con sus datos (no tiene vuelta atrás)DROP TABLE Raza
DMLSELECTConsulta los datosSELECT Nombre FROM Animal
INSERTAgrega registrosINSERT INTO Raza VALUES (1, 'Caniche')
UPDATEModifica valores de registros que ya existenUPDATE Turno SET Estado = 'Atendido' ...
DELETEElimina registros (la tabla queda)DELETE FROM Turno WHERE ...

La sintaxis completa del DDL está en la Unidad 3, y la del DML en la Unidad 4.

De dónde sale: las funciones del SGBD

El apunte de la cátedra dice que el SGBD tiene tres funciones, y las dos primeras son estos lenguajes:

Función del SGBDQué permiteCon qué
Definición (descripción)Describir los datos, su estructura, sus interrelaciones y sus validacionesDDL (en castellano, LDD)
ManipulaciónBuscar, añadir, suprimir y modificar los datosDML (en castellano, LMD)
UtilizaciónCopias de seguridad, carga de archivos, estadísticas, protección contra accesos no autorizados, concurrenciaHerramientas del SGBD para el DBA

Ejemplo: ¿DDL o DML?

Clasificá cada acción: (a) agregar a la tabla Animal la columna Color; (b) cargar un animal nuevo; (c) cambiar el peso de un animal; (d) borrar la tabla Raza; (e) listar los turnos pendientes.

Acción¿Cambia la estructura o los datos?Lenguaje y sentencia
(a) agregar la columna ColorLa estructura: la tabla pasa a tener otra columnaDDL ALTER
(b) cargar un animalLos datos: un registro másDML INSERT
(c) cambiar el pesoLos datos: un valor de un registroDML UPDATE
(d) borrar la tabla RazaLa estructura: la tabla deja de existirDDL DROP
(e) listar los turnos pendientesLos datos: se leen, no se cambianDML SELECT
Errores y trampas
  • SELECT es DML, aunque no cambie nada.
  • DELETE (DML) elimina registros; DROP (DDL) elimina la tabla. UPDATE (DML) cambia valores; ALTER (DDL) cambia columnas.
  • La consigna pide tres cosas: la definición, para qué sirve cada uno y las sentencias. Si falta una, la respuesta queda incompleta.

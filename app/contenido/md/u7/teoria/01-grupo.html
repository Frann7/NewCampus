Grupos

1. Grupo: definición y cómo probar cada axioma

Para qué sirve

Muchísimos conjuntos con una operación se portan igual: los enteros con la suma, los reales sin el cero con el producto, los restos de \(\mathbb{Z}_n\) con la suma, las palabras de ceros y unos con la suma bit a bit. En todos podés operar sin salirte del conjunto, hay un elemento que "no hace nada" y toda operación se puede deshacer. En vez de estudiar cada caso por separado, se estudia una vez la estructura que tienen en común: el grupo. Todo lo que se demuestre para un grupo cualquiera vale después para cada uno de ellos.

Operación binaria

Una operación binaria en un conjunto \(G\) es una regla que a cada par ordenado \((a, b)\) de elementos de \(G\) le asigna un resultado, que se escribe \(a \circ b\). El símbolo \(\circ\) es genérico: en cada caso concreto puede ser la suma \(+\), el producto \(\cdot\) o una operación inventada (\(*\), \(\odot\)...) definida con una fórmula.

Definición (la de la cátedra)

Grupo

Si \(G\) es un conjunto no vacío y \(\circ\) es una operación binaria en \(G\), entonces \((G, \circ)\) es un grupo si cumple:

  1. Ley de cierre: \(\forall a, b \in G:\ a \circ b \in G\).
  2. Asociativa: \(\forall a, b, c \in G:\ a \circ (b \circ c) = (a \circ b) \circ c\).
  3. Neutro: existe \(e \in G\) tal que \(a \circ e = e \circ a = a\) para todo \(a \in G\).
  4. Inversos: para todo \(a \in G\) existe \(b \in G\) tal que \(a \circ b = b \circ a = e\).

Si además \(a \circ b = b \circ a\) para todo \(a, b \in G\), el grupo es abeliano (o conmutativo).

Qué significa cada símbolo

SímboloSe leeQué quiere decir
\((G, \circ)\)"G con la operación círculo"El grupo no es solo el conjunto: es el conjunto y la operación. \(\mathbb{Z}\) con \(+\) es grupo; \(\mathbb{Z}\) con \(\cdot\) no.
\(\forall\)"para todo"La propiedad tiene que valer para cualquier elección de elementos, no para uno solo.
\(\in\)"pertenece a"\(a \in G\): \(a\) es un elemento de \(G\).
\(e\)"el neutro"El elemento que operado con cualquiera lo deja igual. Con la suma es el 0; con el producto, el 1.
\(a^{-1}\)"inverso de \(a\)"El \(b\) del axioma 4. Con la suma se escribe \(-a\) y se llama opuesto.

Por qué cada axioma

  • Cierre: que operar no te saque del conjunto. Los naturales con la resta no lo cumplen: \(3 - 5 = -2\) no es natural.
  • Asociativa: que en una cuenta larga no importe por dónde empezás, así \(a \circ b \circ c\) tiene un solo valor y se puede escribir sin paréntesis.
  • Neutro: el "no hacer nada", el punto de partida para hablar de deshacer.
  • Inversos: que todo se pueda deshacer. Gracias a esto se puede "despejar" en un grupo: de \(a \circ x = b\) sale \(x = a^{-1} \circ b\).

Cómo se prueba cada axioma

Un ejercicio de "probar que \((G, \circ)\) es grupo" es siempre esta receta, en este orden:

AxiomaQué se haceEl error típico
1. CierreTomar \(a, b\) genéricos de \(G\), calcular \(a \circ b\) con la fórmula y mostrar que cumple la condición para estar en \(G\).Olvidarse de la condición del conjunto (por ejemplo, "distinto de cero" o "distinto de \(-1\)").
2. AsociativaCalcular \(a \circ (b \circ c)\) y \((a \circ b) \circ c\) por separado, desarrollar las dos y ver que quedan iguales.Probarlo con tres números: un ejemplo no demuestra un "para todo".
3. NeutroPlantear la ecuación \(a \circ e = a\), despejar \(e\), comprobar que no depende de \(a\), que está en \(G\) y que también \(e \circ a = a\).Que el \(e\) despejado dependa de \(a\): entonces no hay neutro (tiene que ser el mismo para todos).
4. InversosPlantear \(a \circ b = e\) (con el \(e\) ya hallado), despejar \(b\) en función de \(a\), comprobar que \(b \in G\) y que también \(b \circ a = e\).No chequear que el inverso esté en \(G\).
AbelianoCalcular \(a \circ b\) y \(b \circ a\) y ver que son iguales para todo \(a, b\).—
Para probar que algo NO se cumple, alcanza un contraejemplo

Los axiomas dicen "para todo". Para demostrar que valen hay que hacerlo con letras; para demostrar que no valen alcanza con un solo caso con números donde fallen. Si el grupo es abeliano o no, se decide igual: si encontrás \(a, b\) concretos con \(a \circ b \neq b \circ a\), no es abeliano.

Si es abeliano, la mitad del trabajo se ahorra

Si ya probaste que la operación conmuta, \(a \circ e = a\) implica solo \(e \circ a = a\), y \(a \circ b = e\) implica \(b \circ a = e\). Por eso conviene probar la conmutatividad antes del neutro y los inversos, y decirlo en la respuesta.

Los grupos de siempre

  • \((\mathbb{Z}, +)\), \((\mathbb{Q}, +)\), \((\mathbb{R}, +)\), \((\mathbb{C}, +)\): grupos abelianos, neutro 0, inverso de \(a\) el opuesto \(-a\).
  • \((\mathbb{Q}^{*}, \cdot)\), \((\mathbb{R}^{*}, \cdot)\), \((\mathbb{C}^{*}, \cdot)\): el asterisco quiere decir sin el cero. Grupos abelianos, neutro 1, inverso \(1/a\). Hay que sacar el 0 porque no tiene inverso: no existe \(b\) con \(0 \cdot b = 1\).
  • Si \((R, +, \cdot)\) es un anillo (Unidad 6), \((R, +)\) es un grupo abeliano: los primeros axiomas de anillo son justamente los de grupo para la suma.
  • En un cuerpo, los elementos distintos de cero forman un grupo abeliano con el producto.

Ejemplo 1 — Los enteros con la suma, con el producto y con la resta

Enunciado

Decidir si son grupos: a) \((\mathbb{Z}, +)\); b) \((\mathbb{Z}, \cdot)\); c) \((\mathbb{Z}, -)\).

Desarme del enunciado

FraseQué significaLa cuentaA dónde va
"\((\mathbb{Z}, +)\)"enteros con la suma común\(a \circ b = a + b\)inciso a
"\((\mathbb{Z}, \cdot)\)"enteros con el producto común\(a \circ b = a \cdot b\)inciso b
"\((\mathbb{Z}, -)\)"enteros con la resta\(a \circ b = a - b\)inciso c

a) \((\mathbb{Z}, +)\)

  1. Cierre: la suma de dos enteros es un entero.
  2. Asociativa: la suma de enteros es asociativa (propiedad conocida de los números).
  3. Neutro: \(a + e = a \Rightarrow e = 0\), y \(0 \in \mathbb{Z}\).
  4. Inversos: \(a + b = 0 \Rightarrow b = -a\), que es entero.
  5. Abeliano: \(a + b = b + a\).
Respuesta a

Es grupo abeliano.

b) \((\mathbb{Z}, \cdot)\)

Cierre, asociativa y neutro (\(e = 1\)) se cumplen. Falla el axioma 4: el inverso de 2 tendría que cumplir \(2 \cdot b = 1\), o sea \(b = \frac{1}{2}\), que no es entero. Un contraejemplo alcanza.

Respuesta b

No es grupo: el 2 no tiene inverso en \(\mathbb{Z}\).

c) \((\mathbb{Z}, -)\)

El cierre vale (la resta de enteros es entera), pero falla la asociativa. Con números:

\[ (5 - 3) - 1 = 2 - 1 = 1 \qquad\qquad 5 - (3 - 1) = 5 - 2 = 3 \]

Dan distinto: \(1 \neq 3\).

Respuesta c

No es grupo: la resta no es asociativa.

Ejemplo 2 — Estilo parcial: una operación definida con una fórmula

Enunciado

Sea \(G = \mathbb{R} - \{-1\}\) (los reales salvo el \(-1\)) con la operación \(a * b = a + b + ab\). Probar que \((G, *)\) es un grupo abeliano.

Desarme del enunciado

FraseQué significaLa cuentaA dónde va
"\(G = \mathbb{R} - \{-1\}\)"la condición para estar en \(G\) es ser real y distinto de \(-1\)—se revisa en el cierre, el neutro y los inversos
"\(a * b = a + b + ab\)"la fórmula de la operación—se usa en cada axioma
"grupo abeliano"los cuatro axiomas más la conmutativa—cinco pasos

Un truco que ordena todo: \(a + b + ab = (1 + a)(1 + b) - 1\), porque \((1 + a)(1 + b) = 1 + b + a + ab\) y al restar 1 queda \(a + b + ab\). Comprobación con números: \(2 * 3 = 2 + 3 + 6 = 11\) y \((1 + 2)(1 + 3) - 1 = 12 - 1 = 11\).

Paso 1 — Cierre

Tomo \(a, b \in G\), es decir \(a \neq -1\) y \(b \neq -1\). Tengo que ver que \(a * b \neq -1\).

  • \(a * b = (1 + a)(1 + b) - 1\).
  • Como \(a \neq -1\), \(1 + a \neq 0\); como \(b \neq -1\), \(1 + b \neq 0\).
  • Un producto de dos números distintos de cero es distinto de cero: \((1 + a)(1 + b) \neq 0\).
  • Entonces \(a * b = (1 + a)(1 + b) - 1 \neq 0 - 1 = -1\). Queda en \(G\).
Paso 2 — Asociativa

Desarrollo los dos lados con el truco:

  • \((a * b) * c = \big(1 + (a * b)\big)(1 + c) - 1\). Como \(1 + (a * b) = (1 + a)(1 + b)\), queda \((1 + a)(1 + b)(1 + c) - 1\).
  • \(a * (b * c) = (1 + a)\big(1 + (b * c)\big) - 1 = (1 + a)(1 + b)(1 + c) - 1\).

Son la misma expresión: la operación es asociativa.

Paso 3 — Conmutativa

\(a * b = a + b + ab\) y \(b * a = b + a + ba\). Como la suma y el producto de reales conmutan, son iguales. Por eso alcanza con verificar el neutro y los inversos de un solo lado.

Paso 4 — Neutro

Planteo \(a * e = a\) y despejo \(e\):

\[ a + e + ae = a \;\Rightarrow\; e + ae = 0 \;\Rightarrow\; e(1 + a) = 0 \]

Como \(1 + a \neq 0\) (porque \(a \neq -1\)), tiene que ser \(e = 0\). No depende de \(a\) y \(0 \neq -1\), así que \(0 \in G\). Comprobación: \(a * 0 = a + 0 + 0 = a\).

Paso 5 — Inversos

Planteo \(a * b = 0\) (el neutro recién hallado) y despejo \(b\):

\[ a + b + ab = 0 \;\Rightarrow\; b(1 + a) = -a \;\Rightarrow\; b = \frac{-a}{1 + a} \]

Se puede dividir porque \(1 + a \neq 0\). Falta ver que \(b \in G\), o sea \(b \neq -1\). Si fuera \(\frac{-a}{1 + a} = -1\), sería \(-a = -1 - a\), es decir \(0 = -1\): absurdo. Entonces \(b \neq -1\).

Con números: el inverso de 2 es \(\frac{-2}{3}\), y \(2 * \left(-\frac{2}{3}\right) = 2 - \frac{2}{3} - \frac{4}{3} = 0\).

Respuesta

\((G, *)\) es un grupo abeliano, con neutro \(e = 0\) y con inverso \(a^{-1} = \frac{-a}{1 + a}\).

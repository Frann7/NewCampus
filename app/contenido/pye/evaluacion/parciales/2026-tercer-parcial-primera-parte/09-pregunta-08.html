Pregunta 8

Unidad 8 · Tamaño de muestra

Seleccione una:

Para estimar el tiempo medio de carga de un sitio con 99 % de confianza y un error de a lo sumo 2 ms, la fórmula del tamaño de muestra dio \(n = 106{,}17\). ¿Cuántas cargas hay que medir?

  1. 106, porque 0,17 está por debajo de 0,5.
  2. 107, porque el tamaño de muestra se redondea siempre para arriba.
  3. 106,17, el valor exacto que dio la fórmula.
  4. 106, porque con menos datos el error queda más chico.
✓ ResultadosSolo la respuesta

Correcta: b — 107, porque el tamaño de muestra se redondea siempre para arriba.

✎ Explicación detalladaDe dónde sale, la cuenta y las trampas

Qué evalúa

Qué se hace con el resultado de la fórmula del tamaño de muestra.

Por qué

  • No se puede medir una parte de una carga: \(n\) tiene que ser entero.
  • Se redondea siempre para arriba: con 107 datos el error queda en 2 ms o menos; con 106 queda un poco más grande que lo pedido.

Trampas

  • Redondear como siempre (para abajo si es menos de 0,5) acá no vale.
  • Con menos datos el error queda más grande, no más chico.

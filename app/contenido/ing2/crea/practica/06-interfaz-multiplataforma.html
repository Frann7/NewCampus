Ejercicio 6 · Abstract Factory

Diseñar desde un enunciado: interfaz para escritorio y web

Ejercicios de patrones, ejercicio 2. Estás construyendo una aplicación de dibujo que puede trabajar tanto en un entorno de escritorio como en un entorno web. Quieres que tu aplicación sea capaz de crear diferentes tipos de elementos de interfaz de usuario, como botones y cuadros de texto, de manera que se ajusten a la plataforma específica (escritorio o web). Cada elemento de interfaz de usuario tiene los siguientes atributos:

  • Ancho: El ancho del elemento.
  • Alto: La altura del elemento.
  • Texto: El texto que se muestra en el elemento.
  • Color de fondo: El color de fondo del elemento.

Es el primer paso que recomienda el apunte para Abstract Factory. Si la tabla se puede armar, con al menos dos columnas y dos filas, el patrón es este.

Paso 3 — Por qué no Factory Method

Con Factory Method se podría crear "un botón" de distintos tipos, pero nada impediría que la aplicación de escritorio terminara con un botón de escritorio y un cuadro de texto web. Acá hay dos productos que tienen que corresponder a la misma plataforma: eso es una familia.

Paso 4 — El diagrama
  • FabricaUI tiene un método por columna de la tabla: crearBoton() y crearCuadroTexto().
  • Hay una fábrica concreta por fila: FabricaEscritorio crea BotonEscritorio y CuadroTextoEscritorio; FabricaWeb, los dos de web.
  • Aplicacion es el cliente: recibe una fábrica al arrancar, según dónde esté corriendo, y después solo usa Boton y CuadroTexto.
  • Boton y CuadroTexto son clases abstractas (y no interfaces) porque guardan los cuatro atributos; las hijas heredan con línea continua.
Respuesta

Patrón Abstract Factory. La aplicación tiene que crear varios elementos de interfaz (botones y cuadros de texto) que se ajusten todos a una misma plataforma (escritorio o web): son familias de objetos relacionados. FabricaUI declara un método de creación por producto, y cada fábrica concreta crea los elementos de su plataforma. La aplicación trabaja con las interfaces, se garantiza que los elementos son compatibles entre sí, y una plataforma nueva (por ejemplo, móvil) se agrega con una fábrica más.

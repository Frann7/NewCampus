Ejemplo de la cátedra · sessiones

Dos páginas que comparten la sesión

Carpeta sessiones: pagina1.php guarda datos en la sesión y los muestra en una tabla; pagina2.php no guarda nada, solo muestra la misma tabla. Cada una tiene un enlace a la otra.

Archivo 1 — pagina1.php 
<?php
session_start();

$vDatosUsuario = array(
    'apellido' => 'Bonnet',
    'nombres'  => 'Federico',
    'area'     => 'Recursos Humanos'
);

$_SESSION['usuario'] = 'fedebonnet';

$_SESSION['datos'] = $vDatosUsuario;
?>

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1, shrink-to-fit=no">
    <title>Programación Avanzada</title>
    <!-- Bootstrap CSS -->
    <link rel="stylesheet" href="https://stackpath.bootstrapcdn.com/bootstrap/4.5.2/css/bootstrap.min.css" ...>
</head>
<body class="container" style="text-align:center">
    <br>
    <h1>Página 1</h1>
    <br>
    <h4>Éstos son los datos creados en la session.</h4>
    <br>
    El ID de la session:<h4><?php echo session_id()?></h4>
    <br>

    <table class="table">
        <thead>
            <tr>
                <th scope="col">Clave</th>
                <th scope="col">Valor</th>
            </tr>
        </thead>
        <tbody>
        <?php
            if (!empty($_SESSION)) {
                foreach ($_SESSION as $clave => $valor) {
                    echo '<tr>';
                        echo '<td>' . $clave . '</td>';
                        echo '<td>';
                            print_r($valor);
                        echo '</td>';
                    echo '</tr>';
                }
            } else {
                echo "Aún no se ha creado la sessión.";
            }
        ?>
        </tbody>
    </table>
    <br>
    <a href='pagina2.php'> Ir a la página 2</a>
</body>
</html>

(El <link> de Bootstrap trae además un atributo integrity largo, que acá se acortó con ...: sirve para que el navegador verifique que el archivo descargado no fue alterado.)

Archivo 2 — pagina2.php 
<?php
session_start();
?>

<!DOCTYPE html>
...
    <h1>Página 2</h1>
    <br>
    <h4>Muestro los datos de la session desde otro script.</h4>
...

El resto (el id, la tabla con el foreach, el mensaje del else) es idéntico a pagina1.php, y el enlace del final va a pagina1.php. La diferencia es que acá no se asigna nada: solo session_start(), que recupera lo que guardó la otra página.

Qué se ve

Se probó en un servidor con las dos páginas, en este orden:

1. Abrir primero pagina2.php (navegador nuevo)

La sesión se acaba de crear y está vacía: !empty($_SESSION) da false y sale el mensaje del else. 

Página 2
Muestro los datos de la session desde otro script.
El ID de la session:
9cfv1qepmt1eg3r57labblhlqd
Aún no se ha creado la sessión.

2. Abrir pagina1.php

Guarda los datos y los muestra. En pantalla, la tabla:

ClaveValor
usuariofedebonnet
datosArray ( [apellido] => Bonnet [nombres] => Federico [area] => Recursos Humanos )

print_r escribe el arreglo en varias líneas, pero el navegador junta los saltos de línea en un espacio: por eso se ve todo en un renglón.

3. Tocar "Ir a la página 2"

pagina2.php muestra el mismo id y la misma tabla, sin haber asignado nada. En la prueba el id fue 9cfv1qepmt1eg3r57labblhlqd en los tres pasos (la cookie se creó en el paso 1), y el archivo de sesión en el servidor quedó así: 

usuario|s:10:"fedebonnet";datos|a:3:{s:8:"apellido";s:6:"Bonnet";s:7:"nombres";s:8:"Federico";s:4:"area";s:16:"Recursos Humanos";}

Se lee así: usuario es un texto (s) de 10 caracteres; datos es un arreglo (a) de 3 elementos, cada uno con su clave y su valor.

Qué muestra el ejemplo
  • El id es el mismo en las dos páginas: es la misma sesión, reconocida por la cookie PHPSESSID.
  • Los datos se guardan en un script y se leen en otro.
  • En la sesión se puede guardar un arreglo entero, no solo textos.
  • Si lo abrís en otro navegador directamente en pagina2.php, otra vez aparece "Aún no se ha creado la sessión.": cada navegador tiene su propia sesión.
Un detalle del HTML

El mensaje del else se imprime dentro de <tbody> pero fuera de un <tr><td>. Un texto suelto dentro de una tabla no es HTML válido, y el navegador lo saca y lo muestra arriba de la tabla. Para que quede adentro: echo '<tr><td colspan="2">Aún no se ha creado la sesión.</td></tr>';

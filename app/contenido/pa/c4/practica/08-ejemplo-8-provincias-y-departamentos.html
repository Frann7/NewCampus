Provincias y departamentos con la API Georef

Un formulario con dos listas desplegables (<select>): la de provincias se llena sola al abrir la página, pidiéndoselas a Georef, la API del gobierno (diapositiva 18). Al elegir una provincia, la otra lista se llena con sus departamentos. Clase IndexClass en js/pgConsultoApi2Class.js.

        this.selecProvincia.addEventListener('change', () => {

Paso 4 — cargoProvincias() 
    cargoProvincias() {
        const url = "https://apis.datos.gob.ar/georef/api/provincias";

        fetch(url)
            .then(response => response.json())
            .then(data => {
                this.selecProvincia.innerHTML = '';

                data.provincias.forEach(prov => {
                    const option = document.createElement('option');
                            option.value = prov.id;
                            option.textContent = prov.nombre;
                    this.selecProvincia.appendChild(option);
                });
            })
            .catch(error => {
                console.error('Error al cargar las provincias:', error);
            });
    }

Paso 5 — cargoDepartamentos(provinciaId) 
    cargoDepartamentos(provinciaId) {
        const url = `https://apis.datos.gob.ar/georef/api/departamentos?provincia=${provinciaId}`;

        fetch(url)
            .then(response => response.json())
            .then(data => {
                this.selecDepartamento.innerHTML = '';
                data.departamentos.forEach(dep => {
                    const option = document.createElement('option');
                    option.value = dep.id;
                    option.textContent = dep.nombre;
                    this.selecDepartamento.appendChild(option);
                });
            })
            .catch(error => {
                console.error('Error al cargar los departamentos:', error);
            });
    }
}

Faltan departamentos: la API manda 10 por defecto

Entre Ríos tiene 17 departamentos, pero la respuesta trae "cantidad":10 y "total":17: Georef devuelve como mucho 10 si no se le pide otra cosa. En la lista no aparecen, por ejemplo, Nogoyá, Tala ni La Paz. Se arregla agregando a la URL el parámetro max: con departamentos?provincia=30&max=100 llegan los 17 (verificado contra la API). Con las provincias no pasa porque la API sí manda las 24.

La primera provincia no carga sus departamentos

Al abrir la página, la lista de provincias muestra la primera, pero la de departamentos está vacía: los departamentos solo se piden en el evento change, y elegir la provincia que ya está elegida no es un cambio. Para ver los de la primera hay que elegir otra y volver.

El botón "Enviar datos" no hace nada

Es type="submit" pero está afuera del <form> y ningún código escucha su clic (teoría, sección 5). Además los dos select no tienen name, así que aunque se enviara, no llegarían a PHP.

Qué se ve en la página

Los cuatro campos y, debajo, la lista de provincias ya cargada (con la primera elegida) y la de departamentos vacía. Al elegir otra provincia, la segunda lista se llena con hasta 10 de sus departamentos. Cada cambio de provincia reemplaza la lista anterior.

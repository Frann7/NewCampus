Introducción

1. Qué es PHP

Para qué sirve

PHP es un lenguaje de programación para hacer páginas web. Lo que lo distingue es dónde corre: no en tu navegador, sino en el servidor (la computadora que tiene guardada la página). El servidor ejecuta el código PHP, arma el HTML resultante y le manda solo ese resultado al navegador.

La definición de la cátedra, desarmada

PHP en una frase

PHP es un lenguaje de programación interpretado que se ejecuta del lado del servidor.

ParteQué significa
InterpretadoEl código se lee y se ejecuta instrucción por instrucción cada vez que se corre, por un programa llamado intérprete. No hay un paso previo de "compilar" que lo convierta en un ejecutable (como un .exe). Escribís el archivo .php y ya se puede ejecutar.
Del lado del servidorLo ejecuta el servidor web antes de responder. El navegador nunca ve el código PHP, solo lo que ese código imprimió.
El nombrePHP: Hypertext Preprocessor ("preprocesador de hipertexto"). Es un acrónimo recursivo: la primera P del nombre es otra vez "PHP". "Preprocesador" porque procesa la página antes de mandarla.
OrigenLo creó Rasmus Lerdorf en 1994.
Se incrusta en HTMLUn mismo archivo puede tener HTML común y, en el medio, pedacitos de PHP (sección 3).
SintaxisDeriva sobre todo de C, con influencia de Perl y, desde que tiene orientación a objetos, de Java.
LicenciaCódigo abierto: licencia PHP v3.01, de tipo BSD (sin el "copyleft" de la GPL). Es software libre según la Free Software Foundation, pero no es compatible con la GPL por la restricción sobre el uso del nombre "PHP".

Lado clienteLado servidor
Quién lo ejecutaEl navegador (Chrome, Firefox...)El servidor web, antes de responder

EjemplosHTML (maquetar y presentar), JavaScript (acciones en el navegador)PHP, ASP, JSP, .net

Ejemplo 1 — Qué le llega al navegador

Enunciado

Un archivo pagina.php tiene HTML y un pedacito de PHP. ¿Qué recibe el navegador cuando lo pide?

<h1>Mi primera página</h1>
<p>Hoy es un buen día.</p>
<?php
echo "<p>Este párrafo lo escribió PHP.</p>";
?>
<p>Fin.</p>

Qué hace cada línea

LíneaQué hace
<h1>...</h1> y <p>...</p>Es HTML común, está fuera de las etiquetas de PHP: el servidor lo manda tal cual.
<?phpDesde acá empieza el código PHP: el servidor lo ejecuta en vez de mandarlo.
echo "...";echo escribe un texto en la respuesta, en ese mismo lugar de la página. Acá escribe un párrafo HTML.
?>Termina el código PHP. Lo que sigue vuelve a ser HTML que se manda tal cual.

Qué recibe el navegador y por qué

<h1>Mi primera página</h1>
<p>Hoy es un buen día.</p>
<p>Este párrafo lo escribió PHP.</p><p>Fin.</p>
  • El bloque <?php ... ?> desapareció: en su lugar quedó lo que imprimió el echo.
  • Si el usuario hace "ver código fuente", ve esto, no el PHP. Eso es "ejecutarse del lado del servidor".
  • El último párrafo quedó pegado al anterior porque PHP se "come" el salto de línea que va justo después de ?>. En la página no se nota: el navegador muestra los dos párrafos uno debajo del otro igual.

Ejemplo 2 — Con formato del Parcial PHP (preg. 15)

Enunciado

Indique la definición más correcta para PHP (PHP HyperText PreProcessor).

a. PHP es un lenguaje de programación compilado que se ejecuta del lado del cliente.
b. PHP es un lenguaje de programación interpretado que se ejecuta del lado del cliente.
c. PHP es un lenguaje de programación interpretado que se ejecuta del lado del servidor.
d. PHP es un lenguaje de programación compilado que se ejecuta del lado del servidor.

Cómo se resuelve

Las cuatro opciones combinan dos preguntas. Se contesta cada una por separado:

PreguntaRespuestaDescarta
¿Compilado o interpretado?Interpretado: el archivo .php se ejecuta tal como está, sin generar un ejecutable antes.a y d
¿Cliente o servidor?Servidor: el navegador recibe solo el resultado (ejemplo 1).a y b
Respuesta

c. PHP es un lenguaje de programación interpretado que se ejecuta del lado del servidor.

Errores y trampas

No confundir con JavaScript

JavaScript también se usa en páginas web, pero corre en el navegador (lado cliente). PHP corre en el servidor. Si una opción dice "PHP ... del lado del cliente", está mal.

Abrir el .php con doble clic no lo ejecuta

Como PHP necesita un servidor que lo interprete, un archivo .php abierto directamente desde la carpeta no corre: hay que pedirlo a un servidor web. Para eso se instala XAMPP (sección 2).

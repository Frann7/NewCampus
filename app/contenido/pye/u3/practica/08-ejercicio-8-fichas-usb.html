Ejercicio 8 · Constante, acumulada y valor exacto

Producción diaria de fichas USB

En una empresa electrónica se conoce que el volumen de producción diario de fichas USB, en miles de unidades, es una variable aleatoria \(X\) con función de densidad de probabilidad: \(f(x) = c\,(6 + 2x)\) siendo \(0 \leq x \leq 1\).

a) Encuentre \(c\) para que \(f\) sea una función de densidad de probabilidad. b) Determine la función de distribución acumulada para \(X\). c) Obtenga \(P(0{,}1 < X < 0{,}5)\). ¿Qué representa esta probabilidad en la situación problemática? d) Obtenga la probabilidad de que en un día se produzcan exactamente 700 fichas USB.

Inciso a — La constante

Fórmula: \(\displaystyle \int_a^b f(x)\,dx = 1\).

Primitiva de \(6 + 2x\): \(\int 6\,dx = 6x\) y \(\int 2x\,dx = 2 \cdot \tfrac{x^2}{2} = x^2\).

\[ c\int_0^1 (6 + 2x)\,dx = c\Big[6x + x^2\Big]_0^1 = c\,(6 + 1) = 7c = 1 \quad\Longrightarrow\quad c = \frac{1}{7} \]

Con \(c = \tfrac{1}{7}\), \(f(x) = \tfrac{6 + 2x}{7}\) es positiva entre 0 y 1 ✔.

La densidad \((6 + 2x)/7\): una recta que sube de 6/7 a 8/7 (vale más de 1 y está bien: es una altura). Pintada, el área del inciso c.

Inciso b — La acumulada

Fórmula: \(\displaystyle F(x) = \int_{a}^{x} f(t)\,dt\) para \(a \leq x < b\); 0 antes y 1 después.

\[ F(x) = \frac{1}{7}\int_0^x (6 + 2t)\,dt = \frac{1}{7}\Big[6t + t^2\Big]_0^x = \frac{1}{7}\left(6x + x^2\right) \]

\[ F(x) = \begin{cases} 0 & \text{si } x < 0 \\ \dfrac{1}{7}\left(6x + x^2\right) & \text{si } 0 \leq x < 1 \\ 1 & \text{si } x \geq 1 \end{cases} \]

Control: \(F(1) = \tfrac{7}{7} = 1\) ✔.

Inciso c — Entre 0,1 y 0,5

Fórmula: \(P(a < X < b) = F(b) - F(a)\).

\[ F(0{,}5) = \frac{6 \cdot 0{,}5 + 0{,}5^2}{7} = \frac{3 + 0{,}25}{7} = \frac{3{,}25}{7} \qquad F(0{,}1) = \frac{0{,}6 + 0{,}01}{7} = \frac{0{,}61}{7} \]

\[ P(0{,}1 < X < 0{,}5) = \frac{3{,}25 - 0{,}61}{7} = \frac{2{,}64}{7} = 0{,}3771 \]

Qué representa: la probabilidad de que en un día se produzcan entre 100 y 500 fichas USB.

Inciso d — Exactamente 700 fichas

700 fichas son \(x = 0{,}7\) (miles). Fórmula: \(P(X = a) = 0\) en una continua.

\[ P(X = 0{,}7) = 0 \]

Porque \(X\) es continua: la probabilidad de un valor puntual es nula.

Respuesta

a) \(c = 1/7\). b) La \(F\) por tramos de arriba. c) 0,3771: probabilidad de producir en un día entre 100 y 500 fichas. d) 0.

Resultados oficiales de la cátedra

a) \(c = 1/7\); b) \(F(x) = \frac{1}{7}(6x + x^2)\) si \(0 \leq x < 1\); c) 0,3771, probabilidad de que se produzcan en un día entre 100 y 500 fichas USB; d) 0 porque \(X\) es continua  ✓

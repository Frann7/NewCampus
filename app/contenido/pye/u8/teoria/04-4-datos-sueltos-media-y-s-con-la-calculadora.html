Cuando dan los datos uno por uno

4. Datos sueltos: media y \(S\) con la calculadora

Cuándo se usa

Cuando el enunciado no da la media ni el desvío, sino la lista de datos: "se tomó una muestra de 15 usuarios: 6.8, 7.3, 7.5…". La profe avisó que puede pasar. Antes de armar el intervalo hay que sacar \(\bar{x}\) y \(S\). Lo demás es igual que en la sección 3.

Fórmulas (la lógica)

Media y desvío de una muestra

\[ \bar{x} = \frac{\sum x_i}{n} \qquad\qquad S = \sqrt{\frac{\sum (x_i - \bar{x})^2}{n - 1}} \]

Qué significa cada letra

SímboloQué es
\(x_i\)cada dato de la lista
\(\sum x_i\)la suma de todos los datos
\(n\)cuántos datos hay (contalos dos veces)
\(x_i - \bar{x}\)cuánto se aleja cada dato de la media
\(n - 1\)se divide por \(n - 1\), no por \(n\): así \(S^2\) es insesgado (sección 1, ejemplo 2)

A mano es largo y es fácil equivocarse. En el parcial se hace con la calculadora; la fórmula sirve para entender qué te da la calculadora y para elegir bien el desvío.

La calculadora (la ejecución)

Casio fx-82MS / fx-95MS (o parecidas): modo SD
  1. MODE → elegir SD (en estas es la opción 2).
  2. Borrar lo que haya guardado: SHIFT + MODE + 1 (Scl) y =. (Si no está ahí, buscá "Scl" con SHIFT.)
  3. Cargar cada dato y apretar M+: por ejemplo 6.8 M+, 7.3 M+, …
  4. SHIFT + 2 (S-VAR) y elegir: \(\bar{x}\) para la media, \(x\sigma_{n-1}\) para el desvío.
Casio fx-82ES PLUS / fx-570 (o parecidas): modo STAT 1-VAR
  1. Una sola vez: SHIFT + MODE (SETUP), flecha abajo, STAT y elegir OFF (sin columna de frecuencias, para datos sueltos).
  2. MODE → STAT → 1-VAR. Aparece una tabla de una columna.
  3. Cargar cada dato seguido de =: 6.8 =, 7.3 =, …
  4. Al terminar, AC.
  5. SHIFT + la tecla que tiene STAT escrito arriba → VAR → elegir \(\bar{x}\) para la media, o \(sx\) (en algunas aparece \(x\sigma_{n-1}\)) para el desvío. Cada uno seguido de =.
El desvío que se usa: \(sx = x\sigma_{n-1}\)

La calculadora muestra dos desvíos: \(x\sigma_{n-1}\) (o \(sx\)) divide por \(n - 1\), y \(x\sigma_n\) (o \(\sigma x\)) divide por \(n\). Para estimar se usa siempre \(sx = x\sigma_{n-1}\), el \(S\) de la fórmula. Una forma de chequear: \(x\sigma_{n-1}\) siempre da un poco más que \(x\sigma_n\). También fijate que \(n\) (en el menú, la opción \(n\)) dé la cantidad de datos que cargaste.

Ejemplo 1 — Pocos datos: verificar la calculadora a mano

Enunciado

Se midió el tiempo de compilación (en minutos) de 5 builds de un proyecto: 12, 15, 11, 14, 13. Suponiendo que el tiempo de compilación es normal, construya un intervalo de confianza del 95 % para el tiempo medio de compilación.

Por qué este modelo

  • Piden un intervalo para una media.
  • No dan \(\sigma\): el desvío sale de los datos (\(S\)), y \(n = 5 < 30\).
  • La variable es normal: \(t\) con \(\nu = 5 - 1 = 4\).

\[ \bar{x} = \frac{65}{5} = 13 \qquad\qquad S = \sqrt{\frac{10}{5 - 1}} = \sqrt{2{,}5} = 1{,}5811 \]

Paso 3 — Fórmula del intervalo (con \(t\)):

\(IC_{95\%}(\mu) = (11{,}04\ ;\ 14{,}96)\) minutos. Se tiene un 95 % de confianza de que el tiempo medio de compilación del proyecto está entre 11,04 y 14,96 minutos.

Ejemplo 2 — Los 15 datos del Tercer Parcial 2025

Enunciado (adaptado a lo que entra este año)

Una empresa de desarrollo de software desea evaluar si una nueva interfaz del sistema mejora la satisfacción de los usuarios. Para ello toma una muestra aleatoria de 15 usuarios: 6.8, 7.3, 7.5, 7.9, 8.0, 8.1, 8.2, 8.3, 8.4, 8.6, 8.7, 8.9, 9.0, 9.1, 9.2. En la versión anterior, el puntaje promedio de satisfacción (escala de 1 a 10) fue de 7,5. Suponiendo que el puntaje es normal: a) construya un intervalo de confianza del 95 % para la satisfacción media con la nueva interfaz. b) Con ese intervalo, ¿puede decirse que la satisfacción media es mayor que 7,5?

Por qué este modelo

  • Piden un intervalo para una media (la satisfacción media).
  • Los datos vienen sueltos: \(\bar{x}\) y \(S\) se sacan con la calculadora. No hay \(\sigma\).
  • \(n = 15 < 30\), \(\sigma\) desconocida y variable normal: \(t\) con \(\nu = 14\).
  • El 7,5 no entra en la cuenta: es el valor viejo, con el que se compara en el b).

Desarme del enunciado

FraseQué significaLa cuentaA dónde va
"6.8, 7.3, …, 9.2"los datos sueltoscalculadora\(\bar{x}\), \(S\)
"15 usuarios"tamaño de muestra, \(< 30\)\(\nu = 15 - 1\); \(\sqrt{15} = 3{,}873\)\(n = 15\), \(\nu = 14\)
"el puntaje promedio fue de 7,5" (versión anterior)el valor de referencia—para el b)
"95 %"confianza\(\alpha/2 = 0{,}025\)tabla \(t\): fila 14, columna 0,025 → 2,145

Paso 1 — Media y \(S\) con la calculadora. Se cargan los 15 datos (fijate que \(n\) dé 15) y se lee:

Lo que tiene que dar

\(n = 15\)  ·  \(\sum x = 124\)  ·  \(\bar{x} = 8{,}2667\)  ·  \(x\sigma_{n-1} = 0{,}6935\)  (el que se usa)  ·  \(x\sigma_n = 0{,}6700\)  (no)

Con la fórmula: \(\bar{x} = \dfrac{124}{15} = 8{,}2667\), y \(S = 0{,}6935\).

a) El intervalo

Paso 2 — Fórmula (con \(t\)):

\[ \bar{x} - t_{(\alpha/2;\ \nu)}\,\frac{S}{\sqrt{n}} < \mu < \bar{x} + t_{(\alpha/2;\ \nu)}\,\frac{S}{\sqrt{n}} \]

Paso 3 — El error:

\[ E = 2{,}145 \cdot \frac{0{,}6935}{\sqrt{15}} = 2{,}145 \cdot \frac{0{,}6935}{3{,}873} = 2{,}145 \cdot 0{,}1791 = 0{,}3841 \]

Paso 4 — Reemplazar:

\[ 8{,}2667 - 0{,}3841 < \mu < 8{,}2667 + 0{,}3841 \quad\Longrightarrow\quad 7{,}883 < \mu < 8{,}651 \]

Respuesta a)

\(IC_{95\%}(\mu) = (7{,}883\ ;\ 8{,}651)\) puntos. Se tiene un 95 % de confianza de que la satisfacción media de los usuarios con la nueva interfaz está entre 7,883 y 8,651 puntos.

b) ¿Es mayor que 7,5?

Se mira dónde queda 7,5 respecto del intervalo (sección 3, "usar el intervalo para decidir"):

\[ 7{,}5 < 7{,}883 = LI \]

Respuesta b)

El 7,5 queda afuera, por debajo del intervalo: todo el intervalo está por encima de 7,5. Con un 95 % de confianza, la satisfacción media con la nueva interfaz es mayor que la de la versión anterior.

Errores típicos con datos sueltos
  • Usar \(x\sigma_n\) (0,6700) en vez de \(x\sigma_{n-1}\) (0,6935).
  • No borrar la memoria antes de cargar: se suman datos de un ejercicio anterior. Mirá siempre que \(n\) sea el correcto.
  • Escribir \(\nu = 15\): los grados de libertad son \(n - 1 = 14\).

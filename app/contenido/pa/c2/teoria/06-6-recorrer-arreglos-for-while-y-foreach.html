Arreglos

6. Recorrer arreglos: for, while y foreach

Para qué sirve

Recorrer un arreglo es pasar por cada uno de sus elementos, de a uno, para hacer algo con él (mostrarlo, sumarlo, compararlo). Es, según la cátedra, una de las operaciones que más se hacen con arreglos. Hay dos caminos:

  • for o while (los bucles de la Clase 1) con un contador que va 0, 1, 2… y se usa como clave. Sirve solo si las claves son números seguidos desde 0.
  • foreach ("para cada"): una estructura hecha para arreglos. Pasa por todos los elementos, en orden, sean cuales sean sus claves. Ejecuta el bloque una vez por cada clave que tenga el arreglo.

Sintaxis

Con for (claves 0, 1, 2…) 
for ($i = 0; $i < count($arreglo); $i++) {
    // usar $arreglo[$i]
}
Con foreach (cualquier clave) 
foreach ($arreglo as $valor) {
    // usar $valor
}

foreach ($arreglo as $clave => $valor) {
    // usar $clave y $valor
}

Qué es cada parte

ParteQué es
$i = 0(for) El contador arranca en 0, que es la primera clave automática
$i < count($arreglo)(for) Sigue mientras el contador sea menor que la cantidad de elementos: con 3 elementos, $i toma 0, 1 y 2
$i++(for) Al terminar cada vuelta, suma 1 al contador
foreach ($arreglo as ...)Recorre $arreglo desde el primer elemento hasta el último
$valorVariable que elegís vos. En cada vuelta, PHP le copia el valor del elemento que toca
$clave => $valorForma con dos variables: en cada vuelta, $clave recibe la clave y $valor el valor

Ejemplo 3 — foreach con claves mezcladas (teoría de la cátedra)

Con array('a' => 10, 10 => 20, 'c' => 30) un for de 0 a 2 no sirve: las claves son 'a', 10 y 'c', y ninguna es 0, 1 ni 2. Para eso está foreach. 

<?php
$arreglo = array('a' => 10, 10 => 20, 'c' => 30);
foreach ($arreglo as $elemento) {
    echo $elemento . '-';
}
?>
VueltaQué haceCómo quedan las variables
1Toma el primer elemento (clave 'a')$elemento = 10 → sale 10-
2El segundo (clave 10)$elemento = 20 → sale 20-
3El tercero (clave 'c')$elemento = 30 → sale 30-
FinNo quedan elementos—
10-20-30-

Por qué así: todo sale pegado porque no hay ningún salto de línea, y al final queda un guion de más porque se imprime después de cada valor, también del último. (La cátedra lo anota como 10 – 20 - 30, con espacios: la salida real no los tiene.)

Diferencias con la diapositiva

La presentación escribe la clave 'marcar' (con r) y hace echo $clave.'=>'; echo $valor;, sin ningún salto de línea. Así, todo sale pegado en una línea: color=>rojomarcar=>Chevroletaño=>1969. La salida que dibuja la diapositiva (una línea por dato, con mayúsculas) no es la que da ese código.

Errores y trampas

El for de la presentación tiene las partes cambiadas

La diapositiva escribe for ($i=0; $i++; $i< count($colores)) y echo $colores[i];. En el lugar de la condición quedó $i++: en la primera vuelta vale 0 (el ++ suma después de usar el valor), y 0 es falso, así que el for no entra nunca y no imprime nada. Además, [i] sin $ no es la variable. Lo correcto es el ejemplo 1.

El while de la teoría no inicializa el contador

El apunte hace while ($i<=count($a)) sin poner antes $i = 0;, y con <=. PHP avisa Undefined variable $i en la primera vuelta, y con <= da una vuelta de más: pide la clave 7 de un arreglo de 7 elementos (claves 0 a 6) y avisa Undefined array key 7. Hay que inicializar en 0 y usar <. (Ese arreglo, además, repite 'Domingo' y no tiene 'Viernes'.)

echo dentro de otro echo

El apunte escribe echo $key.'-->'.echo $valor;. Eso es un error de sintaxis (Parse error): echo no se puede usar en medio de una expresión. Se escribe echo $key . '-->' . $valor;, que muestra a-->10, 10-->20, c-->30.

Cambiar $valor no cambia el arreglo

En foreach ($num as $n) { $n = $n * 2; }, $n es una copia de cada valor: al terminar, $num sigue igual. Para modificar el arreglo hay que escribir en $num[$clave].

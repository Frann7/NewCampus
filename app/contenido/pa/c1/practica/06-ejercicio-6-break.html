Ejercicio 6 · break

Del 1 al 10, cortando cuando pasa de 4

Realizar un script que muestra los números del 1 al 10 utilizando un ciclo for() pero si el numero es mayor a 4 se termine el ciclo, utilizando la sentencia break.

Paso 1 — Qué pide
  • Un for de 1 a 10.
  • Cuando el número sea mayor a 4 ($i > 4), break: terminar el for entero, no solo esa vuelta.
  • El if con el break va antes del echo: así el 5, que es el que dispara el corte, no llega a mostrarse.
Paso 2 — El código 
<?php
// Recorremos del 1 al 10
for ($i = 1; $i <= 10; $i++) {
    // Si el número es mayor a 4, cortamos el for entero
    if ($i > 4) {
        break;
    }
    // Esto solo se ejecuta mientras no se haya cortado
    echo $i . " ";
}
?>

Paso 4 — Qué imprime y por qué 
1 2 3 4

A diferencia del continue del ejercicio 5, el break no saltea una vuelta: termina el bucle. Aunque la condición del for ($i <= 10) seguía siendo verdadera, no hay más vueltas.

La resolución de la cátedra arranca en 0 
<?php
for ($i = 0; $i < 10; $i++) {
if ($i > 4 ) {
break;
}
echo "Numero: ".$i;
}
?>

  • Empieza en 0, así que muestra también el 0; el enunciado pide del 1 al 10.
  • Su condición es $i < 10, que llegaría solo hasta el 9. En este ejercicio no cambia nada, porque el break corta en el 5 mucho antes, pero para recorrer "del 1 al 10" la condición es $i <= 10.
  • Igual que en el ejercicio 5, sin separador todo sale pegado.

Qué evalúa

Las tres funciones básicas de mysqli para trabajar con una base de datos MySQL desde PHP. Es de la Clase 6.

El concepto, desde cero

Leer datos de una base siempre lleva los mismos tres pasos, y cada uno tiene su función:

PasoFunciónQué hace
1. Conectarsemysqli_connect(servidor, usuario, clave, base)Abre la conexión con el servidor de base de datos y devuelve el identificador de conexión, que se usa en todo lo demás.
2. Consultarmysqli_query(conexion, sql)Manda una consulta SQL por esa conexión y devuelve el resultado (todas las filas que salieron).
3. Leer las filasmysqli_fetch_array(resultado)Devuelve una fila del resultado como array (se puede leer por nombre de columna o por número) y avanza el puntero a la siguiente. Cuando no quedan filas devuelve null, que el while toma como falso.

Juntas se ven así (un ejemplo típico, con una base campus y una tabla alumnos inventadas):

<?php
$conexion = mysqli_connect("localhost", "root", "", "campus");
$resultado = mysqli_query($conexion, "SELECT nombre FROM alumnos");
while ($fila = mysqli_fetch_array($resultado)) {
    echo $fila['nombre'] . "<br>";
}
?>
LíneaQué haceCómo quedan las variables
$conexion = mysqli_connect(...);Se conecta al MySQL del XAMPP con el usuario root sin clave y elige la base campus.$conexion = el identificador de conexión
$resultado = mysqli_query($conexion, "SELECT ...");Ejecuta la consulta por esa conexión.$resultado = todas las filas encontradas
while ($fila = mysqli_fetch_array($resultado))Cada vuelta saca la fila siguiente y mueve el puntero. Sin filas, devuelve null y el ciclo termina.$fila = la fila de esta vuelta
echo $fila['nombre'] . "<br>";Muestra la columna nombre de esa fila.—

La salida depende de lo que haya en la tabla: un nombre por renglón.

Cómo se responde

  • “Crea una conexión” → mysqli_connect().
  • “Enviar una consulta… asociada al identificador de conexión” → mysqli_query().
  • “Devuelve una matriz que corresponde a la fila… mueve el puntero” → mysqli_fetch_array() (fetch = traer).
La trampa

mysqli_query() y mysqli_fetch_array() parecen hacer lo mismo, pero query ejecuta la consulta y trae el resultado entero, mientras que fetch_array saca de ese resultado una fila por vez. La pista en el enunciado es “fila” y “puntero”.

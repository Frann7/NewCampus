9. La clase Page: armar la página con un objeto

Para qué sirve

El ejemplo objeto de la cátedra resuelve lo mismo que la sección 8 (encabezado, menú y pie escritos una sola vez) de otra forma: con una clase. Para leerlo hacen falta cinco ideas nuevas, que se explican acá desde cero.

  • Una clase es un molde: describe qué datos guarda una cosa y qué sabe hacer. No hace nada por sí sola.
  • Un objeto es una cosa hecha con ese molde. Con un mismo molde se pueden hacer muchos objetos, cada uno con sus propios datos. Se crea con new.
  • Las propiedades son las variables que tiene adentro cada objeto.
  • Los métodos son las funciones que tiene adentro la clase: lo que el objeto sabe hacer.
  • private y public dicen quién puede usar cada propiedad o método: private, solo el código de adentro de la clase; public, cualquiera.

Sintaxis

Definir una clase y usarla 
class Nombre
{
    private $propiedad;                  // una variable del objeto

    public function __construct($dato)   // corre sola al hacer new
    {
        $this->propiedad = $dato;
    }

    public function metodo()             // algo que el objeto sabe hacer
    {
        return $this->propiedad;
    }
}

$objeto = new Nombre('valor');           // crea un objeto con el molde
echo $objeto->metodo();                  // le pide que haga algo

Qué es cada parte

ParteQué es
class Nombre { ... }Define el molde. Por costumbre el nombre arranca con mayúscula (Page).
private $propiedad;Declara una propiedad. Cada objeto tiene la suya. Por ser private, desde afuera no se puede leer ni cambiar.
public function metodo()Un método: una función que pertenece a la clase.
__constructEl constructor: un método con ese nombre exacto (dos guiones bajos) que PHP ejecuta solo en el momento del new. Sirve para dejar el objeto listo.
$thisAdentro de la clase, "este objeto", el que está ejecutando el método.
->Entra a una propiedad o a un método de un objeto: $this->propiedad, $objeto->metodo(). La propiedad se escribe sin $ después de la flecha.
new Nombre('valor')Crea un objeto y le pasa 'valor' al constructor.
returnLo que devuelve el método a quien lo llamó.

Ejemplo 1 — Una clase mínima

Enunciado

¿Cuál es la salida del siguiente script PHP?

<?php
class Saludo
{
    private $nombre;

    public function __construct($nombre)
    {
        $this->nombre = $nombre;
    }

    public function getTexto()
    {
        return 'Hola, ' . $this->nombre;
    }
}

$s = new Saludo('Fran');
$t = new Saludo('Ana');
echo $t->getTexto() . ' / ' . $s->getTexto();
?>

Qué hace cada línea

LíneaQué haceCómo quedan los objetos
class Saludo { ... }Solo define el molde; todavía no corre nada.no hay objetos
$s = new Saludo('Fran');Crea un objeto y corre el constructor con $nombre = 'Fran'; el constructor lo guarda en la propiedad del objeto.$s: nombre = 'Fran'
$t = new Saludo('Ana');Otro objeto, con su propia propiedad.$s: 'Fran' · $t: 'Ana'
$t->getTexto()Corre getTexto con $this = $t: devuelve 'Hola, Ana'.sin cambios
$s->getTexto()Ahora $this = $s: devuelve 'Hola, Fran'.sin cambios
echo ... . ' / ' . ...;Pega los dos textos con una barra en el medio.—

Qué imprime y por qué

Hola, Ana / Hola, Fran

El mismo método da resultados distintos porque cada objeto tiene su propio nombre, y $this apunta al objeto que se usó delante de la flecha.

Ejemplo 2 — Una Page en chiquito (formato del parcial)

Esta clase hace lo mismo que la Page de la cátedra, con menos HTML: guarda las partes por separado, setPagina() las une y getHtmlPage() devuelve el resultado.

Enunciado

¿Cuál es la salida del siguiente script PHP?

<?php
class Pagina
{
    private $header;
    private $body;
    private $pagina;

    public function __construct($body)
    {
        $this->header = '<h1>Mi sitio</h1>';
        $this->body = $body;
    }

    public function setPagina()
    {
        $this->pagina = $this->header;
        $this->pagina .= $this->body;
    }

    public function getHtmlPage()
    {
        return $this->pagina;
    }
}

$p = new Pagina('<p>Inicio</p>');
echo '[' . $p->getHtmlPage() . ']';
$p->setPagina();
echo '[' . $p->getHtmlPage() . ']';
?>

Qué hace cada línea

LíneaQué haceCómo quedan las propiedades de $p
$p = new Pagina('<p>Inicio</p>');Corre el constructor: carga el encabezado fijo y el cuerpo recibido. pagina no se toca.header = <h1>Mi sitio</h1> · body = <p>Inicio</p> · pagina = null (sin valor)
echo '[' . $p->getHtmlPage() . ']';Devuelve pagina, que todavía es null; pegado a un texto, null no agrega nada.imprime []
$p->setPagina();Primero =: pagina pasa a ser el header. Después .=: le pega el body al final.pagina = <h1>Mi sitio</h1><p>Inicio</p>
echo '[' . $p->getHtmlPage() . ']';Ahora sí hay página armada.imprime [<h1>Mi sitio</h1><p>Inicio</p>]

Qué imprime y por qué

[][<h1>Mi sitio</h1><p>Inicio</p>]

Es el texto que recibe el navegador (en pantalla se vería [], el título grande y el párrafo). Los primeros corchetes salen vacíos porque getHtmlPage() se llamó antes de setPagina(). Por eso, en el indice.php de la cátedra, el orden es: new Page($body), setPagina() y recién ahí echo $pagina->getHtmlPage().

Cómo es la Page de la cátedra

Igual que la del ejemplo 2, con más partes: las propiedades privadas $header, $menu, $body, $footer y $Pagina; un constructor que llama a cuatro métodos privados (setHeader, setMenu, setBody, setFooter), cada uno cargando un pedazo de HTML; y los dos públicos setPagina() y getHtmlPage(). Está explicada línea por línea en la pestaña Práctica.

Errores y trampas

Lo que más se confunde
  • Lo private no se toca desde afuera. Se probó: echo $p->body; da Fatal error: Uncaught Error: Cannot access private property Pagina::$body, y llamar desde afuera a un método privado de la Page de la cátedra (setHeader()) da Call to private method Page::setHeader() from global scope.
  • Sin $ después de la flecha: $this->body, no $this->$body (esto último significa otra cosa).
  • Llamar dos veces a setPagina() no duplica la página, porque la primera línea usa = y vuelve a empezar; se probó y queda igual. Si las dos fueran .=, sí se duplicaría.
  • Definir la clase no imprime nada. Todo empieza con el new.

Qué es un proceso

Un proceso es la forma en que una organización hace algo: los pasos, quién hace cada uno y con qué. En una empresa de software, el proceso es cómo se planifica un proyecto, cómo se programa, cómo se prueba y cómo se entrega.

Qué es CMMI

CMMI (Capability Maturity Model Integration) es un modelo de madurez: sirve para decir qué tan ordenada (madura) es la forma de trabajar de una empresa, y qué le falta para trabajar mejor. Es una escalera de cinco niveles: cada nivel se apoya en el anterior y no se saltea ninguno.

Los cinco niveles, con una pizzería

Una pizzería que tiene varios locales. El nombre de cada nivel es el que hay que escribir:

NivelQué significaEn la pizzería
Nivel 1 InicialNo hay proceso: todo depende de las personasCada pizzero la hace como le sale; a veces sale bien y a veces no
Nivel 2 GestionadoCada proyecto se planifica y se controla, pero cada uno a su maneraCada local anota los pedidos, con un responsable y una hora de entrega; pero cada local se organiza distinto
Nivel 3 DefinidoHay un proceso escrito, el mismo para toda la organización, y todos lo aplicanUna receta y un procedimiento escritos, iguales en todos los locales, que se le enseñan al empleado nuevo
Nivel 4 Cuantitativamente gestionadoEl proceso se mide con números, que se usan para controlar y predecirSe cronometra cada pedido: lo normal son 20 a 25 minutos, y si un local se pasa, salta el aviso
Nivel 5 En optimización continuaLos números se usan para mejorar el proceso, siempreCon esos números se busca por qué se atrasan los viernes, se cambia el procedimiento, se mide si mejoró y se aplica en todos los locales

Cómo acordarse de los nombres

Cada nombre dice lo que ese nivel tiene de nuevo:

  • Inicial: recién se empieza; todavía no hay nada armado.
  • Gestionado: cada proyecto se gestiona (tiene plan, responsable y seguimiento).
  • Definido: el proceso está definido por escrito, y es uno solo para todos. A esto se le dice también que el proceso está estandarizado: todos lo hacen igual, esté quien esté.
  • Cuantitativamente gestionado: "cuantitativo" quiere decir con cantidades, con números. Se mide.
  • En optimización continua: optimizar es mejorar, y continua es siempre.

El orden no puede ser otro: no se puede tener un proceso igual para todos (3) si cada proyecto es un desorden (falta el 2); no se puede medir "el proceso" (4) si cada equipo tiene el suyo (falta el 3); y no se puede mejorar con datos (5) si no hay datos (falta el 4).

Cómo se ve cada nivel en una empresa

Lo que se dice de la empresaNivel
"Los nuevos empleados aprenden preguntando a los compañeros."Nivel 1
"Los proyectos tienen planificación y responsables."Nivel 2
"Existe una metodología organizacional y se capacita a los integrantes en ella."Nivel 3
"Se establecieron rangos de comportamiento esperados a partir de datos históricos."Nivel 4
"Un grupo analiza las causas de los problemas recurrentes y propone cambios a los procedimientos."Nivel 5

El 2 y el 3, que son los que más se confunden

En los dos hay orden. La pregunta que los separa es: ¿todos los equipos trabajan de la misma manera? Si cada equipo usa sus propios procedimientos, es Nivel 2, por más ordenado que esté cada proyecto. Si hay una forma de trabajar documentada para toda la empresa, y se capacita a la gente en ella, es Nivel 3.

Trampas

  • Tener datos no es estar en el Nivel 4: juntar indicadores en un informe no alcanza; es Nivel 4 cuando los números se usan para controlar y predecir (rangos esperados, alertas).
  • El 4 no es el 5: en el 4 los datos sirven para volver a lo esperado; en el 5, para cambiar el proceso y mejorarlo.
  • Usar Git y Jira no es un nivel: las herramientas ya aparecen en el 2; el nivel lo define cómo se trabaja.

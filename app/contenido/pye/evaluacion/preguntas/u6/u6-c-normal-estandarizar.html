El tiempo de respuesta \(X\) de un servicio web tiene distribución normal con media \(\mu = 120\) ms y desviación estándar \(\sigma = 15\) ms.

Ingrese el resultado utilizando coma como separador decimal y 2 cifras decimales. Ejemplo: 0,10

\(P(X > 135)\) se calcula como Φ(1,00)1 − Φ(1,00)Φ(1,00) − Φ(−1,00)1 − Φ(135)

Tema del Segundo Parcial 2025, Ejercicio 2 (a, b) y Segundo Parcial 2023, Ejercicio 3 b · formato 1ra etapa

Estandarizar es pasar de \(X\) a \(Z = \frac{X - \mu}{\sigma}\), que es normal con media 0 y desvío 1: la única que está en la tabla. La tabla da \(\Phi(z) = P(Z \leq z)\), el área a la izquierda.

\[ z = \frac{135 - 120}{15} = \mathbf{1{,}00} \qquad P(X < 135) = \Phi(1{,}00) = 0{,}8413 \approx \mathbf{0{,}84} \]

Para 105, \(z = -1{,}00\). Un intervalo es el área hasta el techo menos el área hasta el piso:

\[ P(105 < X < 135) = \Phi(1{,}00) - \Phi(-1{,}00) = 0{,}8413 - 0{,}1587 = 0{,}6826 \approx \mathbf{0{,}68} \]

“Mayor que” es el área de la derecha, y como la tabla da la de la izquierda se usa el complemento: \(1 - \Phi(1{,}00) = 0{,}1587\). \(\Phi(1{,}00)\) solo es la parte de abajo, y \(\Phi(135)\) entra a la tabla sin estandarizar.

Ejercicio 4 · Composite

Reconocer el patrón en un código en otro lenguaje

Guía N°2, ejercicio 2. Dado el siguiente código identifique el lenguaje de programación en que se está implementado, qué tipo de patrón se implementa y realice el diagrama correspondiente. 

<?php
namespace Git\ZZZZ\Conceptual;
abstract class Component
{
    protected $parent;
    public function setParent(?Component $parent)
    {
        $this->parent = $parent;
    }
    public function getParent(): Component
    {
        return $this->parent;
    }

    public function add(Component $component): void { }
    public function remove(Component $component): void { }
    public function ismolecula(): bool
    {
        return false;
    }

    abstract public function operation(): string;
}

class atomo extends Component
{
    public function operation(): string
    {
        return "atomo";
    }
}

class molecula extends Component
{
    protected $children;
    public function __construct()
    {
        $this->children = new \SplObjectStorage();
    }

    public function add(Component $component): void
    {
        $this->children->attach($component);
        $component->setParent($this);
    }
    public function remove(Component $component): void
    {
        $this->children->detach($component);
        $component->setParent(null);
    }

    public function ismolecula(): bool
    {
        return true;
    }

    public function operation(): string
    {
        $results = [];
        foreach ($this->children as $child) {
            $results[] = $child->operation();
        }
        return "Branch(" . implode("+", $results) . ")";
    }
}

function clientCode(Component $component)
{
    echo "RESULT: " . $component->operation();
}

$simple = new atomo();
clientCode($simple);

$tree = new molecula();
$branch1 = new molecula();
$branch1->add(new atomo());
$branch1->add(new atomo());
$branch2 = new molecula();
$branch2->add(new atomo());
$tree->add($branch1);
$tree->add($branch2);
clientCode($tree);

(Se dejó lo esencial del código de prueba; en la guía siguen unos echo y una segunda función cliente que no cambian la respuesta.)

Paso 1 — El lenguaje

Es PHP: empieza con <?php, las variables llevan $, se usa $this->, echo y function, y las cadenas se pegan con un punto.

Paso 2 — Listar las clases y quién hereda de quién
Clase¿Hereda?Qué tiene
ComponentNo. Es abstractadd y remove vacíos, y la operación abstracta operation()
atomoextends ComponentSolo operation(), que devuelve un texto fijo. No guarda a nadie
moleculaextends ComponentUn atributo $children (hijos), add y remove con código, y un operation() con un foreach
Paso 3 — Las dos preguntas sobre la clase que guarda a otras
  • ¿De quién hereda molecula? De Component.
  • ¿Qué guarda? Una colección ($children) a la que se le agregan objetos Component: del mismo tipo del que ella hereda.

Hereda de una clase base y guarda una lista de esa misma clase base: es Composite. Lo confirman:

  • el operation() de molecula es un bucle que llama a operation() de cada hijo y junta los resultados;
  • el código de prueba arma un árbol: una molecula ($tree) a la que se le agregan otras dos moléculas ($branch1, $branch2, "ramas"), que tienen átomos;
  • clientCode recibe un Component y lo usa igual sea un átomo o un árbol entero.
Paso 4 — Qué clase es cada parte
Parte del patrónEn el código
ComponenteComponent
Hojaatomo
Compuestomolecula
ClienteclientCode

Los nombres ayudan: un átomo no se divide (hoja) y una molécula está hecha de átomos y de otras moléculas (compuesto).

Paso 5 — El diagrama

En esta versión add y remove están declarados también en Component (vacíos), para que el cliente pueda llamarlos sin preguntar qué clase es. En la estructura del apunte están solo en el Compuesto; las dos formas son Composite.

Respuesta

Lenguaje: PHP. Patrón: Composite (estructural). Component es el componente, atomo la hoja y molecula el compuesto: guarda una colección de Component en $children, tiene add y remove, y su operation() recorre los hijos llamando a la misma operación. El cliente trabaja con Component y trata igual a un átomo que a un árbol de moléculas.

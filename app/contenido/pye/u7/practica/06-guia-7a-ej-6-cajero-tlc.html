Tiempo de atencion en la ventanilla del banco

La cantidad de tiempo que le toma al cajero de un banco atender a un cliente es una variable aleatoria con una media \(\mu = 3{,}2\) minutos y una desviacion estandar \(\sigma = 1{,}6\) minutos. Si se observa una muestra aleatoria de 64 clientes, calcule la probabilidad de que el tiempo medio que el cliente pasa en la ventanilla del cajero sea a) a lo sumo 2,7 minutos; b) mas de 3,5 minutos; c) al menos 3,2 minutos pero menos de 3,4 minutos.

Que metodo y por que
  • Se pregunta por el tiempo medio de 64 clientes: la variable es \(\bar{X}\).
  • No se dice que los tiempos sean normales (de hecho, los tiempos de atencion suelen ser asimetricos: muchos cortos y algunos muy largos). Pero \(n = 64 \geq 30\), asi que por el Teorema del Limite Central la media \(\bar{X}\) es aproximadamente normal, con media \(\mu\) y error estandar \(\sigma/\sqrt{n}\).
Formulas

\[ \sigma_{\bar{X}} = \frac{\sigma}{\sqrt{n}} \qquad z = \frac{\bar{x} - \mu}{\sigma/\sqrt{n}} \]

Desarme del enunciado
FraseTraduccionCuentaA donde va
"\(\mu = 3{,}2\) minutos"centro de la poblacion—\(\mu = 3{,}2\)
"\(\sigma = 1{,}6\) minutos"desvio de un cliente—\(\sigma = 1{,}6\)
"muestra aleatoria de 64 clientes"\(n \geq 30\): TLC\(\sigma_{\bar{X}} = \dfrac{1{,}6}{\sqrt{64}} = \dfrac{1{,}6}{8} = 0{,}2\)\(n = 64\)
"a lo sumo 2,7"2,7 o menos: area a la izquierda—inciso a
"mas de 3,5"area a la derecha—inciso b
"al menos 3,2 pero menos de 3,4"entre 3,2 y 3,4—inciso c

En una variable continua da igual \(<\) que \(\leq\): la probabilidad de un punto exacto es 0. Por eso "a lo sumo" y "menos de" se calculan igual.

Inciso a — A lo sumo 2,7 minutos

Formula:

\[ P(\bar{X} \leq \bar{x}) = F(z) \qquad z = \frac{\bar{x} - \mu}{\sigma/\sqrt{n}} \]

\[ z = \frac{2{,}7 - 3{,}2}{0{,}2} = \frac{-0{,}5}{0{,}2} = -2{,}50 \]

\(F(-2{,}50)\): fila \(-2{,}5\), columna 0,00 → 0,0062.

\[ P(\bar{X} \leq 2{,}7) = \mathbf{0{,}0062} \]

Respuesta a

0,0062: es muy raro (0,62 %) que el promedio de 64 clientes sea de 2,7 minutos o menos; 2,7 esta 2,5 errores estandar por debajo del centro.

Inciso b — Mas de 3,5 minutos

Formula:

\[ P(\bar{X} > \bar{x}) = 1 - F(z) \qquad z = \frac{\bar{x} - \mu}{\sigma/\sqrt{n}} \]

\[ z = \frac{3{,}5 - 3{,}2}{0{,}2} = \frac{0{,}3}{0{,}2} = 1{,}50 \]

\(F(1{,}50)\): fila 1,5, columna 0,00 → 0,9332.

\[ P(\bar{X} > 3{,}5) = 1 - 0{,}9332 = \mathbf{0{,}0668} \]

Respuesta b

0,0668 (6,68 %).

Inciso c — Al menos 3,2 pero menos de 3,4

Formula:

\[ P(\bar{x}_1 \leq \bar{X} < \bar{x}_2) = F(z_2) - F(z_1) \]

\[ z_1 = \frac{3{,}2 - 3{,}2}{0{,}2} = \frac{0}{0{,}2} = 0 \qquad z_2 = \frac{3{,}4 - 3{,}2}{0{,}2} = \frac{0{,}2}{0{,}2} = 1{,}00 \]

  • \(F(1{,}00)\): fila 1,0, columna 0,00 → 0,8413.
  • \(F(0)\): fila 0,0, columna 0,00 → 0,5000 (la media parte la campana al medio).

\[ P(3{,}2 \leq \bar{X} < 3{,}4) = 0{,}8413 - 0{,}5000 = \mathbf{0{,}3413} \]

Respuesta c

0,3413: un 34,13 % de las muestras de 64 clientes tendria un promedio entre 3,2 y 3,4 minutos (entre la media y un error estandar por encima).

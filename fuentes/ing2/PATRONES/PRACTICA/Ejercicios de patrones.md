Ingeniería 2 13/09/2023
Ejercicios patrones de diseño.
Ejercicio 1:
Supongamos que estás desarrollando un videojuego y tienes diferentes tipos de enemigos, como
orcos, trolls y goblins. Cada tipo de enemigo tiene sus propias características y habilidades. Debes
implementar un sistema para crear instancias de estos enemigos de manera dinámica. Cada enemigo
tiene los siguientes atributos:
• Nombre: El nombre del enemigo.
• Puntos de vida: La cantidad de puntos de vida del enemigo.
• Daño: El daño que el enemigo puede infligir en un ataque.
• Velocidad: La velocidad de movimiento del enemigo.
Ejercicio 2:
Estás construyendo una aplicación de dibujo que puede trabajar tanto en un entorno de escritorio
como en un entorno web. Quieres que tu aplicación sea capaz de crear diferentes tipos de elementos
de interfaz de usuario, como botones y cuadros de texto, de manera que se ajusten a la plataforma
específica (escritorio o web). Cada elemento de interfaz de usuario tiene los siguientes atributos:
• Ancho: El ancho del elemento.
• Alto: La altura del elemento.
• Texto: El texto que se muestra en el elemento.
• Color de fondo: El color de fondo del elemento.
Ejercicio 3:
Estás desarrollando una aplicación que necesita conectarse a diferentes bases de datos, como
MySQL, PostgreSQL y MongoDB. Cada base de datos tiene sus propias características y
configuraciones. Necesitas implementar un sistema que permita crear objetos de conexión a la base
de datos de manera que la aplicación pueda trabajar con diferentes bases de datos de manera
transparente. Cada objeto de conexión tiene los siguientes atributos:
• Nombre de la base de datos: El nombre de la base de datos a la que se conecta.
• Host: La dirección del host donde se encuentra la base de datos.
• Puerto: El puerto de conexión a la base de datos.
• Usuario: El nombre de usuario para la autenticación.
• Contraseña: La contraseña para la autenticación.
En cada uno de estos ejercicios, los atributos de las clases son esenciales para la comprensión de
cómo se deben diseñar las clases y cómo se relacionan entre sí. Los patrones de diseño pueden ser
aplicados para manejar la creación y configuración de estas clases de manera eficiente y flexible.

Grimaldi 10.2 · Ej. 11 · Plantear: palabras

Palabras sin dos letras seguidas

Un alfabeto \(\Sigma\) consta de los cuatro caracteres numéricos 1, 2, 3, 4 y los siete caracteres alfabéticos a, b, c, d, e, f, g. Encuentre y resuelva una relación de recurrencia para el número de palabras de longitud \(n\) (en \(\Sigma^{*}\)) tales que no aparezcan caracteres alfabéticos (idénticos o distintos) en forma consecutiva.

Qué tema es y por qué
  • \(\Sigma^{*}\) es el conjunto de todas las palabras (cadenas) que se arman con el alfabeto, de cualquier largo.
  • Es el mismo esquema que las fichas sin azules seguidas: se mira el último carácter, y si es una letra se mira también el anterior.
Desarme del enunciado
FraseQué significaLa cuentaA dónde va
"cuatro caracteres numéricos"dígitos—4 opciones
"siete caracteres alfabéticos"letras—7 opciones
"no aparezcan caracteres alfabéticos en forma consecutiva"después de una letra va un dígito—el caso letra mira el anterior
"palabras de longitud \(n\)"lo que se cuenta—\(a_n\)
Paso 1 — Mirar el último carácter
  • Es un dígito (4 opciones). Lo de antes es una palabra válida de largo \(n - 1\): \(4\,a_{n-1}\).
  • Es una letra (7 opciones). El anterior tiene que ser un dígito (4 opciones), y antes hay una palabra válida de largo \(n - 2\): \(7 \cdot 4\,a_{n-2} = 28\,a_{n-2}\).

\[ a_n = 4a_{n-1} + 28a_{n-2},\ \forall n \geq 2 \]

Paso 2 — Condiciones iniciales
  • \(a_1 = 11\): cualquier carácter.
  • \(a_0 = 1\) (la palabra vacía \(\lambda\)). Control: \(a_2 = 4 \cdot 11 + 28 = 72 = 11^{2} - 7^{2}\) (todas menos letra-letra).
Paso 3 — Resolver

\(a_n - 4a_{n-1} - 28a_{n-2} = 0\): ecuación característica \(r^{2} - 4r - 28 = 0\). Raíces distintas: \(a_n = A_1 r_1^{\,n} + A_2 r_2^{\,n}\).

\(r = \dfrac{4 \pm \sqrt{16 + 112}}{2} = \dfrac{4 \pm \sqrt{128}}{2} = 2 \pm 4\sqrt2\) (porque \(\sqrt{128} = 8\sqrt2\)).

\[ \left\{\begin{array}{l} n = 0:\ A_1 + A_2 = 1 \\ n = 1:\ A_1(2 + 4\sqrt2) + A_2(2 - 4\sqrt2) = 11 \end{array}\right. \]

La segunda: \(2(A_1 + A_2) + 4\sqrt2(A_1 - A_2) = 11 \Rightarrow 4\sqrt2(A_1 - A_2) = 9 \Rightarrow A_1 - A_2 = \tfrac{9}{4\sqrt2} = \tfrac{9\sqrt2}{8}\).

Con \(A_1 + A_2 = 1\): \(A_1 = \dfrac{8 + 9\sqrt2}{16}\), \(A_2 = \dfrac{8 - 9\sqrt2}{16}\).

\[ a_n = \frac{8 + 9\sqrt2}{16}\,(2 + 4\sqrt2)^{n} + \frac{8 - 9\sqrt2}{16}\,(2 - 4\sqrt2)^{n},\ \forall n \geq 0 \]

Paso 4 — Comprobación

Contando con un programa: \(1, 11, 72, 596, 4400, 34288, 260352\) para \(n = 0, \dots, 6\). La relación y la fórmula dan lo mismo.

Respuesta

\(a_n = 4a_{n-1} + 28a_{n-2},\ n \geq 2,\ a_0 = 1,\ a_1 = 11\); \(a_n = \tfrac{8 + 9\sqrt2}{16}(2 + 4\sqrt2)^{n} + \tfrac{8 - 9\sqrt2}{16}(2 - 4\sqrt2)^{n}\).

Solución del libro

En las soluciones (otra edición) es el ejercicio 13: \(a_{n+1} = 4a_n + 28a_{n-1},\ a_0 = 1,\ a_1 = 11\), y la misma fórmula con \(A = (8 + 9\sqrt2)/16\), \(B = (8 - 9\sqrt2)/16\). Coincide.

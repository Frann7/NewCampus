\(X\) es la cantidad de descargas fallidas entre 10 descargas, con distribución binomial, y se trabaja con la tabla acumulada, que da \(P(X \leq r)\). Seleccione las traducciones correctas.

Tema del Segundo Parcial 2023, Ejercicios 4 c, 5 c y 6 a y Segundo Parcial 2025, Ejercicio 3 · formato 1ra etapa

  • “Al menos 3”: \(1 - P(X \leq 2)\)
  • “Al menos 3”: \(1 - P(X \leq 3)\)
  • “A lo sumo 3”: \(P(X \leq 3)\)
  • “Menos de 3”: \(P(X \leq 3)\)
  • “Más de 3”: \(1 - P(X \leq 3)\)
  • “Entre 2 y 5, inclusive”: \(P(X \leq 5) - P(X \leq 2)\)
  • Ninguna opción es correcta

En una discreta, “estricto” o “no estricto” cambia el número:

  • Al menos 3 = \(\{3, 4, \ldots\}\): el complemento es \(\{0, 1, 2\}\), entonces \(1 - P(X \leq 2)\). Con \(1 - P(X \leq 3)\) se pierde el 3.
  • A lo sumo 3 = \(\{0, \ldots, 3\}\) = \(P(X \leq 3)\).
  • Menos de 3 = \(\{0, 1, 2\}\) = \(P(X \leq 2)\): el 3 no entra.
  • Más de 3 = \(\{4, 5, \ldots\}\) = \(1 - P(X \leq 3)\).
  • Entre 2 y 5 inclusive = \(\{2, \ldots, 5\}\) = \(P(X \leq 5) - P(X \leq 1)\). Restando \(P(X \leq 2)\) se pierde el 2.

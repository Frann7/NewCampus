Ejercicio 2 · Conflicto de merge

Leer y resolver un conflicto

Dos desarrolladores cambiaron el precio en el mismo archivo. Al hacer git merge feature-descuento parado en develop, Git responde: 

Auto-merging precios.txt
CONFLICT (content): Merge conflict in precios.txt
Automatic merge failed; fix conflicts and then commit the result.

y el archivo precios.txt queda así:

Teclado: 15000
<<<<<<< HEAD
Mouse: 8000
=======
Mouse: 7200
>>>>>>> feature-descuento
Monitor: 90000

a) ¿Qué tipo de conflicto es? b) ¿Qué versión es de cada rama? c) Indique los pasos para resolverlo dejando el precio con descuento. d) ¿Cómo se cancela el merge si no se quiere seguir?

Paso 1 — Leer el mensaje de Git
LíneaQué dice
Auto-merging precios.txtIntentó fusionar ese archivo solo.
CONFLICT (content): Merge conflict in precios.txtNo pudo: hay un conflicto de contenido en ese archivo.
Automatic merge failed; fix conflicts and then commit the result.Qué hay que hacer: arreglar los conflictos y después confirmar.
Paso 2 — Leer el archivo
Parte del archivoQué es
Teclado: 15000 y Monitor: 90000Fuera de las señales: no hubo conflicto, quedaron fusionadas solas
Entre <<<<<<< HEAD y =======La versión de la rama actual, develop: Mouse: 8000
Entre ======= y >>>>>>> feature-descuentoLa versión de la otra rama, feature-descuento: Mouse: 7200

El conflicto es solo en la línea del mouse: las dos ramas la cambiaron.

Paso 3 — Resolver

Se quiere conservar el precio con descuento. El archivo se edita y queda, sin las tres líneas de señales:

Teclado: 15000
Mouse: 7200
Monitor: 90000

Y se termina el merge:

git add precios.txt
git commit -m "Resuelve el conflicto de precios"
Respuesta

a) Es un conflicto de contenido: las dos ramas modificaron la misma línea del mismo archivo.

b) Mouse: 8000 es la versión de la rama actual (develop, marcada como HEAD); Mouse: 7200 es la de feature-descuento.

c) Pasos:

  1. git status, para ver los archivos en conflicto.
  2. Editar precios.txt: dejar Mouse: 7200 y borrar las líneas <<<<<<<, ======= y >>>>>>>.
  3. git add precios.txt, para marcarlo como resuelto.
  4. git commit, para finalizar el merge.

d) Con git merge --abort, que descarta el merge y deja la rama como estaba antes.

¿Y si los dos hubieran cambiado líneas distintas?

Si uno cambiaba el precio del mouse y el otro el del monitor, no habría conflicto: Git fusiona solo y el archivo queda con los dos cambios. El conflicto aparece porque los dos tocaron la misma línea.

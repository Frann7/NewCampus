Ejercicio 1 · Adapter

Reconocer el patrón en un código C++

Guía N°2, ejercicio 1. Según el siguiente diagrama en C++, identifique de qué patrón se trata, y qué elementos ayudaron a detectar el patrón mencionado. 

class Target {
 public:
  virtual ~Target() = default;

  virtual std::string Request() const {
    return "Target: The default target's behavior.";
  }
};
class convierte {
 public:
  std::string SpecificRequest() const {
    return ".eetpadA eht fo roivaheb laicepS";
  }
};
class conversor : public Target {
 private:
  convierte *convierte_;

 public:
  conversor(convierte *convierte) : convierte_(convierte) {}
  std::string Request() const override {
    std::string to_reverse = this->convierte_->SpecificRequest();
    std::reverse(to_reverse.begin(), to_reverse.end());
    return "conversor: (TRANSLATED) " + to_reverse;
  }
};
void ClientCode(const Target *target) {
  std::cout << target->Request();
}

int main() {
  std::cout << "Client: I can work just fine with the Target objects:\n";
  Target *target = new Target;
  ClientCode(target);
  std::cout << "\n\n";
  convierte *convierte = new convierte;
  std::cout << "Client: The convierte class has a weird interface. See, I don't understand it:\n";
  std::cout << "convierte: " << convierte->SpecificRequest();
  std::cout << "\n\n";
  std::cout << "Client: But I can work with it via the conversor:\n";
  conversor *conversor = new conversor(convierte);
  ClientCode(conversor);
  std::cout << "\n";
  delete target;
  delete convierte;
  delete conversor;
  return 0;
}
Paso 1 — Listar las clases y quién hereda de quién
Clase¿Hereda?Qué tiene
TargetNoUn método virtual: Request()
convierteNo, y no tiene nada virtualUn método con otro nombre: SpecificRequest()
conversorSí: : public TargetUn atributo convierte *convierte_ y el método Request() con override

ClientCode es una función suelta que recibe un Target y llama a Request(): es el cliente.

Paso 2 — Las dos preguntas sobre la clase que guarda a otra
  • ¿De quién hereda conversor? De Target, que es lo que usa el cliente.
  • ¿Qué guarda? Un puntero a convierte, una clase suelta que no tiene nada que ver con Target.

Hereda de la interfaz del cliente y envuelve a una sola clase ajena: es Adapter.

Paso 3 — Qué clase es cada parte
Parte del patrónEn el códigoQué lo confirma
Interfaz con el ClienteTargetEs lo que recibe ClientCode
Servicio (lo incompatible)convierteNo hereda de Target; su método se llama distinto (SpecificRequest) y devuelve el texto al revés
AdaptadorconversorHereda de Target, guarda un convierte recibido en el constructor, y en Request() llama a SpecificRequest() y da vuelta el texto (std::reverse) antes de devolverlo

Paso 4 — Comprobarlo con lo que imprime 
Client: I can work just fine with the Target objects:
Target: The default target's behavior.

Client: The convierte class has a weird interface. See, I don't understand it:
convierte: .eetpadA eht fo roivaheb laicepS

Client: But I can work with it via the conversor:
conversor: (TRANSLATED) Special behavior of the Adaptee.
  • Primer bloque: el cliente trabaja bien con un Target.
  • Segundo: lo que devuelve convierte no se entiende, está al revés. Es la "interfaz rara".
  • Tercero: a través del conversor, el mismo texto sale derecho. Dice "Special behavior of the Adaptee": Adaptee es el nombre en inglés del Servicio, la clase adaptada.
Tal como está en la guía, no compila

En main hay variables que se llaman igual que su clase (convierte *convierte = new convierte;): es lo que quedó al reemplazar los nombres originales. La salida de arriba es la del mismo código con esas dos variables renombradas. Para identificar el patrón no cambia nada.

Paso 5 — El diagrama

La línea de conversor a Target es continua (herencia) y no punteada, porque Target no es una interfaz pura: su método Request() tiene código.

Respuesta

Es el patrón Adapter (estructural). Elementos que lo delatan: convierte es una clase con una interfaz distinta (SpecificRequest) que no hereda de Target; conversor hereda de Target, que es la interfaz que usa el cliente, y guarda un puntero a convierte; y en Request() el conversor llama a SpecificRequest() y transforma el resultado. Así el cliente usa a convierte sin modificarla.

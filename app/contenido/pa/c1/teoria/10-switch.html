10. switch

Para qué sirve

Para comparar una misma variable contra muchos valores posibles y hacer algo distinto según cuál coincida. Hace lo mismo que una cadena de if / else if / else if... preguntando siempre $variable == ..., pero se lee mucho más fácil.

Sintaxis

switch ($variable) {
    case valor1:
        // acción si $variable == valor1
        break;
    case valor2:
        // acción si $variable == valor2
        break;
    default:
        // acción si no coincidió ninguno
        break;
}

Qué es cada parte

ParteQué es
switch ($variable)El valor a comparar. Se evalúa una sola vez.
case valor:Un valor posible, terminado en dos puntos. Si coincide, se empiezan a ejecutar las acciones de abajo. Puede ir entre paréntesis: case (1):.
break;Corta el switch. Sin él, PHP sigue ejecutando las acciones de los case de abajo aunque no coincidan (ejemplo 2).
default:Opcional. Lo que se hace si ningún case coincidió. Es como el else final.

Ejemplo 1 — Qué valor tiene $a (el de la cátedra)

<?php
$a = 3;
switch ($a){
case (1):
print ("El valor es 1");
break;
case (2):
print ("El valor es 2");
break;
case (3):
print ("El valor es 3");
break;
default :
print ("No es ninguno de los valores.");
}
?>

Qué imprime y por qué

El valor es 3
Dos detalles del código del apunte
  • En el apunte, al print del default le falta el ;. Como después viene una } y no un ?>, es error: Parse error: syntax error, unexpected token "}". Arriba está agregado.
  • El "Resultado: El valor es 3" que el apunte escribe antes del ?> es una aclaración para el lector, no parte del código.

Ejemplo 2 — Con formato del Parcial PHP: ¿cuál es la salida? (case sin break)

<?php
$a = 2;
switch ($a) {
    case 1:
        echo "uno ";
    case 2:
        echo "dos ";
    case 3:
        echo "tres ";
        break;
    default:
        echo "otro ";
}
?>

Qué hace cada línea

LíneaQué haceSalida acumulada
$a = 2;Valor a buscar.
case 1:¿2 == 1? No. Saltea su echo.
case 2:¿2 == 2? Sí: empieza a ejecutar.
echo "dos ";Muestra.dos
case 3:No hubo break: PHP ya no compara, sigue de largo hacia abajo.dos
echo "tres ";Se ejecuta aunque $a no sea 3.dos tres
break;Ahora sí, sale.dos tres

Qué imprime y por qué

dos tres

Una vez que un case coincide, PHP ejecuta todo lo de abajo hasta el primer break (o el final del switch). Con $a = 9 no coincidiría ningún case y saldría otro .

Este "seguir de largo" también se usa a propósito, para que varios valores hagan lo mismo: case 1: case 2: echo "Verano"; break; muestra "Verano" tanto para 1 como para 2.

Errores y trampas

Olvidarse el break

Es el error típico del switch: se ejecutan acciones de más (ejemplo 2). Cada case termina con break;, salvo que se quiera agrupar a propósito.

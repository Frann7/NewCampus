Hiciste git commit pero todavía no hiciste git push. ¿Dónde está ese commit?

Inventada · Unidad 6, los tres estados

  • Solo en el área de preparación.
  • En el repositorio local, pero no en el remoto: tus compañeros todavía no lo ven.
  • En el repositorio remoto (GitHub).
  • En ningún lado: sin push el commit se pierde.

El commit queda guardado en el repositorio local (la carpeta .git de tu computadora). El remoto es un cuarto lugar, fuera de tu máquina: para que el commit llegue ahí y lo vea el equipo hay que subirlo con git push.

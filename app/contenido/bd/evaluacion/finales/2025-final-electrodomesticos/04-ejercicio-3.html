Unidad 1 · SQL, DDL y DML

3. ¿Qué es el lenguaje SQL y para que se utiliza? Escriba las sentencias específicas que tiene el lenguaje para DDL y para DML.

✓ ResultadosSolo la respuesta

SQL (Structured Query Language) es el lenguaje de los sistemas de bases de datos relacionales para definir la base y manipular sus datos. Es no procedimental, trabaja sobre conjuntos de registros y se usa solo o embebido en otro lenguaje.

  • DDL (definición de la estructura): CREATE, ALTER, DROP.
  • DML (manipulación de los datos): SELECT, INSERT, UPDATE, DELETE.

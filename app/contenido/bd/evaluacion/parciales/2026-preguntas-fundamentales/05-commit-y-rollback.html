4. COMMIT y ROLLBACK

Unidad 1 · Transacción

¿Qué hacen las sentencias BEGIN TRAN, COMMIT y ROLLBACK? ¿Con qué propiedades de las transacciones se relacionan?

✓ RespuestaPara aprender y escribir en la hoja
  • BEGIN TRAN: marca el comienzo de una transacción; todo lo que sigue es parte de ella.
  • COMMIT: confirma la transacción; los cambios quedan guardados de forma permanente (durabilidad).
  • ROLLBACK: deshace la transacción; la base vuelve a como estaba en el BEGIN TRAN (atomicidad: o todo, o nada).
✎ ExplicaciónUn ejemplo, de dónde sale y las trampas

Cómo se usaron en el TP final

Los scripts de carga empezaban con BEGIN TRAN; después de cargar se hacía un SELECT para revisar. Si estaba bien, COMMIT; si no, ROLLBACK y no había pasado nada.

BEGIN TRAN;
UPDATE Turno SET Estado = 'Cancelado' WHERE FechaHora < '2026-01-01';
SELECT * FROM Turno;   -- se revisa el resultado
ROLLBACK;              -- algo salió mal: se deshace todo

Trampas

  • Después de un COMMIT ya no se puede hacer ROLLBACK de esos cambios: están confirmados.

Consumir una API: una foto de perro al azar

Un botón "Consultar Api" que le pide a la API pública Dog CEO la dirección de una foto de perro al azar, y la muestra junto con el JSON que llegó. Clase IndexClass en js/pgConsultoApiClass.js.

Paso 1 — El HTML 
<div style="text-align: center;">
    <h2>Ejemplo con Javascript para consumir apis</h2>
    <button id="btConsultoApi" class="btn btn-primary">Consultar Api</button>
    <hr />
    <div id="divDatos"></div>
</div>

Un botón y un div vacío donde se va a poner el resultado.

Paso 2 — Qué contesta la API

La dirección https://dog.ceo/api/breeds/image/random devuelve un JSON con dos claves. Una respuesta real (pedida al escribir esto; cada pedido trae otra foto): 

{"message":"https://images.dog.ceo/breeds/spaniel-welsh/n02102177_3916.jpg","status":"success"}
ClaveQué trae
messageLa dirección de la imagen (texto). No es la imagen: es dónde está
status"success" si salió bien
Paso 3 — El JavaScript 
class IndexClass {

    constructor() {
        this.btConsultoApi = document.getElementById('btConsultoApi');
    }

    init() {
        this.addEventListeners();
    }

    addEventListeners() {
        this.btConsultoApi.addEventListener('click', () => {

            const url = "https://dog.ceo/api/breeds/image/random";

            fetch(url)
                .then(response => response.json())
                .then(data => {

                    const imgElement = document.createElement('img');
                        imgElement.src = data.message;
                        imgElement.alt = 'Imagen de perro';
                        imgElement.style.maxWidth = '300px';
                        imgElement.style.marginTop = '10px';

                    const divDatos = document.getElementById('divDatos');
                        divDatos.innerText = JSON.stringify(data, null, 2);

                    const br = document.createElement('br');
                        divDatos.appendChild(br);
                        divDatos.appendChild(imgElement);
                })
                .catch(error => {
                    console.error('Error al consultar la API:', error);
                });
        });
    }
}

window.addEventListener('load',() => {
    new IndexClass().init();
})

Una sola foto por vez

Cada clic trae otra foto y reemplaza la anterior, no la acumula: el innerText = ... vacía el div antes de colgar la nueva. Si en vez de asignar se hiciera solo appendChild, las fotos se irían apilando.

Dos peticiones, no una

La API devuelve texto (la dirección). La foto la baja el navegador después, en otra petición, cuando el <img> entra en la página: lo mismo que pasaba con las etiquetas <img> del HTML (teoría, sección 1).

Qué se ve en la página

Al principio, solo el botón. En cada clic aparece abajo el JSON recibido, en varios renglones ({, la línea de "message", la de "status", }; la sangría no se nota porque el HTML junta los espacios), y debajo una foto de perro de hasta 300px de ancho. La foto cambia en cada clic.

8. Resumen: las funciones mysqli de la cátedra

Para qué sirve

La guía práctica abre con un resumen de funciones, escritas en estilo procedural, y el parcial las pregunta con esos nombres. Esta tabla junta cada una con su equivalente en estilo objetos (el de la teoría) y con lo que devuelve.

La regla para pasar de un estilo al otro

$objeto->metodo(x)  se escribe  mysqli_metodo($objeto, x). En el procedural, el primer parámetro es siempre la conexión (o el resultado, en las de fetch). La única que no lo lleva es mysqli_connect(), porque es la que la crea.

El script procedural completo:

<?php
$conexion = mysqli_connect('127.0.0.1', 'root', '', 'Personal');

if (!$conexion) {
    echo "Error: " . mysqli_connect_error();
    exit;
}

$resultado = mysqli_query($conexion, 'SELECT * FROM personas');

while ($persona = mysqli_fetch_array($resultado)) {
    echo $persona['apellido'] . ", " . $persona['nombres'] . "<br>";
}

mysqli_close($conexion);
?>

Ejemplo 2 — La pregunta 4 del parcial

Enunciado (Parcial PHP, pregunta 4)

Seleccione la definición correcta para cada función:

  1. Crea una conexión a un servidor de base de datos MySQL o derivados de ella.
  2. Nos permite enviar una consulta sobre la base de datos seleccionada y asociada al identificador de conexión pasado como parámetro.
  3. Nos devuelve una matriz que corresponde a la fila recuperada y luego mueve el puntero interno hacia adelante.

Opciones: mysqli_connect(), mysqli_query(), mysqli_fetch_array().

Cómo se reconoce cada una

Frase de la definiciónQué significaFunción
"Crea una conexión a un servidor… MySQL o derivados"Abrir el canal con el servidor. "Derivados" es MariaDBmysqli_connect()
"enviar una consulta"Mandar una instrucción SQL. Query es "consulta" en inglésmysqli_query()
"…al identificador de conexión pasado como parámetro"En el estilo procedural la conexión va como primer parámetro: mysqli_query($conexion, $sql)mysqli_query()
"devuelve una matriz que corresponde a la fila recuperada"Matriz = arreglo. Devuelve una fila como arreglomysqli_fetch_array()
"mueve el puntero interno hacia adelante"Después de cada llamada queda apuntando a la fila siguiente (ejemplo 3 de la sección 5)mysqli_fetch_array()
Respuesta
  1. Crea una conexión… → mysqli_connect()
  2. Enviar una consulta… → mysqli_query()
  3. Devuelve una matriz con la fila… → mysqli_fetch_array()
Errores y trampas
  • La 2 y la 3 se confunden si se lee rápido: las dos hablan de "datos". La pista es el verbo: enviar una consulta (ida) contra devolver una fila (vuelta).
  • El orden de los parámetros: mysqli_query($conexion, $sql), la conexión primero. Al revés no anda.
  • La guía escribe "clase mysqlli", con doble ele: es un error de tipeo. La clase es mysqli.

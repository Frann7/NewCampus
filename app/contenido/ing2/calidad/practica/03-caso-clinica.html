Ejercicio 3 · CMMI · Nivel 2

Diagnosticar un caso largo: la aplicación para la clínica

Práctica 2 de CMMI, ejercicio 1.

Una empresa de desarrollo de software recibió el encargo de construir una aplicación para gestionar los turnos de una clínica privada. El proyecto comenzó con una reunión entre el gerente de la empresa y el cliente, en la que se acordaron de manera general las funcionalidades que tendría el sistema.

Durante las primeras semanas, el equipo de desarrollo comenzó a trabajar directamente sobre la aplicación. Cada desarrollador organizab a sus tareas de acuerdo con sus propios criterios y no existía un cronograma formal del proyecto. El responsable técnico realizaba reuniones informales cuando aparecía algún inconveniente importante.

A medida que avanzó el desarrollo, surgieron varios prob lemas. Algunas funcionalidades solicitadas por el cliente no habían sido implementadas porque el equipo no las había registrado formalmente. Además, se produjeron retrasos debido a que determinadas tareas dependían de otras que todavía no habían terminado. El gerente decidió comenzar a registrar las tareas pendientes, asignar responsables y establecer fechas estimadas de finalización. También se empezó a realizar un seguimiento semanal del avance y de los problemas encontrados. Después de implementar estas medidas, el proyecto logró cumplir con los principales requerimientos del cliente. Sin embargo, cada proyecto de la empresa continúa trabajando de una manera diferente y no existe una forma común de desarrollar y gestionar los proyectos.

Consignas:

  • Identifique en qué situación de madurez se encuentra actualmente la organización. Justifique su respuesta utilizando características presentes en el caso.
  • ¿Qué elementos o prácticas debería incorporar la organización para avanzar hacia el siguiente nivel?
  • Mencione al menos tres evidencias del texto que fundamenten su respuesta.
Paso 1 — Ojo con el tiempo: el caso cuenta una historia

Paso 2 — Las cuatro preguntas
  • 1. ¿Los proyectos se planifican y se siguen? Ahora sí: tareas registradas, responsables, fechas y seguimiento semanal.
  • 2. ¿Hay un proceso común para todos los equipos? No: "no existe una forma común". → Nivel 2.
Respuesta

Situación de madurez: Nivel 2 (Gestionado). La organización pasó de trabajar sin planificación (nivel 1) a gestionar su proyecto, pero todavía no tiene un proceso común.

Tres evidencias del texto:

  1. Se registran las tareas pendientes, se asignan responsables y se establecen fechas estimadas.
  2. Se hace un seguimiento semanal del avance y de los problemas.
  3. Cada proyecto continúa trabajando de manera diferente y no existe una forma común de desarrollar y gestionar: por eso no es nivel 3.

Para avanzar al Nivel 3 (Definido): definir y documentar un proceso estándar para toda la empresa (cómo se relevan los requisitos, cómo se planifica, cómo se prueba); armar un repositorio con ese proceso y sus plantillas; y capacitar a todos los equipos para que lo usen.

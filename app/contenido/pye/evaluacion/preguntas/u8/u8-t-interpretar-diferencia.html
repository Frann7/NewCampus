Para comparar el tiempo de respuesta de una API REST (1) y una GraphQL (2) se obtuvo el intervalo del 95 % \((4{,}39\ ;\ 20{,}01)\) ms para \(\mu_1 - \mu_2\). ¿Cuál es la conclusión correcta?

Estimación parte 2 de la cátedra, pág. 10 (conclusión del Ejemplo 4; entra en el 3er parcial)

  • Como el intervalo no incluye el 0, hay diferencia significativa entre los tiempos medios, y el de la API REST es mayor: entre 4,39 y 20,01 ms más, con 95 % de confianza.
  • Como el intervalo no incluye el 0, no hay diferencia significativa entre los tiempos medios.
  • Hay diferencia significativa y la API GraphQL es la más lenta.
  • El 95 % de las peticiones REST tarda entre 4,39 y 20,01 ms más que las GraphQL.

¿Qué valor de \(\mu_1 - \mu_2\) significa “medias iguales”? ¿Y qué dice el signo del intervalo?

\(\mu_1 - \mu_2 = 0\) es “no hay diferencia”. El intervalo \((4{,}39\ ;\ 20{,}01)\) no lo incluye: con 95 % de confianza hay diferencia significativa. Como es todo positivo, \(\mu_1 > \mu_2\): la API REST (1) tiene mayor tiempo medio.

El intervalo habla de la diferencia de las medias, no de peticiones sueltas.

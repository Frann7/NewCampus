Códigos sin dos números seguidos

Se quiere crear códigos o palabras válidas de longitud \(n\) utilizando caracteres de un alfabeto especial que contiene: 3 letras distintas \(\{A, B, C\}\) y 2 dígitos numéricos distintos \(\{1, 2\}\). Por motivos de seguridad del sistema, no está permitido que aparezcan dos números de forma consecutiva en la palabra. Sea \(W_n\) el número total de palabras válidas de longitud \(n\) que se pueden formar.

a) Encuentre una relación de recurrencia para \(W_n\) junto con las condiciones iniciales para \(W_1\) y \(W_2\).

b) Resuelva la relación de recurrencia para encontrar la fórmula explícita de \(W_n\).

Qué tema es y por qué
  • Contar palabras con una prohibición de "dos seguidos": se mira el último carácter y, si es un número, también el anterior.
  • Sale segundo orden homogénea.

Paso 1 — Inciso a): plantear
  • Termina en letra (3 opciones): lo anterior es cualquier palabra válida de largo \(n - 1\): \(3W_{n-1}\).
  • Termina en número (2 opciones): el anterior tiene que ser letra (3 opciones), y antes hay una palabra válida de largo \(n - 2\): \(2 \cdot 3\,W_{n-2} = 6W_{n-2}\).

\[ W_n = 3W_{n-1} + 6W_{n-2},\ \forall n \geq 3 \]

Condiciones iniciales:

  • \(W_1 = 5\): un carácter cualquiera.
  • \(W_2 = 5^{2} - 2^{2} = 21\): todos los pares menos los cuatro número-número (11, 12, 21, 22).
Paso 2 — Inciso b): resolver

\(W_n - 3W_{n-1} - 6W_{n-2} = 0\): ecuación característica \(r^{2} - 3r - 6 = 0\). Raíces distintas: \(W_n = A_1 r_1^{\,n} + A_2 r_2^{\,n}\).

\(r = \dfrac{3 \pm \sqrt{9 + 24}}{2} = \dfrac{3 \pm \sqrt{33}}{2}\).

Para las constantes conviene extender hacia atrás: con \(n = 2\) la relación pediría \(21 = 3 \cdot 5 + 6W_0\), o sea \(W_0 = 1\) (la palabra vacía). Usando \(W_0 = 1\) y \(W_1 = 5\):

\[ \left\{\begin{array}{l} n = 0:\ A_1 + A_2 = 1 \\ n = 1:\ A_1\,\tfrac{3 + \sqrt{33}}{2} + A_2\,\tfrac{3 - \sqrt{33}}{2} = 5 \end{array}\right. \]

La segunda por 2: \(3(A_1 + A_2) + \sqrt{33}(A_1 - A_2) = 10 \Rightarrow A_1 - A_2 = \tfrac{7}{\sqrt{33}}\).

Con \(A_1 + A_2 = 1\): \(A_1 = \dfrac{\sqrt{33} + 7}{2\sqrt{33}}\), \(A_2 = \dfrac{\sqrt{33} - 7}{2\sqrt{33}}\).

\[ W_n = \frac{\sqrt{33} + 7}{2\sqrt{33}}\left(\frac{3 + \sqrt{33}}{2}\right)^{n} + \frac{\sqrt{33} - 7}{2\sqrt{33}}\left(\frac{3 - \sqrt{33}}{2}\right)^{n},\ \forall n \geq 1 \]

(Si se prefiere no usar \(W_0\), se plantean las ecuaciones con \(n = 1\) y \(n = 2\) contra \(W_1 = 5\) y \(W_2 = 21\): dan las mismas constantes.)

Paso 3 — Comprobación

Contando todas las palabras con un programa: \(5, 21, 93, 405, 1773, 7749, 33885\) para \(n = 1, \dots, 7\). La relación y la fórmula dan lo mismo.

Respuesta

a) \(W_n = 3W_{n-1} + 6W_{n-2},\ n \geq 3,\ W_1 = 5,\ W_2 = 21\).   b) la fórmula de arriba.

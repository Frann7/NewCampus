Aplicar las leyes

8. Simplificación algebraica

Para qué sirve

Simplificar es encontrar una expresión más corta que sea la misma función (misma columna en la tabla). En un circuito, menos letras y menos operaciones son menos componentes. En el parcial se pide "escribir \(f\) en su forma más simple", y la tabla queda como verificación.

Cómo se hace

No hay una receta única, pero este orden casi siempre funciona:

  1. Sacar las barras largas con De Morgan (L2): \(\overline{xy} = \overline{x} + \overline{y}\), \(\overline{x + y} = \overline{x}\,\overline{y}\). Si quedan dos barras juntas, se van (L1).
  2. Distribuir (L5) para que quede una suma de productos: \(\overline{z}(z + \overline{x}) = \overline{z}z + \overline{z}\,\overline{x}\).
  3. Borrar lo que da 0 o 1: \(x\overline{x} = 0\) y \(x + \overline{x} = 1\) (L8); un producto con un 0 es 0 y una suma con un 1 es 1 (L9); los 0 sumando y los 1 multiplicando se van (L7).
  4. Absorber (L10): si un sumando está "contenido" en otro, se borra el más largo. \(\overline{y} + \overline{y}z = \overline{y}\): todo lo que hace 1 a \(\overline{y}z\) ya hace 1 a \(\overline{y}\).
  5. Quitar la barra que sobra (sección 7): \(x + \overline{x}y = x + y\).
  6. Repetidos fuera (L6): \(x + x = x\).

En cada renglón se anota qué ley se usó. Al final, se comprueba con la tabla (o con un par de filas) que la función no cambió.

Ejemplo 1 — El de la cátedra

Enunciado

Simplificar \(xy + (x + y)\overline{z} + y\).

Desarme del enunciado

\(xy + (x + y)\overline{z} + y = xy + x\overline{z} + y\overline{z} + y\)L5, distributiva
\(= (y + xy + y\overline{z}) + x\overline{z}\)L3 y L4, reordenar

Respuesta

\(xy + (x + y)\overline{z} + y = y + x\overline{z}\). Con la distributiva de \(+\) sobre \(\cdot\) también se puede escribir como producto: \(y + x\overline{z} = (y + x)(y + \overline{z})\). Las tres expresiones tienen la misma tabla (verificado).

Ejemplo 2 — Estilo parcial (Parcial 1 2026, ej. 5 a)

Enunciado

Escribir en su forma más simple \(f(x, y, z) = \overline{xy} + \overline{y}z + \overline{z}(z + \overline{x})\).

Desarme del enunciado

FraseQué significaLa cuentaA dónde va
"\(\overline{xy}\)"barra larga sobre un productoDe Morgan\(\overline{x} + \overline{y}\)
"\(\overline{z}(z + \overline{x})\)"producto por un paréntesisdistribuir; aparece \(\overline{z}z = 0\)\(\overline{x}\,\overline{z}\)
"forma más simple"la menor cantidad de letrasabsorberla respuesta
RenglónQué ley se usó
\(f = \overline{x} + \overline{y} + \overline{y}z + \overline{z}(z + \overline{x})\)L2, De Morgan en \(\overline{xy}\)
\(= \overline{x} + \overline{y} + \overline{y}z + \overline{z}z + \overline{z}\,\overline{x}\)L5, distributiva
\(= \overline{x} + \overline{y} + \overline{y}z + 0 + \overline{x}\,\overline{z}\)L8, inversos: \(\overline{z}z = 0\) (y L3 para escribir \(\overline{x}\,\overline{z}\))
\(= (\overline{x} + \overline{x}\,\overline{z}) + (\overline{y} + \overline{y}z)\)L7 (el 0 se va), L3 y L4 (reordenar)
\(= \overline{x} + \overline{y}\)L10, absorción, dos veces

Verificación con la tabla (la del ej. 5 b, sección 4): \(f\) vale 0 solo en \(110\) y \(111\). \(\overline{x} + \overline{y}\) es 0 solo si \(\overline{x} = 0\) y \(\overline{y} = 0\), o sea \(x = y = 1\): justo esas dos filas. ✓

Respuesta

\(f(x, y, z) = \overline{x} + \overline{y}\). (Por De Morgan es lo mismo que \(\overline{xy}\): \(f\) no depende de \(z\).)

Si la barra se lee cortada: \(\overline{x}\,\overline{y}\) en vez de \(\overline{xy}\)

En la foto del parcial la barra es continua. Si fuera \(\overline{x}\,\overline{y}\), la función es otra: \(\overline{x}\,\overline{y} + \overline{y}z + \overline{x}\,\overline{z}\). Ahí \(\overline{x}\,\overline{y} = \overline{x}\,\overline{y}z + \overline{x}\,\overline{y}\,\overline{z}\) (multiplicando por \(z + \overline{z} = 1\)), el primer pedazo lo absorbe \(\overline{y}z\) y el segundo \(\overline{x}\,\overline{z}\), y queda \(\overline{y}z + \overline{x}\,\overline{z}\) (1 en las filas 0, 1, 2 y 5; verificado). Por eso conviene mirar bien hasta dónde llega cada barra.

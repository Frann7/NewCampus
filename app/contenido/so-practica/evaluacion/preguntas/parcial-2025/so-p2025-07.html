Verdadero.

Qué evalúa

Que la swap puede ser partición o archivo, que puede haber varias y que cada una tiene prioridad.

Por qué es verdadero

  • La swap se configura como partición dedicada (lo recomendado) o como archivo dentro de un sistema de archivos (wiki de Debian, diapositiva 8).
  • Desde el núcleo 2.4, Linux maneja hasta 32 áreas de intercambio a la vez.
  • swapon lista cada swap con su tamaño y su prioridad; se usa primero la de prioridad más alta (se fija con swapon -p o con pri= en /etc/fstab).
  • La práctica 3 hace justamente esto: al equipo que ya tiene una partición swap le suma un archivo de 1 GB:
dd if=/dev/zero of=/var/swap bs=4096k count=256   # archivo de 1 GB
chmod 600 /var/swap                                # permisos limitados
mkswap /var/swap                                   # formato de swap
swapon /var/swap                                   # se incorpora

Después, swapon muestra las dos (la partición y el archivo).

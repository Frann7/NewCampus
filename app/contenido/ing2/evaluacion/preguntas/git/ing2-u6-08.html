Después de editar el archivo en conflicto y dejarlo como tiene que quedar, sin los marcadores, ¿cómo se termina el merge?

Inventada · Unidad 6, conflictos

  • git add archivo y después git commit.
  • git merge develop de nuevo.
  • git push origin main directamente.
  • git checkout develop.

Resolver un conflicto son tres pasos: editar el archivo (elegir y borrar los marcadores), git add para decirle a Git que ese archivo ya está resuelto, y git commit para cerrar la fusión. Recién después se sube con push.

Grimaldi 10.1 · Ej. 2 · Resolver primer orden

Solución general de cuatro relaciones de primer orden

Encuentre la solución general para cada una de las siguientes progresiones geométricas.

a) \(a_{n+1} - 1.5a_n = 0,\ n \geq 0\)    b) \(4a_n - 5a_{n-1} = 0,\ n \geq 1\)

c) \(3a_{n+1} - 4a_n = 0,\ n \geq 0,\ a_1 = 5\)    d) \(2a_n - 3a_{n-1} = 0,\ n \geq 1,\ a_4 = 81\)

Qué tema es y por qué
  • Las cuatro son lineales homogéneas de primer orden: cada término es un número fijo por el anterior, sin nada sumado.
  • Hay que llevarlas a la forma \(a_n = d\,a_{n-1}\) (despejando el término de subíndice mayor) para leer la razón \(d\).
  • "Solución general" en a) y b): no hay condición inicial, así que la respuesta queda con \(a_0\) como letra. En c) y d) dan un término que no es \(a_0\): con él se calcula \(a_0\).
  • \(1.5\) es la escritura del libro para \(1{,}5\).
La regla

\[ a_n = d\,a_{n-1},\ \forall n \geq 1 \qquad\Longrightarrow\qquad a_n = a_0\,d^{\,n},\ \forall n \geq 0 \]

Escribirla con \(a_{n+1} = d\,a_n,\ n \geq 0\) es lo mismo: corre el subíndice en uno.

Paso 1 — Inciso a)

Se despeja el de subíndice mayor: \(a_{n+1} = 1{,}5\,a_n\). Entonces \(d = 1{,}5 = \tfrac32\).

Regla \(a_n = a_0\,d^{\,n}\):

\[ a_n = a_0\left(\tfrac{3}{2}\right)^{n},\ \forall n \geq 0 \]

Paso 2 — Inciso b)

\(4a_n = 5a_{n-1} \Rightarrow a_n = \tfrac54\,a_{n-1}\). Entonces \(d = \tfrac54 = 1{,}25\).

Regla \(a_n = a_0\,d^{\,n}\):

\[ a_n = a_0\left(\tfrac{5}{4}\right)^{n},\ \forall n \geq 0 \]

Paso 3 — Inciso c)

\(3a_{n+1} = 4a_n \Rightarrow a_{n+1} = \tfrac43\,a_n\). Entonces \(d = \tfrac43\).

Regla \(a_n = a_0\,d^{\,n}\), con el dato \(a_1 = 5\) para hallar \(a_0\):

\[ a_1 = a_0 \cdot \tfrac43 = 5 \ \Rightarrow\ a_0 = 5 \cdot \tfrac34 = \tfrac{15}{4} \]

\[ a_n = \tfrac{15}{4}\left(\tfrac43\right)^{n} = 5\left(\tfrac43\right)^{n-1},\ \forall n \geq 0 \]

(La segunda forma sale de \(\tfrac{15}{4} = 5 \cdot \tfrac34\) y \(\tfrac34 \cdot \left(\tfrac43\right)^{n} = \left(\tfrac43\right)^{n-1}\).)

Paso 4 — Inciso d)

\(2a_n = 3a_{n-1} \Rightarrow a_n = \tfrac32\,a_{n-1}\). Entonces \(d = \tfrac32\).

Regla \(a_n = a_0\,d^{\,n}\), con el dato \(a_4 = 81\):

\[ a_4 = a_0\left(\tfrac32\right)^{4} = a_0 \cdot \tfrac{81}{16} = 81 \ \Rightarrow\ a_0 = 16 \]

\[ a_n = 16\left(\tfrac32\right)^{n},\ \forall n \geq 0 \]

Paso 5 — Comprobación
  • c) Con la relación: \(a_1 = 5,\ a_2 = \tfrac43 \cdot 5 = \tfrac{20}{3},\ a_3 = \tfrac{80}{9}\). Con la fórmula \(5(4/3)^{n-1}\): \(5,\ \tfrac{20}{3},\ \tfrac{80}{9}\). Coinciden.
  • d) Con la relación desde \(a_0 = 16\): \(16, 24, 36, 54, 81\). El quinto es \(a_4 = 81\), como pide el enunciado.
Respuesta

a) \(a_n = a_0(3/2)^{n}\)   b) \(a_n = a_0(5/4)^{n}\)   c) \(a_n = 5(4/3)^{n-1}\)   d) \(a_n = 16(3/2)^{n}\), todas para \(n \geq 0\).

Solución del libro

El libro da \(a_n = (1{,}5)^{n}a_0\), \(a_n = (1{,}25)^{n}a_0\), \(a_n = 5(4/3)^{n-1}\) y \(a_n = 16(3/2)^{n}\). Coinciden los cuatro.

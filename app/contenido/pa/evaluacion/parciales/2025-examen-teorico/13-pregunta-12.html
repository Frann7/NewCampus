Pregunta 12

5 puntos Git · Sistemas de control de versiones

¿Cuál de las siguientes opciones contiene únicamente nombres de sistemas de control de versiones (VCS)?

  1. Git y Subversion
  2. Git y Docker
  3. Mercurial y Node
  4. Bazaar y Podman
✓ ResultadosSolo la respuesta

a. Git y Subversion

✎ Explicación detalladaQué evalúa, la idea, opción por opción y las trampas

Qué evalúa

Distinguir los sistemas de control de versiones de otras herramientas.

La idea

Un sistema de control de versiones (VCS) guarda la historia de los cambios del código: quién cambió qué y cuándo, y permite volver atrás. Los conocidos son Git, Subversion (SVN), Mercurial y Bazaar.

Los otros nombres son de otra cosa: Docker y Podman son de contenedores (empaquetar una aplicación con todo lo que necesita para correr), y Node (Node.js) es un entorno para ejecutar JavaScript fuera del navegador.

Opción por opción

Opción¿Va?Por qué
Git y SubversionSíLos dos son VCS.
Git y DockerNoDocker es de contenedores.
Mercurial y NodeNoMercurial sí es VCS, Node no.
Bazaar y PodmanNoBazaar sí es VCS, Podman es de contenedores.

Trampas

  • La palabra clave es únicamente: tres opciones tienen un VCS de verdad y otro que no. Hay que mirar los dos nombres.

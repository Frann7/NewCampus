Script para listar los comentarios

Escriba un script en PHP que genere un listado de todos los comentarios guardados en la base de datos. Dicho script deberá ser ejecutado mediante el link "Ver los Comentarios" incluido en la página de inicio del sitio. Para esto deberá modificar la etiqueta <a> para que apunte al mismo.

Paso 1 — Qué pide
  1. Un script nuevo, listarComentarios.php, que haga un SELECT de la tabla y muestre cada fila (secciones 4 y 5 de la teoría).
  2. Cambiar en index.php el link "Ver los Comentarios", que en la Clase 3 quedó sin destino (la guía 3 decía que se iba a desarrollar más adelante).
Paso 2 — El link en index.php 
<a href="formContacto.php">Agregar Comentario</a>
<a href="listarComentarios.php">Ver los Comentarios</a>

El href es el nombre exacto del script nuevo. Es el único cambio en index.php.

Paso 3 — El código: listarComentarios.php

Arma las filas de la tabla HTML en un string y después lo imprime, como hace el sitio de ejemplo de la cátedra:

<?php
require_once 'conexion.php';

$sql = "SELECT id_comentario, nombre, asunto, correo, comentario FROM comentarios";
$resultado = $mysqli->query($sql);

$filasTabla = "";

if ($resultado->num_rows > 0) {
    while ($fila = $resultado->fetch_array()) {
        $filasTabla .= "<tr>"
            . "<td>" . htmlspecialchars($fila['nombre']) . "</td>"
            . "<td>" . htmlspecialchars($fila['asunto']) . "</td>"
            . "<td>" . htmlspecialchars($fila['correo']) . "</td>"
            . "<td>" . htmlspecialchars($fila['comentario']) . "</td>"
            . "</tr>";
    }
} else {
    $filasTabla = "<tr><td colspan='4'>Todavía no hay comentarios.</td></tr>";
}

$mysqli->close();
?>
<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <title>Comentarios</title>
</head>
<body>
  <h2>Comentarios</h2>
  <table border="1">
    <tr><th>Nombre</th><th>Asunto</th><th>Correo</th><th>Comentario</th></tr>
    <?php echo $filasTabla; ?>
  </table>
  <a href="index.php">Volver</a>
</body>
</html>

Paso 6 — Qué se ve

El HTML de la tabla que genera con los datos de ejemplo (verificado reemplazando la base por esas tres filas). PHP manda todas las filas en un solo renglón; acá están cortadas en <tr> para leerlas:

    <tr><th>Nombre</th><th>Asunto</th><th>Correo</th><th>Comentario</th></tr>
    <tr><td>Ana</td><td>Consulta</td><td>ana@mail.com</td><td>¿Cuándo es el parcial?</td></tr>
    <tr><td>Luis</td><td>Saludo</td><td>luis@mail.com</td><td>Muy bueno el sitio</td></tr>
    <tr><td>Sofi</td><td>Prueba</td><td>sofi@mail.com</td><td>Escribo &lt;b&gt;en negrita&lt;/b&gt;</td></tr>
</table>

En el navegador:

NombreAsuntoCorreoComentario
AnaConsultaana@mail.com¿Cuándo es el parcial?
LuisSaludoluis@mail.comMuy bueno el sitio
SofiPruebasofi@mail.comEscribo <b>en negrita</b>

Lo de Sofi se ve tal cual lo escribió, con los signos, y no en negrita. Sin htmlspecialchars el navegador habría ejecutado la etiqueta: cualquiera podría meter HTML o JavaScript en la página de todos con solo dejar un comentario. Con la tabla vacía, se ve una sola fila: "Todavía no hay comentarios." (también verificado).

Errores y trampas
  • Las claves de $fila son los nombres de las columnas de la tabla del ejercicio 1, no los name del formulario. Acá coinciden porque se eligieron iguales.
  • Cerrar antes de terminar de leer: el close() va después del while, no antes.
  • Las comillas adentro del string: colspan='4' lleva comillas simples porque el string de PHP está entre dobles.
Resultado

listarComentarios.php recorre el SELECT con fetch_array() y arma una tabla HTML con una fila por comentario; el link "Ver los Comentarios" de index.php apunta a él. La guía no tiene hoja de resultados.

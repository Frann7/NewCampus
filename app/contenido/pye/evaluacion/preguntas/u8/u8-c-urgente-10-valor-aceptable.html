Una máquina está regulada para que la media de llenado sea 2,25 litros. Con una muestra se obtuvo el intervalo del 95 % \((2{,}140\ ;\ 2{,}240)\) litros para la media de llenado. Al nivel 0,05, ¿es aceptable el funcionamiento de la máquina?

Basado en el Tercer Parcial 2025, Ej. 1 b (allá se planteó como prueba de hipótesis; este año se contesta con el intervalo)

  • No: 2,25 queda afuera del intervalo, así que no es un valor creíble para la media de llenado.
  • Sí: 2,25 está muy cerca del límite superior 2,240.
  • Sí: la media de la muestra (2,19) está dentro del intervalo.
  • No se puede decidir sin hacer una prueba de hipótesis.

El intervalo del 95 % es el conjunto de valores creíbles para \(\mu\) con esa confianza (nivel \(\alpha = 0{,}05\)). Para decidir si un valor es aceptable se mira si está adentro:

  • Adentro → es compatible con los datos: aceptable.
  • Afuera → no es compatible: no es aceptable (la máquina está desregulada).

2,25 > 2,240: queda afuera, por poco, pero afuera. Que \(\bar{x}\) esté dentro no dice nada: siempre es el centro del intervalo.

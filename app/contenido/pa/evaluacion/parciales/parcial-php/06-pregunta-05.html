Qué evalúa

Seguir if anidados con condiciones booleanas (!, &&). Es de la Clase 1 (estructuras de control).

El concepto, desde cero

El código del enunciado está mal sangrado, y eso confunde. Ordenado, con cada { alineado con su }, es esto:

<?php
$string = "Hola, Mundo!";
$a = ?;
$b = ?;
$c = ?;
if ($a) {
    if ($b && !$c) {
        echo "Adios mundo cruel!";
    } else if (!$b && !$c) {
        echo "Nada por aquí";
    }
} else {
    if (!$b) {
        if (!$a && (!$b && $c)) {
            echo "Hola, mundo!";
        } else {
            echo "Adios mundo!";
        }
    } else {
        echo "No exactamente";
    }
}
?>

De la salida hacia atrás

Lo más rápido es mirar qué camino lleva al único echo que dice “Hola, mundo!”:

  • Está dentro del else del primer if ($a) ⇒ $a tiene que ser false.
  • Está dentro de if (!$b) ⇒ $b tiene que ser false.
  • Y la condición !$a && (!$b && $c) tiene que dar true: con $a y $b en false queda true && (true && $c), así que $c tiene que ser true.

Resultado: False, False, True, la opción d.

Las trampas

$string está para distraer: nunca se imprime. Lo que sale en pantalla es solo lo que dicen los echo.

El enunciado dice “Hola, Mundo!” y el script imprime “Hola, mundo!”, con minúscula. Ningún camino imprime exactamente lo que dice el enunciado; la diferencia es un descuido de quien lo escribió, y la respuesta esperada es la d, la única que llega a ese echo.

Guiarse por la sangría: el código está mal indentado y parece que el else va con otro if. Siempre contá llaves.

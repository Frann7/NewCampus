Script de alta de comentarios

Realice un script en PHP que permita tomar los datos del formulario y escribir dichos comentarios en la tabla comentarios de la base de datos creada en el punto 1. Recuerde que el nombre del script a crear deberá coincidir con el declarado en el atributo action de la etiqueta form. Para establecer la conexión a la base de datos utilice el archivo de conexión desarrollado en el punto 3 [es el punto 2].

Paso 1 — De dónde vienen los datos

Del formulario de contacto de la Clase 3 (formContacto.php), que manda por post a procesoForm.php. En la Clase 3 ese script solo mostraba los datos; ahora los guarda. Lo que importa del formulario son dos cosas: el action (a qué script va) y el name de cada campo (con qué clave llega a $_POST). Conviene que los name sean iguales a las columnas de la tabla, para no confundirse: 

<form method="post" action="procesoForm.php">
    <label>Nombre: <input type="text" name="nombre"></label><br>
    <label>Asunto: <input type="text" name="asunto"></label><br>
    <label>Correo: <input type="text" name="correo"></label><br>
    <label>Comentario: <textarea name="comentario"></textarea></label><br>
    <input type="reset" value="Restablecer">
    <input type="submit" value="Enviar">
</form>
Paso 2 — Qué tiene que hacer el script
  1. Revisar que llegaron los cuatro datos; si no, cortar.
  2. Incluir conexion.php (ejercicio 2): queda la conexión en $mysqli.
  3. Guardar los datos con un INSERT. Como vienen de un formulario, con consulta preparada (sección 6: así no se puede inyectar SQL).
  4. Avisar si se guardó y ofrecer volver.
  5. Cerrar la conexión.
Paso 3 — El código: procesoForm.php 
<?php
if (!isset($_POST['nombre'], $_POST['asunto'], $_POST['correo'], $_POST['comentario'])) {
    die("No se recibieron datos");
}

require_once 'conexion.php';

$nombre     = trim($_POST['nombre']);
$asunto     = trim($_POST['asunto']);
$correo     = trim($_POST['correo']);
$comentario = trim($_POST['comentario']);

$sql  = "INSERT INTO comentarios (nombre, asunto, correo, comentario) VALUES (?, ?, ?, ?)";
$stmt = $mysqli->prepare($sql);
$stmt->bind_param("ssss", $nombre, $asunto, $correo, $comentario);

if ($stmt->execute()) {
    $mensaje = "Gracias, tu comentario se guardó con el número " . $mysqli->insert_id . ".";
} else {
    $mensaje = "No se pudo guardar el comentario.";
}

$stmt->close();
$mysqli->close();
?>
<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <title>Comentario enviado</title>
</head>
<body>
  <p><?php echo $mensaje; ?></p>
  <a href="index.php">Volver al inicio</a>
</body>
</html>

Paso 5 — Qué se ve

El HTML que genera, verificado corriendo el script con esos datos y la base reemplazada por una de ejemplo que devuelve el id 4: 

<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <title>Comentario enviado</title>
</head>
<body>
  <p>Gracias, tu comentario se guardó con el número 4.</p>
  <a href="index.php">Volver al inicio</a>
</body>
</html>

En pantalla: "Gracias, tu comentario se guardó con el número 4." y el link. En phpMyAdmin, la tabla comentarios tiene una fila nueva con id_comentario 4 y Ana sin los espacios. Si se abre el script sin pasar por el formulario, se ve solo "No se recibieron datos" (también verificado).

Errores y trampas
  • El name manda. Si el campo se llama name="Nombre", llega como $_POST['Nombre'], y isset($_POST['nombre']) da falso.
  • Las comillas del INSERT: con consulta preparada los ? van sin comillas. Si armás el SQL pegando las variables, los textos sí llevan comillas simples, y queda abierto a la inyección SQL.
  • Un comentario de más de 250 caracteres no entra en VARCHAR(250): la base lo rechaza con error. Se puede limitar en el formulario con maxlength="250" en el textarea.
Resultado

procesoForm.php recibe el formulario por $_POST, guarda una fila en comentarios con un INSERT preparado y muestra con qué número quedó. La guía no tiene hoja de resultados.

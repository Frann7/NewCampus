¿Qué es el lenguaje SQL y para qué se utiliza?

✓ RespuestaPara aprender y escribir en la hoja

SQL (Structured Query Language) es el lenguaje que usan casi todos los sistemas de bases de datos relacionales para definir la base (tablas, claves, restricciones) y para manipular sus datos (consultar, agregar, modificar y borrar).

  • Es no procedimental (4ta generación): se dice qué se quiere, no cómo obtenerlo.
  • Trabaja sobre conjuntos de registros: una sentencia afecta a todas las filas que cumplen la condición.
  • Tiene propiedad dual: se usa solo (autocontenido) o embebido en otro lenguaje (huésped).
  • Sus sentencias se dividen en DDL (CREATE, ALTER, DROP) y DML (SELECT, INSERT, UPDATE, DELETE).

Las palabras de la respuesta

  • Relacional: la base guarda los datos en tablas vinculadas por sus claves (lo del 1er parcial).
  • No procedimental: en C habría que leer registro por registro con un bucle; en SQL alcanza con SELECT Nombre FROM Animal WHERE Raza = 'Caniche', y el SGBD decide cómo buscar.
  • Autocontenido / huésped: se ejecuta solo en SQL Server Management Studio, o va adentro de un programa en PHP o C# (el lenguaje anfitrión).

Trampas

  • SQL no es el SGBD: es el lenguaje con el que se le habla. SQL Server, MySQL y Oracle son SGBD.

16. Git: qué es y sus características

Unidad 6 · Git

Defina Git y explique sus características principales. Defina commit, rama (branch), merge y pull request.

✓ RespuestaPara aprender y escribir en la hoja

Git: un sistema de control de versiones distribuido, libre, creado por Linus Torvalds en 2005, para que varias personas trabajen en el mismo proyecto sin pisarse.

  • Distribuido: cada copia es un repositorio completo; se trabaja sin conexión.
  • Instantáneas, no diferencias: cada commit guarda una foto de todos los archivos.
  • Operaciones locales: casi todo se hace sin el servidor, por eso es rápido.
  • Integridad: todo se verifica con un hash SHA-1 (40 caracteres hexadecimales).
  • Solo añade información: lo confirmado es muy difícil de perder.

  • Commit: una captura de los cambios en un momento, con un mensaje.
  • Rama: una versión paralela, para trabajar sin afectar la principal (main).
  • Merge: combinar los cambios de una rama en otra.
  • Pull request: el pedido, en GitHub o GitLab, para que revisen e integren una rama.

Las cinco características, en una línea cada una

  • Distribuido: todos tienen todo.
  • Instantáneas: guarda fotos, no diferencias.
  • Local: no necesita el servidor para casi nada.
  • Integridad: cada cosa tiene su hash; si cambia, Git se entera.
  • Solo añade: lo confirmado no se pierde.

Trampas

  • Git no es GitHub: Git es el sistema; GitHub, la plataforma que aloja el repositorio remoto y donde se hacen los pull requests.
  • El pull request no es un comando de Git: es un pedido en la plataforma.
  • Lo que Git puede perder son los cambios sin confirmar; lo confirmado, no.

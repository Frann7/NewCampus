3. Transacción y ACID

Unidad 1 · Transacción

Defina Transacción en base de datos. Definición y propiedades.

✓ RespuestaPara aprender y escribir en la hoja

Una transacción es un conjunto de operaciones sobre la base que se ejecutan como una sola unidad de trabajo: o se realizan todas, o ninguna. Lleva la base de un estado consistente a otro. Se confirma con COMMIT o se deshace con ROLLBACK.

  • Atomicidad: se ejecuta completa o no se ejecuta nada.
  • Consistencia: deja la base en un estado válido, respetando las restricciones de integridad.
  • Aislamiento: las transacciones simultáneas no se interfieren.
  • Durabilidad: lo confirmado es permanente, aunque falle el sistema.
✎ ExplicaciónUn ejemplo, de dónde sale y las trampas

Para qué existe

Una transferencia son dos UPDATE (restar en una cuenta, sumar en la otra). Si el sistema se cae entre los dos, desaparece la plata. Dentro de una transacción, si el segundo no llega, el primero se deshace.

BEGIN TRAN;
UPDATE Cuenta SET Saldo = Saldo - 1000 WHERE Numero = 10;
UPDATE Cuenta SET Saldo = Saldo + 1000 WHERE Numero = 20;
COMMIT;

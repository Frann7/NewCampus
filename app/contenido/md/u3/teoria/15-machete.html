15. Machete de la unidad

Las operaciones en \(B = \{0, 1\}\)

  • \(x + y = 1\) si al menos uno es 1. \(1 + 1 = 1\).
  • \(xy = 1\) solo si los dos son 1.
  • \(\overline{0} = 1\), \(\overline{1} = 0\). Una barra larga se hace al final de lo que tapa.
  • Suma \(= 0\) ⇒ todos 0. Producto \(= 1\) ⇒ todos 1.

Las leyes

LeyFormaSu dual
L1 Doble complemento\(\overline{\overline{x}} = x\)—
L2 De Morgan\(\overline{x + y} = \overline{x}\,\overline{y}\)\(\overline{xy} = \overline{x} + \overline{y}\)
L3 Conmutativa\(x + y = y + x\)\(xy = yx\)
L4 Asociativa\(x + (y + z) = (x + y) + z\)\(x(yz) = (xy)z\)
L5 Distributiva\(x + yz = (x + y)(x + z)\)\(x(y + z) = xy + xz\)
L6 Idempotencia\(x + x = x\)\(xx = x\)
L7 Identidad\(x + 0 = x\)\(x \cdot 1 = x\)
L8 Inversos\(x + \overline{x} = 1\)\(x\overline{x} = 0\)
L9 Dominación\(x + 1 = 1\)\(x \cdot 0 = 0\)
L10 Absorción\(x + xy = x\)\(x(x + y) = x\)
Útil (sale de L5, L8, L7)\(x + \overline{x}y = x + y\)\(x(\overline{x} + y) = xy\)

Dual: \(+ \leftrightarrow \cdot\) y \(0 \leftrightarrow 1\), sin tocar las barras (y con paréntesis).

Simplificar

De Morgan para sacar barras largas → distribuir → borrar \(x\overline{x}\) y los 0 → absorber → \(x + \overline{x}y = x + y\) → repetidos fuera. Verificar con la tabla.

Los dos trucos sin tabla

  • De una forma a la otra: \(\sum m(L) = \prod M(\text{las filas que no están en } L)\). Con \(f^{-1}(1)\) se tienen los mintérminos; los maxtérminos son las filas que faltan.
  • Evaluar en un punto: pasar el punto a número \(k\). Con \(\prod M\): \(k\) en la lista → 0, si no → 1. Con \(\sum m\): al revés. Justificación: cada \(M_k\) es 0 solo en su fila y el producto es 0 si algún factor lo es.

Ecuaciones

Primero las que fijan valores (suma \(= 0\), producto \(= 1\), \(\overline{E} = 0 \Rightarrow E = 1\)); reemplazar; las que quedan con varias opciones, por casos; listar todas las soluciones y verificarlas.

Conteo

  • Filas de la tabla: \(2^{n}\). Funciones: \(2^{2^{n}}\). Conjunciones fundamentales (o mintérminos): \(2^{n}\).
  • Con filas fijas: \(2^{\text{filas libres}}\). Exactamente \(k\) unos: \(\binom{2^{n}}{k}\). Filas atadas a valer lo mismo: \(2^{\text{grupos}}\).

Nos permite enviar una consulta sobre la base de datos seleccionada y asociada al identificador de conexión pasado como parámetro. mysqli_connect()mysqli_fetch_array()mysqli_query()

Nos devuelve una matriz que corresponde a la fila recuperada y luego mueve el puntero interno hacia adelante. mysqli_connect()mysqli_fetch_array()mysqli_query()

Parcial PHP · preg. 4

Para leer de una base MySQL hay tres pasos: mysqli_connect() abre la conexión y devuelve el identificador de conexión; mysqli_query() manda la consulta SQL por esa conexión; mysqli_fetch_array() saca una fila del resultado como array y avanza el puntero a la siguiente (por eso se usa en un while).

Si dudás entre query y fetch_array: la pista es “fila” y “puntero”, que son de fetch_array.

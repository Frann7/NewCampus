¿Qué patrón de diseño aplica este código?

#include <iostream>
#include <vector>

class Integrante {
public:
    virtual ~Integrante() {}
    virtual int sueldo() const = 0;
};

class Empleado : public Integrante {
private:
    int sueldo_;

public:
    Empleado(int sueldo) : sueldo_(sueldo) {}
    int sueldo() const override { return sueldo_; }
};

class Equipo : public Integrante {
private:
    std::vector<Integrante*> integrantes_;

public:
    void agregar(Integrante* integrante) { integrantes_.push_back(integrante); }
    int sueldo() const override {
        int total = 0;
        for (Integrante* i : integrantes_) {
            total += i->sueldo();
        }
        return total;
    }
};

int main() {
    Empleado ana(900), luis(700);
    Equipo soporte;
    soporte.agregar(&ana);
    soporte.agregar(&luis);
    std::cout << soporte.sueldo() << "\n";
    return 0;
}

Inventada · estilo Parcial 2025, Práctica 2

  • Observer
  • Strategy
  • Composite
  • Facade

Equipo hereda de Integrante y a la vez guarda una lista de Integrante*: una lista de su mismo tipo, así que adentro de un equipo puede haber empleados u otros equipos. Su sueldo() recorre la lista, le pide lo mismo a cada uno y devuelve la suma. Es Composite: Integrante es el componente, Empleado la hoja y Equipo el contenedor. Observer también tiene lista y bucle, pero la lista es de otra interfaz y solo se avisa: no vuelve ningún resultado.

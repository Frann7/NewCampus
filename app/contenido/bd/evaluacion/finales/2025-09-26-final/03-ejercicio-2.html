Ejercicio 2

Unidad 3 · Cabecera y detalle

Ejercicio 2: Utilizando lenguaje SQL, crear las tablas de libros y de pedidos (cabecera y detalle), con sus atributos y claves correspondientes.

✓ ResultadosSolo la respuesta 
CREATE TABLE Libro (
  ISBN         VARCHAR(13)   NOT NULL,
  Titulo       VARCHAR(150)  NOT NULL,
  Autor        VARCHAR(100),
  AnioEdicion  INT,
  Genero       VARCHAR(50),
  CONSTRAINT PK_Libro PRIMARY KEY (ISBN)
);

CREATE TABLE Pedido (
  Numero  INT          NOT NULL,
  Fecha   DATE         NOT NULL,
  Estado  VARCHAR(30)  NOT NULL,
  CUIT    VARCHAR(13)  NOT NULL,
  CONSTRAINT PK_Pedido PRIMARY KEY (Numero),
  CONSTRAINT FK_Pedido_Cliente FOREIGN KEY (CUIT) REFERENCES Cliente(CUIT)
);

CREATE TABLE Pedido_Detalle (
  NumeroPedido    INT            NOT NULL,
  ISBN            VARCHAR(13)    NOT NULL,
  PrecioUnitario  DECIMAL(10,2)  NOT NULL,
  Cantidad        INT            NOT NULL,
  CONSTRAINT PK_Pedido_Detalle PRIMARY KEY (NumeroPedido, ISBN),
  CONSTRAINT FK_Pedido_Detalle_Pedido FOREIGN KEY (NumeroPedido) REFERENCES Pedido(Numero),
  CONSTRAINT FK_Pedido_Detalle_Libro FOREIGN KEY (ISBN) REFERENCES Libro(ISBN)
);

Cliente tiene que estar creada antes que Pedido.

✎ Explicación detalladaLas tres tablas y las decisiones

Qué evalúa

Tres CREATE TABLE (Unidad 3): Libro, la cabecera Pedido y el detalle Pedido_Detalle, con PK compuesta. Es la forma de la práctica "Factura con su detalle".

DecisiónPor qué
ISBN VARCHAR(13)13 caracteres (puede empezar con ceros o tener una X): texto
CUIT VARCHAR(13)Con guiones; mismo tipo que Cliente.CUIT
Estado VARCHAR(30)Entra "Pendiente de entrega"
PRIMARY KEY (NumeroPedido, ISBN)Un renglón por libro en cada pedido
Resolución

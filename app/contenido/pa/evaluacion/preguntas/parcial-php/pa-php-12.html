¿El siguiente código Php es correcto y tiene como salida "INGRESA"?

<?php
$a=true;
if ($a) {
echo "INGRESA";
}
?>

Parcial PHP · preg. 12

  • Si es correcto
  • No, porque es falso por defecto .
  • Emite un error, porque la estructura de control IF no posee condición para evaluar

true es un valor booleano (verdadero; el otro es false), y if (condición) { … } ejecuta lo de las llaves solo si la condición es true.

Es correcto: $a vale true y una variable sola es una condición válida (if ($a) equivale a if ($a == true)), así que imprime INGRESA.

No es “falso por defecto”, porque se le asignó true en la línea anterior; y el if sí tiene condición: $a.

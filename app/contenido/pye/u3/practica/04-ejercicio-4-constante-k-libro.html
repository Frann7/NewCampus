Ejercicio 4 · Constante \(k\) y acumulada

Préstamo de un libro de Programación

Sea \(X\) la cantidad de tiempo en días durante el cual un famoso libro de Programación de la biblioteca de nuestra facultad es ocupado en calidad de préstamo por algún estudiante en las cercanías de un examen parcial y suponga que \(X\) presenta la siguiente función de densidad: \(f(x) = \begin{cases} k\,x & \text{con } 0 \leq x \leq 2 \\ 0 & \text{en c.o.c.} \end{cases}\)

a) Encuentre el valor de la constante \(k\) para que \(f\) sea una función de densidad de probabilidad. b) Grafique \(f\). c) Determine la función de distribución acumulada de probabilidad. Grafique. d) ¿Cuál es la probabilidad de que un estudiante ocupe mencionado libro menos de 36 horas?

Desarme del enunciado

FraseQué significaLa cuentaA dónde va
"tiempo en días"la unidad de \(X\)—todo se pasa a días
"\(0 \leq x \leq 2\)"el préstamo dura entre 0 y 2 días—límites 0 y 2
"menos de 36 horas"pasar a días\(36 / 24 = 1{,}5\)\(P(X < 1{,}5)\)
Inciso a — La constante

Fórmula: \(\displaystyle \int_a^b f(x)\,dx = 1\).

\[ \int_0^2 k\,x\,dx = k\left[\frac{x^2}{2}\right]_0^2 = k\left(\frac{4}{2} - 0\right) = 2k = 1 \quad\Longrightarrow\quad k = \frac{1}{2} \]

Con \(k = \tfrac{1}{2}\), \(f(x) = \tfrac{x}{2} \geq 0\) entre 0 y 2 ✔.

Inciso b — Gráfico de \(f\)

\(f(x) = x/2\): una recta que sube de 0 (en \(x = 0\)) a 1 (en \(x = 2\)); afuera vale 0. Forma un triángulo de área \(2 \cdot 1 / 2 = 1\). Pintada, el área del inciso d.

Inciso c — La acumulada

Fórmula: \(\displaystyle F(x) = \int_{a}^{x} f(t)\,dt\) para \(a \leq x < b\); 0 antes y 1 después.

\[ F(x) = \int_0^x \frac{t}{2}\,dt = \left[\frac{t^2}{4}\right]_0^x = \frac{x^2}{4} \]

\[ F(x) = \begin{cases} 0 & \text{si } x < 0 \\ \dfrac{x^2}{4} & \text{si } 0 \leq x < 2 \\ 1 & \text{si } x \geq 2 \end{cases} \]

Controles: \(F(0) = 0\) y \(F(2) = 4/4 = 1\) ✔. \(F'(x) = \tfrac{2x}{4} = \tfrac{x}{2} = f(x)\) ✔.

\(F(x) = x^2/4\): 0 hasta 0, una curva que sube cada vez más rápido hasta 1 en \(x = 2\), y 1 después.

Inciso d — Menos de 36 horas

36 horas son \(36 / 24 = 1{,}5\) días. Fórmula: \(P(X < c) = F(c)\) (en una continua, \(<\) y \(\leq\) dan lo mismo).

\[ P(X < 1{,}5) = F(1{,}5) = \frac{(1{,}5)^2}{4} = \frac{2{,}25}{4} = 0{,}5625 \]

Respuesta

a) \(k = 1/2\). b) y c) Los gráficos y la \(F\) por tramos de arriba. d) La probabilidad de que un estudiante tenga el libro menos de 36 horas es 0,5625.

Resultados oficiales de la cátedra

a) \(k = 1/2\); c) \(F(x) = x^2/4\) si \(0 \leq x < 2\); d) \(P(X < 1{,}5) = F(1{,}5) = 0{,}5625\)  ✓

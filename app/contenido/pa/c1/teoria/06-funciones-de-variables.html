6. Funciones de variables

Para qué sirve

Como en PHP las variables no declaran su tipo (sección 5), a veces hace falta preguntarle a una variable qué tiene adentro. Para eso están estas funciones. Una función se usa escribiendo su nombre y, entre paréntesis, el dato sobre el que trabaja: gettype($x).

Sintaxis

gettype($variable)     // devuelve el nombre del tipo, como texto
is_string($variable)   // devuelve true o false
var_dump($variable);   // muestra el tipo y el valor

Qué es cada una

FunciónQué hace
gettype()Devuelve el tipo de la variable, como texto: "integer", "double", "string", "boolean", "array", "NULL"...
is_array()Devuelve true si es un array, si no false.
is_bool()true si es booleana.
is_integer()true si es un entero (también existe con el nombre corto is_int()).
is_float()true si es float.
is_object()true si es un objeto.
is_string()true si es un string.
is_resource()true si es algún tipo de recurso.
var_dump()Vuelca (muestra) la información de la variable: su tipo, su valor y, si es un contenedor como un array, su estructura (qué tiene adentro y en qué posición).

Cómo se lee lo que muestra var_dump

MuestraSe lee
int(20)Entero, vale 20.
float(99.9)Float, vale 99,9.
string(4) "Hola"String de 4 caracteres (el número entre paréntesis es el largo), vale "Hola".
bool(false)Booleano, vale falso.
NULLNo tiene valor.
array(2) { ... }Array con 2 elementos; adentro de las llaves, cada posición y su valor.

Ejemplo 1 — Preguntar el tipo con gettype()

<?php
$entero = 25;
$decimal = 2.5;
$texto = "Hola";
$logico = true;
$nada = null;
echo gettype($entero) . "<br>";
echo gettype($decimal) . "<br>";
echo gettype($texto) . "<br>";
echo gettype($logico) . "<br>";
echo gettype($nada);
?>

Qué hace cada línea

LíneaQué haceQué sale
$entero = 25; ... $nada = null;Crea cinco variables, una de cada tipo.—
echo gettype($entero) . "<br>";gettype devuelve el texto "integer"; se le pega un salto de línea y se muestra.integer
echo gettype($decimal) . "<br>";Para un float, gettype devuelve "double" (es el nombre histórico del float).double
echo gettype($texto) . "<br>";Un string.string
echo gettype($logico) . "<br>";Un booleano.boolean
echo gettype($nada);Sin valor.NULL

Qué imprime y por qué

integer
double
string
boolean
NULL

Un renglón por variable gracias a los <br>. Lo único que sorprende es double: así llama gettype al float.

Ejemplo 2 — Con formato del Parcial PHP (preg. 20)

Enunciado

La función var_dump() vuelca información sobre una variable, mostrando su estructura, su tipo y valor. ¿Verdadero o falso?

Para comprobarlo, se le pasan a var_dump cuatro variables distintas:

<?php
$edad = 20;
$precio = 99.90;
$activo = false;
$colores = array("rojo", "verde");
var_dump($edad);
var_dump($precio);
var_dump($activo);
var_dump($colores);
?>

Qué hace cada línea

LíneaQué haceQué muestra
$edad = 20; ... $colores = array(...);Crea un entero, un float, un booleano y un array de dos textos (array(...) arma una lista; se ve en la clase 2).—
var_dump($edad);Tipo y valor.int(20)
var_dump($precio);Tipo y valor. El cero final de 99.90 no cambia el número, así que no se muestra.float(99.9)
var_dump($activo);Tipo y valor. A diferencia de echo, sí muestra el false.bool(false)
var_dump($colores);Tipo, cantidad de elementos y la estructura: cada posición (empiezan en 0) con el tipo y el valor de lo que guarda.el bloque array(2) {...}

Qué imprime y por qué

int(20)
float(99.9)
bool(false)
array(2) {
  [0]=>
  string(4) "rojo"
  [1]=>
  string(5) "verde"
}

Se ve el tipo y el valor de cada una, y en el array además cómo está armado por dentro: eso es lo que el enunciado llama "estructura".

Respuesta

Verdadero. var_dump() muestra tipo, valor y, en los datos compuestos, la estructura.

Errores y trampas

Para ver un booleano, var_dump y no echo 
<?php
$x = 5;
echo is_integer($x);
echo "|";
echo is_string($x);
echo "|";
var_dump(is_string($x));
?>
1||bool(false)

is_integer($x) da true y echo lo muestra como 1; is_string($x) da false y echo no muestra nada (por eso los dos | quedan juntos). var_dump, en cambio, dice bool(false) con todas las letras.

El largo de un string cuenta bytes

var_dump("Año"); muestra string(4) "Año", no 3: la ñ (y las letras con tilde) ocupan 2 bytes en UTF-8, la codificación de los archivos.

En el navegador sale todo en un renglón

var_dump separa con saltos de línea de texto, que el navegador no respeta (sección 3). Para verlo ordenado como arriba se encierra entre echo "<pre>"; y echo "</pre>";, la etiqueta HTML que respeta los saltos de línea.

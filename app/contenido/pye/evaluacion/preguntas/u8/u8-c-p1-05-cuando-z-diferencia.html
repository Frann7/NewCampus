Se quiere un intervalo de confianza para \(\mu_1 - \mu_2\), la diferencia del tiempo medio de ejecución de dos algoritmos (muestras independientes, poblaciones normales). ¿En cuáles casos corresponde usar \(Z\)?

Tercer parcial — primera parte probable (inventada)

  • \(\sigma_1 = 3\) ms y \(\sigma_2 = 4\) ms conocidas, con \(n_1 = 12\) y \(n_2 = 10\).
  • \(\sigma\) desconocidas, \(n_1 = 40\) y \(n_2 = 36\), con \(S_1\) y \(S_2\) de las muestras.
  • \(\sigma\) desconocidas, \(n_1 = 40\) y \(n_2 = 18\), con \(S_1\) y \(S_2\) de las muestras.
  • \(\sigma\) desconocidas, \(n_1 = 15\) y \(n_2 = 20\), con \(S_1\) y \(S_2\) de las muestras.

Para \(\mu_1 - \mu_2\) se usa \(Z\) en dos casos:

  • \(\sigma_1\) y \(\sigma_2\) conocidas, sin importar el tamaño de las muestras.
  • \(\sigma\) desconocidas pero \(n_1 \geq 30\) y \(n_2 \geq 30\): se usa \(Z\) con \(S_1\) y \(S_2\).

Si las \(\sigma\) no se conocen y alguna muestra tiene menos de 30, va \(t\) (pooled o Welch, según la regla \(S^{2}_{mayor}/S^{2}_{menor}\)). Con \(n_2 = 18\) ya alcanza para que sea \(t\).

  • En la diferencia de medias, con \(\sigma_1\) y \(\sigma_2\) conocidas va \(Z\) aunque las muestras sean chicas (así está en el diagrama de la cátedra).
  • Tienen que ser grandes las dos muestras para usar \(Z\) con \(S\): una sola no alcanza.

El control acceso por usuario se denomina a veces, y de forma poco afortunada, como autenticación. La técnica más común para el control de acceso por usuario en un sistema compartido o en un servidor es el registro o conexión de usuario (user log on), se requiere el identificador de usuario (ID) y una contraseña (password).

Verdadero.

Qué evalúa

El control de acceso orientado al usuario (Stallings).

Por qué es verdadero

Es la frase del libro. El control de acceso por usuario a veces se llama "autenticación" (el libro dice que el nombre no es feliz, porque la autenticación es solo una parte). La técnica más común es el inicio de sesión con un ID y una contraseña.

El ID dice quién es y qué privilegios tiene; la contraseña comprueba que sea él. El otro tipo es el control de acceso orientado a los datos (listas de control de acceso, matriz de acceso).

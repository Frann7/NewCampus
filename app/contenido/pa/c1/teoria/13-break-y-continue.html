13. break y continue

Para qué sirve

Un bucle normalmente da todas sus vueltas hasta que la condición se vuelve falsa. A veces hace falta cortarlo antes (break) o saltear una vuelta y seguir con la próxima (continue). Casi siempre van dentro de un if que decide cuándo hacerlo.

Sintaxis

break;      // sale del bucle en el que está
break 2;    // sale de 2 estructuras anidadas (la suya y la de afuera)
continue;   // termina esta vuelta y pasa a la siguiente

Qué es cada parte

SentenciaQué haceQué pasa después
break;Termina el bucle entero en ese momento.Sigue con lo que está después del bucle.
break N;Un número opcional que dice de cuántas estructuras anidadas salir. break 1; es lo mismo que break;.Sigue después de la estructura número N, contando desde adentro.
continue;Saltea lo que queda de esta vuelta.En un for, hace el incremento y vuelve a preguntar la condición: el bucle sigue.

Ejemplo 3 — Con formato del Parcial PHP (preg. 13): break 2

Enunciado

La siguiente afirmación es correcta: en el lenguaje PHP la sentencia break acepta un argumento numérico opcional el cual indica de cuántas estructuras anidadas encerradas se debe salir (ej: break 2). ¿Verdadero o falso?

Para verlo, dos for anidados, idénticos salvo por el break. Primero con break solo:

<?php
for ($i = 1; $i <= 3; $i++) {
    for ($j = 1; $j <= 3; $j++) {
        if ($j == 2) {
            break;
        }
        echo $i . "-" . $j . " ";
    }
}
?>
1-1 2-1 3-1

Y con break 2:

<?php
for ($i = 1; $i <= 3; $i++) {
    for ($j = 1; $j <= 3; $j++) {
        if ($j == 2) {

        }
        echo $i . "-" . $j . " ";
    }
}
?>

Verdadero. El número que sigue a break es opcional e indica de cuántas estructuras anidadas salir.

Ejemplo 4 — El break 2 del apunte

El apunte muestra este código, sin ningún echo:

<?php
for ($i = 0; $i < 10; $i++) {
    for ($j = 0; $j < 3; $j++) {
        if (($j + $i) % 5 == 0) {
            break 2;
        }
    }
}
?>

La condición ($j + $i) % 5 == 0 pregunta si la suma es múltiplo de 5 (el módulo, sección 8). En la primera vuelta, $i = 0 y $j = 0: \(0 + 0 = 0\) y 0 % 5 es 0. ¡Se cumple enseguida! El break 2 corta los dos bucles antes de que hagan nada.

Para que se vea el efecto, el mismo código arrancando $i en 1 y mostrando cada par:

<?php
for ($i = 1; $i < 10; $i++) {
    for ($j = 0; $j < 3; $j++) {
        if (($j + $i) % 5 == 0) {
            break 2;
        }
        echo $i . "-" . $j . " ";
    }
}
echo "<br>";
echo "Salió con i=" . $i . " y j=" . $j;
?>

Con un break solo, en cambio, saldría únicamente del for de $j y $i seguiría con 4, 5... El comentario del apunte ("sale de este ciclo y se saltea el siguiente en 1") quiere decir eso: sale del ciclo de adentro y también del de afuera.

Errores y trampas

break 2 con un solo bucle

Si no hay tantas estructuras para salir, PHP no ejecuta el script:

<?php
for ($i = 1; $i <= 3; $i++) {
    if ($i == 2) {
        break 2;
    }
    echo $i;
}
?>
Fatal error: Cannot 'break' 2 levels in ... on line 4
El switch también cuenta como estructura

Un break dentro de un switch sale del switch, no del bucle que lo rodea. Para cortar el bucle desde adentro de un switch hace falta break 2.

break o continue

break = "no sigo más". continue = "esta no, la próxima sí". En el parcial ponen las dos salidas como opciones (ejemplo 1: la d es lo que daría con break).

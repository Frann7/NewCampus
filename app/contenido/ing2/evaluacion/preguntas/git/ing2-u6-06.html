¿Cuándo aparece un conflicto de merge?

Inventada · Unidad 6, conflictos

  • Siempre que se fusionan dos ramas.
  • Cuando dos ramas cambiaron las mismas líneas del mismo archivo y Git no puede decidir con cuál quedarse.
  • Cuando dos personas editan archivos distintos.
  • Cuando se hace git push sin haber hecho git add.

La fusión es automática mientras los cambios no se pisen: archivos distintos, o zonas distintas del mismo archivo. El conflicto aparece cuando las dos ramas tocaron las mismas líneas (o una borró un archivo que la otra modificó): ahí Git frena y pide que decida una persona.

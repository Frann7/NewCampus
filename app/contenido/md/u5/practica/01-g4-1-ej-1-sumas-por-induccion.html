Grimaldi 4.1 · Ej. 1 · Inducción con sumas

Seis fórmulas de sumas demostradas por inducción

Demuestre lo siguiente mediante inducción matemática.

a) \(1^2 + 3^2 + 5^2 + \cdots + (2n-1)^2 = (n)(2n-1)(2n+1)/3\)

b) \(1 \cdot 3 + 2 \cdot 4 + 3 \cdot 5 + \cdots + n(n+2) = (n)(n+1)(2n+7)/6\)

c) \(\displaystyle\sum_{i=1}^{n} \frac{1}{i(i+1)} = \frac{n}{n+1}\)

d) \(\displaystyle\sum_{i=1}^{n} 2^{i-1} = \sum_{i=0}^{n-1} 2^{i} = 2^n - 1\)

e) \(\displaystyle\sum_{i=1}^{n} i^3 = \frac{n^2(n+1)^2}{4} = \left(\sum_{i=1}^{n} i\right)^2\)

f) \(1^3 + 3^3 + 5^3 + \cdots + (2n-1)^3 = n^2(2n^2 - 1)\)

Qué tema es y por qué
  • Las seis son igualdades que dependen de un entero positivo \(n\): se prueban con el principio de inducción matemática (en la teoría de esta unidad).
  • En todas el truco del paso inductivo es el mismo: la suma hasta \(k+1\) es la suma hasta \(k\) más el último término; la suma hasta \(k\) se cambia por la fórmula (eso es usar la hipótesis) y se hace álgebra hasta llegar a la fórmula con \(k+1\).
Principio de inducción matemática

Sea \(S(n)\) una proposición sobre los enteros \(n \geq n_0\). Si

  1. Base: \(S(n_0)\) es verdadera, y
  2. Paso inductivo: para todo \(k \geq n_0\), suponiendo \(S(k)\) verdadera (la hipótesis inductiva) se deduce \(S(k+1)\),

entonces \(S(n)\) es verdadera para todo \(n \geq n_0\).

Antes de hacer álgebra: escribí la meta

En cada paso inductivo conviene escribir primero qué tiene que dar (la fórmula con \(n = k+1\)). Así sabés hacia dónde factorizar y no te perdés en la cuenta.

Paso 1 — Inciso a: \(\sum (2i-1)^2 = n(2n-1)(2n+1)/3\)

\(S(n)\): \(1^2 + 3^2 + \cdots + (2n-1)^2 = \dfrac{n(2n-1)(2n+1)}{3}\). Meta para \(k+1\): \(\dfrac{(k+1)(2k+1)(2k+3)}{3}\) (se reemplaza \(n\) por \(k+1\): \(2(k+1)-1 = 2k+1\) y \(2(k+1)+1 = 2k+3\)).

RenglónPor qué
\(n = 1\): izquierda \(1^2 = 1\); derecha \(\frac{1 \cdot 1 \cdot 3}{3} = 1\)base: \(S(1)\) es verdadera
\(1^2 + \cdots + (2k-1)^2 = \frac{k(2k-1)(2k+1)}{3}\)hipótesis inductiva \(S(k)\), con \(k \geq 1\)
\(1^2 + \cdots + (2k-1)^2 + (2k+1)^2 = \frac{k(2k-1)(2k+1)}{3} + (2k+1)^2\)la suma hasta \(k+1\) es la suma hasta \(k\) más el término \(2(k+1)-1 = 2k+1\) al cuadrado; se usa la hipótesis
\(= \frac{(2k+1)\,[\,k(2k-1) + 3(2k+1)\,]}{3}\)factor común \(\frac{2k+1}{3}\) (el segundo sumando se escribe \(\frac{3(2k+1)^2}{3}\))
\(= \frac{(2k+1)(2k^2 + 5k + 3)}{3}\)\(2k^2 - k + 6k + 3 = 2k^2 + 5k + 3\)
\(= \frac{(2k+1)(k+1)(2k+3)}{3}\)se factoriza: \((k+1)(2k+3) = 2k^2 + 3k + 2k + 3\) ✓
\(S(k) \Rightarrow S(k+1)\); por inducción vale para todo \(n \in \mathbb{Z}^+\)es la meta, reordenada
Paso 2 — Inciso b: \(\sum i(i+2) = n(n+1)(2n+7)/6\)

Meta para \(k+1\): \(\dfrac{(k+1)(k+2)(2k+9)}{6}\) (porque \(2(k+1)+7 = 2k+9\)).

RenglónPor qué
\(n = 1\): izquierda \(1 \cdot 3 = 3\); derecha \(\frac{1 \cdot 2 \cdot 9}{6} = 3\)base
\(1 \cdot 3 + \cdots + k(k+2) = \frac{k(k+1)(2k+7)}{6}\)hipótesis inductiva
\(\cdots + k(k+2) + (k+1)(k+3) = \frac{k(k+1)(2k+7)}{6} + (k+1)(k+3)\)se agrega el término \(n = k+1\): \((k+1)(k+3)\); se usa la hipótesis
\(= \frac{(k+1)\,[\,k(2k+7) + 6(k+3)\,]}{6}\)factor común \(\frac{k+1}{6}\)
\(= \frac{(k+1)(2k^2 + 13k + 18)}{6}\)\(2k^2 + 7k + 6k + 18\)
\(= \frac{(k+1)(k+2)(2k+9)}{6}\)\((k+2)(2k+9) = 2k^2 + 9k + 4k + 18\) ✓; es la meta
Paso 3 — Inciso c: \(\sum \frac{1}{i(i+1)} = \frac{n}{n+1}\)

Meta para \(k+1\): \(\dfrac{k+1}{k+2}\).

RenglónPor qué
\(n = 1\): \(\frac{1}{1 \cdot 2} = \frac{1}{2} = \frac{1}{1+1}\)base
\(\sum_{i=1}^{k} \frac{1}{i(i+1)} = \frac{k}{k+1}\)hipótesis inductiva
\(\sum_{i=1}^{k+1} \frac{1}{i(i+1)} = \frac{k}{k+1} + \frac{1}{(k+1)(k+2)}\)se separa el último término (\(i = k+1\)) y se usa la hipótesis
\(= \frac{k(k+2) + 1}{(k+1)(k+2)}\)denominador común \((k+1)(k+2)\)
\(= \frac{k^2 + 2k + 1}{(k+1)(k+2)} = \frac{(k+1)^2}{(k+1)(k+2)}\)trinomio cuadrado perfecto
\(= \frac{k+1}{k+2}\)se simplifica \(k+1 \neq 0\); es la meta
Paso 4 — Inciso d: \(\sum 2^{i-1} = 2^n - 1\)

La primera igualdad no necesita inducción: es un cambio de índice. Si se llama \(j = i - 1\), cuando \(i\) va de 1 a \(n\), \(j\) va de 0 a \(n-1\), y \(2^{i-1} = 2^{j}\). Son los mismos sumandos \(1 + 2 + 4 + \cdots + 2^{n-1}\).

Meta para \(k+1\): \(2^{k+1} - 1\).

RenglónPor qué
\(n = 1\): \(2^{0} = 1 = 2^1 - 1\)base
\(\sum_{i=1}^{k} 2^{i-1} = 2^k - 1\)hipótesis inductiva
\(\sum_{i=1}^{k+1} 2^{i-1} = (2^k - 1) + 2^{k}\)último término: \(2^{(k+1)-1} = 2^k\); se usa la hipótesis
\(= 2 \cdot 2^k - 1 = 2^{k+1} - 1\)\(2^k + 2^k = 2 \cdot 2^k\) y propiedad de potencias; es la meta
Paso 5 — Inciso e: \(\sum i^3 = \frac{n^2(n+1)^2}{4}\)

Meta para \(k+1\): \(\dfrac{(k+1)^2(k+2)^2}{4}\).

RenglónPor qué
\(n = 1\): \(1^3 = 1 = \frac{1 \cdot 4}{4}\)base
\(\sum_{i=1}^{k} i^3 = \frac{k^2(k+1)^2}{4}\)hipótesis inductiva
\(\sum_{i=1}^{k+1} i^3 = \frac{k^2(k+1)^2}{4} + (k+1)^3\)se separa el último término y se usa la hipótesis
\(= \frac{(k+1)^2\,[\,k^2 + 4(k+1)\,]}{4}\)factor común \(\frac{(k+1)^2}{4}\)
\(= \frac{(k+1)^2(k^2 + 4k + 4)}{4} = \frac{(k+1)^2(k+2)^2}{4}\)trinomio cuadrado perfecto; es la meta

La segunda igualdad sale de la suma de los primeros \(n\) enteros (en la teoría de esta unidad): \(\sum_{i=1}^{n} i = \frac{n(n+1)}{2}\), y al cuadrado da \(\frac{n^2(n+1)^2}{4}\).

Paso 6 — Inciso f: \(\sum (2i-1)^3 = n^2(2n^2 - 1)\)

Meta para \(k+1\): \((k+1)^2\,(2(k+1)^2 - 1) = (k^2 + 2k + 1)(2k^2 + 4k + 1) = 2k^4 + 8k^3 + 11k^2 + 6k + 1\) (desarrollado, para comparar al final).

RenglónPor qué
\(n = 1\): \(1^3 = 1 = 1^2(2 - 1)\)base
\(1^3 + \cdots + (2k-1)^3 = k^2(2k^2 - 1)\)hipótesis inductiva
\(1^3 + \cdots + (2k+1)^3 = k^2(2k^2 - 1) + (2k+1)^3\)el término \(n = k+1\) es \((2k+1)^3\); se usa la hipótesis
\(= 2k^4 - k^2 + 8k^3 + 12k^2 + 6k + 1\)\((2k+1)^3 = 8k^3 + 12k^2 + 6k + 1\) (cubo de un binomio)
\(= 2k^4 + 8k^3 + 11k^2 + 6k + 1\)se juntan los \(k^2\)
\(= (k+1)^2\,(2(k+1)^2 - 1)\)es la meta desarrollada más arriba
Respuesta

En los seis incisos se verificó la base \(n = 1\) y se probó \(S(k) \Rightarrow S(k+1)\); por el principio de inducción las seis fórmulas valen para todo \(n \in \mathbb{Z}^+\).

Solución del libro

El libro da las demostraciones de b y c, iguales a las de arriba (en b llega a \((k+1)(2k^2 + 13k + 18)/6 = (k+1)(k+2)(2k+9)/6\)). De a, d, e y f no da solución; verificación propia: Python comprobó las seis igualdades para \(n = 1, \dots, 29\).

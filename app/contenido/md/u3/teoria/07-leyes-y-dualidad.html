Las herramientas para simplificar

7. Leyes de las funciones booleanas y dualidad

Para qué sirve

Son las mismas diez leyes de la sección 2, ahora escritas con \(+\), \(\cdot\), la barra, 0 y 1. Valen para variables (\(x, y, z\)) y para funciones enteras (\(f, g, h\)). Son las únicas "reglas de juego" permitidas para transformar una expresión en otra igual: simplificar (sección 8) y pasar a las formas normales (secciones 9 y 10) es aplicarlas una detrás de otra, diciendo cuál se usó en cada renglón.

La distributiva rara: \(x + yz = (x + y)(x + z)\)

En los números, la suma no se distribuye sobre el producto (\(2 + 3 \cdot 4 \neq (2 + 3)(2 + 4)\)). En Boole sí. Es la que permite pasar de una suma a un producto, y se usa para la f.n.c. (sección 10). Comprobación con la tabla (las 8 filas):

Dualidad

En cada ley hay una propiedad \(s\) y su dual \(s^{d}\), que sale de \(s\) haciendo estos cambios a la vez:

Cómo se arma el dual \(s^{d}\)

\[ + \;\longleftrightarrow\; \cdot \qquad\qquad 0 \;\longleftrightarrow\; 1 \]

Las variables y las barras quedan como están.

Principio de dualidad: si \(s\) es una igualdad verdadera (un teorema), \(s^{d}\) también lo es. Por eso alcanza con demostrar una de las dos mitades de cada ley.

Cuidado con los paréntesis al cambiar \(\cdot\) por \(+\)

El producto se hace antes que la suma, así que al dualizar hay que agregar paréntesis para que se conserve el orden: el dual de \(x + yz\) es \(x(y + z)\), no \(x \cdot y + z\).

Demostración de la absorción (la pide la guía complementaria)

Se demuestra con las otras leyes, renglón por renglón:

RenglónQué ley se usó
\(x + xy = x \cdot 1 + xy\)L7, identidad: \(x = x \cdot 1\)
\(= x(1 + y)\)L5, distributiva (sacar \(x\) factor común)
\(= x(y + 1)\)L3, conmutativa de \(+\)
\(= x \cdot 1\)L9, dominación: \(y + 1 = 1\)
\(= x\)L7, identidad

La otra mitad, \(x(x + y) = x\), es la dual. Se puede usar el principio de dualidad, o hacerla directa:

RenglónQué ley se usó
\(x(x + y) = xx + xy\)L5, distributiva
\(= x + xy\)L6, idempotencia: \(xx = x\)
\(= x\)L10, la absorción recién demostrada

Por tabla también sale: \(x + xy\) y \(x(x + y)\) dan las dos \(0, 0, 1, 1\) en las filas \(00, 01, 10, 11\), igual que \(x\). La idea: si \(x = 1\), los dos lados dan 1; si \(x = 0\), \(xy\) es 0 y los dos lados dan 0. El valor de \(y\) no importa.

Ejemplo 1 — Escribir el dual

Enunciado

Escribir el dual de \(x + 0 = x\) y de \(x + \overline{x}y = x + y\).

Desarme del enunciado

FraseQué significaLa cuentaA dónde va
"\(x + 0\)"\(+\) pasa a \(\cdot\), 0 pasa a 1—\(x \cdot 1\)
"\(x + \overline{x}y\)"la suma pasa a producto, el producto pasa a suma (con paréntesis)—\(x(\overline{x} + y)\)
"\(x + y\)"la suma pasa a producto—\(xy\)
Respuesta

\((x + 0 = x)^{d}\) es \(x \cdot 1 = x\) (la otra mitad de L7). \((x + \overline{x}y = x + y)^{d}\) es \(x(\overline{x} + y) = xy\).

Ejemplo 2 — Estilo parcial: una ley "extra" muy útil y su dual (guía, Boole 2 g)

Enunciado

Demostrar \(x + \overline{x}y = x + y\), y deducir su dual.

Desarme del enunciado

FraseQué significaLa cuentaA dónde va
"\(x + \overline{x}y\)"una suma con un producto adentroconviene la distributiva rarapasarla a producto
"deducir su dual"principio de dualidadcambiar \(+ \leftrightarrow \cdot\)\(x(\overline{x} + y) = xy\)
RenglónQué ley se usó
\(x + \overline{x}y = (x + \overline{x})(x + y)\)L5, distributiva de \(+\) sobre \(\cdot\)
\(= 1 \cdot (x + y)\)L8, inversos: \(x + \overline{x} = 1\)
\(= x + y\)L7, identidad (y L3 para dar vuelta el producto)

El dual, directo: \(x(\overline{x} + y) = x\overline{x} + xy = 0 + xy = xy\) (L5, L8, L7).

Respuesta

\(x + \overline{x}y = x + y\) y su dual \(x(\overline{x} + y) = xy\). Las dos se comprobaron también con la tabla. En palabras: "si ya está \(x\) sumando, la barra de \(x\) que acompaña a \(y\) sobra".

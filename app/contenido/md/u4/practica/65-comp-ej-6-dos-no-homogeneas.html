Complementaria P2 · Recurrencia · Ej. 6 · No homogéneas

Una de segundo orden con constante y una de primer orden con \(5n\)

Resolver las siguientes ecuaciones de recurrencia:

a. \(a_{n+2} - 6a_{n+1} + 9a_n = 50,\ \forall n \geq 0,\ a_0 = 0,\ a_1 = 1\)

b. \(a_{n+1} - a_n = 5n,\ \forall n \geq 0,\ a_0 = 1\)

Qué tema es y por qué
  • a) Segundo orden con una constante del lado derecho; b) primer orden con un polinomio de grado 1. Las dos son no homogéneas.
  • Método de coeficientes indeterminados (en la teoría de esta unidad).
El método (se repite en cada inciso)

1. \(a_n = a_n^{(h)} + a_n^{(p)}\), con las constantes de \(a_n^{(h)}\) calculadas al final.

2. Particular según \(g(n)\): constante \(\to A\); polinomio de grado 1 \(\to An + B\).

3. Una constante choca con la homogénea solo si \(r = 1\) es raíz; entonces se multiplica por \(n\).

Paso 1 — Inciso a): homogénea

\(r^{2} - 6r + 9 = (r - 3)^{2} = 0\): raíz doble 3. \(\ a_n^{(h)} = (C_1 + C_2 n)\,3^{n}\).

Paso 2 — Inciso a): particular

\(g(n) = 50\), constante \(\to a_n^{(p)} = A\). No choca: 1 no es raíz.

Reemplazando: \(A - 6A + 9A = 4A = 50 \Rightarrow A = \tfrac{25}{2}\).

Paso 3 — Inciso a): constantes

\(a_n = (C_1 + C_2 n)3^{n} + \tfrac{25}{2}\):

\[ \left\{\begin{array}{l} n = 0:\ C_1 + \tfrac{25}{2} = 0 \Rightarrow C_1 = -\tfrac{25}{2} \\ n = 1:\ 3(C_1 + C_2) + \tfrac{25}{2} = 1 \Rightarrow -\tfrac{75}{2} + 3C_2 = -\tfrac{23}{2} \Rightarrow 3C_2 = 26 \Rightarrow C_2 = \tfrac{26}{3} \end{array}\right. \]

\[ a_n = \left(-\frac{25}{2} + \frac{26}{3}\,n\right)3^{n} + \frac{25}{2},\ \forall n \geq 0 \]

Comprobación: con la relación, \(a_2 = 50 + 6 \cdot 1 - 9 \cdot 0 = 56\), \(a_3 = 50 + 6 \cdot 56 - 9 \cdot 1 = 377\). Con la fórmula, \(a_2 = \left(-\tfrac{25}{2} + \tfrac{52}{3}\right)9 + \tfrac{25}{2} = \tfrac{29}{6} \cdot 9 + \tfrac{25}{2} = 56\); \(a_3 = \left(-\tfrac{25}{2} + 26\right)27 + \tfrac{25}{2} = \tfrac{27}{2} \cdot 27 + \tfrac{25}{2} = 377\). Coinciden.

Paso 4 — Inciso b)
  • Homogénea \(a_{n+1} = a_n\): \(a_n^{(h)} = C\).
  • \(g(n) = 5n\) \(\to An + B\), pero \(B\) choca con \(C\) (1 es raíz): \(a_n^{(p)} = An^{2} + Bn\).
  • Reemplazando: \(A(n+1)^{2} + B(n+1) - An^{2} - Bn = 2An + A + B = 5n\). Entonces \(2A = 5 \Rightarrow A = \tfrac52\) y \(A + B = 0 \Rightarrow B = -\tfrac52\).
  • Completa: \(a_n = C + \tfrac52 n^{2} - \tfrac52 n\). Con \(a_0 = 1\): \(C = 1\).

\[ a_n = 1 + \frac{5n(n - 1)}{2},\ \forall n \geq 0 \]

Comprobación: relación \(1, 1, 6, 16, 31, 51\); fórmula \(1 + 0,\ 1 + 0,\ 1 + 5,\ 1 + 15,\ 1 + 30,\ 1 + 50\). Coinciden.

Respuesta

a) \(a_n = \left(-\tfrac{25}{2} + \tfrac{26}{3}n\right)3^{n} + \tfrac{25}{2}\)   b) \(a_n = 1 + \tfrac{5n(n-1)}{2}\), para \(n \geq 0\).

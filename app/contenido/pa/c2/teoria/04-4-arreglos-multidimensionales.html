Arreglos

4. Arreglos multidimensionales

Para qué sirve

Un arreglo puede guardar cualquier tipo de dato, incluso otro arreglo. Cuando el valor de un elemento es un arreglo, se habla de arreglo multidimensional:

  • Un arreglo de arreglos es como una tabla (filas y columnas): por ejemplo, una lista de personas donde cada persona es un arreglo con sus datos.
  • PHP permite anidar todos los niveles que hagan falta.

Sintaxis

Crear y leer 
$tabla = array();
$tabla[] = array(valor, valor);      // la fila 0 es un arreglo
$tabla[] = array(valor, valor);      // la fila 1 es otro arreglo

echo $tabla[fila][columna];

Qué es cada parte

ParteQué es
$tabla[] = array(...);Agrega al final de $tabla un elemento cuyo valor es un arreglo entero
$tabla[fila]El primer par de corchetes elige un elemento de afuera: devuelve un arreglo
$tabla[fila][columna]El segundo par de corchetes elige un elemento dentro de ese arreglo: devuelve el valor

La cátedra lo dice así: bastará con ir indicando las claves hasta llegar al valor que queremos recuperar. Se leen de izquierda a derecha, de afuera hacia adentro.

Ejemplo 1 — "chauestas" (teoría de la cátedra)

Enunciado

¿Cuál es la salida del siguiente script?

<?php
$array = array();
$array[] = array('hola', 'chau');
$array[] = array('estas', 'como');
echo $array[0][1] . $array[1][0];
?>
LíneaQué haceCómo quedan las variables
$array = array();Crea un arreglo vacío$array: (vacío)
$array[] = array('hola', 'chau');Agrega en la clave 0 un arreglo de dos textos0 => (0 => hola · 1 => chau)
$array[] = array('estas', 'como');Agrega en la clave 1 otro arreglo0 => (hola, chau) · 1 => (0 => estas · 1 => como)
echo $array[0][1] . $array[1][0];$array[0] es ('hola','chau') y su [1] es chau. $array[1] es ('estas','como') y su [0] es estas. El . los pega sin espacio(no cambia nada)

Ejemplo 2 — Una lista de personas (presentación de la cátedra)

<?php
$personas = array();

$persona2 = array('documento' => 11222333, 'apellido' => 'Aramburu', 'nombres' => 'Exequiel');
$personas[] = $persona1;
$personas[] = $persona2;

$personas[] = $persona2;Guarda una copia de $persona2 en la clave 1$personas: 0 => (Bonnet) · 1 => (Aramburu)

Errores y trampas

Un espacio adentro de la clave cambia la clave

En la presentación, la clave está escrita ' nombres', con un espacio adelante. Esa es otra clave: $persona1['nombres'] da Warning: Undefined array key "nombres". Acá se escribió sin el espacio. Además, la diapositiva dibuja la salida de print_r con comillas y flechas ('documento'=>11222333), que no es como imprime PHP: la salida real es la de arriba.

Un solo par de corchetes devuelve un arreglo

echo $personas[1]; no muestra los datos: imprime Array con un aviso (sección 2). Hace falta el segundo par de corchetes para llegar a un valor.

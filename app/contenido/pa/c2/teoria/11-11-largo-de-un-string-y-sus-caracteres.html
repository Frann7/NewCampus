Strings

11. El largo de un string y sus caracteres: strlen y $cadena[i]

Para qué sirve

  • strlen() (string length) dice cuánto mide un string. Se usa para validar (que una clave tenga 8 caracteres) o para recorrerlo.
  • Un string se puede tratar como un arreglo de caracteres: $cadena[0] es el primero, $cadena[1] el segundo, y así.

Sintaxis

Largo y un carácter 
strlen($cadena)     // devuelve un número
$cadena[posicion]   // devuelve un string de un carácter

Qué es cada parte

ParteQué es
strlen($cadena)La longitud en bytes. Cuenta todo: letras, espacios, signos, números
$cadena[posicion]El carácter en esa posición. La primera posición es 0, igual que en los arreglos
Última posiciónstrlen($cadena) - 1 (en textos sin tildes)
Bytes y caracteres: por qué las tildes cuentan doble

La cátedra dice que strlen() mide la longitud en bytes. Un byte es la unidad de memoria donde se guarda un carácter. Los archivos PHP se guardan en la codificación UTF-8, donde:

  • las letras sin tilde, los números, el espacio y los signos comunes ocupan 1 byte;
  • á é í ó ú ñ y sus mayúsculas ocupan 2 bytes;
  • otros símbolos, como la raya –, ocupan 3 bytes.

Por eso strlen('Martín') da 7 y no 6. Esto importa en la práctica (ejercicios 9 y 10).

Ejemplo 4 — Recorrer un string con for (teoría de la cátedra)

<?php
$cadena = "La cadena a mostrar.";
for ($i = 0; $i < strlen($cadena); $i++) {
    if ($cadena[$i] > 'c') {
        echo $cadena[$i];
    }
}
?>

La comparación $cadena[$i] > 'c' compara códigos de carácter: cada carácter tiene un número, y en ese orden van primero el espacio y los signos, después las mayúsculas y al final las minúsculas (a < b < c < d…). Entonces > 'c' deja pasar solo las minúsculas de la d a la z.

Errores y trampas

$cadena[i] con tildes da medio carácter

Como la í de 'Martín' ocupa 2 bytes (posiciones 4 y 5), $m[4] devuelve solo el primer byte, que no es un carácter válido: el navegador muestra �. La posición, como strlen(), cuenta bytes.

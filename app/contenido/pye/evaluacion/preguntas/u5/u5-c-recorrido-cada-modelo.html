Elija los valores que puede tomar \(X\) en cada caso.

\(X \sim\) Binomial con \(n = 6\) y \(p = 0{,}3\): 0, 1, ..., 61, 2, ..., 60, 1, 2, ... sin tope0, 1, 2, 3

\(X \sim\) Poisson con \(\lambda t = 3\): 0, 1, 2, 31, 2, 3, ... sin tope0, 1, 2, ... sin tope0, 1, ..., 6

\(X\) = cantidad de ensayos hasta el primer éxito (geométrica): 0, 1, 2, ... sin tope1, 2, 3, ... sin tope0, 11, 2, ..., n

\(X \sim\) Hipergeométrica con \(N = 10\), \(k = 3\), \(n = 5\): 0, 1, ..., 50, 1, 2, 32, 3, 4, 50, 1, ..., 10

Teoría de la Unidad 5 (recorrido de cada modelo) · tema ★ del Segundo Parcial 2023, Ej. 4 a (“para qué valores de X es válida”)

  • Binomial: de 0 éxitos a los \(n = 6\) ensayos.
  • Poisson: 0, 1, 2, ... sin tope: no hay un número fijo de ensayos que la limite.
  • Geométrica: arranca en 1, porque el primer éxito ocurre, como pronto, en el primer ensayo. Nunca vale 0.
  • Hipergeométrica: va de \(\max(0,\; n - (N - k))\) a \(\min(n, k)\). Hay 7 fracasos, así que con \(n = 5\) puede no salir ningún éxito (mínimo 0); y solo hay 3 éxitos en la población, así que el máximo es 3 aunque se saquen 5.

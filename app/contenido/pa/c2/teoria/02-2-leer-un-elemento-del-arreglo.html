Arreglos

2. Leer un elemento: indexados y asociativos

Para qué sirve

Para usar un dato del arreglo (mostrarlo, hacer una cuenta) hay que decirle a PHP cuál: se escribe el nombre del arreglo y, entre corchetes, la clave del elemento. PHP busca esa clave y devuelve su valor.

Sintaxis

Leer un elemento 
echo $arreglo[clave];

Qué es cada parte

ParteQué es
$arregloEl nombre del arreglo, con su $ como cualquier variable
[clave]La clave del elemento que querés. Si es un número va sola ([1]); si es texto, entre comillas (['negro'])
echoMuestra el valor que está guardado en esa clave (nunca la clave)
La regla que resuelve las dos preguntas del parcial

Lo que va entre corchetes siempre es una clave, y lo que sale por pantalla siempre es el valor de esa clave. Para responder: buscá la clave en la columna de la izquierda (la de antes de =>) y leé lo que tiene a la derecha.

Ejemplo 1 — Arreglo indexado (preg. 8 del parcial)

Enunciado (Parcial PHP, pregunta 8)

¿Cuál es la salida del siguiente script PHP? a. Domingo · b. Lunes · c. Ninguno de los anteriores · d. Hola mundo!! · e. Martes

<?php
$dias_semana = array('Domingo', 'Lunes', 'Martes', 'Miércoles', 'Jueves',
'Viernes', 'Sábado');
echo $dias_semana[1];
?>

Qué hace cada línea

LíneaQué haceCómo quedan las variables
$dias_semana = array(...);Crea un arreglo con 7 valores y sin claves escritas: PHP numera desde 0 (sección 1)0 => Domingo · 1 => Lunes · 2 => Martes · 3 => Miércoles · 4 => Jueves · 5 => Viernes · 6 => Sábado
echo $dias_semana[1];Busca la clave 1 y muestra su valor(no cambia nada)
Lunes
Respuesta: b. Lunes

La clave 1 es el segundo elemento, porque el primero (Domingo) tiene la clave 0. La opción "a. Domingo" es la trampa de quien cuenta desde 1.

Ejemplo 2 — Arreglo asociativo (preg. 2 del parcial)

Enunciado (Parcial PHP, pregunta 2)

¿Cuál es la salida del siguiente script PHP? a. negro · b. dorado · c. Ninguna de las anteriores · d. Carbón

<?php
$mineral = array(
'dorado' => 'negro',
'plateado' => 'Plata',
'brillante' => 'Diamante',
'negro' => 'Carbón'
);
echo $mineral['negro'];
?>

Qué hace cada línea

LíneaQué haceCómo quedan las variables
$mineral = array(...);Crea un arreglo asociativo de 4 elementos. A la izquierda de cada => está la clave; a la derecha, el valordorado => negro · plateado => Plata · brillante => Diamante · negro => Carbón
echo $mineral['negro'];Busca la clave 'negro' (la cuarta fila) y muestra su valor(no cambia nada)
Carbón
Respuesta: d. Carbón

La palabra 'negro' aparece dos veces: como valor de la clave 'dorado' y como clave de 'Carbón'. Entre corchetes siempre va una clave, así que PHP usa la segunda. Las opciones "a. negro" y "b. dorado" son las trampas de quien busca 'negro' entre los valores.

Ejemplo 3 — Usar el valor en un texto

<?php
$persona = array('documento' => 22444555, 'apellido' => 'Gomez', 'nombre' => 'Martín');
echo $persona['apellido'] . ', ' . $persona['nombre'];
?>
LíneaQué haceCómo quedan las variables
$persona = array(...);Arreglo asociativo con tres datos de una personadocumento => 22444555 · apellido => Gomez · nombre => Martín
echo ... . ', ' . ...;Lee dos elementos y los une con el operador de concatenación . (Clase 1), con una coma y un espacio en el medio(no cambia nada)
Gomez, Martín

Errores y trampas

Una clave que no existe no muestra nada (y avisa)

echo $dias_semana[7]; no da error fatal: muestra un aviso Warning: Undefined array key 7 y no imprime ningún valor. Con 7 días, la última clave es la 6.

Las claves de texto distinguen mayúsculas

$mineral['Negro'] no es lo mismo que $mineral['negro']: da Warning: Undefined array key "Negro".

echo del arreglo entero no lo muestra

echo $dias_semana; (sin corchetes) imprime solo la palabra Array y el aviso Warning: Array to string conversion. Para ver todo el arreglo se usa print_r() o var_dump() (sección 3).

Error de tipeo en la presentación de la cátedra

La diapositiva crea $colores pero hace echo $color[2]; (sin la s). Así no imprime verde: PHP avisa Warning: Undefined variable $color y no muestra nada. Con echo $colores[2]; sí sale verde.

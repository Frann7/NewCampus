Arreglos

3. Mostrar el arreglo entero: print_r y var_dump

Para qué sirve

echo muestra un valor por vez (sección 2). Para ver todo el arreglo de un saque, con sus claves, PHP trae dos funciones pensadas para depurar (revisar qué tiene una variable mientras programás):

  • print_r(): muestra cada clave con su valor. Lectura rápida.
  • var_dump(): muestra lo mismo y además el tipo y el tamaño de cada dato.

La cátedra lo resume así: echo sirve para presentar datos en pantalla, print_r() para depurar arreglos.

Sintaxis

Las dos funciones 
print_r($variable);
var_dump($variable);

Qué es cada parte

var_dump($colores);

Por qué:

  • print_r abre con Array y lista [clave] => valor.
  • var_dump abre con array(3) porque hay 3 elementos, y debajo de cada clave pone el tipo (string), el largo (rojo tiene 4 letras, verde 5) y el valor entre comillas.

Ejemplo 3 — Por qué var_dump dice más (formato del parcial)

Enunciado (Parcial PHP, pregunta 20)

Verdadero o falso: "La función var_dump(), vuelca información sobre una variable, mostrando su estructura, su tipo y valor."

Para verlo, un arreglo con un dato de cada tipo, impreso con las dos funciones:

<?php
$mezcla = array(10, 'diez', 10.5, true, null, false);
print_r($mezcla);
var_dump($mezcla);
?>
LíneaQué haceCómo quedan las variables

print_r($mezcla);Imprime claves y valores(no cambia nada)

Por qué:

  • print_r muestra true como 1, y null y false como nada: las claves 4 y 5 parecen iguales y no se sabe qué tienen.
  • var_dump dice exactamente qué es cada cosa: int, string, float, bool, NULL. Esa es su "estructura, tipo y valor".
Respuesta: Verdadero

var_dump() muestra la estructura (cuántos elementos y qué claves), el tipo y el valor de cada dato. Es la diferencia con print_r(), que no muestra tipos.

Errores y trampas

En el navegador sale todo en una línea

El navegador junta los saltos de línea y los espacios del texto (HTML los ignora), así que el print_r del ejemplo 1 se ve Array ( [0] => rojo [1] => azul [2] => verde ). Para verlo con sangría se lo encierra en la etiqueta <pre>, que respeta el texto tal cual: 

echo '<pre>';
print_r($colores);
echo '</pre>';
string(n) cuenta bytes, no letras

var_dump('Miércoles') muestra string(10) aunque la palabra tiene 9 letras: la é ocupa 2 bytes. Se explica en la sección 11.

Error de tipeo en la presentación de la cátedra

Las diapositivas crean $colores y después llaman a print_r($color) y var_dump($color). Con ese nombre no muestran el arreglo (avisan Undefined variable $color); la salida que dibujan es la de $colores.

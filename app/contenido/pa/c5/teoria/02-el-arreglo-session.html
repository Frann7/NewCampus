Sesiones

2. $_SESSION: guardar datos y leerlos desde otro script

Para qué sirve

Además de identificar al navegador, session_start() deja listo un arreglo llamado $_SESSION. Lo que guardes ahí se conserva entre una página y otra: lo guardás en un script y lo leés en cualquier otro, mientras sea el mismo navegador y la sesión siga viva.

Es un array asociativo (Clase 2): un arreglo donde cada valor se busca por una clave de texto en vez de por un número de posición. En $_SESSION['nombre'], la clave es 'nombre'.

Sintaxis

Guardar y leer 
session_start();                    // siempre primero
$_SESSION['clave'] = valor;         // guardar (o pisar, si la clave ya existía)
echo $_SESSION['clave'];            // leer, en este script o en otro

Qué es cada parte

ParteQué es
$_SESSIONEl arreglo de la sesión. Lo crea session_start() y se llena con lo que había guardado en el archivo del servidor.
'clave'El nombre del dato, entre comillas. Lo elegís vos ('usuario', 'token'...).
valorLo que se guarda: un texto, un número o incluso un arreglo entero.
Cuándo se grabaAl terminar el script, PHP escribe todo $_SESSION en el archivo sess_<id>. En el próximo session_start() lo vuelve a leer.

$_SESSION al lado de $_GET y $_POST

Los tres son arrays asociativos que PHP llena solo (se los llama superglobales: existen en cualquier parte del script). La diferencia es de dónde salen los datos:

ArregloDe dónde salen los datosQuién los escribe
$_GETDe los parámetros de la URL: pagina.php?color=rojoEl navegador, en cada pedido (Clase 3)
$_POSTDe un formulario enviado con method="post"El navegador, en cada pedido (Clase 3)
$_SESSIONDel archivo de sesión que está en el servidorTu script; el navegador solo manda el id

Esa última columna es la clave de la clase: lo que hay en $_GET y $_POST lo puede escribir cualquiera que mande un pedido; lo que hay en $_SESSION solo lo escribe tu código, y el navegador nunca lo ve. Por eso, en las secciones 5 y 6, el código secreto se guarda en la sesión.

Ejemplo 1 — Guardar en index.php y leer en home.php (el de la cátedra)

Enunciado

Desde un navegador se abre primero index.php y después home.php. ¿Qué muestra home.php?

index.php:

<?php
session_start();                    // creamos la sesión
$_SESSION['nombre'] = 'Federico';   // guardamos el nombre
$_SESSION['apellido'] = 'Bonnet';   // guardamos el apellido
?>

home.php:

<?php
session_start();                    // recuperamos la sesión del script anterior
echo $_SESSION['nombre'];           // mostramos lo que guardó index.php
echo $_SESSION['apellido'];
?>

Qué hace cada línea

Archivo y líneaQué haceCómo queda $_SESSION
index.php: session_start();Primera visita: crea la sesión y manda la cookie PHPSESSID.[] (vacío)
$_SESSION['nombre'] = 'Federico';Guarda 'Federico' con la clave 'nombre'.['nombre' => 'Federico']
$_SESSION['apellido'] = 'Bonnet';Guarda 'Bonnet' con la clave 'apellido'. Al terminar el script, todo se graba en el archivo.['nombre' => 'Federico', 'apellido' => 'Bonnet']
home.php: session_start();El navegador mandó la cookie: PHP abre el mismo archivo y llena $_SESSION con lo guardado.['nombre' => 'Federico', 'apellido' => 'Bonnet']
echo $_SESSION['nombre'];Imprime Federico.sin cambios
echo $_SESSION['apellido'];Imprime Bonnet, pegado a lo anterior.sin cambios

Qué imprime y por qué

FedericoBonnet
  • home.php nunca asignó esos valores: los recuperó de la sesión.
  • Sale todo junto porque ningún echo agrega un espacio. Para separarlo: echo $_SESSION['nombre'] . ' ' . $_SESSION['apellido'];
  • Así quedó el archivo de sesión en el servidor (se abrió en la prueba): nombre|s:8:"Federico";apellido|s:6:"Bonnet";. Es $_SESSION escrito como texto: cada clave, su tipo (s = string, texto), su largo y su valor.
  • Si home.php lo abre otro navegador, que nunca pasó por index.php, su sesión está vacía y $_SESSION['nombre'] no existe. Cada navegador tiene sus datos.
Errata del PDF

En el PDF dice $_SESSION['nombre] = 'Federico';, con la comilla de la clave sin cerrar. Así no corre: PHP da Parse error: syntax error, unexpected identifier "Federico", expecting "]". La clave va entre dos comillas: ['nombre'].

Ejemplo 2 — ¿Cuál es la salida? (un arreglo dentro de la sesión)

Enunciado

¿Cuál es la salida del siguiente script PHP?

<?php
session_start();
$_SESSION['usuario'] = 'fedebonnet';
$_SESSION['datos'] = array('apellido' => 'Bonnet', 'area' => 'Recursos Humanos');
echo count($_SESSION) . ' ';
echo $_SESSION['datos']['area'];
?>

Qué hace cada línea

LíneaQué haceCómo queda $_SESSION
session_start();Abre la sesión (suponemos que es nueva, vacía).[]
$_SESSION['usuario'] = 'fedebonnet';Guarda un texto.1 elemento: 'usuario'
$_SESSION['datos'] = array(...);Guarda un arreglo entero en una sola clave. Adentro tiene dos datos, pero para $_SESSION es un solo elemento.2 elementos: 'usuario' y 'datos'
echo count($_SESSION) . ' ';count() (Clase 2) cuenta los elementos del arreglo: son 2. Imprime 2 y un espacio.sin cambios
echo $_SESSION['datos']['area'];Dos claves seguidas: ['datos'] da el arreglo de adentro y ['area'] busca en él. Imprime Recursos Humanos.sin cambios

Qué imprime y por qué

2 Recursos Humanos

La trampa es el 2: count() cuenta las claves de primer nivel ('usuario' y 'datos'), no los datos que hay adentro del arreglo guardado.

Ejemplo 3 — ¿Cuál es la salida? (recorrer la sesión con foreach)

Enunciado

¿Cuál es la salida del siguiente script PHP, si la sesión empieza vacía?

<?php
session_start();
$_SESSION['usuario'] = 'fedebonnet';
$_SESSION['area'] = 'RRHH';
$_SESSION['usuario'] = 'fran';
foreach ($_SESSION as $clave => $valor) {
    echo $clave . '=' . $valor . ' ';
}
?>

Qué hace cada línea

LíneaQué haceCómo queda $_SESSION
$_SESSION['usuario'] = 'fedebonnet';Crea la clave 'usuario'.['usuario' => 'fedebonnet']
$_SESSION['area'] = 'RRHH';Crea la clave 'area', después de la anterior.['usuario' => 'fedebonnet', 'area' => 'RRHH']
$_SESSION['usuario'] = 'fran';La clave ya existía: pisa el valor, no agrega otra. La clave conserva su lugar (primera).['usuario' => 'fran', 'area' => 'RRHH']
foreach (... as $clave => $valor)Recorre el arreglo en orden (Clase 2). Vuelta 1: $clave = 'usuario', $valor = 'fran'. Vuelta 2: $clave = 'area', $valor = 'RRHH'.sin cambios
echo $clave . '=' . $valor . ' ';En cada vuelta imprime clave=valor y un espacio.sin cambios

Qué imprime y por qué

usuario=fran area=RRHH

fedebonnet no aparece porque la tercera línea lo pisó. Esto mismo hacen pagina1.php y pagina2.php de la cátedra para mostrar la sesión en una tabla (están explicados en la pestaña Práctica).

Ejemplo 4 — Emparejar las definiciones (formato del parcial)

Enunciado (Parcial PHP, pregunta 7)

Indique la correcta opción para cada definición:

  • Es un array asociativo que contiene variables de sesión disponibles para el script actual.
  • Es un array asociativo de variables pasado al script actual vía parámetros URL.
  • Es un array asociativo de variables pasadas al script actual a través del método HTTP POST.

Opciones: $_SESSION, $_GET, $_POST.

Cómo se resuelve

Se busca en cada definición la palabra que dice de dónde salen los datos:

Frase de la definiciónQué significaRespuesta
"variables de sesión"los datos guardados en la sesión del servidor$_SESSION
"vía parámetros URL"lo que va después del ? en la dirección$_GET
"método HTTP POST"lo que manda un formulario con method="post"$_POST

Los tres en un mismo script

Para verlo funcionando: el formulario manda nombre=Ana por POST a tres.php?color=rojo. 

<?php
session_start();
$_SESSION['usuario'] = 'fedebonnet';
echo $_GET['color'] . ' / ' . $_POST['nombre'] . ' / ' . $_SESSION['usuario'];
?>
ExpresiónDe dónde saleValor
$_GET['color']la URL: ?color=rojorojo
$_POST['nombre']el cuerpo del pedido POSTAna
$_SESSION['usuario']la sesión, que acaba de escribir el propio scriptfedebonnet
rojo / Ana / fedebonnet
Respuesta

Variables de sesión → $_SESSION. Parámetros URL → $_GET. Método HTTP POST → $_POST.

Errores y trampas

Lo que más se confunde
  • $_REQUEST no trae la sesión. $_REQUEST junta lo de $_GET, $_POST y las cookies (Clase 3), nunca $_SESSION. En el script de arriba, print_r($_REQUEST) muestra color y nombre, pero no usuario.
  • Un arreglo no se imprime con echo. echo $_SESSION['datos']; imprime la palabra Array y un Warning: Array to string conversion. Para verlo entero, print_r() (es lo que usan pagina1.php y pagina2.php).
  • Asignar a una clave que ya existe la pisa; no se acumulan dos valores.
  • Leer una clave que no existe da Warning: Undefined array key. Para preguntar antes si está, se usan isset() o empty() (sección 3).

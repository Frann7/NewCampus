5. Recorrer los resultados

Para qué sirve

query() dejó en $resultado un apuntador a las filas, no las filas. Para trabajar con ellas hay que transformarlas en un arreglo de PHP, una por una. Eso hacen los métodos fetch (en inglés, "ir a buscar").

Sintaxis

while ($persona = $resultado->fetch_assoc())
{
    // $persona es un arreglo con una fila
}

En estilo procedural: mysqli_fetch_assoc($resultado) y mysqli_fetch_array($resultado).

Qué es cada parte

ParteQué es
fetch_assoc()Toma la fila siguiente y la devuelve como arreglo asociativo: las claves son los nombres de las columnas de la tabla
fetch_array()Lo mismo, pero el arreglo trae la fila dos veces: con claves numéricas (0, 1, 2…, en el orden de las columnas) y con los nombres. Se le puede pedir solo una forma: fetch_array(MYSQLI_ASSOC) (nombres) o fetch_array(MYSQLI_NUM) (números). Sin nada, es MYSQLI_BOTH (las dos)
El puntero interno$resultado recuerda por qué fila va. Cada fetch devuelve la fila donde está el puntero y lo mueve una adelante. No vuelve solo al principio
Cuando no quedan filasfetch devuelve null
while ($persona = ...)Otra vez un solo =: en cada vuelta guarda la fila en $persona y el while mira si eso es verdadero. Un arreglo con datos es verdadero; null es falso. Así el bucle da una vuelta por fila y termina solo

El ejemplo del PDF tiene tres descuidos
  • La tabla tiene las columnas IdPersona, Nombres… y el arreglo muestra idPersona, nombre. En la realidad, las claves son exactamente los nombres de las columnas, con las mismas mayúsculas. Acá están escritos iguales en los dos lados.
  • Los documentos del arreglo no coinciden con los de la tabla (García figura con 22333444 en una y con 11222333 en la otra). Acá se usan los de la tabla.
  • Dice que el arreglo queda "en la variable $resultado": queda en $persona. $resultado sigue siendo el apuntador.

Ejemplo 2 — Qué trae fetch_array()

Enunciado

Con la tabla de ejemplo y la conexión abierta, ¿qué imprime?

<?php
$resultado = $mysqli->query('SELECT * FROM personas WHERE idPersona = 2');
$fila = $resultado->fetch_array();
print_r($fila);
echo $fila[2] . ", " . $fila['nombres'];
?>
LíneaQué haceCómo quedan las variables
2Pide solo la fila con id 2$resultado = apuntador a 1 fila
3La saca con las dos clases de claves$fila = 8 elementos: 0, idPersona, 1, documento, 2, apellido, 3, nombres
4Muestra el arreglo entero
5$fila[2] es la tercera columna (se cuenta desde 0): el apellido. $fila['nombres'], los nombres"Bonnet" y "Federico"

Qué imprime (verificado armando ese mismo arreglo):

Array
(
    [0] => 2
    [idPersona] => 2
    [1] => 11222333
    [documento] => 11222333
    [2] => Bonnet
    [apellido] => Bonnet
    [3] => Federico
    [nombres] => Federico
)
Bonnet, Federico

Cada dato aparece dos veces: una con su posición y otra con su nombre. Por eso la definición del parcial dice que devuelve "una matriz" (un arreglo) y la de la guía, "un array asociativo, numérico, o ambas".

Ejemplo 3 — ¿Cuál es la salida? El puntero no vuelve

Enunciado

Con la tabla de ejemplo y la conexión abierta, ¿cuál es la salida?

<?php
$resultado = $mysqli->query('SELECT * FROM personas');
$primera = $resultado->fetch_assoc();
echo $primera['apellido'] . ": ";
while ($p = $resultado->fetch_assoc()) {
    echo $p['apellido'] . " ";
}
?>
LíneaQué haceCómo quedan las variables
2Trae las 3 personaspuntero en la fila 1
3Saca la fila 1 fuera del bucle$primera = García; puntero en la 2
4Imprime García:
5 (vuelta 1)El while arranca donde quedó el puntero$p = Bonnet; puntero en la 3
5 (vuelta 2)$p = Aramburu; puntero al final
5 (vuelta 3)Devuelve null, termina$p = null
Respuesta (con la tabla de ejemplo, verificada) 
García: Bonnet Aramburu

García no se repite dentro del bucle: cada fetch movió el puntero "hacia adelante", como dice la definición del parcial.

Errores y trampas
  • Las claves distinguen mayúsculas. Si la columna se llama apellido, $persona['Apellido'] no existe: da un Warning: Undefined array key y no imprime nada.
  • Con fetch_assoc() no hay números: $persona[0] no existe. Los números solo vienen con fetch_array().
  • Todo llega como texto. Aunque la columna sea INT, el valor viene como string ('1', no 1). En print_r no se nota; con var_dump sí.
  • Un if en vez de while saca una sola fila: la primera.

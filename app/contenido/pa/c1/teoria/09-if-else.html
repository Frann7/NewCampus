Estructuras de control · condicionales

9. if / else

Para qué sirve

Las estructuras de control deciden el camino que sigue el programa. Hay dos familias: las condicionales (eligen qué ejecutar: if y switch) y las iterativas (repiten: while, do...while, for). El if ejecuta un bloque de código solo si una condición es verdadera, y con else se dice qué hacer si no lo es.

Sintaxis

if (condición) {
    sentencias si es verdadera;
} else {
    sentencias si es falsa;
}

Anidado, para más de dos caminos:

if (condición1) {
    sentencias si condición1 es verdadera;
} else if (condición2) {
    sentencias si condición1 es falsa y condición2 verdadera;
} else {
    sentencias si las dos son falsas;
}

Qué es cada parte

ParteQué es
(condición)Algo que se evalúa a verdadero o falso: una comparación ($a < 5), una combinación con &&, ||, !, o directamente una variable booleana (if ($a)). Va siempre entre paréntesis.
{ ... }El bloque que se ejecuta. Cada llave que se abre tiene que cerrarse.
elseOpcional. Lo que se ejecuta si la condición es falsa.
else if (...)Otra condición, que solo se mira si las anteriores fueron falsas. Se puede escribir también junto: elseif.

Si la condición no es un booleano

PHP la convierte. Cuentan como falso: false, 0, 0.0, "" (texto vacío), "0", null y un array vacío. Todo lo demás es verdadero (cualquier número distinto de 0, cualquier texto con algo).

Cómo se sigue un if a mano

  1. Reemplazá cada variable de la condición por su valor.
  2. Resolvé los ! primero, después los paréntesis de adentro hacia afuera.
  3. Si da true, entrás al bloque y salteás todos los else; si da false, pasás al else if o al else.

Ejemplo 1 — Comparar con 5 (el de la cátedra, corregido)

<?php
$a = 5;
if ($a < 5){
echo "El valor es menor que cinco";
}else if ($a == 5){
echo "El valor es igual a cinco.";
}else{
echo "El valor es mayor a cinco.";
}
?>

Las dos diferencias con el apunte
  • El apunte escribe else if ($a = 5), con un solo =. Eso no compara: asigna (ver trampas, abajo).
  • Tiene una llave } de más al final, que hace que PHP no ejecute nada: Parse error: Unmatched '}' in ... on line 10.

Mundo con mayúscula

El enunciado dice que la salida es "Hola, Mundo!", pero el echo imprime "Hola, mundo!" (con minúscula). La M mayúscula está solo en $string, que no se imprime nunca. Es un descuido del enunciado: igual la única opción que llega a ese mensaje es la d.

Errores y trampas

Un = en la condición: siempre entra 
<?php
$a = 7;
if ($a < 5){
echo "El valor es menor que cinco";
}else if ($a = 5){
echo "El valor es igual a cinco.";
}else{
echo "El valor es mayor a cinco.";
}
echo "<br>";
echo $a;
?>
El valor es igual a cinco.
5

Con $a = 7 debería decir "mayor a cinco". Pero $a = 5 guarda 5 en $a, y la condición vale 5, que es distinto de 0: cuenta como verdadero. Resultado: dice "igual a cinco" y encima le cambió el valor a $a. Para comparar, siempre ==.

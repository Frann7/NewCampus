Grimaldi 10.3 · Ej. 1 · Primer orden no homogénea

Cuatro relaciones de primer orden no homogéneas

Resuelva las siguientes relaciones de recurrencia.

a) \(a_{n+1} - a_n = 2n + 3,\ n \geq 0,\ a_0 = 1\)    b) \(a_{n+1} - a_n = 3n^{2} - n,\ n \geq 0,\ a_0 = 3\)

c) \(a_{n+1} - 2a_n = 5,\ n \geq 0,\ a_0 = 1\)    d) \(a_{n+1} - 2a_n = 2^{n},\ n \geq 0,\ a_0 = 1\)

Qué tema es y por qué
  • Primer orden, con algo que no depende de los términos sumado del lado derecho, \(g(n)\): son no homogéneas.
  • Se usa el método de coeficientes indeterminados de la cátedra (en la teoría de esta unidad): solución = homogénea asociada + una particular.
El método (se repite en cada inciso)

1. \(a_n = a_n^{(h)} + a_n^{(p)}\).

2. \(a_n^{(h)}\): la solución de la relación con \(g(n) = 0\). Para \(a_{n+1} = d\,a_n\) es \(a_n^{(h)} = C\,d^{\,n}\) (la constante \(C\) se calcula al final).

3. \(a_n^{(p)}\) según la familia de \(g(n)\): constante \(\to A\); polinomio de grado \(t\) \(\to\) polinomio completo de grado \(t\); \(k \cdot r^{n} \to A\,r^{n}\).

4. Si lo propuesto ya está dentro de \(a_n^{(h)}\) (choca), se multiplica por \(n\).

5. Se reemplaza \(a_n^{(p)}\) en la relación y se igualan coeficientes. Después, \(C\) sale de la condición inicial con la solución completa.

Paso 1 — Inciso a): \(a_{n+1} - a_n = 2n + 3\)
  • Homogénea: \(a_{n+1} = a_n\) (\(d = 1\)) \(\Rightarrow a_n^{(h)} = C \cdot 1^{n} = C\), una constante.
  • \(g(n) = 2n + 3\) es polinomio de grado 1 \(\to\) se propondría \(An + B\). Pero el \(B\) suelto es una constante, igual que \(a_n^{(h)}\): choca. Se multiplica por \(n\): \(a_n^{(p)} = n(An + B) = An^{2} + Bn\).

Reemplazando en \(a_{n+1} - a_n = 2n + 3\):

\[ A(n+1)^{2} + B(n+1) - An^{2} - Bn = 2An + A + B = 2n + 3 \]

Igualando coeficientes: \(2A = 2 \Rightarrow A = 1\); \(A + B = 3 \Rightarrow B = 2\). Entonces \(a_n^{(p)} = n^{2} + 2n\).

Solución completa: \(a_n = C + n^{2} + 2n\). Con \(a_0 = 1\): \(C = 1\).

\[ a_n = n^{2} + 2n + 1 = (n + 1)^{2},\ \forall n \geq 0 \]

Comprobación: relación \(1, 4, 9, 16, 25\); fórmula \((n+1)^{2}\): \(1, 4, 9, 16, 25\).

Paso 2 — Inciso b): \(a_{n+1} - a_n = 3n^{2} - n\)
  • Homogénea: la misma, \(a_n^{(h)} = C\).
  • \(g(n)\) es polinomio de grado 2 \(\to\) \(An^{2} + Bn + D\), pero la constante \(D\) choca con \(C\): se multiplica por \(n\), \(a_n^{(p)} = An^{3} + Bn^{2} + Dn\).

Reemplazando (con \((n+1)^{3} - n^{3} = 3n^{2} + 3n + 1\) y \((n+1)^{2} - n^{2} = 2n + 1\)):

\[ A(3n^{2} + 3n + 1) + B(2n + 1) + D = 3An^{2} + (3A + 2B)n + (A + B + D) = 3n^{2} - n \]

\(3A = 3 \Rightarrow A = 1\); \(3 + 2B = -1 \Rightarrow B = -2\); \(1 - 2 + D = 0 \Rightarrow D = 1\). Entonces \(a_n^{(p)} = n^{3} - 2n^{2} + n = n(n - 1)^{2}\).

Solución completa: \(a_n = C + n(n-1)^{2}\). Con \(a_0 = 3\): \(C = 3\).

\[ a_n = 3 + n(n - 1)^{2},\ \forall n \geq 0 \]

Comprobación: relación \(3, 3, 5, 15, 39\); fórmula: \(3,\ 3 + 0,\ 3 + 2,\ 3 + 12,\ 3 + 36\). Coinciden.

Paso 3 — Inciso c): \(a_{n+1} - 2a_n = 5\)
  • Homogénea: \(a_{n+1} = 2a_n \Rightarrow a_n^{(h)} = C\,2^{n}\).
  • \(g(n) = 5\), constante \(\to a_n^{(p)} = A\). No choca: \(C\,2^{n}\) no es constante.

Reemplazando: \(A - 2A = 5 \Rightarrow A = -5\).

Solución completa: \(a_n = C\,2^{n} - 5\). Con \(a_0 = 1\): \(C - 5 = 1 \Rightarrow C = 6\).

\[ a_n = 6 \cdot 2^{n} - 5,\ \forall n \geq 0 \]

Comprobación: relación \(1, 7, 19, 43, 91\); fórmula \(6 - 5,\ 12 - 5,\ 24 - 5,\ 48 - 5,\ 96 - 5\). Coinciden.

Paso 4 — Inciso d): \(a_{n+1} - 2a_n = 2^{n}\)
  • Homogénea: \(a_n^{(h)} = C\,2^{n}\).
  • \(g(n) = 2^{n} \to A\,2^{n}\), pero eso es exactamente la forma de \(a_n^{(h)}\): choca. Se multiplica por \(n\): \(a_n^{(p)} = A\,n\,2^{n}\).

Reemplazando:

\[ A(n+1)2^{n+1} - 2An\,2^{n} = A(n+1)2^{n+1} - An\,2^{n+1} = A\,2^{n+1} = 2^{n} \Rightarrow 2A = 1 \Rightarrow A = \tfrac12 \]

Entonces \(a_n^{(p)} = \tfrac12 n\,2^{n} = n\,2^{n-1}\).

Solución completa: \(a_n = C\,2^{n} + n\,2^{n-1}\). Con \(a_0 = 1\): \(C = 1\).

\[ a_n = 2^{n} + n\,2^{n-1},\ \forall n \geq 0 \]

Comprobación: relación \(1, 3, 8, 20, 48\); fórmula \(1,\ 2 + 1,\ 4 + 4,\ 8 + 12,\ 16 + 32\). Coinciden.

Si no se multiplica por \(n\)

En d), con \(a_n^{(p)} = A\,2^{n}\) queda \(2A\,2^{n} - 2A\,2^{n} = 0 = 2^{n}\): imposible. Cuando al reemplazar la particular "desaparece", es la señal de que chocaba con la homogénea.

Respuesta

a) \((n+1)^{2}\)   b) \(3 + n(n-1)^{2}\)   c) \(6 \cdot 2^{n} - 5\)   d) \(2^{n} + n\,2^{n-1}\), todas para \(n \geq 0\).

Solución del libro

El libro da \((n+1)^{2}\), \(3 + n(n-1)^{2}\), \(6(2^{n}) - 5\) y \(2^{n} + n(2^{n-1})\). Coinciden los cuatro. (El libro los saca escribiendo los primeros términos y sumando; acá se usó el método de la cátedra, y llega a lo mismo.)

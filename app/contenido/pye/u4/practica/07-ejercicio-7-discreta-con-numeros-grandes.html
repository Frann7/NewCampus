Ejercicio 7 · Discreta con numeros grandes

Utilidades proyectadas para fin de ano

La investigacion sugiere el siguiente espectro de utilidades (en dolares) con sus respectivas probabilidades. Encuentre la utilidad esperada y la desviacion estandar.

\(x\)−15.000015.00025.00030.00050.000100.000150.000200.000
\(f(x)\)0,050,150,150,300,200,100,050,030,02
Paso 1 — Esperanza

Formula:

\[ E(X) = \sum x \cdot f(x) \]

Multiplicamos cada monto por su probabilidad (ojo con el negativo del primero):

\[ E(X) = (-15000)(0{,}05) + (0)(0{,}15) + (15000)(0{,}15) + (25000)(0{,}30) + (30000)(0{,}20) \]

\[ \qquad\qquad + \;(50000)(0{,}10) + (100000)(0{,}05) + (150000)(0{,}03) + (200000)(0{,}02) \]

\[ E(X) = -750 + 0 + 2250 + 7500 + 6000 + 5000 + 5000 + 4500 + 4000 = \mathbf{33{.}500} \]

Respuesta

La utilidad esperada es de $33.500.

Paso 2 — Momento de segundo orden

Formula:

\[ E(X^{2}) = \sum x^{2} \cdot f(x) \]

Aca los numeros se van a las nubes. Conviene trabajar en millones o usar notacion cientifica.

\[ E(X^{2}) = (2{,}25\times10^{8})(0{,}05) + 0 + (2{,}25\times10^{8})(0{,}15) + (6{,}25\times10^{8})(0{,}30) + \ldots \]

\[ E(X^{2}) = \mathbf{2{.}697{.}500{.}000} \]

Paso 3 — Varianza y desvio

Formula:

\[ V(X) = E(X^{2}) - \big[E(X)\big]^{2} \]

\[ V(X) = 2{.}697{.}500{.}000 - (33{.}500)^{2} = 2{.}697{.}500{.}000 - 1{.}122{.}250{.}000 \]

\[ V(X) = \mathbf{1{.}575{.}250{.}000} \]

Formula:

\[ \sigma = \sqrt{V(X)} = \sqrt{1{.}575{.}250{.}000} = \mathbf{39{.}689{,}42} \]

Resultado oficial de la catedra

\(E(X)=33500\); \(SD(X)=39689{,}42\)  ✓

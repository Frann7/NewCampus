Longitud de las piezas después del ajuste

Cierto ajuste a una máquina cambiará la longitud de las piezas que produce. La longitud de las piezas está normalmente distribuida, y la desviación estándar es de 0,5 mm. Después de hacer un ajuste, se toma una muestra aleatoria para determinar la longitud media de las piezas que ahora se produce. Las mediciones resultantes son las siguientes:

75,3   76   75   77   75,4   76,3   77   74,9   76,5   75,8.

  1. ¿Cuál es la variable de estudio y el parámetro de interés?
  2. ¿Qué gráfico utilizaría para mostrar esta información?
  3. Encuentre la estimación puntual para la longitud media de todas las piezas que ahora se producen.
  4. Construya un intervalo de confianza del 95 % para la verdadera longitud media de todas las piezas. Interprete.
  5. Si se sabe por estudios anteriores que la media poblacional es de 76 mm, plantee una prueba de hipótesis conveniente con la que pueda relacionar el resultado con el ítem anterior.

Inciso a — Variable y parámetro
Respuesta a

Variable de estudio: \(X\) = longitud (en mm) de una pieza producida después del ajuste. Cuantitativa continua.

Parámetro de interés: \(\mu\) = longitud media de todas las piezas que la máquina produce ahora.

Inciso b — Gráfico
Respuesta b

La longitud es cuantitativa continua: un histograma o un diagrama de caja.

Inciso c — Estimación puntual

La estimación puntual de \(\mu\) es un solo número: el promedio de la muestra.

Estimador puntual de la media

\[ \hat{\mu} = \bar{x} = \frac{\sum x_i}{n} \]

\[ \hat{\mu} = \frac{75{,}3 + 76 + 75 + 77 + 75{,}4 + 76{,}3 + 77 + 74{,}9 + 76{,}5 + 75{,}8}{10} = \frac{759{,}2}{10} = \mathbf{75{,}92} \]

En la calculadora (Casio fx-991ES PLUS)
  • MODE 3 (STAT) 1 (1-VAR); cargar las 10 mediciones, cada una seguida de =, y AC.
  • SHIFT 1 4 (Var) 2 (\(\bar{x}\)) = → 75,92.

El desvío de la muestra no hace falta: \(\sigma\) ya es dato.

Respuesta c

\(\hat{\mu} = \bar{x} = 75{,}92\) mm: es la mejor estimación, con un solo número, de la longitud media de todas las piezas que ahora se producen.

Inciso d — Intervalo de confianza del 95 %

\(\sigma\) conocida y población normal → \(Z\), aunque la muestra sea chica (\(n = 10\)).

Intervalo para \(\mu\) con \(\sigma\) conocida

\[ \bar{x} \pm z_{\alpha/2}\,\frac{\sigma}{\sqrt{n}} \qquad E = z_{\alpha/2}\,\frac{\sigma}{\sqrt{n}} \]

  • \(z_{0{,}025} = 1{,}96\): en la tabla normal, \(F(1{,}96) = 0{,}9750\) deja 0,025 a la derecha.
  • Error estándar: \(\dfrac{\sigma}{\sqrt{n}} = \dfrac{0{,}5}{\sqrt{10}} = \dfrac{0{,}5}{3{,}1623} = 0{,}1581\) mm.
  • \(E = 1{,}96 \times 0{,}1581 = 0{,}3099\) mm.

\[ \bar{x} - E < \mu < \bar{x} + E \]

\[ 75{,}92 - 0{,}3099 < \mu < 75{,}92 + 0{,}3099 \]

\[ \mathbf{75{,}61 < \mu < 76{,}23} \]

Respuesta d

\(IC_{95\%}(\mu) = (\,75{,}61\ ;\ 76{,}23\,)\) mm. Con 95 % de confianza, la verdadera longitud media de todas las piezas que se producen después del ajuste está entre 75,61 y 76,23 mm.

Inciso e — Prueba de hipótesis

1. Hipótesis.

Antes del ajuste la media era 76 mm. La pregunta de fondo es si el ajuste la cambió, y el enunciado no dice para qué lado. Para poder "relacionarla con el ítem anterior" tiene que ser bilateral y con \(\alpha = 0{,}05\), el complemento del 95 % del intervalo:

\[ H_0: \mu = 76 \qquad H_1: \mu \neq 76 \qquad \alpha = 0{,}05 \]

2. ¿\(Z\) o \(t\)? \(\sigma = 0{,}5\) conocida → \(Z\).

3. Estadístico. Fórmula:

Estadístico para \(\mu\) con \(\sigma\) conocida

\[ z = \frac{\bar{x} - \mu_0}{\sigma/\sqrt{n}} \]

Con el error estándar del inciso d (\(0{,}1581\)):

\[ z = \frac{75{,}92 - 76}{0{,}1581} = \frac{-0{,}08}{0{,}1581} = -0{,}5060 \approx \mathbf{-0{,}51} \]

4. Valor crítico y región de rechazo. Bilateral con \(\alpha = 0{,}05\): \(z_{0{,}025} = 1{,}96\).

\[ \text{Región de rechazo: } z < -1{,}96 \text{ o } z > 1{,}96 \]

El \(z\) de la muestra queda cerca del centro, lejos de las dos zonas de rechazo.

5. Decisión.

\[ -1{,}96 < z = -0{,}51 < 1{,}96 \;\Longrightarrow\; \text{no se rechaza } H_0 \]

6. Valor \(p\). Bilateral: el área de la cola donde cayó \(z\), por 2.

\[ p = 2 \cdot F(-|z|) = 2 \cdot F(-0{,}51) = 2 \times 0{,}3050 = \mathbf{0{,}6100} \]

\[ p = 0{,}6100 > 0{,}05 = \alpha \;\Longrightarrow\; \text{no se rechaza } H_0 \]

7. Relación con el intervalo.

  • El intervalo del 95 % es \((75{,}61\ ;\ 76{,}23)\) y contiene al 76.
  • La prueba bilateral con \(\alpha = 0{,}05\) no rechaza \(\mu = 76\).

Coinciden, como tiene que pasar: con el mismo \(\alpha\) (0,05 y 95 %) y la misma \(\sigma\), la prueba bilateral rechaza \(H_0\) justo cuando \(\mu_0\) queda afuera del intervalo. Si el intervalo no hubiera tenido al 76, la prueba lo habría rechazado.

Respuesta e

\(H_0: \mu = 76\) vs \(H_1: \mu \neq 76\), \(\alpha = 0{,}05\); \(z = -0{,}51\), entre \(-1{,}96\) y \(1{,}96\); \(p = 0{,}6100\). No se rechaza \(H_0\): no hay evidencia de que el ajuste haya cambiado la longitud media de las piezas.

Se relaciona con el inciso d porque 76 está dentro del intervalo \((75{,}61\ ;\ 76{,}23)\): las dos herramientas dicen que 76 mm sigue siendo un valor creíble para la media.

Sin resultado oficial

Este final no tiene resolución de la cátedra. Los incisos a a d coinciden con el banco de autoevaluación (\(\bar{x} = 75{,}92\), intervalo \((75{,}61\ ;\ 76{,}23)\)). La prueba está verificada con Python: con \(z\) sin redondear (\(-0{,}5060\)) el valor \(p\) da 0,6129; con \(z = -0{,}51\) y la tabla, 0,6100. La decisión es la misma.

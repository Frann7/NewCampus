12. for

Para qué sirve

El for es un bucle pensado para cuando hay un contador: junta en un solo renglón las tres cosas que en un while quedan desparramadas (el valor inicial, la condición y el incremento). Hace lo mismo, pero se lee más fácil.

Sintaxis

for (inicio; condición; incremento) {
    sentencia_1;
    sentencia_2;
}

Qué es cada parte

ParteQué esCuándo se ejecuta
inicioLe da el valor de arranque a la variable de control. Ej.: $i = 0.Una sola vez, al principio.
condiciónLo que tiene que ser verdadero para hacer otra vuelta. Ej.: $i <= 10.Antes de cada vuelta.
incrementoDe cuánto en cuánto cambia la variable. Ej.: $i++ (o $i-- para bajar).Al final de cada vuelta.
;Las tres partes se separan con punto y coma.—

El orden real es: inicio → condición → vuelta → incremento → condición → vuelta → incremento → ... hasta que la condición da falso.

El for del apunte tiene comas

El apunte escribe for ($i=0, $i <=10, $i++). Con comas, PHP no encuentra las tres partes y no ejecuta nada: Parse error: syntax error, unexpected token ")", expecting ";". Las partes se separan con punto y coma (como en la presentación). También le falta cerrar las comillas en print ("<br>);.

Errores y trampas

Un = en la condición del for

El segundo for del apunte es for ($i=10, $i =10, $i--). Aun cambiando las comas por punto y coma, la condición $i = 10 asigna 10 en cada vuelta (vale 10, que es verdadero): el $i-- nunca llega a notarse y es un bucle infinito. Para contar hacia atrás va una comparación, como $i >= 1 del ejemplo 3.

¿Cuál es la función esencial del DNS (Domain Name System) para la navegación de sitios web?

  1. Establecer la conexión segura (cifrada) entre el navegador y el servidor web.
  2. Gestionar el historial de navegación y las cookies del usuario.
  3. Definir los métodos de solicitud de datos entre el cliente y el servidor (GET, POST, etc.).
  4. Traducir los nombres de dominio legibles para humanos (ej. fcyt.uader.edu.ar) en direcciones IP (ej. 45.224.188.177) necesario para localizar el servidor.

Qué evalúa

Para qué sirve el DNS.

La idea

Las computadoras se encuentran por dirección IP (números como 45.224.188.177), pero las personas escribimos nombres (fcyt.uader.edu.ar). El DNS es la “agenda” de Internet: le das el nombre y te devuelve la IP. Es lo primero que pasa cuando escribís una dirección en el navegador; recién con la IP el navegador puede conectarse al servidor.

Opción por opción

Opción¿Va?Por qué
Establecer la conexión segura (cifrada)…NoEso lo hace TLS (HTTPS).
Gestionar el historial y las cookies…NoEso lo hace el navegador.
Definir los métodos GET, POST…NoEso lo define el protocolo HTTP.
Traducir los nombres de dominio en direcciones IP…SíEs la función del DNS.

Trampas

  • Las tres incorrectas son funciones reales de otras piezas (TLS, el navegador, HTTP): no son absurdas, solo no son del DNS.

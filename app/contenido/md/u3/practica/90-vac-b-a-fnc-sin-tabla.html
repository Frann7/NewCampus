La f.n.c. sin tabla a partir de f⁻¹(1) = {001, 010, 100, 111}

a) Sabiendo que \(f : B^3 \to B \,/\, f^{-1}(1) = \{001, 010, 100, 111\}\):

i. Halla la expresión algebraica de la forma normal conjuntiva sin usar la tabla.

ii. Escribe la expresión con los mínterminos o máxterminos, según corresponda.

Qué tema es y por qué
  • \(f^{-1}(1)\) es la lista de entradas donde \(f\) vale 1. Pero la f.n.c. se arma con las entradas donde \(f\) vale 0: un maxtérmino por cada una.
  • Entonces hay que conseguir \(f^{-1}(0)\) sin tabla: son las entradas de \(B^3\) que no están en \(f^{-1}(1)\).
  • "Según corresponda" en ii: como en i se pidió la f.n.c., corresponde escribirla con maxtérminos, \(\prod M(\dots)\).

Paso 1 — Pasar \(f^{-1}(1)\) a etiquetas

Regla: la entrada \(xyz\) se lee en base 2, etiqueta \(= 4x + 2y + z\).

  • \(001 = 1\), \(010 = 2\), \(100 = 4\), \(111 = 4 + 2 + 1 = 7\).
Paso 2 — Sacar \(f^{-1}(0)\) sin tabla

Cada entrada de \(B^3\) está en \(f^{-1}(1)\) o en \(f^{-1}(0)\), nunca en las dos. De las etiquetas 0 a 7 se sacan 1, 2, 4 y 7:

\[f^{-1}(0) = \{0, 3, 5, 6\} = \{000, 011, 101, 110\}\] Paso 3 — Un maxtérmino por cada entrada con 0 (inciso i)
Regla del maxtérmino

Variable que vale 0 → sin barra. Variable que vale 1 → con barra. Así la suma vale 0 solo en esa entrada.

et.\(xyz\)cada variablemaxtérmino
0000\(x,\ y,\ z\)\(x + y + z\)
3011\(x,\ \overline{y},\ \overline{z}\)\(x + \overline{y} + \overline{z}\)
5101\(\overline{x},\ y,\ \overline{z}\)\(\overline{x} + y + \overline{z}\)
6110\(\overline{x},\ \overline{y},\ z\)\(\overline{x} + \overline{y} + z\)

Control de uno: en \(011\), \(x + \overline{y} + \overline{z} = 0 + 0 + 0 = 0\); en cualquier otra entrada algún sumando cambia a 1.

\[f(x, y, z) = (x + y + z)(x + \overline{y} + \overline{z})(\overline{x} + y + \overline{z})(\overline{x} + \overline{y} + z)\] Paso 4 — Con maxtérminos (inciso ii)

\(\prod M(\dots)\) lista las etiquetas donde \(f\) vale 0:

\[f = \prod M(0, 3, 5, 6)\]

(La misma función con mintérminos sería \(\sum m(1, 2, 4, 7)\), las etiquetas de \(f^{-1}(1)\).)

El error típico

Armar maxtérminos con las entradas de \(f^{-1}(1)\). Eso da un producto que vale 0 justo donde \(f\) vale 1: la función complementaria. La f.n.c. se arma siempre con los ceros.

Respuesta

i) \(f(x, y, z) = (x + y + z)(x + \overline{y} + \overline{z})(\overline{x} + y + \overline{z})(\overline{x} + \overline{y} + z)\)

ii) \(f = \prod M(0, 3, 5, 6)\)

Verificación

Las actividades no traen resultados. Evaluando el producto en las 8 entradas con Python, vale 1 exactamente en \(001, 010, 100, 111\). Es la función que vale 1 cuando hay una cantidad impar de unos.

El enunciado, otra vez

100 usuarios observados un día: 20 no publicaron nada, 25 publicaron una vez, 18 dos veces, 15 tres, 10 cuatro y el resto cinco. Piden definir la variable, su distribución (tabla de \(x = 0\) a 5), verificarla y graficarla, \(P(\text{exactamente } 2)\), \(P(\text{al menos } 3)\) y la acumulada con su gráfico.

¿De qué tema es?

Unidad 3: variable aleatoria discreta, su función de probabilidad \(f(x)\) y su función acumulada \(F(x)\).

Los conceptos que hacen falta, desde cero

1. Función de probabilidad de una variable discreta

\(f(x) = P(X = x)\): la probabilidad de cada valor. Para que sea una distribución tiene que cumplir:

\[ f(x) \geq 0 \ \text{ para todo } x \qquad\text{y}\qquad \sum_{x} f(x) = 1 \]

Cuando sale de datos observados, cada probabilidad es la frecuencia relativa: cuántos casos tienen ese valor, dividido el total.

2. Función de distribución acumulada

\[ F(x) = P(X \leq x) = \sum_{t \leq x} f(t) \]

Acumula la probabilidad desde el valor más chico hasta \(x\). En una discreta es una escalera: salta en cada valor posible y queda plana entre uno y otro.

Inciso c — Verificar y graficar

Las dos condiciones:

  1. \(f(x) \geq 0\): todos los valores de la tabla son positivos. ✓
  2. \(\sum f(x) = 1\): \(\;0{,}20 + 0{,}25 + 0{,}18 + 0{,}15 + 0{,}10 + 0{,}12 = 1\). ✓

Una distribución discreta se grafica con bastones: una línea vertical en cada valor de \(x\), de altura \(f(x)\). No se unen, porque entre un valor y otro no hay probabilidad.

Inciso d — Exactamente dos publicaciones

\[ P(X = x) = f(x) \]

\[ P(X = 2) = f(2) = 0{,}18 \]

Respuesta d

\(P(X = 2) = 0{,}18\): el 18 % de los usuarios publica exactamente dos veces por día.

Inciso e — Al menos tres publicaciones

“Al menos tres” es 3 o más: \(X \geq 3\). Se suman esos valores:

\[ P(X \geq 3) = f(3) + f(4) + f(5) = 0{,}15 + 0{,}10 + 0{,}12 = 0{,}37 \]

Por el complemento da lo mismo (lo contrario de “3 o más” es “2 o menos”):

\[ P(X \geq 3) = 1 - P(X \leq 2) = 1 - (0{,}20 + 0{,}25 + 0{,}18) = 1 - 0{,}63 = 0{,}37 \]

Respuesta e

\(P(X \geq 3) = 0{,}37\): el 37 % de los usuarios hace al menos tres publicaciones.

Inciso f — Función acumulada y su gráfico

Fórmula:

\[ F(x) = P(X \leq x) = \sum_{t \leq x} f(t) \]

Se va sumando de izquierda a derecha:

  • \(F(0) = 0{,}20\)
  • \(F(1) = 0{,}20 + 0{,}25 = 0{,}45\)
  • \(F(2) = 0{,}45 + 0{,}18 = 0{,}63\)
  • \(F(3) = 0{,}63 + 0{,}15 = 0{,}78\)
  • \(F(4) = 0{,}78 + 0{,}10 = 0{,}88\)
  • \(F(5) = 0{,}88 + 0{,}12 = 1\)

\(F\) está definida para todo número real, no solo para 0, 1, …, 5. Por eso se escribe por tramos: por ejemplo, \(F(2{,}7) = P(X \leq 2{,}7) = P(X \leq 2) = 0{,}63\).

\[ F(x) = \begin{cases} 0 & x < 0 \\ 0{,}20 & 0 \leq x < 1 \\ 0{,}45 & 1 \leq x < 2 \\ 0{,}63 & 2 \leq x < 3 \\ 0{,}78 & 3 \leq x < 4 \\ 0{,}88 & 4 \leq x < 5 \\ 1 & x \geq 5 \end{cases} \]

El gráfico es una escalera: cada escalón arranca con un punto lleno a la izquierda (ahí el valor ya está incluido) y sube en cada valor posible tanto como su \(f(x)\).

Respuesta f

La función por tramos y el gráfico escalonado de arriba. Control: arranca en 0 y termina en 1. ✓

Las trampas de este ejercicio
  1. “El resto”: hay que calcularlo (12); si lo salteás, la suma no da 1.
  2. “Al menos tres” incluye el 3.
  3. \(F(x)\) solo con los seis números: la acumulada se escribe por tramos, desde \(x < 0\) hasta \(x \geq 5\).
  4. Unir los bastones como si fuera continua: en una discreta van separados.

¿Qué patrón de diseño aplica este código?

#include <iostream>

class Descuento {
public:
    virtual ~Descuento() {}
    virtual int aplicar(int monto) const = 0;
};

class SinDescuento : public Descuento {
public:
    int aplicar(int monto) const override { return monto; }
};

class DescuentoEfectivo : public Descuento {
public:
    int aplicar(int monto) const override { return monto - monto / 10; }
};

class Carrito {
private:
    Descuento* descuento_;

public:
    Carrito(Descuento* descuento) : descuento_(descuento) {}
    void cambiarDescuento(Descuento* descuento) { descuento_ = descuento; }
    int total(int monto) const { return descuento_->aplicar(monto); }
};

int main() {
    SinDescuento sin;
    DescuentoEfectivo efectivo;
    Carrito carrito(&sin);
    std::cout << carrito.total(1000) << "\n";
    carrito.cambiarDescuento(&efectivo);
    std::cout << carrito.total(1000) << "\n";
    return 0;
}

Inventada · estilo Parcial 2025, Práctica 2

  • Observer
  • Adapter
  • Factory Method
  • Strategy

Carrito guarda un puntero a una interfaz (Descuento), tiene un método para cambiarlo (cambiarDescuento()) y, para hacer la cuenta, delega en él (descuento_->aplicar()). El mismo carrito da 1000 o 900 según qué objeto tenga puesto. Es Strategy: Carrito es el contexto, Descuento la estrategia y las otras dos las estrategias concretas. La pista contra Observer: guarda una y la puede cambiar; Observer guarda muchas y les avisa.

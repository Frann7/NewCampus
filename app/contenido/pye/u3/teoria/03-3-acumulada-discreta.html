3. Función de distribución acumulada de una discreta

Cuándo se usa

Cuando piden "determinar la función de distribución acumulada", "escribir la expresión de \(F(x)\)", "graficar \(F\)", o una probabilidad con "a lo sumo", "al menos", "más de", "menos de". También cuando el enunciado da la acumulada (o su gráfico) y hay que sacar probabilidades de ella.

Fórmula

\[ F(x) = P(X \leq x) = \sum_{t \leq x} f(t) \qquad \text{para } -\infty < x < +\infty \]

Escrita por tramos, para una variable con valores \(x_1 < x_2 < \ldots < x_n\):

\[ F(x) = \begin{cases} 0 & \text{si } x < x_1 \\ f(x_1) & \text{si } x_1 \leq x < x_2 \\ f(x_1) + f(x_2) & \text{si } x_2 \leq x < x_3 \\ \quad\vdots \\ 1 & \text{si } x \geq x_n \end{cases} \]

Qué significa cada letra

SímboloQué esEjemplo
\(F(x)\) (mayúscula)la acumulada: probabilidad de que \(X\) valga \(x\) o menos\(F(2) = f(0) + f(1) + f(2)\)
\(f(x)\) (minúscula)la función de probabilidad de la sección 2: la de un valor solo\(f(2) = P(X = 2)\)
\(t\)una letra auxiliar que recorre los valores de la tabla que no pasan de \(x\)\(\sum_{t \leq 2} f(t)\): sumar los de 2 para abajo

De dónde sale

"\(X \leq 2\)" es el evento "\(X = 0\) o \(X = 1\) o \(X = 2\)". Esos casos no pueden pasar a la vez (\(X\) vale una sola cosa), así que sus probabilidades se suman. La acumulada es una suma corrida: cada casillero es el anterior más el \(f(x)\) nuevo.

\(F\) está definida para cualquier número, no solo para los de la tabla. Por ejemplo, \(F(1{,}7) = P(X \leq 1{,}7)\): como entre 1 y 2 no hay valores, es lo mismo que \(P(X \leq 1) = F(1)\). Por eso la fórmula se escribe por tramos: entre dos valores de la tabla, \(F\) no cambia.

El complemento (para "al menos" y "más de")

Lo contrario de un evento \(A\) se llama complemento (\(\bar{A}\)): "que no pase \(A\)". Como entre los dos cubren todo, \(P(A) + P(\bar{A}) = 1\), y entonces:

\[ P(A) = 1 - P(\bar{A}) \]

Ejemplo suelto: si \(P(X \leq 2) = 0{,}63\), la probabilidad de lo contrario, \(X \geq 3\), es \(1 - 0{,}63 = 0{,}37\). Conviene cuando lo pedido tiene muchos valores y lo contrario tiene pocos, o cuando ya tenés la acumulada hecha.

Cómo se traduce cada frase

Para valores enteros consecutivos (0, 1, 2…). "El anterior" es el valor de la tabla que está justo antes.

FraseEn símbolosCon \(f\)Con \(F\)
"exactamente 3"\(X = 3\)\(f(3)\)\(F(3) - F(2)\)
"a lo sumo 3", "como máximo 3", "no más de 3"\(X \leq 3\)\(f(0) + \ldots + f(3)\)\(F(3)\)
"menos de 3"\(X < 3\), o sea \(X \leq 2\)\(f(0) + f(1) + f(2)\)\(F(2)\)
"al menos 3", "como mínimo 3", "3 o más"\(X \geq 3\)\(f(3) + f(4) + \ldots\)\(1 - F(2)\)
"más de 3"\(X > 3\), o sea \(X \geq 4\)\(f(4) + f(5) + \ldots\)\(1 - F(3)\)
"entre 2 y 4" (inclusive)\(2 \leq X \leq 4\)\(f(2) + f(3) + f(4)\)\(F(4) - F(1)\)
En una discreta, \(<\) y \(\leq\) dan distinto

\(X < 3\) no incluye al 3; \(X \leq 3\) sí. La diferencia es exactamente \(f(3)\). En las continuas (sección 5) esto deja de importar; acá importa siempre.

El gráfico: una escalera

  • Vale 0 a la izquierda del primer valor y 1 desde el último en adelante.
  • Entre dos valores es plana (no hay nada que sumar) y en cada valor salta hacia arriba. El tamaño del salto es \(f(x)\) de ese valor.
  • Nunca baja (es "no decreciente"): siempre se suma algo positivo o nada.
  • En cada salto, el punto lleno va a la izquierda del escalón (en el valor, \(F\) ya incluye su \(f\)) y el punto vacío a la derecha (el escalón llega hasta ahí pero sin tocarlo).

Por eso, leyendo el gráfico al revés, \(f(x)\) es la altura del salto en \(x\): \(f(x) = F(x) - F(\text{anterior})\).

Ejemplo 1 — Computadoras defectuosas (de la cátedra)

Enunciado

Un embarque de 8 computadoras contiene 3 defectuosas; una escuela compra 2. \(X\) es el número de computadoras defectuosas que compra la escuela, con la distribución:

\(x\)012
\(f(x)\)10/2815/283/28

a) Obtenga la acumulada \(F(x)\). b) ¿Qué probabilidad existe de comprar a lo sumo 1 defectuosa? c) ¿Y al menos 1 defectuosa?

Desarme del enunciado

FraseQué significaLa cuentaA dónde va
"a lo sumo 1"1 o menos\(F(1)\)\(P(X \leq 1)\)
"al menos 1"1 o más; lo contrario es "ninguna"\(1 - F(0)\)\(P(X \geq 1)\)

a) La suma corrida

\[ F(x) = \sum_{t \leq x} f(t) \]

  • \(F(0) = f(0) = \dfrac{10}{28} = 0{,}357\)
  • \(F(1) = f(0) + f(1) = \dfrac{10}{28} + \dfrac{15}{28} = \dfrac{25}{28} = 0{,}893\)
  • \(F(2) = \dfrac{25}{28} + \dfrac{3}{28} = \dfrac{28}{28} = 1\)

\[ F(x) = \begin{cases} 0 & \text{si } x < 0 \\ 10/28 & \text{si } 0 \leq x < 1 \\ 25/28 & \text{si } 1 \leq x < 2 \\ 1 & \text{si } x \geq 2 \end{cases} \]

Tres saltos, uno por valor: de 10/28, de 15/28 y de 3/28. Punto lleno a la izquierda de cada escalón.

b) A lo sumo 1

Fórmula: \(P(X \leq x) = F(x)\).

\[ P(X \leq 1) = F(1) = f(0) + f(1) = \frac{10}{28} + \frac{15}{28} = \frac{25}{28} = 0{,}893 \]

c) Al menos 1, por complemento

Fórmula: \(P(X \geq x) = 1 - F(\text{anterior})\). Lo contrario de "al menos 1" es "ninguna" (\(X = 0\)):

\[ P(X \geq 1) = 1 - P(X \leq 0) = 1 - F(0) = 1 - \frac{10}{28} = \frac{18}{28} = 0{,}643 \]

Control por el camino largo: \(f(1) + f(2) = \frac{15}{28} + \frac{3}{28} = \frac{18}{28}\). ✔

El apunte "Unidad 3" de la cátedra tiene un error acá

En la página 5 del PDF Unidad 3 la cuenta de "al menos 1" está hecha como \(1 - [f(0) + f(1)] = 3/28\). Eso es \(1 - F(1) = P(X \geq 2)\), "al menos 2". Las diapositivas Tema 3 — Parte A (página 14) lo hacen bien: \(1 - f(0) = 18/28\).

Respuesta

a) La \(F\) por tramos de arriba. b) \(25/28 = 0{,}893\). c) \(18/28 = 0{,}643\).

Ejemplo 2 — Publicaciones en una red social (Parcial 1 2025, ej. 4d, 4e y 4f)

Enunciado

\(X\): número de publicaciones que hace un usuario en un día, con la distribución que salió de observar a 100 usuarios:

\(x\)012345
\(f(x)\)0,200,250,180,150,100,12

d) ¿Cuál es la probabilidad de que un usuario haga exactamente dos publicaciones? e) ¿Cuál es la probabilidad de que un usuario haga al menos tres publicaciones? f) Determinar la función de distribución acumulada de probabilidad. Graficar.

Desarme del enunciado

FraseQué significaLa cuentaA dónde va
"exactamente dos"un solo valor\(f(2)\)\(P(X = 2)\)
"al menos tres"3, 4 o 5; lo contrario es 0, 1 o 2\(1 - F(2)\)\(P(X \geq 3)\)
"función de distribución acumulada"la suma corrida, por tramos—\(F(x)\)

Conviene hacer primero la acumulada (inciso f), porque el e) la usa.

f) La acumulada

\[ F(x) = \sum_{t \leq x} f(t) \]

\(x\)012345
\(f(x)\)0,200,250,180,150,100,12
\(F(x)\)0,200,20 + 0,25 = 0,450,45 + 0,18 = 0,630,63 + 0,15 = 0,780,78 + 0,10 = 0,880,88 + 0,12 = 1

\[ F(x) = \begin{cases} 0 & \text{si } x < 0 \\ 0{,}20 & \text{si } 0 \leq x < 1 \\ 0{,}45 & \text{si } 1 \leq x < 2 \\ 0{,}63 & \text{si } 2 \leq x < 3 \\ 0{,}78 & \text{si } 3 \leq x < 4 \\ 0{,}88 & \text{si } 4 \leq x < 5 \\ 1 & \text{si } x \geq 5 \end{cases} \]

La escalera arranca en 0, salta en cada valor de 0 a 5 y termina en 1.

d) Exactamente dos

Fórmula: \(P(X = x) = f(x)\).

\[ P(X = 2) = f(2) = 0{,}18 \]

Con la acumulada da lo mismo: \(F(2) - F(1) = 0{,}63 - 0{,}45 = 0{,}18\).

e) Al menos tres

Fórmula: \(P(X \geq x) = 1 - F(\text{anterior})\).

\[ P(X \geq 3) = 1 - P(X \leq 2) = 1 - F(2) = 1 - 0{,}63 = 0{,}37 \]

Control: \(f(3) + f(4) + f(5) = 0{,}15 + 0{,}10 + 0{,}12 = 0{,}37\). ✔

Respuesta

d) La probabilidad de que un usuario haga exactamente dos publicaciones es 0,18. e) La probabilidad de que haga al menos tres publicaciones es 0,37. f) La \(F\) por tramos y su gráfico, arriba.

Ejemplo 3 — Solicitudes a la base de datos (Final 25/02/2026, ej. 2b a 2d)

Enunciado

Un servidor procesa 5 solicitudes por minuto. \(X\): número de solicitudes que requieren acceso a base de datos, con la distribución (la \(k\) ya hallada, \(k = 0{,}35\)):

\(x\)012345
\(f(x)\)0,050,150,250,350,150,05

b) Calcule la función de probabilidad acumulada \(F(x)\). c) Grafique \(f\) y \(F\). Establezca las características de estas gráficas. d) ¿Cuál es la probabilidad de que al menos 2 solicitudes requieran acceso a base de datos?

Desarme del enunciado

FraseQué significaLa cuentaA dónde va
"al menos 2"2 o más; lo contrario es 0 o 1\(1 - F(1)\)\(P(X \geq 2)\)
"características de estas gráficas"describir bastones y escalera—la lista de esta sección

b) La acumulada

\[ F(x) = \sum_{t \leq x} f(t) \]

\[ F(x) = \begin{cases} 0 & \text{si } x < 0 \\ 0{,}05 & \text{si } 0 \leq x < 1 \\ 0{,}20 & \text{si } 1 \leq x < 2 \\ 0{,}45 & \text{si } 2 \leq x < 3 \\ 0{,}80 & \text{si } 3 \leq x < 4 \\ 0{,}95 & \text{si } 4 \leq x < 5 \\ 1 & \text{si } x \geq 5 \end{cases} \]

c) Los dos gráficos y sus características

\(f(x)\): un bastón por valor.

\(F(x)\): la escalera. El salto más grande está en 3 (0,35), donde está el bastón más alto.

  • De \(f\): bastones separados, solo en los valores 0 a 5; cada altura está entre 0 y 1 y todas suman 1.
  • De \(F\): escalonada; vale 0 antes del 0 y 1 desde el 5; nunca baja; salta en cada valor y el salto mide \(f(x)\); es plana entre valores.

d) Al menos 2

Fórmula: \(P(X \geq x) = 1 - F(\text{anterior})\).

\[ P(X \geq 2) = 1 - P(X \leq 1) = 1 - F(1) = 1 - 0{,}20 = 0{,}80 \]

Respuesta

b) La \(F\) de arriba. c) Los dos gráficos y la lista. d) La probabilidad de que al menos 2 solicitudes requieran acceso a la base de datos es 0,80.

Errores y trampas

  • "Al menos 3" con \(1 - F(3)\): así se saca el 3 también. Es \(1 - F(2)\): se resta lo que queda antes del 3.
  • Escribir la \(F\) solo en los valores de la tabla: pidieron una función para todo \(x\); van los tramos con \(\leq\) a la izquierda y \(<\) a la derecha, más el 0 del principio y el 1 del final.
  • Valores que no son consecutivos (−100, 0, 50…): "el anterior" es el de la tabla, no "restar 1". En la guía, \(P(X \geq 150) = 1 - F(100)\).

Problema dual

12. De la f.n.d. a la f.n.c. (y al revés)

Para qué sirve

Muchas consignas dan una forma y piden la otra: "sabiendo \(f^{-1}(1)\), la f.n.c."; "dada \(\sum m\), escribir \(\prod M\)". No hace falta rehacer nada: las dos listas se complementan.

El problema dual (la diapositiva de la cátedra)

f.n.d.f.n.c.
conjunciones fundamentales \((xyz)\)disyunciones fundamentales \((x + y + z)\)
se buscan las filas donde \(f = 1\)se buscan las filas donde \(f = 0\)
suma de mintérminos \(\sum m\)producto de maxtérminos \(\prod M\)
0 → con barra, 1 → sin barra0 → sin barra, 1 → con barra

La regla

Las dos listas se reparten las filas

\[ \sum m(L) = \prod M(\text{las filas de } 0 \text{ a } 2^{n} - 1 \text{ que no están en } L) \]

De dónde sale:

  • Cada fila de la tabla tiene un 0 o un 1, nunca las dos cosas.
  • La lista del \(\sum m\) son las filas con 1; la del \(\prod M\) son las filas con 0.
  • Entonces, entre las dos están todas las filas, cada una una sola vez. Si la f.n.d. tiene \(m\) términos y la f.n.c. tiene \(k\) factores, \(m + k = 2^{n}\).
DatoLo que se escribe
\(f^{-1}(1)\) (dónde vale 1)esas filas son los mintérminos; las que faltan, los maxtérminos
\(f^{-1}(0)\) (dónde vale 0)esas filas son los maxtérminos; las que faltan, los mintérminos

Ejemplo de la cátedra: \(xy + yz = \sum m(3, 6, 7) = \prod M(0, 1, 2, 4, 5)\). De 0 a 7, las que no son 3, 6 ni 7 son 0, 1, 2, 4, 5.

Ejemplo 2 — Estilo parcial (Recuperatorio, actividad B a)

Enunciado

Sabiendo que \(f : B^{3} \to B \,/\, f^{-1}(1) = \{001, 010, 100, 111\}\): i. hallar la expresión algebraica de la forma normal conjuntiva sin usar la tabla; ii. escribir la expresión con los mintérminos o maxtérminos, según corresponda.

Desarme del enunciado

FraseQué significaLa cuentaA dónde va
"\(f^{-1}(1) = \{001, 010, 100, 111\}\)"las filas donde \(f = 1\)\(1, 2, 4, 7\)\(f = \sum m(1, 2, 4, 7)\)
"forma normal conjuntiva"hacen falta las filas donde \(f = 0\)de 0 a 7 faltan \(0, 3, 5, 6\)los maxtérminos
"sin usar la tabla"no escribir las 8 filasusar la regla del complemento de la listala justificación
"según corresponda"la f.n.c. es producto de maxtérminos—\(\prod M\)
Paso 1 — Las filas donde \(f\) vale 0

\(B^{3}\) tiene 8 elementos, de \(000\) a \(111\) (filas 0 a 7). Toda fila que no está en \(f^{-1}(1)\) tiene \(f = 0\). Las de \(f^{-1}(1)\) son \(001 = 1\), \(010 = 2\), \(100 = 4\), \(111 = 7\); entonces \(f^{-1}(0) = \{000, 011, 101, 110\}\), las filas \(0, 3, 5, 6\).

Paso 2 — Un maxtérmino por cada una (0 → sin barra, 1 → con barra)
fila\(x\,y\,z\)maxtérminovale 0 solo si
0000\(x + y + z\)\(x = y = z = 0\)
3011\(x + \overline{y} + \overline{z}\)\(x = 0\), \(y = 1\), \(z = 1\)
5101\(\overline{x} + y + \overline{z}\)\(x = 1\), \(y = 0\), \(z = 1\)
6110\(\overline{x} + \overline{y} + z\)\(x = 1\), \(y = 1\), \(z = 0\)
Paso 3 — Multiplicarlos y justificar

El producto vale 0 si alguno de los factores es 0, o sea exactamente en las filas 0, 3, 5 y 6; en las demás (1, 2, 4, 7) todos los factores valen 1 y el producto es 1. Es la función pedida.

Respuesta

i. \(f(x, y, z) = (x + y + z)(x + \overline{y} + \overline{z})(\overline{x} + y + \overline{z})(\overline{x} + \overline{y} + z)\)

ii. Como es una f.n.c., corresponden los maxtérminos: \(f = \prod M(0, 3, 5, 6)\).

(Verificado: esa expresión vale 1 exactamente en \(001, 010, 100, 111\).)

El error que hay que evitar

Armar los maxtérminos con las tiras de \(f^{-1}(1)\). Esas filas son las de los mintérminos (\(f = \sum m(1, 2, 4, 7)\)): para la f.n.c. se usan las que faltan.

Ejemplo 3 — Verdadero o falso (guía complementaria, Boole 1 b ii)

Enunciado

Sean \(f, g : B^{3} \to B\) con \(f = \sum m(1, 2, 3)\) y \(g = \prod M(1, 2, 3)\). ¿Es cierto que \(f + g = 1\)?

Desarme del enunciado

FraseQué significaLa cuentaA dónde va
"\(f = \sum m(1, 2, 3)\)"\(f = 1\) en las filas 1, 2, 3—\(f^{-1}(1) = \{1, 2, 3\}\)
"\(g = \prod M(1, 2, 3)\)"\(g = 0\) en 1, 2, 3, y 1 en las otraslas que faltan de 0 a 7\(g = \sum m(0, 4, 5, 6, 7)\)
"\(f + g = 1\)"en cada fila, al menos una vale 1juntar las dos listas¿están las 8 filas?

\(\{1, 2, 3\} \cup \{0, 4, 5, 6, 7\} = \{0, 1, \ldots, 7\}\): en toda fila, \(f\) o \(g\) vale 1.

Respuesta

Verdadero. Más aún: \(g\) es exactamente \(\overline{f}\) (vale 1 donde \(f\) vale 0), y \(f + \overline{f} = 1\) es la ley de los inversos (L8).

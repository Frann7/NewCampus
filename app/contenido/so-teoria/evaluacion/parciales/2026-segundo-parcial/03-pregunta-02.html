Podemos encontrar tres técnicas para llevar a cabo la E/S:

  1. E/S parametrizada, E/S dirigida por interrupciones y Acceso indirecto de memoria (Indirect Memory Access, DMA).
  2. E/S programada, E/S dirigida por configuración y Acceso indirecto de memoria (Indirect Memory Access, DMA).
  3. E/S programada, E/S dirigida por interrupciones y Acceso directo a memoria (Direct Memory Access, DMA).
  4. E/S parametrizada, E/S dirigida por configuración y Acceso indirecto de memoria (Indirect Memory Access, DMA).
✓ ResultadosSolo la respuesta

Correcta: c — E/S programada, E/S dirigida por interrupciones y Acceso directo a memoria (Direct Memory Access, DMA).

✎ Explicación detalladaDe dónde sale, opción por opción y las trampas

Qué evalúa

Las tres técnicas de E/S (Stallings y Tanenbaum).

La idea

TécnicaCómo esLa CPU
E/S programadaLa CPU manda la orden y consulta el estado del dispositivo una y otra vez hasta que termina (espera activa).Queda ocupada esperando.
Dirigida por interrupcionesLa CPU manda la orden y sigue con otra cosa; el dispositivo la interrumpe cuando está listo.Libre, pero atiende una interrupción por cada dato.
DMA (acceso directo a memoria)Un módulo DMA pasa el bloque entero entre el dispositivo y la memoria.Libre: una sola interrupción al final.

Trampas

  • DMA es acceso directo. Las siglas "DMA" aparecen en todas las opciones: lo que delata es la palabra "Indirect".

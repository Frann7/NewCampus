Se va de la salida hacia atrás. El único echo "Hola, mundo!" está en el else de if ($a) (⇒ $a = false), dentro de if (!$b) (⇒ $b = false) y pide !$a && (!$b && $c) (⇒ $c = true): False, False, True.

Corriendo las otras: False, True, True y False, True, False imprimen “No exactamente”; True, True, False imprime “Adios mundo cruel!”.

Ojo: el enunciado dice “Hola, Mundo!” y el script imprime “Hola, mundo!” (minúscula); es un descuido del enunciado. Y $string no se usa: está para distraer.

¿Cuál de las siguientes ediciones de Windows NO puede actuar como servidor (anfitrión) de Escritorio remoto (RDP)?

Segundo parcial probable · preg. 20

  • Windows 11 Pro
  • Windows 10 Home
  • Windows Server
  • Windows 11 Enterprise
  • Windows 10 Education

Correcta:

  • Windows 10 Home

Por qué puede entrar

En 2025 la pregunta de Escritorio remoto fue el grupo de usuarios. La exposición tiene otros datos con forma de pregunta: las ediciones, el puerto y las sesiones.

Requisitos (punto 3 de la exposición)

RolEdiciones
Servidor (anfitrión)Windows 10/11 Pro, Enterprise, Education y Windows Server. No Home
ClienteCualquier edición de Windows (mstsc.exe), y también macOS, iOS, Android y Linux

Lo demás que puede caer

  • Puerto: TCP 3389. Modelo cliente-servidor: el servidor manda la imagen de la pantalla; el cliente, el teclado y el mouse.
  • Acceso: por defecto solo administradores; los demás, en el grupo "Usuarios de Escritorio remoto". NLA autentica antes de abrir la sesión; todo viaja cifrado.
  • Sesiones: Windows de escritorio, una sola activa (si te conectás remoto, la sesión física se bloquea). Windows Server, varias, con RDS y licencias CAL.
  • Alternativas: TeamViewer, AnyDesk, Chrome Remote Desktop, VNC.

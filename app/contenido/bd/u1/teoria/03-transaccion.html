Definiciones

3. Transacción y sus propiedades

Para escribir en la hoja

Una transacción es una unidad de la ejecución de un programa. Puede incluir distintos accesos a la base de datos: consultas, actualizaciones, ejecuciones de procedimientos almacenados, vistas, etc. Empieza con una marca (BEGIN TRAN) y termina con una confirmación (COMMIT) o con una cancelación (ROLLBACK).

Propiedades:

  • Atomicidad: las transacciones se ven como operaciones atómicas: ocurren totalmente o no ocurren.
  • Consistencia: la ejecución de la transacción, aislada, conserva la consistencia de la base de datos.
  • Aislamiento: el SGBD garantiza que dos transacciones que se ejecutan al mismo tiempo tengan el nivel de aislamiento correcto para que no se produzcan inconsistencias. Los datos se hacen efectivos en la base recién con el COMMIT.
  • Durabilidad: una vez confirmada con COMMIT, los cambios quedan guardados aunque después falle el sistema.

Es la definición de las diapositivas "Transacciones y concurrencia" de la cátedra (clase del 15/09). En la grabación se ven las de atomicidad, consistencia y aislamiento; la de durabilidad no llegó a verse, así que su texto es el que completa la sigla ACID.

Ejemplo: con el caso del parcial

En la clínica veterinaria, cuando un turno se atiende hay que hacer dos cosas: registrar la consulta y pasar el turno a "Atendido".

BEGIN TRAN;
INSERT INTO Consulta (Numero, Diagnostico, Observaciones, Fecha, NumeroTurno)
VALUES (501, 'Otitis', 'Control en 7 días', '2026-10-14', 3020);
UPDATE Turno SET Estado = 'Atendido' WHERE Numero = 3020;
COMMIT;
  • Atomicidad: si el UPDATE falla, el INSERT se deshace; no queda una consulta para un turno que sigue "Pendiente".
  • Aislamiento: mientras no llega el COMMIT, el resto de los usuarios no ve el cambio a medias.
Errores y trampas
  • La consigna pide definición y propiedades: nombrar las propiedades sin explicar cada una deja la respuesta a medias.
  • Un INSERT con varias filas en un solo VALUES ya es una transacción: si falla una fila, no entra ninguna (clase del 13/08). Tres INSERT separados, no.

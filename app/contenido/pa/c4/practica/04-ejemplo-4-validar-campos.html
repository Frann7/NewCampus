Validar los campos de un formulario

El mismo formulario del ejemplo 3 (sin el nombre precargado), con un solo botón: "Valido Datos". Avisa con un cartel qué campo falta, y además el nombre y la edad se pintan de rojo o verde apenas el usuario sale de ellos. Clase IndexClass en js/pForm2Class.js.

Validar es revisar que los datos estén bien (completos, con el formato correcto) antes de usarlos. Hacerlo en JavaScript tiene una ventaja: el usuario se entera al instante, sin esperar una respuesta del servidor.

Paso 1 — El constructor y los eventos 
class IndexClass {

    constructor(){
        this.txtNombre = document.getElementById('txtNombre');
        this.txtApellido = document.getElementById('txtApellido');
        this.txtEdad = document.getElementById('txtEdad');
        this.txtDireccion = document.getElementById('txtDireccion');
        this.btValidoDatos = document.getElementById('btValidoDatos');
    }

    init() {
        this.addEventListeners();
    }

    addEventListeners() {
        this.btValidoDatos.addEventListener('click', () => {
            this.validoDatos();
        });

        this.txtNombre.addEventListener('blur', () => {
            if (this.txtNombre.value.trim() === '') {
                this.txtNombre.style.borderColor = 'red';
            } else {
                this.txtNombre.style.borderColor = 'green';
            }
        });

        this.txtEdad.addEventListener('blur', () => {
            this.validoEdad();
        });
    }
EscuchadorCuándo correQué hace
click en el botónAl apretar "Valido Datos"Llama al método validoDatos() (paso 2). Va envuelto en una flecha para que se ejecute en el clic y no al cargar
blur en el nombreAl salir del campo nombreSi, sin los espacios de los costados, está vacío: borde rojo. Si no: verde (teoría, sección 5, ejemplo 2)
blur en la edadAl salir del campo edadLlama a validoEdad() (paso 3)

Fijate que el código del nombre está escrito adentro del escuchador, y el de la edad está en un método aparte. Hacen lo mismo; el método aparte es más ordenado y se puede reutilizar.

Paso 2 — validoDatos(): el primero que falte 
    validoDatos() {
        let nombre = this.txtNombre.value;
        let apellido = this.txtApellido.value;
        let edad = this.txtEdad.value;
        let direccion = this.txtDireccion.value;

        if (nombre === '') {
            alert('El nombre es obligatorio');
            this.txtNombre.focus();
            return;
        }

        if (apellido === '') {
            alert('El apellido es obligatorio');
            this.txtApellido.style.borderColor = 'red';
            this.txtApellido.focus();
            return;
        }

        if (edad === '') {
            alert('La edad es obligatoria');
            this.txtEdad.style.borderColor = 'red';
            this.txtEdad.focus();
            return;
        }

        if (direccion === '') {
            alert('La dirección es obligatoria');
            this.txtDireccion.style.borderColor = 'red';
            this.txtDireccion.focus();
            return;
        }
    }
LíneaQué hace
let nombre = this.txtNombre.value; (y las otras tres)Copia lo escrito en cada campo a una variable local, para escribir menos en los if
if (nombre === '')Pregunta si el nombre está vacío
alert('...')Muestra el cartel. El código se frena hasta que el usuario aprieta Aceptar
this.txtApellido.style.borderColor = 'red';Pinta el borde del campo que falta (el nombre no tiene esta línea)
this.txtApellido.focus();Lleva el cursor a ese campo, para que el usuario lo complete
return;Sale del método en ese momento. Los if de abajo ya no se revisan: se avisa de a un error por vez
Paso 3 — validoEdad() 
    validoEdad() {
        let edad = this.txtEdad.value;

        if (edad === '' || isNaN(edad) ) {
            this.txtEdad.style.borderColor = 'red';
        } else {
            this.txtEdad.style.borderColor = 'green';
        }
    }
}

Rojo si está vacía o si no es un número; verde si no. Hacen falta las dos condiciones porque isNaN('') da false (teoría, sección 2). Verificado con Node.js: '' → rojo; '20', '-3' y '2.5' → verde. Una edad negativa o con decimales pasa: la validación solo mira que sea número.

Paso 4 — ¿Qué pasa? (recorrido de un usuario)
Qué hace el usuarioQué pasa
Aprieta Valido Datos con todo vacíoCartel "El nombre es obligatorio" y el cursor va al nombre. El borde del nombre no cambia (ese if no lo pinta)
Escribe "Ana" y sale del campo con TabEl blur pinta el nombre de verde
Aprieta Valido DatosEl nombre pasa. Cartel "El apellido es obligatorio", borde del apellido rojo, cursor ahí
Escribe "Paz" y aprieta Valido DatosCartel "La edad es obligatoria", edad en rojo. El apellido sigue rojo: nadie le saca el color, porque el apellido no tiene blur
Completa la edad y la dirección y aprieta Valido DatosNo pasa nada: ningún if se cumple, el método termina sin mensaje
Lo que este ejemplo deja a medias
  • Espacios: el blur del nombre usa trim() pero validoDatos() no. Con tres espacios en el nombre, el borde se pone rojo pero el botón lo deja pasar.
  • Cuando todo está bien, no hace nada. El ejemplo 5 completa justamente eso: si todo está bien, envía el formulario a PHP.
  • El campo de edad es type="number": el navegador no deja escribir letras sueltas, así que el isNaN casi nunca llega a decidir; queda como protección.
Qué se ve en la página

Cuatro campos y un botón. Cada clic en el botón avisa con un cartel el primer campo vacío (en el orden nombre, apellido, edad, dirección) y lleva el cursor ahí. Salir del nombre o de la edad los pinta de verde o rojo.

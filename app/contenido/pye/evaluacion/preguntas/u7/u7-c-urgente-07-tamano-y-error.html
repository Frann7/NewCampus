Sobre el error de estimación \(e = z_{\alpha/2}\,\dfrac{\sigma}{\sqrt{n}}\) y el tamaño de muestra \(n = \left(\dfrac{z_{\alpha/2}\,\sigma}{e}\right)^2\), seleccione las afirmaciones correctas.

Introducción a la Inferencia (Katz), 4.1: fórmula del error y tamaño de muestra · Teoría de la Unidad 7

  • Con \(\sigma = 10\), \(e = 2\) y 95 % de confianza hacen falta 97 observaciones.
  • Con \(\sigma = 10\), \(e = 2\) y 95 % de confianza hacen falta 96 observaciones.
  • Para que el error sea la mitad, con la misma confianza, \(n\) se multiplica por 4.
  • Para que el error sea la mitad, con la misma confianza, alcanza con duplicar \(n\).
  • El error \(e\) es la mitad del ancho del intervalo de confianza.
  • Si la fórmula da \(n = 42{,}1\), se toman 42 porque el decimal es chico.

\(n = (1{,}96 \cdot 10 / 2)^2 = 96{,}04\). El \(n\) se redondea siempre para arriba: con 96 el error quedaría un poco por encima de 2. Por eso 97, y por eso 42,1 pasa a 43, no a 42.

\(e\) está dividido por \(\sqrt{n}\): para \(e/2\) hace falta \(\sqrt{n}\) el doble, o sea \(n\) por 4 (duplicar \(n\) solo divide el error por 1,41). Y el intervalo es \(\bar{x} \pm e\): va \(e\) para cada lado, así que el ancho es \(2e\).

Cambiar varios párrafos y agregar nuevos

Como el ejemplo 1, pero los botones actúan sobre todos los párrafos a la vez, y hay uno más: "Nuevo Párrafo", que agrega un párrafo a la lista. La clase se llama PaginaClass (js/page2Class.js).

Paso 1 — El HTML 
<div id="parrafos">
    <p>Parrafo 1</p>
    <p>Parrafo 2</p>
    <p>Parrafo 3</p>
    <p>Parrafo 4</p>
</div>
<hr />
<button id="btCambioTexto">Cambiar Texto</button>
<button id="btCambioColor">Cambiar Color</button>
<button id="btCambioFondo">Cambiar Fondo</button>
<button id="btAumentoTamaño">+</button><button id="btDisminuirTamaño">-</button>
<button id="btNuevoParrafo">Nuevo Párrafo</button>

Los párrafos no tienen id: se van a seleccionar todos juntos por su etiqueta. El que sí tiene id es el div que los contiene, porque ahí se van a colgar los nuevos.

Paso 2 — El constructor: tres formas de seleccionar los párrafos 
class PaginaClass {

    constructor(){
        this.parrafos = document.getElementsByTagName('p');
        this.vParrafos = Array.from(document.getElementsByTagName('p'));
        this.vParrafos1 = document.querySelectorAll('p');

        this.btCambioTexto = document.getElementById('btCambioTexto');
        this.btCambioColor = document.getElementById('btCambioColor');
        this.btCambioFondo = document.getElementById('btCambioFondo');
        this.btAumentoTamaño = document.getElementById('btAumentoTamaño');
        this.btDisminuirTamaño = document.getElementById('btDisminuirTamaño');
        this.btNuevoParrafo = document.getElementById('btNuevoParrafo');
    }

    init() {
        this.addEventListeners();
    }

Las tres primeras líneas son las tres formas de la teoría (sección 3) puestas una al lado de la otra para compararlas; el código solo usa la del medio. init() no pone texto inicial: los párrafos ya vienen escritos en el HTML.

Paso 3 — Los botones que recorren los párrafos 
    addEventListeners() {
        this.btCambioTexto.addEventListener('click', () => {
            this.vParrafos.forEach((parrafo, index) => {
                parrafo.textContent = `Parrafo ${index + 1} modificado`;
            });
        });

        this.btCambioColor.addEventListener('click', () => {
            this.vParrafos.forEach(parrafo => {
                parrafo.style.color = "red";
            });
        });

        this.btCambioFondo.addEventListener('click', () => {
            this.vParrafos.forEach(parrafo => {
                parrafo.style.backgroundColor = "#f0f0f0";
            });
        });

        this.btAumentoTamaño.addEventListener('click', () => {
            this.vParrafos.forEach(parrafo => {
                let currentSize = window.getComputedStyle(parrafo).fontSize;
                parrafo.style.fontSize = (parseFloat(currentSize) + 2) + "px";
            });
        });

        this.btDisminuirTamaño.addEventListener('click', () => {
            this.vParrafos.forEach(parrafo => {
                let currentSize = window.getComputedStyle(parrafo).fontSize;
                parrafo.style.fontSize = (parseFloat(currentSize) - 2) + "px";
            });
        });
BotónQué haceQué se ve
Cambiar TextoRecorre el array con su posición (index, desde 0) y a cada párrafo le escribe su número (index + 1) seguido de "modificado""Parrafo 1 modificado" ... "Parrafo 4 modificado"
Cambiar ColorA cada uno, letra rojaLos 4 en rojo
Cambiar FondoA cada uno, fondo #f0f0f0 (un gris muy claro, en notación hexadecimal de CSS)Los 4 con franja gris
+ / -A cada uno, la cuenta de tamaño del ejemplo 1Todos crecen o se achican 2px por clic

La diferencia con el ejemplo 1 es que, como son varios, cada botón tiene un forEach adentro: una flecha adentro de otra flecha. La de afuera se ejecuta en cada clic; la de adentro, una vez por párrafo.

Paso 4 — Nuevo Párrafo 
        this.btNuevoParrafo.addEventListener('click', () => {
            const nuevoParrafo = document.createElement('p');
            nuevoParrafo.textContent = `Parrafo ${this.vParrafos.length + 1}`;
            document.getElementById('parrafos').appendChild(nuevoParrafo);
            this.vParrafos.push(nuevoParrafo);
        });
    }
}

Un segundo clic agrega "Parrafo 6", porque el array ya tiene 5 (verificado con Node.js reproduciendo la cuenta del array).

Por qué hace falta el push

vParrafos es una copia fija hecha con Array.from en el constructor: el párrafo nuevo está en la página, pero no en el array. Sin el push, los botones de color y tamaño (que recorren el array) no lo tocarían, y el siguiente "Nuevo Párrafo" volvería a decir "Parrafo 5". Con la colección viva (this.parrafos) el párrafo nuevo habría aparecido solo, pero esa colección no tiene forEach.

Qué se ve en la página

Cuatro párrafos y seis botones. Si se agrega un párrafo y después se aprieta "Cambiar Texto", quedan "Parrafo 1 modificado" ... "Parrafo 5 modificado": el nuevo también, porque está en el array.

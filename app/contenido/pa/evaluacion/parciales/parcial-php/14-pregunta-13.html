Qué evalúa

El número opcional de break. Es de la Clase 1, “Detener y continuar”, que muestra un break 2 dentro de dos for.

El concepto, desde cero

break corta el ciclo (o el switch) en el que está. Con un número, break n sale de n estructuras anidadas de una vez: break 1 es lo mismo que break, break 2 sale del ciclo de adentro y también del de afuera.

<?php
for ($i = 1; $i <= 3; $i++) {
  for ($j = 1; $j <= 3; $j++) {
    if ($j == 2) break 2;
    echo "$i-$j ";
  }
}
echo "fin";
?>

Verdadero.

La trampa

break 2 no quiere decir “saltear 2 vueltas”: el número cuenta estructuras de las que salir. (continue también acepta un número.)

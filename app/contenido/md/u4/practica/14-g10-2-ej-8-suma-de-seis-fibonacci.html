Grimaldi 10.2 · Ej. 8(a) · Fibonacci: una identidad

Seis Fibonacci seguidos suman \(4F_{n+4}\)

Para \(n \in \mathbb{N}\), demuestre que a) \(\displaystyle\sum_{r=0}^{5} F_{n+r} = 4F_{n+4}\).

Qué tema es y por qué
  • \(\sum_{r=0}^{5} F_{n+r}\) es \(F_n + F_{n+1} + F_{n+2} + F_{n+3} + F_{n+4} + F_{n+5}\): seis Fibonacci seguidos, empezando en el de lugar \(n\).
  • La única herramienta es la relación de Fibonacci, \(F_{k} = F_{k-1} + F_{k-2}\), usada para juntar de a dos términos.
Paso 1 — La regla

\[ F_{k} + F_{k+1} = F_{k+2}\quad\text{para todo } k \geq 0 \]

(Es la relación \(F_{m} = F_{m-1} + F_{m-2}\) con \(m = k + 2\).)

Paso 2 — La demostración, renglón por renglón
RenglónPor qué
\(\sum_{r=0}^{5} F_{n+r} = F_n + F_{n+1} + F_{n+2} + F_{n+3} + F_{n+4} + F_{n+5}\)Definición de la sumatoria
\(= F_{n+2} + F_{n+2} + F_{n+3} + F_{n+4} + F_{n+5}\)\(F_n + F_{n+1} = F_{n+2}\) (regla con \(k = n\))
\(= 2F_{n+2} + F_{n+3} + F_{n+4} + (F_{n+3} + F_{n+4})\)\(F_{n+5} = F_{n+3} + F_{n+4}\) (regla con \(k = n+3\))
\(= 2F_{n+2} + 2F_{n+3} + 2F_{n+4}\)Se agrupan los iguales
\(= 2(F_{n+2} + F_{n+3}) + 2F_{n+4}\)Factor común 2
\(= 2F_{n+4} + 2F_{n+4} = 4F_{n+4}\)\(F_{n+2} + F_{n+3} = F_{n+4}\) (regla con \(k = n+2\))
Paso 3 — Comprobación con números

Con \(n = 0\): \(0 + 1 + 1 + 2 + 3 + 5 = 12\) y \(4F_4 = 4 \cdot 3 = 12\). Con \(n = 3\): \(2 + 3 + 5 + 8 + 13 + 21 = 52\) y \(4F_7 = 4 \cdot 13 = 52\). (Se comprobó para \(n = 0\) a \(19\).)

Respuesta

Juntando \(F_n + F_{n+1}\), abriendo \(F_{n+5}\) y juntando \(F_{n+2} + F_{n+3}\), la suma queda \(4F_{n+4}\).

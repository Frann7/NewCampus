\(X\) es la cantidad de solicitudes con error en una hora y se trabaja con la tabla acumulada, que da \(P(X \leq r)\). Expresiones:

a) \(P(X \leq 5)\)

b) \(P(X \leq 4)\)

c) \(1 - P(X \leq 5)\)

d) \(1 - P(X \leq 4)\)

e) \(P(X \leq 8) - P(X \leq 2)\)

Elija la expresión que corresponde a cada frase.

“Menos de 5 solicitudes con error”: a)b)c)d)e)

“Al menos 5 solicitudes con error”: a)b)c)d)e)

“Más de 5 solicitudes con error”: a)b)c)d)e)

“Entre 3 y 8 solicitudes con error, ambos inclusive”: a)b)c)d)e)

Tema del Segundo Parcial 2023, Ejercicios 4 c, 5 c y 6 a · formato 1ra etapa

La tabla lee para abajo, incluido. Para arriba se usa el complemento: \(P(\text{arriba}) = 1 - P(\text{abajo})\). La única duda es dónde cortar, y se resuelve escribiendo la lista de valores que querés.

Menos de 5 = {0, ..., 4} = \(P(X \leq 4)\): b). El 5 no entra, por eso no es a).

Al menos 5 = {5, 6, ...}; lo que sobra es {0, ..., 4}, así que \(1 - P(X \leq 4)\): d).

Más de 5 = {6, 7, ...}; lo que sobra es {0, ..., 5}, así que \(1 - P(X \leq 5)\): c). Confundir “al menos” con “más de” es el error que más puntos cuesta.

Entre 3 y 8 inclusive = {3, ..., 8}: todo hasta 8 menos lo que sobra abajo, {0, 1, 2}: \(P(X \leq 8) - P(X \leq 2)\): e). Restar la fila 3 tiraría al 3.

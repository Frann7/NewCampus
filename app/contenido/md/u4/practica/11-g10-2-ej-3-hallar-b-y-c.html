Grimaldi 10.2 · Ej. 3 · Hallar los coeficientes

Hallar \(b\), \(c\) y \(a_n\) a partir de cuatro términos

Si \(a_0 = 0,\ a_1 = 1,\ a_2 = 4\) y \(a_3 = 37\) satisfacen la relación de recurrencia \(a_{n+2} + b\,a_{n+1} + c\,a_n = 0\), donde \(n \geq 0\) y \(b, c\) son constantes, encuentre \(a_n\).

Qué tema es y por qué
  • Segundo orden homogénea, pero con los coeficientes desconocidos.
  • La relación vale para todo \(n \geq 0\): en particular para \(n = 0\) y \(n = 1\). Eso da dos ecuaciones con \(b\) y \(c\). Después se resuelve como siempre.
Paso 1 — Usar la relación con \(n = 0\) y \(n = 1\)

\(n = 0\): \(a_2 + b\,a_1 + c\,a_0 = 0 \Rightarrow 4 + b \cdot 1 + c \cdot 0 = 0 \Rightarrow b = -4\).

\(n = 1\): \(a_3 + b\,a_2 + c\,a_1 = 0 \Rightarrow 37 - 4 \cdot 4 + c \cdot 1 = 0 \Rightarrow c = -21\).

La relación es \(a_{n+2} - 4a_{n+1} - 21a_n = 0,\ n \geq 0\).

Paso 2 — Resolverla

Ecuación característica: \(a_{n+2} \to r^{2}\), \(a_{n+1} \to r\), \(a_n \to 1\). Raíces distintas: \(a_n = A_1 r_1^{\,n} + A_2 r_2^{\,n}\).

\(r^{2} - 4r - 21 = 0 \Rightarrow (r - 7)(r + 3) = 0 \Rightarrow r_1 = 7,\ r_2 = -3\).

\(a_n = A_1\,7^{n} + A_2\,(-3)^{n}\).

\[ \left\{\begin{array}{l} n = 0:\ A_1 + A_2 = 0 \\ n = 1:\ 7A_1 - 3A_2 = 1 \end{array}\right. \]

De la primera, \(A_2 = -A_1\); en la segunda, \(7A_1 + 3A_1 = 10A_1 = 1 \Rightarrow A_1 = \tfrac1{10},\ A_2 = -\tfrac1{10}\).

\[ a_n = \tfrac{1}{10}\left[7^{n} - (-3)^{n}\right],\ \forall n \geq 0 \]

Paso 3 — Comprobación

Con la fórmula: \(a_2 = \tfrac{49 - 9}{10} = 4\), \(a_3 = \tfrac{343 + 27}{10} = 37\). Son los datos.

Respuesta

\(b = -4,\ c = -21\) y \(a_n = \tfrac{1}{10}\left[7^{n} - (-3)^{n}\right],\ n \geq 0\).

Solución del libro

El libro da \(b = -4\), \(c = -21\) y \(a_n = (1/10)[(7)^{n} - (-3)^{n}]\). Coincide.

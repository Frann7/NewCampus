Qué evalúa

Qué es un IDE y si tiene que estar instalado en la computadora.

La idea

Un IDE (entorno de desarrollo integrado) junta en un programa las herramientas para programar: editor, ejecutar, depurar, Git, autocompletado. Ejemplos: Visual Studio Code, NetBeans, PhpStorm.

Lo falso es el “siempre”: hay IDE en la nube, que se usan desde el navegador sin instalar nada: GitHub Codespaces, Replit, AWS Cloud9, VS Code para web.

Trampas

  • Las palabras absolutas (siempre, nunca, solo) son la señal: con un solo contraejemplo la frase es falsa. El resto de la definición está bien.

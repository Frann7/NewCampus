Qué evalúa

La diapositiva "Incorporando soporte" de la clase 17.

Por qué es verdadero

GParted tiene el menú Ver → Soporte para sistemas de archivos, con una tabla que dice qué puede hacer con cada uno (crear, aumentar, reducir, mover, copiar…) y qué paquete hace falta (e2fsprogs para ext2/3/4, ntfs-3g para NTFS, xfsprogs para XFS…). Si falta, se instala y aparece el soporte. El ejemplo de la clase es ReiserFS 4: 

apt install reiser4progs

Indique la definición más correcta para PHP (PHP HyperText PreProcessor).

Parcial PHP · preg. 15

  • PHP es un lenguaje de programación compilado que se ejecuta del lado del cliente.
  • PHP es un lenguaje de programación interpretado que se ejecuta del lado del cliente.
  • PHP es un lenguaje de programación interpretado que se ejecuta del lado del servidor.
  • PHP es un lenguaje de programación compilado que se ejecuta del lado del servidor.

PHP es un lenguaje interpretado (el intérprete ejecuta el script en cada pedido, no se compila antes) que se ejecuta del lado del servidor (el navegador recibe solo el HTML que genera, nunca el código PHP).

Las otras opciones cambian una de esas dos palabras: compilado, o del lado del cliente (eso es JavaScript).

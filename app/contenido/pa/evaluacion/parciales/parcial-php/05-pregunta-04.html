Qué evalúa

Las tres funciones básicas de mysqli para trabajar con una base de datos MySQL desde PHP. Es de la Clase 6.

El concepto, desde cero

Una base de datos guarda información ordenada en tablas: cada tabla es como una planilla, con columnas (los datos que se guardan: nombre, edad…) y filas (cada registro: un alumno, un producto…). MySQL (o MariaDB, que viene en el XAMPP) es el programa que maneja esas bases: un servidor de base de datos que recibe pedidos y los responde.

Los pedidos se escriben en SQL, el lenguaje de las bases de datos; a cada pedido se lo llama consulta. Por ejemplo, SELECT nombre FROM alumnos quiere decir “traé la columna nombre de la tabla alumnos”.

PHP habla con MySQL a través de mysqli, un grupo de funciones que empiezan con mysqli_. Una función es una instrucción con nombre que ya viene hecha: se la llama con su nombre y, entre paréntesis, los datos que necesita (sus parámetros), y devuelve un resultado que se guarda en una variable. Leer datos de una base siempre lleva los mismos tres pasos, y cada uno tiene su función:

PasoFunciónQué hace
1. Conectarsemysqli_connect(servidor, usuario, clave, base)Abre la conexión con el servidor de base de datos y devuelve el identificador de conexión: un valor que representa esa conexión abierta y que se pasa a todas las funciones que vienen después, para que sepan por dónde hablar.
2. Consultarmysqli_query(conexion, sql)Manda una consulta SQL por esa conexión y devuelve el resultado (todas las filas que salieron).
3. Leer las filasmysqli_fetch_array(resultado)Devuelve una fila del resultado como array (se puede leer por nombre de columna o por número) y avanza el puntero —la marca interna de “por qué fila voy”— a la siguiente. Cuando no quedan filas devuelve null (“nada”), que el while toma como falso.

Un ejemplo con las tres

Un ejemplo típico, con una base campus y una tabla alumnos inventadas:

<?php
$conexion = mysqli_connect("localhost", "root", "", "campus");
$resultado = mysqli_query($conexion, "SELECT nombre FROM alumnos");
while ($fila = mysqli_fetch_array($resultado)) {
    echo $fila['nombre'] . "<br>";
}
?>

Cómo se responde

  • “Crea una conexión” → mysqli_connect() (connect = conectar).
  • “Enviar una consulta… asociada al identificador de conexión” → mysqli_query() (query = consulta).
  • “Devuelve una matriz que corresponde a la fila… mueve el puntero” → mysqli_fetch_array() (fetch = traer; matriz es otra forma de decir array).
La trampa

mysqli_query() y mysqli_fetch_array() parecen hacer lo mismo, pero query ejecuta la consulta y trae el resultado entero, mientras que fetch_array saca de ese resultado una fila por vez. La pista en el enunciado es “fila” y “puntero”.

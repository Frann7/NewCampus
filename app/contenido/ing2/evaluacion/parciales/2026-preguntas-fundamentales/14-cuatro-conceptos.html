Realice un cuadro comparativo entre gestión de cambios, gestión de la configuración, control de cambios y control de versiones.

Gestión de cambiosRegistrar y evaluar cada cambio que se pide (tiempo, recursos, riesgos) y decidir si se hace.Un cliente pide algo nuevo: se evalúa y se decide.

Cómo no mezclarlos

Van de lo más amplio a lo más técnico: la gestión de cambios decide si se hace un cambio; la gestión de la configuración ordena todo lo del proyecto; el control de cambios es el trámite para aprobarlo; el control de versiones guarda cómo quedó el código.

Trampa

Git es control de versiones, no gestión de cambios: Git no decide si un cambio se aprueba.

9. DELETE, DROP, UPDATE y ALTER

Unidad 1 · DDL y DML

¿Cuál es la diferencia entre DELETE y DROP? ¿Y entre UPDATE y ALTER?

✓ RespuestaPara aprender y escribir en la hoja
  • DELETE (DML) borra filas de una tabla; la tabla sigue existiendo. DROP (DDL) borra la tabla entera, con su estructura y sus datos.
  • UPDATE (DML) cambia valores de filas que existen. ALTER (DDL) cambia la estructura: agrega, modifica o saca columnas y restricciones.
✎ ExplicaciónUn ejemplo, de dónde sale y las trampas 
DELETE FROM Turno WHERE Estado = 'Cancelado';   -- borra esos turnos
DROP TABLE Turno;                               -- la tabla deja de existir
UPDATE Animal SET Peso = 12.5 WHERE NumeroHC = 7; -- cambia un dato
ALTER TABLE Animal ADD Color VARCHAR(20);        -- agrega una columna

Es la forma de comprobar que se entendió la diferencia entre DDL y DML. Unidad 1, sección 2, y Unidad 4, sección 5.

Trampas

  • DELETE y UPDATE sin WHERE afectan a todas las filas.

¿Qué significa esta declaración dentro de una clase de C++?

virtual double area() const = 0;

Inventada · Base, sección 4

  • Que area() devuelve siempre 0.
  • Que area() es un método virtual puro: la clase es abstracta y no se puede instanciar.
  • Que area() es un método estático.
  • Que area() es privado.

virtual ... = 0; es un método virtual puro: está declarado pero no tiene código, y las clases hijas están obligadas a escribirlo. Una clase con al menos uno es abstracta: no se puede hacer new de ella. Es como se escribe en C++ una interfaz o un método abstracto de un diagrama.

El tiempo semanal de mantenimiento de una máquina (en horas) depende de dos variables aleatorias \(X\) e \(Y\): duración de mantenimiento mecánico y duración de mantenimiento eléctrico, siendo su función de densidad conjunta:

\[ f(x, y) = k(x + 2y) \qquad 0 \leq x \leq 1,\ \ 0 \leq y \leq 1 \]

  1. Hallar el valor de \(k\) para que \(f(x,y)\) sea una función de densidad de probabilidad.
  2. Las densidades marginales de las variables aleatorias \(X\) e \(Y\). ¿Son independientes? Justifique.
  3. ¿Cuál es la probabilidad de que el tiempo de mantenimiento mecánico esté entre un cuarto y tres cuartos de hora?
  4. Defina Esperanza y Varianza de una variable aleatoria continua.
  5. Demuestre la propiedad o teorema de Varianza de una variable \(X\).

Este final no tiene resolución cargada: los resultados se calcularon para este ejercicio.

  1. ¿Qué condición da la ecuación para hallar \(k\)?

    • Que la integral doble de \(f\) sobre el cuadrado \([0,1]\times[0,1]\) valga 1
    • Que \(f(1,1) = 1\)
    • Que la integral de \(f\) en \(x\) valga 1 para cada \(y\)
    • Que \(f(x,y) = g(x)\,h(y)\)

    Con una variable el área total es 1. Con dos, lo que vale 1 es el volumen bajo la superficie.

    \(\int_{0}^{1}\!\int_{0}^{1} k(x + 2y)\,dx\,dy = 1\). Se integra primero en \(x\) (con \(y\) como constante) y después en \(y\).

  2. Integrá en \(x\): \(\left[\frac{x^{2}}{2} + 2xy\right]_{0}^{1} = \square + 2y\). ¿Cuánto vale el término suelto?

    \(\frac{1^{2}}{2}\).

    Queda \(\frac{1}{2} + 2y\).

  3. ¿Cuánto vale \(\displaystyle\int_{0}^{1}\!\!\int_{0}^{1} (x + 2y)\,dx\,dy\)?

    Después de integrar en \(x\) queda \(\int_{0}^{1}\left(\frac{1}{2} + 2y\right) dy\). Primitiva: \(\frac{y}{2} + y^{2}\).

    \(\frac{1}{2} + 1 = \frac{3}{2} = 1{,}5\).

  4. ¿Cuánto vale \(k\)?

    El volumen total es 1: \(k \cdot \int_{0}^{1}\!\int_{0}^{1}(x + 2y)\,dx\,dy = 1\).

    \(\frac{3}{2}k = 1 \Rightarrow k = \frac{2}{3} \approx 0{,}6667\).

  5. ¿Cómo se obtiene la densidad marginal de \(X\)?

    • \(\displaystyle g(x) = \int_{0}^{1} f(x,y)\,dy\): se integra en \(y\)
    • \(\displaystyle g(x) = \int_{0}^{1} f(x,y)\,dx\): se integra en \(x\)
    • \(g(x) = f(x, 0)\)
    • \(g(x) = f(x, 1) - f(x, 0)\)

    Es lo mismo que sumar una fila en una tabla: se “barre” la otra variable.

    La marginal de \(X\) integra la conjunta en todo el recorrido de \(Y\): \(g(x) = \int f(x,y)\,dy\). Para \(Y\), al revés: \(h(y) = \int f(x,y)\,dx\).

  6. En \(g(x) = \frac{2}{3}\int_{0}^{1}(x + 2y)\,dy\), ¿cuánto vale \(\displaystyle\int_{0}^{1} 2y\,dy\)?

    Primitiva: \(y^{2}\).

    \(1^{2} - 0 = 1\). Y \(\int_{0}^{1} x\,dy = x\) (acá \(x\) es constante).

  7. ¿Cuál es la densidad marginal de \(X\)?

    • \(g(x) = \frac{2}{3}(x + 1)\), para \(0 \leq x \leq 1\)
    • \(g(x) = \frac{2}{3}\left(\frac{x^{2}}{2} + 2x\right)\), para \(0 \leq x \leq 1\)
    • \(g(x) = \frac{2}{3}\left(x + \frac{1}{2}\right)\), para \(0 \leq x \leq 1\)
    • \(g(x) = \frac{2}{3}(x + 2y)\), para \(0 \leq x \leq 1\)

    \(g(x) = \int_{0}^{1} \frac{2}{3}(x + 2y)\,dy\). La marginal de \(X\) no puede tener \(y\).

    \(g(x) = \frac{2}{3}\left[xy + y^{2}\right]_{0}^{1} = \frac{2}{3}(x + 1)\). Control: \(\int_{0}^{1}\frac{2}{3}(x+1)\,dx = \frac{2}{3}\cdot\frac{3}{2} = 1\).

  8. Para \(h(y) = \frac{2}{3}\int_{0}^{1}(x + 2y)\,dx\), ¿cuánto vale \(\displaystyle\int_{0}^{1} x\,dx\)?

    Primitiva: \(\frac{x^{2}}{2}\).

    \(\frac{1}{2}\). Y \(\int_{0}^{1} 2y\,dx = 2y\) (acá \(y\) es constante).

  9. ¿Cuál es la densidad marginal de \(Y\)?

    • \(h(y) = \frac{2}{3}\left(\frac{1}{2} + 2y\right) = \frac{1}{3} + \frac{4}{3}y\), para \(0 \leq y \leq 1\)
    • \(h(y) = \frac{2}{3}(1 + 2y)\), para \(0 \leq y \leq 1\)
    • \(h(y) = \frac{2}{3}(y + 1)\), para \(0 \leq y \leq 1\)
    • \(h(y) = \frac{2}{3}\left(\frac{1}{2} + y^{2}\right)\), para \(0 \leq y \leq 1\)

    \(h(y) = \int_{0}^{1} \frac{2}{3}(x + 2y)\,dx\): ahora la constante es \(y\).

    \(h(y) = \frac{2}{3}\left[\frac{x^{2}}{2} + 2xy\right]_{0}^{1} = \frac{2}{3}\left(\frac{1}{2} + 2y\right) = \frac{1}{3} + \frac{4}{3}y\). Control: \(\int_{0}^{1} h(y)\,dy = \frac{1}{3} + \frac{2}{3} = 1\).

  10. Probá la independencia en el punto \((0,0)\). ¿Cuánto vale \(g(0)\cdot h(0)\)?

    \(g(0) = \frac{2}{3}(0 + 1)\) y \(h(0) = \frac{1}{3}\).

    \(\frac{2}{3}\cdot\frac{1}{3} = \frac{2}{9} \approx 0{,}2222\). En cambio \(f(0,0) = \frac{2}{3}(0 + 0) = 0\).

  11. ¿Son independientes \(X\) e \(Y\)?

    • No: \(g(x)\,h(y) \neq f(x,y)\); por ejemplo en \((0,0)\), \(\frac{2}{9} \neq 0\)
    • Sí: el dominio es un cuadrado
    • Sí: las dos marginales integran 1
    • No: porque \(k \neq 1\)

    Son independientes si y solo si \(f(x,y) = g(x)\,h(y)\) para todo par. Multiplicá las marginales y compará.

    \(g(x)\,h(y) = \frac{2}{3}(x+1)\left(\frac{1}{3} + \frac{4}{3}y\right)\), que no es \(\frac{2}{3}(x + 2y)\): en \((0,0)\) da \(\frac{2}{9}\) y \(f(0,0) = 0\). No son independientes. La conjunta es una suma, no se factoriza en una parte con \(x\) por otra con \(y\).

  12. La pregunta es solo sobre el mantenimiento mecánico. ¿Qué se integra?

    • \(\displaystyle\int_{1/4}^{3/4} g(x)\,dx\), la marginal de \(X\)
    • \(\displaystyle\int_{1/4}^{3/4} h(y)\,dy\), la marginal de \(Y\)
    • \(\displaystyle\int_{1/4}^{3/4}\!\int_{1/4}^{3/4} f(x,y)\,dx\,dy\)
    • \(g\left(\frac{3}{4}\right) - g\left(\frac{1}{4}\right)\)

    Si solo interviene \(X\), se usa la densidad de \(X\) sola. ¿Cuál es la variable del mantenimiento mecánico?

    Mecánico es \(X\), y la otra variable queda libre: \(P\left(\frac{1}{4} \leq X \leq \frac{3}{4}\right) = \int_{1/4}^{3/4} \frac{2}{3}(x + 1)\,dx\). Integrar la conjunta con \(y\) de 0 a 1 da lo mismo.

  13. La primitiva de \(x + 1\) es \(\frac{x^{2}}{2} + x\). ¿Cuánto vale en \(x = \frac{3}{4}\)?

    \(\frac{0{,}5625}{2} + 0{,}75\).

    \(0{,}28125 + 0{,}75 = 1{,}03125 = \frac{33}{32}\).

  14. ¿Y en \(x = \frac{1}{4}\)?

    \(\frac{0{,}0625}{2} + 0{,}25\).

    \(0{,}03125 + 0{,}25 = 0{,}28125 = \frac{9}{32}\).

  15. ¿Cuánto vale \(\displaystyle\int_{1/4}^{3/4} (x + 1)\,dx\)?

    Primitiva \(\frac{x^{2}}{2} + x\), evaluada arriba menos abajo.

    \(1{,}03125 - 0{,}28125 = 0{,}75\).

  16. ¿Cuál es la probabilidad de que el mantenimiento mecánico dure entre un cuarto y tres cuartos de hora?

    \(\int_{1/4}^{3/4} g(x)\,dx\), con \(g(x) = \frac{2}{3}(x + 1)\).

    \(P = \frac{2}{3} \cdot 0{,}75 = 0{,}5\). La mitad de las semanas el mantenimiento mecánico dura entre 15 y 45 minutos.

  17. ¿Cuál es la definición de Esperanza de una variable aleatoria continua con densidad \(f\)?

    • \(\displaystyle E(X) = \mu = \int_{-\infty}^{\infty} x \cdot f(x)\,dx\)
    • \(\displaystyle E(X) = \int_{-\infty}^{\infty} f(x)\,dx\)
    • \(E(X) = \sum x \cdot f(x)\)
    • \(\displaystyle E(X) = \int_{-\infty}^{\infty} x^{2} \cdot f(x)\,dx\)

    Cada valor pesado por su densidad; en una continua la suma se vuelve integral.

    \(E(X) = \int x\,f(x)\,dx\): el promedio a la larga. La segunda opción siempre da 1, y la última es \(E(X^{2})\).

  18. ¿Cuál es la definición de Varianza de una variable aleatoria continua?

    • \(\displaystyle V(X) = E\big[(X - \mu)^{2}\big] = \int_{-\infty}^{\infty} (x - \mu)^{2} f(x)\,dx\)
    • \(\displaystyle V(X) = \int_{-\infty}^{\infty} (x - \mu)\,f(x)\,dx\)
    • \(V(X) = [E(X)]^{2}\)
    • \(\displaystyle V(X) = \sqrt{\int_{-\infty}^{\infty} x^{2} f(x)\,dx}\)

    Es el promedio de las distancias a la media, al cuadrado.

    \(V(X) = E[(X-\mu)^{2}]\). Sin el cuadrado (segunda opción) los apartamientos se cancelan y da siempre 0. \(V(X) = E(X^{2}) - \mu^{2}\) es la fórmula de cálculo, que se demuestra en el inciso e.

  19. La demostración de \(V(X) = E(X^{2}) - \mu^{2}\), ¿de dónde parte?

    • De la definición: \(V(X) = \int (x - \mu)^{2} f(x)\,dx\)
    • De \(V(X) = E(X^{2}) - \mu^{2}\)
    • De \(E(X) = \int x\,f(x)\,dx\) elevada al cuadrado
    • De \(V(aX + b) = a^{2}V(X)\)

    No se puede partir de lo que se quiere demostrar.

    Se parte de la definición del inciso d. \(\mu = E(X)\) es un número fijo.

  20. Al desarrollar el cuadrado y separar la integral, ¿cómo queda?

    • \(\displaystyle \int x^{2} f(x)\,dx - 2\mu\int x\,f(x)\,dx + \mu^{2}\int f(x)\,dx\)
    • \(\displaystyle \int x^{2} f(x)\,dx - \mu^{2}\int f(x)\,dx\)
    • \(\displaystyle \int x^{2} f(x)\,dx - 2\mu + \mu^{2}\)
    • \(\displaystyle \left(\int x\,f(x)\,dx - \mu\right)^{2}\)

    \((x - \mu)^{2} = x^{2} - 2\mu x + \mu^{2}\); la integral de una suma es la suma de las integrales y las constantes salen afuera.

    \(\int (x^{2} - 2\mu x + \mu^{2}) f(x)\,dx = \int x^{2} f(x)\,dx - 2\mu \int x f(x)\,dx + \mu^{2}\int f(x)\,dx\): \(2\mu\) y \(\mu^{2}\) son constantes.

  21. ¿Cuánto vale \(\displaystyle\int_{-\infty}^{\infty} f(x)\,dx\)?

    Es el área total bajo una densidad.

    1, por ser densidad. Y \(\int x\,f(x)\,dx = \mu\), \(\int x^{2} f(x)\,dx = E(X^{2})\).

  22. Reemplazando cada integral por lo que vale, ¿cómo termina?

    • \(E(X^{2}) - 2\mu \cdot \mu + \mu^{2} \cdot 1 = E(X^{2}) - \mu^{2}\)
    • \(E(X^{2}) - 2\mu + \mu^{2} = E(X^{2}) - \mu\)
    • \(E(X^{2}) - 2\mu^{2} + \mu^{2} \cdot 0 = E(X^{2}) - 2\mu^{2}\)
    • \(E(X^{2}) \cdot \mu^{2} - 2\mu = E(X^{2}) - \mu^{2}\)

    \(\int x\,f(x)\,dx = \mu\) y \(\int f(x)\,dx = 1\).

    \[ V(X) = E(X^{2}) - 2\mu^{2} + \mu^{2} = E(X^{2}) - \mu^{2} = E(X^{2}) - [E(X)]^{2} \qquad \blacksquare \]

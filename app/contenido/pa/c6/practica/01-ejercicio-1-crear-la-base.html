Ejercicio 1 · phpMyAdmin

Creación de la base de datos

Haciendo uso de PhpMyAdmin, cree una base de datos de nombre DB_Comentarios. Dicha base de datos deberá contener una sola tabla de nombre comentarios con los siguientes campos: id_comentario: INTEGER, not null, autoincrement; nombre: VARCHAR(100); asunto: VARCHAR(150); correo: VARCHAR(100); comentario: VARCHAR(250). El campo id_comentario deberá ser definido como clave primaria de la tabla al momento de crear la misma.

Paso 1 — Qué pide

Una tabla con una columna por cada campo del formulario de contacto de la Clase 3 (nombre, asunto, correo, comentario), más un número que identifique a cada comentario. Ese número tiene que ser clave primaria (no se repite) y autoincremental (lo pone la base), como se vio en la sección 2 de la teoría.

Las otras cuatro columnas no dicen "not null", así que el enunciado no exige nada: el SQL de abajo las deja opcionales (Nulo tildado). Si quedan sin tildar tampoco molesta, porque el formulario siempre manda los cuatro campos, aunque sea vacíos. Motor: InnoDB, el de fábrica.

Paso 4 — El SQL equivalente

Es lo que phpMyAdmin ejecuta al guardar. También se puede pegar en la pestaña SQL y da lo mismo:

CREATE DATABASE DB_Comentarios;

CREATE TABLE comentarios (
    id_comentario INT NOT NULL AUTO_INCREMENT,
    nombre        VARCHAR(100),
    asunto        VARCHAR(150),
    correo        VARCHAR(100),
    comentario    VARCHAR(250),
    PRIMARY KEY (id_comentario)
);

Paso 5 — Qué se ve

En el panel izquierdo aparece la base y, adentro, la tabla comentarios. En su pestaña Estructura se ven las cinco columnas, con una llave al lado de id_comentario (clave primaria) y AUTO_INCREMENT en la columna Extra. La tabla todavía está vacía: las filas las va a cargar el ejercicio 3.

En Windows la base aparece en minúsculas

MariaDB en Windows guarda los nombres en minúsculas: vas a ver db_comentarios. No es un error, y conectarse con 'DB_Comentarios' funciona igual.

Resultado

Base DB_Comentarios con la tabla comentarios: id_comentario INT clave primaria autoincremental, y nombre, asunto, correo, comentario de tipo VARCHAR(100), (150), (100) y (250). La guía no tiene hoja de resultados.

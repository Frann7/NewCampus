6. El captcha: el código dibujado en una imagen

Para qué sirve

El token de la sección 5 está escrito en el HTML, y un programa que lee el HTML lo encuentra. El captcha cambia una sola cosa: el código no se escribe en la página, se dibuja en una imagen, y se le pide a la persona que lo tipee en un campo. Leer texto de una imagen es mucho más difícil para un programa que para una persona.

Los pasos son los mismos del token:

  1. PHP inventa un código al azar y lo guarda en la sesión.
  2. Con ese código dibuja una imagen, que se muestra en el formulario.
  3. La persona lee la imagen y escribe el código en un campo de texto.
  4. El script que recibe compara lo escrito con lo guardado en la sesión.

Una imagen hecha por PHP

En el formulario de la cátedra (formCaptcha.php) la imagen es <img src="includes/rdnimg.php">: el src no es un archivo .png sino un script PHP. Funciona porque el navegador, al ver un <img>, hace otro pedido aparte a esa dirección, y rdnimg.php le contesta con una imagen en vez de con HTML. El orden real es:

  1. El navegador pide formCaptcha.php y recibe el HTML del formulario.
  2. Ve el <img> y pide includes/rdnimg.php (con la misma cookie de sesión).
  3. rdnimg.php sortea el código, lo guarda en $_SESSION['rand_code'] y devuelve la imagen.

En el PDF de teoría el ejemplo pone <img src="imgRnd.png">: es una simplificación. Una imagen .png fija no puede mostrar un código distinto cada vez; tiene que ser un script que la dibuje, como rdnimg.php.

Sintaxis

El campo en el formulario 
<img src="includes/rdnimg.php">
<input type="text" name="rand_code" value="">
Dibujar la imagen (las funciones de rdnimg.php) 
header('Content-Type: image/png');                 // "lo que sigue es una imagen PNG"
$im = imagecreatetruecolor(120, 30);               // lienzo de 120 x 30 píxeles
$color_texto = imagecolorallocate($im, 233, 14, 91); // un color (rojo, verde, azul)
imagestring($im, 10, 5, 5, $str, $color_texto);    // escribe $str en el lienzo
imagepng($im);                                     // manda la imagen al navegador
imagedestroy($im);                                 // libera la memoria

Qué es cada parte

ParteQué hace
header('Content-Type: image/png')Avisa en la cabecera de la respuesta que no viene HTML sino una imagen PNG. Como toda cabecera, tiene que ir antes de cualquier salida.
imagecreatetruecolor(ancho, alto)Crea una imagen en memoria, toda negra, del tamaño pedido.
imagecolorallocate($im, r, g, b)Define un color por sus componentes rojo, verde y azul (de 0 a 255). 233, 14, 91 es un rosa fuerte.
imagestring($im, fuente, x, y, texto, color)Escribe el texto con una de las letras que trae PHP (de la 1, la más chica, a la 5). x e y son los píxeles desde la esquina de arriba a la izquierda.
imagepng($im)Convierte la imagen a PNG y la manda como respuesta.
imagedestroy($im)Borra la imagen de la memoria del servidor.
name="rand_code"El campo donde la persona escribe el código; llega en $_POST['rand_code'].

Estas funciones son de GD, una extensión de PHP para dibujar imágenes (una extensión es un paquete de funciones que se activa en el php.ini).

Ejemplo 1 — rdnimg.php, el script de la cátedra

Enunciado

¿Qué hace este script y qué se ve en el formulario?

<?php
session_start();

if (!empty($_SESSION['rand_code'])) {
    unset($_SESSION['rand_code']);
}

if (empty($_SESSION['rand_code'])) {
    $str = "";
    $a = "0123456789abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ";
    for ($i = 0; $i <= 3; $i++) {
        $str .= $a[rand(0, 61)];
    }
    $_SESSION['rand_code'] = $str;
}
header('Content-Type: image/png');
$im = imagecreatetruecolor(120, 30);
$color_texto = imagecolorallocate($im, 233, 14, 91);
imagestring($im, 10, 5, 5, $str, $color_texto);
imagepng($im);
imagedestroy($im);
?>

Qué se ve y por qué

Un rectángulo negro de 120 × 30 píxeles con cuatro caracteres rosas arriba a la izquierda (en la prueba, B4Y5). Al mismo tiempo, en el servidor, la sesión quedó así (se abrió el archivo): rand_code|s:4:"B4Y5";. La persona escribe B4Y5 en el campo, y procesoForm.php compara $_POST['rand_code'] con $_SESSION['rand_code'].

Ejemplo 2 — ¿Qué responde procesoForm.php? (formato del parcial)

Enunciado

La imagen mostró B4Y5, así que $_SESSION['rand_code'] vale "B4Y5". ¿Qué imprime este fragmento de procesoForm.php si la persona escribe B4Y5? ¿Y si escribe b4y5? 

<?php
session_start();
if (!empty($_POST['rand_code'])) {
    if ($_POST['rand_code'] == $_SESSION['rand_code']) {
        echo "LOS DATOS PROVIENEN DE NUESTRO FORMULARIO CON CAPTCHA.";
    } else {
        echo "LOS DATOS PROVIENEN DE OTRO ORIGEN.";
    }
}
?>

Qué hace cada línea

LíneaCon B4Y5Con b4y5
!empty($_POST['rand_code'])Hay algo: entra.Hay algo: entra.
$_POST['rand_code'] == $_SESSION['rand_code']"B4Y5" == "B4Y5" → true"b4y5" == "B4Y5" → false: las mayúsculas y las minúsculas son caracteres distintos
echo ...el mensaje de "CON CAPTCHA"el mensaje de "OTRO ORIGEN"

Qué imprime y por qué

Con B4Y5:

LOS DATOS PROVIENEN DE NUESTRO FORMULARIO CON CAPTCHA.

Con b4y5:

LOS DATOS PROVIENEN DE OTRO ORIGEN.

La comparación con == entre textos distingue mayúsculas de minúsculas. La persona tiene que copiar el código exacto.

Errores y trampas

Lo que más se confunde
  • En este XAMPP, GD viene apagada. En C:\xampp\php\php.ini la línea es ;extension=gd (el ; la desactiva). Así, rdnimg.php corta con Fatal error: Call to undefined function imagecreatetruecolor() y en el formulario se ve una imagen rota. Hay que sacarle el ; y reiniciar Apache desde el panel de XAMPP.
  • ¿Cuántos caracteres? for ($i = 0; $i <= 3; $i++) da 4 vueltas (0, 1, 2, 3), no 3. Con < serían 3.
  • Cada vez que se pide la imagen, cambia el código. Si la imagen se recarga, el código anterior deja de servir.
  • El código lo crea la imagen, no el formulario. formCaptcha.php además arma un $_SESSION['token'] de 6 caracteres que no se usa en ningún lado: el que se compara es rand_code, que crea rdnimg.php.
  • No hay que imprimir nada antes de header() en rdnimg.php: un espacio o una línea en blanco antes del <?php se mezcla con los bytes de la imagen y la rompe.

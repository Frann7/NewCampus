Los dispositivos externos dedicados a la E/S en un computador se pueden agrupar, a grandes rasgos, en tres categorías:

Segundo parcial 2025 · preg. 34

  • Legibles para el usuario, Legibles para la máquina y Criptografía
  • Legibles para el usuario, Legibles para la máquina y de energía.
  • Legibles para el usuario y Legibles para la máquina
  • Legibles para el usuario, Legibles para la máquina y de Comunicación.

Correcta:

  • Legibles para el usuario, Legibles para la máquina y de Comunicación

Qué evalúa

Las tres categorías de dispositivos externos de Stallings (capítulo de E/S).

La idea

CategoríaPara quéEjemplos
Legibles para el usuarioComunicarse con el usuario.Impresoras, pantalla, teclado, mouse.
Legibles para la máquinaComunicarse con equipos electrónicos.Discos, pendrives, sensores, controladores.
De comunicaciónComunicarse con dispositivos remotos.Módems, placas de red.

Entre categorías (y dentro de cada una) cambian la velocidad, el uso, la complejidad del control, la unidad de transferencia, cómo se representan los datos y las condiciones de error.

Trampas

  • Es la clasificación de Stallings (por con quién se comunica el dispositivo). No mezclarla con la de Tanenbaum, de bloque y de carácter (preguntas 26, 35 y 43).

Un mini sitio que arma una tabla con foreach

La carpeta de práctica de la Clase 2 trae un ejemplo.zip: un pequeño "Sistema Recursos Humanos" con tres páginas (inicio, formulario de personas y listado de personas). Lo que toca a esta clase es cómo el listado se arma recorriendo un arreglo multidimensional con foreach.

Paso 1 — Qué archivos tiene
ArchivoQué es

Bootstrap es una librería de estilos: las clases como btn btn-info o table que aparecen en el HTML le dan el aspecto a botones y tablas. No es PHP.

Paso 2 — Cómo se arma cada página: require_once 
<!DOCTYPE html>
<html lang="es">
<?php require_once 'includes/head.php';?>
<?php require_once 'includes/menu.php'; ?>
    ... el contenido propio de la página ...
<?php require_once 'includes/footer.php'; ?>
  • require_once 'archivo.php'; inserta en ese lugar el contenido de otro archivo, como si estuviera escrito ahí. Si el archivo ya se había insertado antes, no lo repite (eso es el _once, "una vez").
  • Así, el encabezado, el menú y el pie se escriben una sola vez y las tres páginas los comparten: si se cambia el menú, cambia en todas.
  • Las etiquetas quedan repartidas: head.php abre el <body> y un <div class="container">, y footer.php cierra </body> y </html>.
Paso 3 — El arreglo y el foreach (php/datosTabla.php) 
<?php
    $vPersonas = array(
        array(
            'id'=>3,
            'documento' => '22333444',
            'nombre' => 'Toto',
            'apellido' => 'Toto'
        ),
        array(
            'id'=>4,
            'documento' => '23232332',
            'nombre' => 'Tata',
            'apellido' => 'Tata'
        )
    );

    $filasTabla="";
    foreach ( $vPersonas as $cadaPersona ) {
        $filasTabla .= "<tr>";
            $filasTabla .= "<th scope='row'>" . $cadaPersona['id'] . "</th>";
            $filasTabla .= "<td>" . $cadaPersona['documento'] . "</td>";
            $filasTabla .= "<td>" . $cadaPersona['nombre'] . "</td>";
            $filasTabla .= "<td>" . $cadaPersona['apellido'] . "</td>";
        $filasTabla .= "</tr>";
    }
?>

El operador .=

$filasTabla .= "texto"; es una forma corta de $filasTabla = $filasTabla . "texto";: agrega el texto al final de lo que ya tenía la variable. Así se va armando un string largo de a pedazos.

Qué hace cada línea

LíneaQué haceCómo quedan las variables
$vPersonas = array( array(...), array(...) );Un arreglo multidimensional (teoría, sección 4): dos elementos, cada uno un arreglo asociativo con los datos de una persona0 => (id 3, Toto Toto) · 1 => (id 4, Tata Tata)
$filasTabla="";Empieza con un string vacío, para ir agregándole$filasTabla = ''
foreach ( $vPersonas as $cadaPersona ) {Recorre las personas (teoría, sección 6); en cada vuelta, $cadaPersona es el arreglo de unaVuelta 1: la de id 3; vuelta 2: la de id 4
$filasTabla .= "<tr>";Abre una fila de tabla HTMLse agrega <tr>
... "<th scope='row'>" . $cadaPersona['id'] . "</th>";Primera celda: el id, leído con su clave (teoría, sección 2)se agrega <th scope='row'>3</th>
Las tres líneas de <td>Una celda con el documento, otra con el nombre, otra con el apellidose agregan tres <td>...</td>
$filasTabla .= "</tr>";Cierra la filauna fila completa por persona

El archivo no imprime nada: deja el texto armado en $filasTabla. Al terminar el foreach, la variable vale (comprobado con PHP; todo va en una sola línea, acá se cortó en dos para que entre): 

<tr><th scope='row'>3</th><td>22333444</td><td>Toto</td><td>Toto</td></tr>
<tr><th scope='row'>4</th><td>23232332</td><td>Tata</td><td>Tata</td></tr>

Las comillas simples de scope='row' pueden ir sueltas adentro porque el string está entre comillas dobles (teoría, sección 10).

Paso 4 — Dónde se usa (listadoPersonas.php) 
<?php require_once 'php/datosTabla.php'; ?>
...
    <table class="table">
        <thead> ... #, Documento, Nombre, Apellido ... </thead>
        <tbody>
            <tr> ... 1, 22333444, Exeuiel, Aramburu ... </tr>
            <tr> ... 2, 23232332, Federico, Bonnet ... </tr>
            <?php echo $filasTabla; ?>
        </tbody>
    </table>
  • El require_once de arriba ejecuta datosTabla.php, así que $filasTabla ya existe en esta página.
  • La tabla tiene dos filas escritas a mano en HTML, y en el lugar del echo $filasTabla; aparecen las dos filas que armó el foreach.

La idea del ejemplo: los datos que hoy están en el arreglo podrían venir de otro lado (más adelante, de una base de datos, Clase 6), y la página no cambiaría: el foreach arma una fila por cada persona, sean 2 o 200.

Paso 5 — El formulario (formPersonas.php y procesoFormulario.php)

Los formularios son tema de la Clase 3; acá solo lo que hace falta para entender qué pasa al usar el ejemplo. 

<form method="GET" action="/php/procesoFormulario.php" ...>
    ... campos nombre, apellido, fechaNacimiento y ciudad ...
    <button class="btn btn-primary" type="submit">Enviar datos</button>
</form>
  • action dice a qué script se mandan los datos y method="GET" cómo (pegados en la dirección de la página).
  • En procesoFormulario.php hay tres bloques: uno para GET y otro para POST con los campos de este formulario, y un tercero para POST con otros campos (correo, fecha_nacimiento, opciones, comentarios). Los dos primeros están comentados (entre /* y */), así que solo funciona el tercero.
Tal como viene, enviar el formulario muestra una página en blanco

El formulario manda por GET, pero el único bloque activo de procesoFormulario.php pregunta si el método es POST (if ( $_SERVER["REQUEST_METHOD"] == "POST")): no entra y no imprime nada (comprobado con el servidor de PHP). Para verlo andar hay que descomentar el bloque // METODO GET, que lee justo los campos de este formulario.

Otros detalles del ejemplo
  • action="/php/procesoFormulario.php" y el ícono /imgs/favicon.ico empiezan con /: se buscan desde la raíz del servidor. Si el proyecto está en una subcarpeta de htdocs (por ejemplo http://localhost/ejemplo/), apuntan a http://localhost/php/... y no los encuentra. Sin la barra inicial (php/procesoFormulario.php) funcionan en cualquier carpeta.
  • En el <select> de ciudad, las tres opciones tienen value="Paraná": elijas Oro Verde o Diamante, se envía Paraná.

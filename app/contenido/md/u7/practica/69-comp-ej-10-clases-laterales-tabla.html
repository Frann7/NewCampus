Complementaria P3 · Grupos · Ej. 10 · Subgrupo generado y clases laterales

Grupo dado por tabla: \(\langle a \rangle\), \(\langle a \rangle * c = c * \langle a \rangle\) y las clases laterales de \(\langle d \rangle\)

La siguiente tabla da la operación binaria para un grupo \((G, *)\):

\(*\)\(e\)\(a\)\(b\)\(c\)\(d\)\(f\)
\(e\)\(e\)\(a\)\(b\)\(c\)\(d\)\(f\)
\(a\)\(a\)\(b\)\(e\)\(d\)\(f\)\(c\)
\(b\)\(b\)\(e\)\(a\)\(f\)\(c\)\(d\)
\(c\)\(c\)\(f\)\(d\)\(e\)\(b\)\(a\)
\(d\)\(d\)\(c\)\(f\)\(a\)\(e\)\(b\)
\(f\)\(f\)\(d\)\(c\)\(b\)\(a\)\(e\)

a. Dar la lista de los elementos del subgrupo generado por \(\langle a \rangle\).

b. Mostrar que \(\langle a \rangle * c = c * \langle a \rangle\).

c. Determinar todas las clases laterales de \(\langle d \rangle\).

Qué tema es y por qué
  • Es un grupo de 6 elementos dado por su tabla (en la teoría de esta unidad, la tabla de un grupo). El neutro es \(e\): su fila y su columna repiten los encabezados.
  • Se usan el subgrupo generado \(\langle x \rangle\) (las potencias de \(x\)) y las clases laterales (multiplicar todo un subgrupo por un elemento, de un lado o del otro).
  • Cómo se lee la tabla: \(x * y\) está en la fila de \(x\) y la columna de \(y\). El orden importa: este grupo no es abeliano (por ejemplo \(a * c = d\) pero \(c * a = f\)).
Paso 1 — a. El subgrupo \(\langle a \rangle\)
Subgrupo generado

\(\langle x \rangle = \{x, x^2, x^3, \dots\}\): se multiplica \(x\) por sí mismo hasta llegar al neutro. La cantidad de elementos es el orden \(o(x)\).

  • \(a^1 = a\).
  • \(a^2 = a * a\): fila \(a\), columna \(a\) → \(b\).
  • \(a^3 = a^2 * a = b * a\): fila \(b\), columna \(a\) → \(e\). Se llegó al neutro: se corta.
Respuesta a

\(\langle a \rangle = \{e, a, b\}\), con \(o(a) = 3\).

Coincide con Lagrange: 3 divide a 6, el orden del grupo.

Paso 2 — b. \(\langle a \rangle * c = c * \langle a \rangle\)
Clases laterales

Si \(H\) es subgrupo de \(G\) y \(x \in G\): clase lateral izquierda \(x * H = \{x * h \ / \ h \in H\}\); clase lateral derecha \(H * x = \{h * x \ / \ h \in H\}\).

Con \(H = \langle a \rangle = \{e, a, b\}\) y \(x = c\):

\(h\)\(h * c\) (fila \(h\), columna \(c\))\(c * h\) (fila \(c\), columna \(h\))
\(e\)\(c\)\(c\)
\(a\)\(d\)\(f\)
\(b\)\(f\)\(d\)
  • \(\langle a \rangle * c = \{c, d, f\}\).
  • \(c * \langle a \rangle = \{c, f, d\} = \{c, d, f\}\).
Respuesta b

\(\langle a \rangle * c = \{c, d, f\} = c * \langle a \rangle\): son el mismo conjunto.

Trampa

La igualdad es de conjuntos, no elemento a elemento: \(a * c = d\) y \(c * a = f\) son distintos. Lo que coincide es la lista completa, en otro orden.

Paso 3 — c. Las clases laterales de \(\langle d \rangle\)

Primero el subgrupo: \(d^1 = d\), \(d^2 = d * d\) (fila \(d\), columna \(d\)) \(= e\). Entonces \(\langle d \rangle = \{e, d\}\).

Se repite la definición: \(x * \langle d \rangle = \{x * e,\ x * d\}\) y \(\langle d \rangle * x = \{e * x,\ d * x\}\). Como el grupo no es abeliano, se calculan las dos.

Izquierdas (\(x * d\): fila \(x\), columna \(d\)):

\(x\)\(x * e\)\(x * d\)\(x * \langle d \rangle\)
\(e\)\(e\)\(d\)\(\{e, d\}\)
\(a\)\(a\)\(f\)\(\{a, f\}\)
\(b\)\(b\)\(c\)\(\{b, c\}\)
\(c\)\(c\)\(b\)\(\{b, c\}\)
\(d\)\(d\)\(e\)\(\{e, d\}\)
\(f\)\(f\)\(a\)\(\{a, f\}\)

Derechas (\(d * x\): fila \(d\), columna \(x\)):

\(x\)\(e * x\)\(d * x\)\(\langle d \rangle * x\)
\(e\)\(e\)\(d\)\(\{e, d\}\)
\(a\)\(a\)\(c\)\(\{a, c\}\)
\(b\)\(b\)\(f\)\(\{b, f\}\)
\(c\)\(c\)\(a\)\(\{a, c\}\)
\(d\)\(d\)\(e\)\(\{e, d\}\)
\(f\)\(f\)\(b\)\(\{b, f\}\)

Como dice el lema de las clases laterales: cada una tiene 2 elementos (lo mismo que \(\langle d \rangle\)), dos clases son iguales o disjuntas, y entre todas cubren \(G\). Hay \(6 / 2 = 3\) clases de cada lado.

Respuesta c

Izquierdas: \(\{e, d\}\), \(\{a, f\}\), \(\{b, c\}\).

Derechas: \(\{e, d\}\), \(\{a, c\}\), \(\{b, f\}\).

Contraste con el inciso b

Con \(\langle a \rangle\) la clase izquierda y la derecha de \(c\) coincidían; con \(\langle d \rangle\) no: \(a * \langle d \rangle = \{a, f\}\) pero \(\langle d \rangle * a = \{a, c\}\). En un grupo no abeliano eso depende del subgrupo; en uno abeliano, las dos siempre son iguales.

Verificación (la guía no trae resultados)

Con Python, cargando la tabla: la operación es asociativa (216 ternas), no es conmutativa, \(\langle a \rangle = \{e, a, b\}\), \(\langle d \rangle = \{e, d\}\), y las clases calculadas coinciden con las de arriba.

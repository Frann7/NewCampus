¿Qué es un pull request?

Inventada · Unidad 6, los comandos

  • El comando git pull.
  • Una solicitud, hecha en la plataforma (GitHub, GitLab), para que los cambios de una rama se revisen y se integren en otra.
  • Una copia de seguridad del repositorio.
  • El mensaje que se escribe en un commit.

Un pull request no es un comando de Git: se abre en la plataforma, y permite revisar, discutir y aprobar los cambios de una rama antes de integrarlos. git pull es otra cosa: trae del remoto los commits nuevos y los integra.

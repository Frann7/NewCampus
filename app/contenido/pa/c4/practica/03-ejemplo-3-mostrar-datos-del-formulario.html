Mostrar y limpiar los datos de un formulario

Un formulario con cuatro campos (nombre, apellido, edad, dirección) y dos botones: "Mostrar Datos" escribe abajo lo que hay en los campos y "Limpiar Datos" los vacía. Nada se envía a ningún lado: todo pasa en el navegador. Clase IndexClass en js/pForm1Class.js.

PiezaQué es
<link href="...bootstrap.min.css">Carga Bootstrap, una hoja de estilos ya hecha. Las clases row, col-md-6, form-control, btn btn-primary son suyas: acomodan los campos de a dos por fila y les dan el aspecto de los campos y botones
placeholder="Nombre"Texto gris de ayuda que se ve mientras el campo está vacío. No es el valor: value sigue siendo ""
value="Cristhian"El nombre arranca ya escrito
type="number"El campo de edad solo acepta números (y muestra flechitas)
Los botones, afuera del <form>Así un clic no envía el formulario (teoría, sección 5): solo hace lo que diga JavaScript
<div id="divDatos">Lugar vacío donde se van a escribir los datos
Paso 2 — La clase 
class IndexClass {

    constructor(){
        this.txtNombre = document.getElementById('txtNombre');
        this.txtApellido = document.getElementById('txtApellido');
        this.txtEdad = document.getElementById('txtEdad');
        this.txtDireccion = document.getElementById('txtDireccion');

        this.btMostrarDatos = document.getElementById('btMostrarDatos');
        this.btLimpiarDatos = document.getElementById('btLimpiarDatos');
        this.divDatos = document.getElementById('divDatos');
    }

    init() {
        this.addEventListeners();
    }

    addEventListeners() {
        this.btMostrarDatos.addEventListener('click', () => {
            this.divDatos.textContent = `Nombre: ${this.txtNombre.value}, Apellido: ${this.txtApellido.value}, Edad: ${this.txtEdad.value}, Dirección: ${this.txtDireccion.value}`;
        });

        this.btLimpiarDatos.addEventListener('click', () => {
            this.txtNombre.value = '';
            this.txtApellido.value = '';
            this.txtEdad.value = '';
            this.txtDireccion.value = '';
            this.divDatos.textContent = '';
        });
    }
}

window.addEventListener('load',() => {
    new IndexClass().init();
})
ParteQué hace
constructor()Guarda los 4 campos, los 2 botones y el div de resultados
init()Solo llama a addEventListeners()
Clic en Mostrar DatosArma un template literal con el value de cada campo en ese momento y lo pone como texto del div
Clic en Limpiar DatosAsigna '' al value de cada campo (los vacía; vuelven a verse los placeholder) y vacía el div
window.addEventListener('load', ...)Crea el objeto e inicia todo al terminar de cargar
Paso 3 — ¿Qué se ve? (tres casos)
Qué hace el usuarioQué aparece en divDatosPor qué
Abre la página y aprieta Mostrar Datos sin escribir nadaNombre: Cristhian, Apellido: , Edad: , Dirección: El nombre tiene value="Cristhian"; los otros están vacíos (el placeholder no cuenta)
Completa Pérez, 20 y Urquiza 100, y aprieta MostrarNombre: Cristhian, Apellido: Pérez, Edad: 20, Dirección: Urquiza 100Lee lo escrito en el momento del clic
Aprieta Limpiar y después MostrarNombre: , Apellido: , Edad: , Dirección: Limpiar vació también el nombre: el "Cristhian" del HTML no vuelve solo
textContent para lo que escribió el usuario

El resultado se muestra con textContent, no con innerHTML: si alguien escribe <b>Ana</b> en el nombre, se ve tal cual, sin interpretarse como HTML (teoría, sección 4).

Qué se ve en la página

Los cuatro campos en dos filas, con el nombre ya cargado, y los dos botones. Mostrar Datos escribe una línea con los cuatro valores; Limpiar Datos deja todo vacío. No hay PHP ni envío: los datos nunca salen del navegador.

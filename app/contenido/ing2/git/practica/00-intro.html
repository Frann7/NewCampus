Unidad 6 — Práctica de Git y versionado

Las guías de la cátedra no traen ejercicios de este tema: la única consigna que existe es la del parcial 2025 (resuelta en la Teoría, sección 3). Estos tres ejercicios son variantes de esa consigna y de lo que desarrolla el apunte, con los comandos probados en un repositorio de prueba.

Antes de resolver

El mapa y las tres preguntas

Directorio        Área de          Repositorio         Repositorio
de trabajo        preparación      local               remoto (origin)

    │── git add ──────▶│                │                    │
    │                  │── git commit ─▶│                    │
    │                  │                │──── git push ─────▶│
    │◀───────────────── git pull ────────────────────────────│

Para escribir cualquier secuencia de Git, antes de cada comando conviene preguntarse:

  1. ¿En qué rama estoy parado? (git checkout para cambiar.)
  2. ¿Dónde están los cambios ahora? (directorio de trabajo, preparación, local o remoto.)
  3. ¿A dónde los quiero llevar? El comando es el que une esos dos lugares.

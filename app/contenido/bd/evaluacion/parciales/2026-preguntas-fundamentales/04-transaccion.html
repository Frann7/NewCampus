3. Transacción y sus propiedades

Unidad 1 · Transacción

Defina Transacción en base de datos. Definición y propiedades.

✓ RespuestaPara aprender y escribir en la hoja

Transacción: es una unidad de ejecución de un programa, que puede incluir varios accesos a la base (consultas, actualizaciones, procedimientos almacenados, vistas). Empieza con BEGIN TRAN y termina con COMMIT (se confirma) o ROLLBACK (se cancela).

  • Atomicidad: se ejecuta toda o no se ejecuta nada.
  • Consistencia: ejecutada sola, deja la base consistente.
  • Aislamiento: si se ejecutan varias al mismo tiempo, el SGBD las aísla para que no generen inconsistencias. Los cambios se hacen efectivos recién con el COMMIT.

De dónde sale

De las diapositivas "Transacciones y concurrencia" de la cátedra (clase del 15/09), que traen esas tres propiedades. Otros libros suman una cuarta, durabilidad (lo confirmado queda guardado aunque falle el sistema): la sigla ACID. Unidad 1, sección 3, con el ejemplo de la clínica.

BEGIN TRAN;
INSERT INTO Consulta (Numero, Diagnostico, Observaciones, Fecha, NumeroTurno)
VALUES (501, 'Otitis', 'Control en 7 días', '2026-10-14', 3020);
UPDATE Turno SET Estado = 'Atendido' WHERE Numero = 3020;
COMMIT;

Si el UPDATE falla, el INSERT se deshace (atomicidad).

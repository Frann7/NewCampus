Ejercicio 2 · Conexión

Creación de un archivo de conexión

Crear un script en PHP que permita establecer una conexión con el servidor MySQL. Las credenciales de acceso deberán ser las siguientes: Servidor: localhost; Usuario: root; Password: (sin contraseña). Utilice para esto las clases mysqli y mysqli_result de PHP.

Paso 1 — Por qué un archivo aparte

Los ejercicios 3, 4 y 5 necesitan conectarse a la base, y la conexión hay que abrirla en cada script (sección 3 de la teoría). En vez de copiar las mismas líneas tres veces, se escriben una vez en conexion.php y cada script lo incluye con require_once. Si un día cambia la contraseña, se cambia en un solo lugar.

La clase mysqli_result que nombra el enunciado no aparece en este archivo: es la del resultado de un SELECT, y se usa en el ejercicio 4.

Paso 3 — El código: conexion.php 
<?php
try {
    $mysqli = new mysqli('localhost', 'root', '', 'DB_Comentarios');
} catch (mysqli_sql_exception $e) {
    echo "No se pudo establecer la conexión.<br>";
    echo "Error número: " . $e->getCode() . "<br>";
    echo "Error descripción: " . $e->getMessage();
    exit;
}

$mysqli->set_charset('utf8');
?>

LíneaQué haceCómo quedan las variables

4Si falló, atrapa la excepción$e = la excepción

Se usa try/catch y no el if ($mysqli->connect_errno) de la teoría porque el PHP 8.2 de XAMPP lanza una excepción al fallar, y el if nunca se llegaría a ejecutar (ejemplo 2 de la sección 3).

Paso 5 — Qué se ve

Si se abre http://localhost/conexion.php con MySQL prendido: una página en blanco. Es lo correcto, porque no hay nada que mostrar; este archivo no se visita, se incluye.

Con MySQL apagado (verificado con un servidor inexistente), el navegador muestra:

No se pudo establecer la conexión.
Error número: 2002
Error descripción: No se puede establecer una conexión ya que el equipo de destino denegó expresamente dicha conexión
El ejercicio 3 dice "punto 3"

La guía dice "utilice el archivo de conexión desarrollado en el punto 3", pero el archivo de conexión es este, el del punto 2. Es un error de numeración.

Resultado

conexion.php deja abierta la conexión en $mysqli para quien lo incluya, o corta con un mensaje si no puede conectar.

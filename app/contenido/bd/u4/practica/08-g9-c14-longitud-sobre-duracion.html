Longitud sobre duración

Indicar por cada itinerario la relación longitud sobre duración, ordenados de mayor a menor siendo los mayores los más exigentes.

Las tablas que usa 
Itinerario (Codigo (PK), Duracion, Longitud, CantVisitantes)
Cómo se arma
  • Una columna calculada: en el SELECT se puede escribir una cuenta con columnas: Longitud / Duracion, con su alias.
  • Orden: de mayor a menor, con el alias: ORDER BY Exigencia DESC.
Resolución 
SELECT Codigo, Longitud, Duracion, Longitud / Duracion AS Exigencia
FROM Itinerario
ORDER BY Exigencia DESC;

Longitud es DECIMAL, así que la división da con decimales. Si las dos fueran INT, SQL Server dividiría entero (7 / 2 = 3): ahí conviene CAST(Longitud AS DECIMAL(10,2)) / Duracion.

5 puntos Unidad 6 · Git

3. Indique los pasos que debe seguir el equipo de desarrollo para registrar todos los cambios del código desde el Working Directory hacia la rama develop, y luego integrarlos en main, asegurando que ambas ramas estén actualizadas en el remoto (Git Workflow).

✓ ResultadosSolo la respuesta 
git checkout develop
git add .
git commit -m "Descripción de los cambios"
git push origin develop
git checkout main
git merge develop
git push origin main
✎ Explicación detalladaEl concepto desde cero, el desarme de la consigna, la respuesta y las trampas

Qué evalúa

Conocer los tres estados de Git y los comandos que llevan un cambio de un lugar a otro, incluyendo las ramas y el repositorio remoto.

El concepto

Directorio        Área de          Repositorio         Repositorio
de trabajo        preparación      local               remoto (origin)

    │── git add ──────▶│                │                    │
    │                  │── git commit ─▶│                    │
    │                  │                │──── git push ─────▶│
  • Working Directory (directorio de trabajo): los archivos que se editan. Estado: modificado.
  • Staging Area (área de preparación): lo que va a entrar en el próximo commit. Estado: preparado.
  • Repositorio local: los commits. Estado: confirmado.
  • Remoto (origin): la copia compartida del equipo.

Paso 3 — Comprobarlo

Ejecutada en un repositorio de prueba, al final git log --oneline --all --decorate muestra:

c11a3b1 (HEAD -> main, origin/main, origin/develop, develop) Cambia el titulo y agrega estilos
6d83081 Version inicial

Las dos ramas locales y las dos del remoto apuntan al mismo commit.

Trampas

  • El merge se hace parado en la rama que recibe: primero git checkout main, después git merge develop.
  • Dos push, no uno: la consigna dice "ambas ramas".
  • Sin add no hay commit: la consigna arranca en el Working Directory para que aparezcan los tres estados.
  • Suma agregar git pull antes de empezar y antes del merge, para traer lo que hayan subido los demás.

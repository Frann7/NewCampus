10. Strings: comillas simples, dobles y caracteres de escape

Para qué sirve

Un string (cadena de texto) es cualquier conjunto de caracteres entre comillas. Gran parte de lo que hace PHP es armar texto para mostrar en una página, así que es clave saber qué imprime exactamente cada forma de escribirlo.

  • Un string empieza y termina con el mismo tipo de comillas: simples '...' o dobles "...".
  • A diferencia de otros lenguajes, en PHP no son lo mismo:
Comillas simples '...'Comillas dobles "..."

Sintaxis

Las dos formas 
$texto = 'Hola, $nombre';    // literal: tal cual
$texto = "Hola, $nombre";    // con el valor de $nombre adentro

Qué es cada parte: las secuencias de escape

Una secuencia de escape es una barra invertida \ seguida de un carácter. Sirve para escribir dentro del string algo que de otra forma no se podría: una comilla igual a la que lo cierra, un salto de línea, un $ que no sea variable.

Las dos últimas formas dan lo mismo: con comillas dobles la variable va adentro; con simples, se concatena afuera. La práctica de la cátedra usa las dos.

Errores y trampas

\n no es un salto de línea en el navegador

\n pone un salto de línea en el texto que genera PHP, pero el navegador lo muestra como un espacio (HTML ignora los saltos del texto, sección 3). Para bajar de línea en la página se imprime <br>. El ejemplo 1 se ve en el navegador como Saludos, Martín Saludos, $nombre\n, en una línea.

"\ " no escapa un espacio

La cátedra dice que se puede escapar un espacio con \. No es así: \ no es una secuencia de escape, y PHP imprime la barra tal cual. echo "dejamos \ un espacio"; muestra dejamos \ un espacio.

Comillas tipográficas en los PDF

Los apuntes y la práctica resuelta de la cátedra muestran muchas comillas como “ ” (las "curvas" que pone el procesador de texto). PHP solo acepta " y ' rectas: copiado tal cual, echo $un_dia.”<br />”; da Parse error. Al pasar un código del PDF a un archivo, hay que cambiarlas.

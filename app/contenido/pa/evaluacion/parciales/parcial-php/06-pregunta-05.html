Qué evalúa

Seguir if anidados (un if adentro de otro) cuyas condiciones usan valores booleanos y los operadores ! y &&. Es de la Clase 1 (estructuras de control). La pregunta va al revés de lo habitual: no da los valores y pide la salida, sino que da la salida y pide los valores.

Primero: qué son esos ?

$a = ?; no es PHP válido. El ? es el hueco que esconde el enunciado: ahí iría un valor, y averiguar cuál es justamente lo que se pregunta. Si se corriera el script así, PHP ni siquiera arrancaría: antes de ejecutar nada revisa que todo el código esté bien escrito, y en la línea 3 se frena con

Parse error: syntax error, unexpected token "?" ... on line 3

(parse error = error de sintaxis: algo escrito que PHP no entiende). Para resolver, se hace de cuenta que en cada ? va uno de los valores de las opciones. Cada opción da los tres valores en orden: “False, True, True” quiere decir $a = false; $b = true; $c = true;.

Booleanos: true y false

Un booleano es un valor que solo puede ser una de dos cosas: true (verdadero) o false (falso). En esta pregunta $a, $b y $c van a ser booleanos: cada una vale true o false. Las opciones los escriben con mayúscula (False, True) y es lo mismo: PHP acepta true, True y TRUE por igual.

if / else: se ejecuta UNA sola de las dos ramas

if (condición) {
    // bloque 1: se ejecuta si la condición es true
} else {
    // bloque 2: se ejecuta si la condición es false
}

PHP mira la condición una vez: si es true, ejecuta el bloque 1 y saltea el bloque 2; si es false, saltea el bloque 1 y ejecuta el 2. Nunca los dos, y siempre uno (si hay else). Las líneas con // son comentarios: notas para el que lee, PHP las ignora.

Si no hay else y la condición es false, el if no hace nada y PHP sigue con lo que venga después de la }. Con else if: si la primera condición da false, prueba la segunda; si también da false (y no hay un else final), no ejecuta nada.

Una variable sola como condición: if ($a) pregunta “¿$a es true?”. Si $a vale true, entra al bloque; si vale false, va al else. No hace falta escribir if ($a == true): es lo mismo.

! da vuelta el valor: !$b se lee “no $b” y es true justamente cuando $b es false.

If anidados: cómo leer el árbol

Un if anidado es un if que está adentro del bloque de otro. El de adentro solo se mira si PHP entró a ese bloque; si tomó la otra rama, el de adentro ni se lee. Para saber qué está adentro de qué se cuentan las llaves: cada { abre un bloque y la } que le corresponde lo cierra. La sangría (los espacios al principio de cada línea) solo sirve para que lo lea una persona: PHP la ignora.

El código del enunciado está mal sangrado, y eso confunde. Es el mismo código con cada { alineado con su }:

<?php
$string = "Hola, Mundo!";
$a = ?;
$b = ?;
$c = ?;
if ($a) {
    if ($b && !$c) {
        echo "Adios mundo cruel!";
    } else if (!$b && !$c) {
        echo "Nada por aquí";
    }
} else {
    if (!$b) {
        if (!$a && (!$b && $c)) {
            echo "Hola, mundo!";
        } else {
            echo "Adios mundo!";
        }
    } else {
        echo "No exactamente";
    }
}
?>

Y como árbol: cada nivel es una pregunta, y según la respuesta se baja por una rama o por la otra.

  • Nivel 1 — if ($a)
    • $a true → Nivel 2 — if ($b && !$c)
      • true → imprime Adios mundo cruel!
      • false → else if (!$b && !$c)
        • true → imprime Nada por aquí
        • false → no imprime nada (no hay else final)
    • $a false (else) → Nivel 2 — if (!$b)
      • true → Nivel 3 — if (!$a && (!$b && $c))
        • true → imprime Hola, mundo!
        • false → imprime Adios mundo!
      • false (else) → imprime No exactamente

Como en cada if se toma una sola rama, el script imprime a lo sumo un mensaje. $string no aparece en ningún echo: se guarda y nunca se usa.

El camino hasta “Hola, mundo!”

Se busca el único echo que dice “Hola, mundo!” y se sube por el árbol, viendo qué tiene que pasar en cada nivel para llegar ahí.

Nivel 1 — el if de afuera

Condición: if ($a). El echo está en el bloque del else, y al else se entra solo si la condición es false. La condición es $a sola ⇒ $a tiene que ser false.

Nivel 2 — el if que está dentro del else

Condición: if (!$b). El echo está en el bloque del if (no en su else, que imprime “No exactamente”) ⇒ !$b tiene que ser true ⇒ por la tabla del !, $b tiene que ser false.

Nivel 3 — el if de más adentro

Condición: if (!$a && (!$b && $c)). El echo está en el bloque del if (el else imprime “Adios mundo!”) ⇒ toda la condición tiene que dar true. Se reemplazan los valores que ya se sabe que son obligatorios:

  • !$a = !false = true.
  • Entre paréntesis: !$b && $c = !false && $c = true && $c.
  • Todo junto: true && (true && $c). Por la tabla del &&, eso da true solo si $c es true.

⇒ $c tiene que ser true.

$a = false, $b = false, $c = true: d) False, False, True.

En a y c lo que decide es $b: con $a en false y $b en true, el nivel 2 ya manda a “No exactamente”, sin importar $c.

Las trampas

$string está para distraer: nunca se imprime. Lo que sale en pantalla es solo lo que dicen los echo.

El enunciado dice “Hola, Mundo!” y el script imprime “Hola, mundo!”, con minúscula. Ningún camino imprime exactamente lo que dice el enunciado; la diferencia es un descuido de quien lo escribió, y la respuesta esperada es la d, la única que llega a ese echo.

Guiarse por la sangría: el código está mal indentado y parece que el else va con otro if. Siempre contá llaves.

Ejercicio 3: Utilizando sentencias SQL, realice los scripts correspondientes para generar cada uno de los siguientes listados:

  1. Listado de pedidos pendientes, ordenado por fecha del pedido, de más antiguo a más nuevo, mostrando el número de pedido, fecha, código del cliente, razón social, importe total del pedido (no discriminar por artículo).
  2. Listado de cantidad de pedidos pendientes por cliente, ordenado por País, Provincia, Localidad, Razón Social. Se debe mostrar: País, Provincia, Localidad, Razón Social, Código de Cliente, Cantidad de Pedidos pendientes.
  3. Listado de clientes, ordenados por total facturado de mayor a menor, según las facturas de los últimos 12 meses, agrupado por Año y Mes de la factura. La información que se debe listar es la siguiente: AÑO, MES, RAZON SOCIAL, TOTAL FACTURADO.
✓ ResultadosSolo la respuesta

a)

SELECT p.Numero, p.Fecha, c.CUIT AS CodigoCliente, c.RazonSocial,
       SUM(d.Cantidad * d.PrecioUnitario) AS ImporteTotal
FROM Pedido p
INNER JOIN Cliente c ON c.CUIT = p.CUIT
INNER JOIN Pedido_Detalle d ON d.NumeroPedido = p.Numero
WHERE p.Estado = 'Pendiente'
GROUP BY p.Numero, p.Fecha, c.CUIT, c.RazonSocial
ORDER BY p.Fecha ASC;

b)

SELECT pa.Nombre AS Pais, pv.Nombre AS Provincia, ci.Nombre AS Localidad,
       c.RazonSocial, c.CUIT AS CodigoCliente,
       COUNT(p.Numero) AS CantidadPedidosPendientes
FROM Cliente c
INNER JOIN Ciudad ci ON ci.IdCiudad = c.IdCiudad
INNER JOIN Provincia pv ON pv.IdProvincia = ci.IdProvincia
INNER JOIN Pais pa ON pa.IdPais = pv.IdPais
INNER JOIN Pedido p ON p.CUIT = c.CUIT
WHERE p.Estado = 'Pendiente'
GROUP BY pa.Nombre, pv.Nombre, ci.Nombre, c.RazonSocial, c.CUIT
ORDER BY pa.Nombre, pv.Nombre, ci.Nombre, c.RazonSocial;

c)

SELECT YEAR(f.Fecha) AS Anio, MONTH(f.Fecha) AS Mes, c.RazonSocial,
       SUM(fd.Cantidad * fd.PrecioUnitario) AS TotalFacturado
FROM Factura f
INNER JOIN Factura_Detalle fd ON fd.IdFactura = f.IdFactura
INNER JOIN Pedido p ON p.Numero = f.NumeroPedido
INNER JOIN Cliente c ON c.CUIT = p.CUIT
WHERE f.Fecha >= DATEADD(MONTH, -12, GETDATE())
GROUP BY YEAR(f.Fecha), MONTH(f.Fecha), c.CUIT, c.RazonSocial
ORDER BY TotalFacturado DESC;

a) Pedidos pendientes con su importe total

  • "Importe total del pedido (no discriminar por artículo)" = una fila por pedido con la suma de sus renglones: SUM(d.Cantidad * d.PrecioUnitario). Dentro de una función se puede hacer una cuenta.
  • Por eso este a) lleva GROUP BY (por pedido): sin él saldría una fila por libro.
  • Filtro: p.Estado = 'Pendiente'. Orden: p.Fecha ASC.
SELECT p.Numero, p.Fecha, c.CUIT AS CodigoCliente, c.RazonSocial,
       SUM(d.Cantidad * d.PrecioUnitario) AS ImporteTotal
FROM Pedido p
INNER JOIN Cliente c ON c.CUIT = p.CUIT
INNER JOIN Pedido_Detalle d ON d.NumeroPedido = p.Numero
WHERE p.Estado = 'Pendiente'
GROUP BY p.Numero, p.Fecha, c.CUIT, c.RazonSocial
ORDER BY p.Fecha ASC;

b) Cantidad por cliente

Igual al b) del parcial: Pais ← Provincia ← Ciudad ← Cliente → Pedido, COUNT, y esta vez también se muestra el código del cliente (el CUIT).

SELECT pa.Nombre AS Pais, pv.Nombre AS Provincia, ci.Nombre AS Localidad,
       c.RazonSocial, c.CUIT AS CodigoCliente,
       COUNT(p.Numero) AS CantidadPedidosPendientes
FROM Cliente c
INNER JOIN Ciudad ci ON ci.IdCiudad = c.IdCiudad
INNER JOIN Provincia pv ON pv.IdProvincia = ci.IdProvincia
INNER JOIN Pais pa ON pa.IdPais = pv.IdPais
INNER JOIN Pedido p ON p.CUIT = c.CUIT
WHERE p.Estado = 'Pendiente'
GROUP BY pa.Nombre, pv.Nombre, ci.Nombre, c.RazonSocial, c.CUIT
ORDER BY pa.Nombre, pv.Nombre, ci.Nombre, c.RazonSocial;

c) Total facturado por año y mes

  • Se suma el detalle de las facturas (no el del pedido): "según las facturas".
  • El cliente se encuentra por el pedido que generó la factura: Factura → Pedido → Cliente.
  • "De mayor a menor": ORDER BY TotalFacturado DESC.
SELECT YEAR(f.Fecha) AS Anio, MONTH(f.Fecha) AS Mes, c.RazonSocial,
       SUM(fd.Cantidad * fd.PrecioUnitario) AS TotalFacturado
FROM Factura f
INNER JOIN Factura_Detalle fd ON fd.IdFactura = f.IdFactura
INNER JOIN Pedido p ON p.Numero = f.NumeroPedido
INNER JOIN Cliente c ON c.CUIT = p.CUIT
WHERE f.Fecha >= DATEADD(MONTH, -12, GETDATE())
GROUP BY YEAR(f.Fecha), MONTH(f.Fecha), c.CUIT, c.RazonSocial
ORDER BY TotalFacturado DESC;

Trampas

  • En a), sin GROUP BY el total no se puede calcular; con él, las columnas que se muestran van todas al GROUP BY.
  • En b), "Localidad" es la ciudad: el nombre de la columna lo elige uno con el alias.

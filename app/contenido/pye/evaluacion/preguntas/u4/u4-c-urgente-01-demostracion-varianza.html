Un alumno escribió esta demostración de \(V(X) = E(X^{2}) - \mu^{2}\), con \(\mu = E(X)\):

(1) \(V(X) = E\left[(X - \mu)^{2}\right]\)
(2) \(\phantom{V(X)} = E\left(X^{2} - \mu^{2}\right)\)
(3) \(\phantom{V(X)} = E(X^{2}) - E(\mu^{2})\)
(4) \(\phantom{V(X)} = E(X^{2}) - \mu^{2}\)

¿Qué paso está mal?

El paso (2). El cuadrado del binomio está mal desarrollado: \((X - \mu)^{2} = X^{2} - 2\mu X + \mu^{2}\), no \(X^{2} - \mu^{2}\). Que el final “coincida” es pura casualidad: una demostración con un paso falso no demuestra nada. El (1) es la definición, y el (3) y el (4) están bien hechos a partir de lo anterior (linealidad de \(E\) y esperanza de una constante).

La demostración correcta:

  1. Definición: \(V(X) = E\left[(X - \mu)^{2}\right]\).
  2. Cuadrado del binomio: \(= E\left(X^{2} - 2\mu X + \mu^{2}\right)\).
  3. La esperanza es lineal: \(= E(X^{2}) - 2\mu\,E(X) + E(\mu^{2})\) (\(\mu\) es constante, sale afuera).
  4. \(E(X) = \mu\) y \(E(\mu^{2}) = \mu^{2}\): \(= E(X^{2}) - 2\mu^{2} + \mu^{2}\).
  5. Se agrupa: \(V(X) = E(X^{2}) - \mu^{2} = E(X^{2}) - [E(X)]^{2}\).

Vale igual para discretas (sumas) y continuas (integrales): solo se usa que \(E\) es lineal.

Caso 7 — Río Bravo Data

Unidad 5 · CMMI · Subir de nivel

La empresa Río Bravo Data desarrolla sistemas de análisis de datos. Presenta estas características:

  • Tiene un proceso documentado, común a todos los equipos.
  • Mide los defectos y los tiempos de todos sus proyectos, y tiene rangos esperados para cada uno.
  • Cuando un proyecto se sale del rango, lo corrige para volver a lo habitual; los procedimientos no se revisan.

Proponga tres acciones concretas que le permitan a Río Bravo Data alcanzar el siguiente nivel de madurez del modelo CMMI.

✓ RespuestaPara aprender y escribir en la hoja

Está en el Nivel 4 (Cuantitativamente gestionado): mide sus procesos y tiene rangos esperados, pero usa los datos solo para "volver a lo habitual". Para llegar al Nivel 5 (En optimización continua):

  1. Analizar las causas de los problemas que se repiten, usando los datos históricos.
  2. Proponer mejoras al proceso a partir de esos datos (por ejemplo, automatizar las pruebas), probarlas y comprobar con mediciones que mejoran.
  3. Incorporar lo que funciona al proceso estándar de toda la empresa, y fomentar que los equipos propongan innovaciones.

Así los datos se usan para mejorar el proceso siempre, que es lo que define al Nivel 5.

✎ ExplicaciónCómo se llega
Paso 1 — En qué nivel está

Tiene proceso común (3) y mide con rangos esperados (4), pero no cambia el proceso (no llega al 5).

Paso 2 — Qué define al nivel siguiente

El Nivel 5 es usar los números para mejorar el proceso, de forma continua: analizar por qué pasan los problemas, cambiar el procedimiento y comprobar que el cambio sirvió.

Paso 3 — Las acciones

Son los tres momentos de una mejora: buscar la causa, probar un cambio midiendo el resultado, y dejarlo incorporado para todos.

Trampa

“Corregir el desvío” no es mejorar: es volver al mismo punto. La acción tiene que cambiar el proceso.

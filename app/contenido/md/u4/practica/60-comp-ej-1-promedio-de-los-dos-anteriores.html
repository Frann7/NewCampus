Complementaria P2 · Recurrencia · Ej. 1 · Promedio de los dos anteriores

Cada término es el promedio de los dos anteriores

Sea \(a_0 = 1\) y \(a_2 = 2\) y cada término de la sucesión \(a_n\) se obtiene como la media aritmética (o promedio) de los dos anteriores. Se pide:

a. Calcular \(a_3\), \(a_4\) y \(a_5\).

b. Plantear la relación de recurrencia.

c. Obtener la solución general \(a_n\) de la relación de recurrencia.

Qué tema es y por qué
  • "Promedio de los dos anteriores": cada término depende de los dos de antes, con coeficientes fijos y sin nada sumado. Es segundo orden homogénea.
  • Dan \(a_0\) y \(a_2\) (no \(a_1\)). Se puede trabajar igual: \(a_2\) también lo genera la regla, así que de él se despeja \(a_1\).
¿\(a_2 = 2\) o \(a_1 = 2\)?

Lo habitual es dar \(a_0\) y \(a_1\), así que "\(a_2 = 2\)" puede ser una errata de "\(a_1 = 2\)". Las dos lecturas dan resultados distintos. Abajo se resuelve con el enunciado tal cual (\(a_0 = 1,\ a_2 = 2\), que es consistente y tiene solución única), y al final está la otra lectura completa. En un examen, conviene escribir qué lectura se toma.

Paso 1 — Inciso b): la relación (se plantea primero porque a) la usa)

\[ a_n = \frac{a_{n-1} + a_{n-2}}{2},\ \forall n \geq 2 \qquad\Longleftrightarrow\qquad 2a_n - a_{n-1} - a_{n-2} = 0 \]

Con \(n = 2\): \(a_2 = \frac{a_1 + a_0}{2} \Rightarrow 2 = \frac{a_1 + 1}{2} \Rightarrow a_1 = 3\).

Paso 2 — Inciso a): \(a_3, a_4, a_5\) con la relación

\(a_3 = \dfrac{a_2 + a_1}{2} = \dfrac{2 + 3}{2} = \dfrac52\)

\(a_4 = \dfrac{a_3 + a_2}{2} = \dfrac{5/2 + 2}{2} = \dfrac94\)

\(a_5 = \dfrac{a_4 + a_3}{2} = \dfrac{9/4 + 5/2}{2} = \dfrac{19}{8}\)

Paso 3 — Inciso c): resolver

Ecuación característica: \(a_n \to r^{2}\), \(a_{n-1} \to r\), \(a_{n-2} \to 1\). Raíces distintas: \(a_n = A_1 r_1^{\,n} + A_2 r_2^{\,n}\).

\(2r^{2} - r - 1 = 0 \Rightarrow (2r + 1)(r - 1) = 0 \Rightarrow r_1 = 1,\ r_2 = -\tfrac12\).

\(a_n = A_1 + A_2\left(-\tfrac12\right)^{n}\). Las constantes se pueden sacar directo con los datos \(a_0\) y \(a_2\):

\[ \left\{\begin{array}{l} n = 0:\ A_1 + A_2 = 1 \\ n = 2:\ A_1 + \tfrac14 A_2 = 2 \end{array}\right. \]

Restando: \(\tfrac34 A_2 = -1 \Rightarrow A_2 = -\tfrac43\); \(A_1 = 1 + \tfrac43 = \tfrac73\).

\[ a_n = \frac73 - \frac43\left(-\frac12\right)^{n},\ \forall n \geq 0 \]

Paso 4 — Comprobación

Fórmula: \(a_1 = \tfrac73 + \tfrac23 = 3\), \(a_3 = \tfrac73 + \tfrac16 = \tfrac52\), \(a_4 = \tfrac73 - \tfrac1{12} = \tfrac94\), \(a_5 = \tfrac73 + \tfrac1{24} = \tfrac{19}{8}\). Coincide con la relación.

Respuesta (con \(a_0 = 1,\ a_2 = 2\))

a) \(a_3 = \tfrac52,\ a_4 = \tfrac94,\ a_5 = \tfrac{19}{8}\).   b) \(a_n = \tfrac12 a_{n-1} + \tfrac12 a_{n-2},\ n \geq 2\).   c) \(a_n = \tfrac73 - \tfrac43\left(-\tfrac12\right)^{n}\).

La otra lectura: \(a_0 = 1,\ a_1 = 2\)
  • La relación es la misma, y por lo tanto \(a_n = A_1 + A_2(-\tfrac12)^{n}\).
  • Términos: \(a_2 = \tfrac{2 + 1}{2} = \tfrac32\), \(a_3 = \tfrac74\), \(a_4 = \tfrac{13}{8}\), \(a_5 = \tfrac{27}{16}\).
  • Constantes: \(A_1 + A_2 = 1\), \(A_1 - \tfrac12 A_2 = 2\) \(\Rightarrow A_2 = -\tfrac23,\ A_1 = \tfrac53\).

\[ a_n = \frac53 - \frac23\left(-\frac12\right)^{n},\ \forall n \geq 0 \]

Verificación

La guía no trae resultados. Con un programa se calcularon los primeros 10 términos con la relación y con cada fórmula: coinciden en las dos lecturas. Las dos fórmulas se acercan a una constante (\(\tfrac73\) y \(\tfrac53\)) porque \((-\tfrac12)^{n} \to 0\): los promedios se van estabilizando.

Cual es la salida del siguiente script PHP:

<?php
$mineral = array(
'dorado' => 'negro',
'plateado' => 'Plata',
'brillante' => 'Diamante',
'negro' => 'Carbón'
);
echo $mineral['negro'];

?>

Parcial PHP · preg. 2

  • negro
  • dorado
  • Ninguna de las anteriores
  • Carbón

En un array asociativo cada valor tiene una clave ('clave' => 'valor'), y $mineral['negro'] busca la clave negro, que es la última: su valor es Carbón.

“negro” también es el valor de la clave dorado, pero los corchetes nunca buscan por valor: responder “negro” o “dorado” es leer el array al revés.

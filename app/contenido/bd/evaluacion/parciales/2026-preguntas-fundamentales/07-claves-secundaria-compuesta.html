6. Clave secundaria y compuesta

Unidad 1 · Claves

Defina clave secundaria y clave compuesta.

✓ RespuestaPara aprender y escribir en la hoja
  • Clave secundaria (o alternativa): una clave candidata que no fue elegida como primaria. También identifica a cada fila, y en SQL se asegura con UNIQUE.
  • Clave compuesta: una clave formada por más de un atributo, porque ninguno solo identifica la fila. Por ejemplo, (NumeroConsulta, CodigoTratamiento) en Consulta_Tratamiento.
✎ ExplicaciónUn ejemplo, de dónde sale y las trampas

Cómo se ven en SQL

CREATE TABLE Consulta_Tratamiento (
  NumeroConsulta     INT  NOT NULL,
  CodigoTratamiento  INT  NOT NULL,
  Costo              DECIMAL(10,2),
  CONSTRAINT PK_Consulta_Tratamiento PRIMARY KEY (NumeroConsulta, CodigoTratamiento)
);

Una PK compuesta: cada número de consulta se repite (una consulta con varios tratamientos), pero el par no.

En un final la pidieron junto con primaria y foránea. Unidad 1, sección 4.

Trampas

  • "Compuesta" dice cuántos atributos tiene; "primaria" dice qué papel cumple. Una clave puede ser las dos cosas.

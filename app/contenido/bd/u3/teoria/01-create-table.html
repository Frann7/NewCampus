1. La forma del CREATE TABLE

La forma general 
CREATE TABLE NombreTabla (
  Columna1  TIPO  NOT NULL,
  Columna2  TIPO,
  ...
  CONSTRAINT PK_NombreTabla PRIMARY KEY (Columna1)
);
  • Una línea por columna: el nombre, el tipo de dato y, si no puede quedar vacía, NOT NULL.
  • Las líneas se separan con coma; la última no lleva.
  • Al final, las claves (sección 2). Todo va entre paréntesis, y la sentencia termina con punto y coma.
  • Los nombres van sin espacios ni tildes (FechaNac, Numero_HC): así se evitan errores. En clase los profes recomiendan además ponerle a cada campo un prefijo de su tabla (socio_nombre, embarc_matricula), para que en los JOIN no haya dos columnas con el mismo nombre; no es obligatorio.

Los tipos de datos de SQL Server

Son los de la diapositiva "Del DER al SQL Server" de la cátedra. Para el parcial alcanza con estos:

TipoQué guardaPara qué atributo
INTUn número entero (hasta unos 2.000 millones)Códigos, números de turno, legajos, cantidades
DECIMAL(p, s)Un número con decimales exactos: p dígitos en total, s de ellos después de la comaPrecios, costos, sueldos, pesos, superficies
VARCHAR(n)Un texto de hasta n caracteres (ocupa solo lo que usa)Nombres, direcciones, descripciones, documentos con guiones
CHAR(n)Un texto de exactamente n caracteresCódigos de largo fijo: sexo (CHAR(1)), letra de zona
DATEUna fecha (año, mes, día)Fecha de nacimiento, de ingreso, de una factura
TIMEUna horaHora de un recorrido
DATETIMEFecha y hora juntasFechaHora de un turno
BIT0 o 1 (no o sí)"Tiene mantenimiento", "está activo"

Cómo se lee DECIMAL(p, s): DECIMAL(10, 2) tiene 10 dígitos en total y 2 son decimales, así que entra hasta 99.999.999,99. DECIMAL(5, 2) llega a 999,99: alcanza para el peso de un animal en kilos.

Ejemplo 1: una tabla sin claves foráneas

Zona (Codigo (PK), Nombre, Extension) — la extensión es en m2 y puede tener decimales.

AtributoQué esTipo
CodigoUn número que identifica la zona; es la PK, no puede faltarINT NOT NULL
NombreUn texto corto; toda zona tiene nombreVARCHAR(50) NOT NULL
ExtensionMetros cuadrados, con decimalesDECIMAL(10,2)
CREATE TABLE Zona (
  Codigo     INT           NOT NULL,
  Nombre     VARCHAR(50)   NOT NULL,
  Extension  DECIMAL(10,2),
  CONSTRAINT PK_Zona PRIMARY KEY (Codigo)
);

Errores y trampas
  • Un número con el que no se hacen cuentas y puede tener guiones o ceros adelante (teléfono, CUIT) va como VARCHAR.
  • La plata nunca va en INT: se pierden los centavos. DECIMAL(10,2).
  • La coma de más antes del paréntesis final (..., )) es el error de sintaxis más común.
  • El largo exacto de un VARCHAR no lo corrigen: que sea razonable (un nombre en 50 o 100 está bien).

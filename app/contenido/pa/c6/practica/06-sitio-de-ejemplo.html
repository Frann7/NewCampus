El sitio de ejemplo de la cátedra: alta y listado de personas

Material de la teoría de la Clase 6: un "Sistema Recursos Humanos" con un formulario para cargar personas (documento, nombres, apellido) y un listado. Hace lo mismo que los ejercicios 3 y 4, pero con el acceso a la base metido adentro de clases de PHP.

Paso 1 — Qué archivos tiene 
index.php                    inicio: tres botones (Inicio, Formulario, Listado)
formPersonas.php             el formulario de alta
listadoPersonas.php          el listado en una tabla
includes/
    mysqliConn.php           la clase que abre la conexión

    page/navbar.php          la barra de navegación
    page/footer.php          cierre de la página
php/

Las páginas no escriben su propio encabezado: lo traen con require_once de includes/page/, así todas comparten el mismo <head>, la misma barra y el mismo pie. Los estilos son de Bootstrap, una hoja de estilos ya hecha que se baja de internet (por eso las clases btn, table, form-control).

Paso 3 — La clase de la tabla: php/class/PersonaClass.php

Guarda una persona en propiedades privadas y tiene los métodos para leer y escribir la tabla. Lo de clases se vio en la Clase 5; para leerla alcanza con esto: private = solo se usa adentro de la clase; $this = "este objeto"; __construct corre solo al hacer new, y __destruct corre solo cuando el objeto deja de existir (a más tardar, al terminar el script). 

<?php
require_once $_SERVER['DOCUMENT_ROOT'].'/includes/mysqliConn.php';

class PersonaClass {

    private $mysqli;
    private $documento;
    private $apellido;
    private $nombres;

    public function __construct()
    {
        $oMysqli = new ManagerMysqli();
        $this->mysqli = $oMysqli->getConnection();
    }

    public function setDocumento($documento) { $this->documento = (int)$documento; }
    public function setNombres($nombres) { $this->nombres = $nombres; }
    public function setApellido($apellido) { $this->apellido = $apellido; }

    // (getters: getDocumento, getApellido, getNombres)

    public function getAll() { ... }       // paso 4
    public function addPersona() { ... }   // paso 5

    public function __destruct() { $this->mysqli->close(); }
}

Paso 4 — Leer: getAll() 
public function getAll() {

    $query = "SELECT * FROM personas";

    $result = $this->mysqli->query($query);

    $vPersonas = array();

    if ($result->num_rows > 0)
    {
        while( $row = $result->fetch_array() )
        {
           $vPersona = array(
            'documento' => $row['documento'],
            'apellido' => $row['apellido'],
            'nombres' => $row['nombres']
           );

           $vPersonas[] = $vPersona;
        }
    }

    return $vPersonas;
}

La diferencia con el ejercicio 4: acá la página no toca la base. Recibe un arreglo común de PHP y lo dibuja. Si un día cambia la base, se cambia solo la clase.

Paso 5 — Escribir: addPersona() 
public function addPersona() {

    $stmt = $this->mysqli->prepare("INSERT INTO personas (documento, apellido, nombres) VALUES (?, ?, ?)");

    if ($stmt) {
        $stmt->bind_param("iss", $this->documento, $this->apellido, $this->nombres);
        $result = $stmt->execute();
        $stmt->close();
        return $result;
    } else {
        return false;
    }
}

Paso 6 — El recorrido de un alta
  1. formPersonas.php muestra tres campos (documento, nombres, apellido) y manda por POST a /php/procesoFormulario.php.
  2. procesoFormulario.php corta con die("No se recibieron Datos") si falta alguno de los tres.
  3. Crea new PersonaClass(): el constructor abre la conexión.
  4. Valida cada dato con las funciones de la Clase 5 y solo si pasa lo carga: ctype_digit para el documento (y lo pasa a entero), ctype_alpha para apellido y nombres (y les aplica htmlspecialchars).
  5. Llama a addPersona() y, según devuelva true o false, arma el mensaje "Persona Agregada" o "Error al agregar Persona".
  6. Muestra el mensaje en un cartel de Bootstrap con un botón para volver al formulario. Al terminar el script, __destruct cierra la conexión.

Paso 8 — Cómo probarlo en tu PC
  1. Descomprimir el zip directamente en htdocs, no en una subcarpeta (ver trampas).
  2. En phpMyAdmin, crear la base rrhh con una tabla personas. El zip no trae la base; por el código, tiene que tener al menos estas columnas (deducido, los largos son de ejemplo): 
    CREATE TABLE personas (
    documento INT,
    apellido  VARCHAR(50),
    nombres   VARCHAR(50)
);
  3. En mysqliConn.php, cambiar usuario y contraseña por los tuyos ("root" y ""), o crear el usuario fede con permisos sobre rrhh (sección 2).
Errores y trampas del ejemplo
  • Rutas desde la raíz. El formulario manda a /php/procesoFormulario.php y las clases se incluyen con $_SERVER['DOCUMENT_ROOT']. Las dos cosas apuntan a la raíz de htdocs: si el sitio está en htdocs/SitioEjemplo/, el formulario da "Not Found" y los require_once no encuentran los archivos.
  • TelefonoClass.php declara otra vez class PersonaClass (es una copia sin terminar). Si un script incluyera los dos archivos, PHP corta con Fatal error: Cannot declare class PersonaClass, because the name is already in use (verificado). Hoy ninguna página lo incluye, así que no molesta.
  • ctype_alpha rechaza tildes y espacios. Verificado: "Garcia" pasa, pero "García" y "De la Fuente" no. Cuando no pasa, el setter no se llama, ese dato queda vacío y la página no avisa por qué: la persona se guarda sin apellido o el INSERT falla, según cómo esté definida la tabla.
  • La contraseña de la base está escrita en el código. Es normal (el código PHP no le llega al navegador), pero por eso ese archivo no se sube a un repositorio público. En este apunte está tapada.
Resumen

Mismo esquema que la guía (conectar, INSERT preparado, SELECT + fetch_array + tabla HTML), pero repartido: ManagerMysqli da la conexión, PersonaClass es la única que habla con la tabla y las páginas solo reciben arreglos y los muestran.

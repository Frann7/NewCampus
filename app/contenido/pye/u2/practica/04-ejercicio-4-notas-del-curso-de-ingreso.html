Paso 1 — Ordenar

Inicio: 1, 1, 1, 2, 2, 3, 3, 4, 5, 5.   Final: 3, 4, 5, 6, 6, 6, 7, 8, 9, 9.

Inciso a — Media

\[ \bar{X} = \frac{1}{n}\sum X_i \qquad \bar{X}_I = \frac{27}{10} = 2{,}7 \qquad \bar{X}_F = \frac{63}{10} = 6{,}3 \]

Inciso a — Mediana

\[ \tilde{X} = \frac{1}{2}\left[ X_{\left(\frac{n}{2}\right)} + X_{\left(\frac{n}{2}+1\right)} \right] = \frac{X_{(5)} + X_{(6)}}{2} \qquad \tilde{X}_I = \frac{2 + 3}{2} = 2{,}5 \qquad \tilde{X}_F = \frac{6 + 6}{2} = 6 \]

Inciso a — Moda

Inicio: el 1 aparece 3 veces (más que cualquier otro): \(Mo_I = 1\). Final: el 6 aparece 3 veces: \(Mo_F = 6\).

Inciso a — Varianza y desvío

Fórmula:

\[ S^2 = \frac{n \sum X_i^2 - \left(\sum X_i\right)^2}{n\,(n - 1)} \]

Inicio (\(\sum x = 27\), \(\sum x^2 = 95\)):

\[ S_I^2 = \frac{10 \cdot 95 - 27^2}{10 \cdot 9} = \frac{950 - 729}{90} = \frac{221}{90} = 2{,}456 \qquad S_I = \sqrt{2{,}456} = 1{,}567 \]

Final (\(\sum x = 63\), \(\sum x^2 = 433\)):

\[ S_F^2 = \frac{10 \cdot 433 - 63^2}{90} = \frac{4330 - 3969}{90} = \frac{361}{90} = 4{,}011 \qquad S_F = \sqrt{4{,}011} = 2{,}003 \]

Inciso b — Mayor dispersión

Las medias son distintas (2,7 y 6,3): se comparan los CV. Fórmula:

\[ CV = \frac{S}{\bar{X}} \qquad CV_I = \frac{1{,}567}{2{,}7} = 0{,}580 \qquad CV_F = \frac{2{,}003}{6{,}3} = 0{,}318 \]

Respuesta b

\(CV_I > CV_F\): las notas de la prueba inicial presentan mayor dispersión (relativa a su media), aunque su \(S\) sea menor.

Ordenados: 1, 2, 3, 3, 3, 4, 4, 5, 5, 6 (\(\sum = 36\), \(\sum x^2 = 150\)).

\[ \bar{X} = \frac{\sum X_i}{n} = \frac{36}{10} = 3{,}6 \qquad \tilde{X} = \frac{X_{(5)} + X_{(6)}}{2} = \frac{3 + 4}{2} = 3{,}5 \]

\[ S^2 = \frac{n \sum X_i^2 - \left(\sum X_i\right)^2}{n\,(n - 1)} = \frac{10 \cdot 150 - 36^2}{90} = \frac{1500 - 1296}{90} = \frac{204}{90} = 2{,}267 \qquad S = 1{,}5055 \]

Respuesta c

El incremento medio es 3,6 puntos, la mediana 3,5 y el desvío 1,5055: en promedio cada alumno subió 3,6 puntos entre el inicio y el final.

Resultados oficiales de la cátedra

Inicial: media 2,7; mediana 2,5; moda 1; \(s = 1{,}567\); \(s^2 = 2{,}455\). Final: media 6,3; mediana 6; moda 6; \(s = 2{,}003\); \(s^2 = 4{,}012\). \(CV_I = 0{,}581\), \(CV_F = 0{,}318\): más dispersa la inicial. Incremento: media 3,6; mediana 3,5; \(s = 1{,}5055\) ✓

Las varianzas difieren en el último decimal porque la cátedra elevó al cuadrado el desvío ya redondeado (\(1{,}567^2 = 2{,}455\)); la fracción exacta da \(221/90 = 2{,}4556\) y \(361/90 = 4{,}0111\).

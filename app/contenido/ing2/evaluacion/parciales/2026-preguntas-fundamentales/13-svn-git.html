12. Control de versiones: centralizado y distribuido

Unidad 6 · Control de versiones

Represente gráficamente la arquitectura de un control de versiones centralizado y la de uno distribuido, indicando el servidor, los repositorios y las copias de trabajo. Compárelos en un cuadro y dé un ejemplo de cada uno.

✓ RespuestaPara aprender y escribir en la hoja

Centralizado (SVN): un servidor central con el único repositorio; cada desarrollador tiene solo su copia de trabajo y hace commit y update contra el servidor.

Distribuido (Git): cada desarrollador tiene un repositorio local completo y su copia de trabajo; el servidor remoto (GitHub) es el repositorio que se comparte, con push y pull.

Las tres palabras

  • Servidor: la computadora a la que se conectan todos.
  • Repositorio: la base de datos con todo el historial de versiones.
  • Copia de trabajo: los archivos que cada uno edita en su computadora.

La única diferencia de fondo es dónde está el repositorio: en SVN solo en el servidor; en Git, en cada desarrollador.

Trampas

  • En Git también hay servidor (GitHub, GitLab): no es obligatorio, pero se usa para compartir.
  • Git no es GitHub: Git es el sistema; GitHub, la plataforma que aloja el remoto.

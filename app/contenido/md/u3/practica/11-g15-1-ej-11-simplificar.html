Grimaldi 15.1 · Ej. 11 · Simplificar con las leyes

Simplificar cuatro expresiones booleanas

Simplifique las siguientes expresiones booleanas.

a) \(xy + (x + y)\overline{z} + y\)    b) \(x + y + \overline{(\overline{x} + y + z)}\)
c) \(yz + wx + z + [wz(xy + wz)]\)    d) \(x_1 + \overline{x}_1x_2 + \overline{x}_1\overline{x}_2x_3 + \overline{x}_1\overline{x}_2\overline{x}_3x_4 + \cdots\)

Qué tema es y por qué
  • Simplificar es reescribir la expresión con menos letras, usando las leyes de la tabla de la teoría de esta unidad. Cada renglón dice qué ley se usó.
  • Las que más se usan acá:
    • Distributiva: \(a(b + c) = ab + ac\) y \(a + bc = (a + b)(a + c)\).
    • Absorción: \(a + ab = a\) (si está \(a\) solo, cualquier término que lo contenga como factor sobra).
    • De Morgan: \(\overline{a + b} = \overline{a}\,\overline{b}\); doble complemento: \(\overline{\overline{a}} = a\).
    • Idempotencia: \(a + a = a\), \(aa = a\).
  • Al final, cada resultado se controló con la tabla completa (las \(2^n\) entradas).
Inciso a) — \(xy + (x + y)\overline{z} + y\) \[ \begin{aligned} xy + (x + y)\overline{z} + y &= xy + x\overline{z} + y\overline{z} + y && \text{distributiva} \\ &= (y + xy + y\overline{z}) + x\overline{z} && \text{conmutativa y asociativa de +} \\ &= y + x\overline{z} && \text{absorción: } y + xy = y \text{ y } y + y\overline{z} = y \end{aligned} \]

Este es el mismo ejemplo que muestra la teoría de la cátedra al presentar la tabla de leyes.

Inciso b) — \(x + y + \overline{(\overline{x} + y + z)}\) \[ \begin{aligned} x + y + \overline{(\overline{x} + y + z)} &= x + y + \overline{\overline{x}}\;\overline{y}\;\overline{z} && \text{De Morgan} \\ &= x + y + x\overline{y}\,\overline{z} && \text{doble complemento} \\ &= (x + x\overline{y}\,\overline{z}) + y && \text{conmutativa y asociativa} \\ &= x + y && \text{absorción: } x + x(\overline{y}\,\overline{z}) = x \end{aligned} \] Inciso c) — \(yz + wx + z + [wz(xy + wz)]\)

Primero el corchete:

\[ \begin{aligned} wz(xy + wz) &= wzxy + wzwz && \text{distributiva} \\ &= wxyz + wz && \text{conmutativa e idempotencia } (ww = w,\ zz = z) \end{aligned} \]

Ahora la expresión entera:

\[ \begin{aligned} yz + wx + z + wxyz + wz &= (z + yz + wz + wxyz) + wx && \text{conmutativa y asociativa} \\ &= z + wx && \text{absorción: los tres términos tienen el factor } z \end{aligned} \] Inciso d) — \(x_1 + \overline{x}_1x_2 + \overline{x}_1\overline{x}_2x_3 + \cdots\)

Una regla auxiliar, que sale de las leyes y se usa varias veces:

\(a + \overline{a}b = a + b\)

\(a + \overline{a}b = (a + \overline{a})(a + b)\) (distributiva de \(+\) sobre \(\cdot\)) \(= 1 \cdot (a + b)\) (inversos) \(= a + b\) (identidad).

  1. Con \(a = x_1\), \(b = x_2\): \(x_1 + \overline{x}_1x_2 = x_1 + x_2\).
  2. Lo que sigue es \((x_1 + x_2) + \overline{x}_1\overline{x}_2x_3\). Por De Morgan, \(\overline{x}_1\overline{x}_2 = \overline{x_1 + x_2}\). Con \(a = x_1 + x_2\) y \(b = x_3\), la regla da \(x_1 + x_2 + x_3\).
  3. Igual con el siguiente: \(\overline{x}_1\overline{x}_2\overline{x}_3 = \overline{x_1 + x_2 + x_3}\), y queda \(x_1 + x_2 + x_3 + x_4\).
  4. Cada término nuevo pierde todas las barras: si la suma termina en \(x_n\), el resultado es \(x_1 + x_2 + \cdots + x_n\).

Con palabras: el término \(k\)-ésimo vale 1 cuando \(x_k\) es el primer 1. La suma vale 1 si hay algún 1, que es lo mismo que \(x_1 + \cdots + x_n\).

Respuesta

a) \(y + x\overline{z}\)   b) \(x + y\)   c) \(wx + z\)   d) \(x_1 + x_2 + x_3 + x_4 + \cdots\)

Solución del libro

El libro da a) \(y + x\overline{z}\), b) \(x + y\), c) \(wx + z\), d) \(x_1 + x_2 + x_3 + x_4 + \cdots\). Coincide (la d se probó con 1 a 6 variables).

Ejemplo de la cátedra · objeto

La página armada con la clase Page

Carpeta objeto: class/Page.php define una clase que guarda el encabezado, el menú y el pie, y indice.php la usa para mostrar la portada del "Sistema Recursos Humanos" pasándole solo el contenido del medio. Las ideas de clase, objeto, private, __construct y $this están en la teoría, sección 9.

Archivo 1 — class/Page.php 
<?php
class Page
{
    private $header;
    private $menu;
    private $body;
    private $footer;
    private $Pagina;

    public function __construct($body)
    {
        $this->setHeader();
        $this->setMenu();
        $this->setBody($body);
        $this->setFooter();
    }

    private function setHeader()
    {
        $this->header = '<!DOCTYPE html>
            <html lang="es">
            <head>
                <meta charset="UTF-8">
                ...
                <title>Programación Avanzada</title>
                <link rel="stylesheet" href="...bootstrap.min.css" ...>
            </head>
            <body class="bg-light">
                <div class="container">';
    }

    private function setMenu()
    {
        $this->menu = '<!-- Barra de navegación -->
            <nav class="navbar navbar-expand-lg navbar-light bg-light">
                ... (el mismo menú de includes/head.php: Inicio,
                     Formulario con Token, Formulario con Captcha) ...
            </nav>';
    }

    private function setFooter()
    {
        $this->footer = '</div>
            <script src="...jquery-3.5.1.slim.min.js" ...></script>
            <script src="...popper.min.js" ...></script>
            <script src="...bootstrap.min.js" ...></script>
            </body>
            </html>';
    }

    private function setBody($body)
    {
        $this->body = $body;
    }

    public function setPagina()
    {
        $this->Pagina = $this->header;
        $this->Pagina .= $this->menu;
        $this->Pagina .= $this->body;
        $this->Pagina .= $this->footer;
    }

    public function getHtmlPage()
    {
        return $this->Pagina;
    }
}

Los textos de HTML de setHeader, setMenu y setFooter se acortaron con ...: son el mismo HTML de includes/head.php y includes/footer.php del ejemplo formularios, metido entre comillas simples. Un texto entre comillas puede ocupar varias líneas.

Qué hace cada parte

ParteQué hace
private $header; ... private $Pagina;Cinco propiedades: un pedazo de HTML cada una, y $Pagina para la página entera. Privadas: desde afuera no se tocan.
public function __construct($body)Corre solo con el new. Llama a los cuatro set... para cargar las partes. $this->setHeader() es "llamá al método setHeader de este mismo objeto".
private function setHeader()Guarda en $this->header el principio de la página: <!DOCTYPE>, <head> y la apertura de <body> y del contenedor.
private function setMenu()Guarda la barra de navegación.
private function setFooter()Guarda el cierre: </div>, los scripts y </body></html>.
private function setBody($body)Guarda el contenido que llegó por el constructor. Es lo único que cambia de una página a otra.
public function setPagina()Une las cuatro partes en orden: primero = (empieza con el header) y después .= (le pega menú, cuerpo y pie).
public function getHtmlPage()Devuelve la página armada. No la imprime: el que la llama decide qué hacer con ella.

Por qué unos son private y otros public: los set... de las partes solo los usa el constructor, adentro de la clase. Desde afuera alcanza con dos cosas: armar (setPagina) y pedir el resultado (getHtmlPage).

Archivo 2 — indice.php 
<?php
require_once 'class/Page.php';

$body = ' <h4 class="text-center">Sistema Recursos Humanos</h4>
    <br />
<!-- Opciones de Acceso -->
<div class="row justify-content-lg-center">
  <div class="col col-lg-auto">
      <a href="inicio.php" type="button" class="btn btn-info">Inicio</a>
  </div>
  <div class="col col-lg-auto">
      <a href="formToken.php" type="button" class="btn btn-info">Formulario con Token</a>
  </div>
  <div class="col col-lg-auto">
      <a href="formCaptcha.php" type="button" class="btn btn-info">Formulario con Captcha</a>
  </div>
</div>';

$pagina = new Page($body);
$pagina->setPagina();
echo $pagina->getHtmlPage();

LíneaQué haceCómo queda el objeto $pagina
require_once 'class/Page.php';Trae la definición de la clase (teoría, sección 8). No imprime nada: definir una clase no ejecuta nada.no existe todavía
$body = '...';Un texto con el HTML del medio: título y tres botones.—
$pagina = new Page($body);Crea el objeto. El constructor carga header, menú, body (con $body) y footer.las cuatro partes cargadas; Pagina sin valor

echo $pagina->getHtmlPage();Pide la página y la imprime.sin cambios
Qué se ve

Se probó en un servidor: indice.php devuelve una página HTML completa (3372 bytes), que empieza así: 

<!DOCTYPE html>
                        <html lang="es">
                            <head>
                                <meta charset="UTF-8">
                                ...
                                <title>Programación Avanzada</title>
                                ...
                               <div class="container"><!-- Barra de navegación -->
        <nav class="navbar navbar-expand-lg navbar-light bg-light">
        ...

En el navegador se ve igual que inicio.php del ejemplo formularios: la barra con el logo y "Programación Avanzada", el título "Sistema Recursos Humanos" y los tres botones. Los espacios de más al principio de cada renglón vienen de cómo está indentado el texto dentro de Page.php; el navegador los ignora.

Qué muestra el ejemplo
  • La misma idea que require_once de head.php y footer.php, con una clase: el encabezado, el menú y el pie están escritos una sola vez, y cada página solo arma su $body.
  • No tiene que ver con la seguridad de formularios: es una forma de ordenar el código de las páginas.
Trampas del ejemplo
  • Los botones llevan a páginas que no están en esta carpeta. inicio.php, formToken.php y formCaptcha.php están en formularios/, no en objeto/: desde indice.php dan error 404 (no encontrado).
  • Sin setPagina() no sale nada. Se probó: si se llama a getHtmlPage() antes, devuelve NULL y el echo no imprime nada.
  • Los métodos privados no se llaman desde afuera. $pagina->setHeader(); en indice.php da Fatal error: Uncaught Error: Call to private method Page::setHeader() from global scope.
  • Ojo con las comillas del HTML: como el HTML va entre comillas simples '...', adentro se usan dobles (class="btn"). Una comilla simple en el medio del HTML cortaría el texto.

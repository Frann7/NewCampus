7. Función de distribución acumulada de una continua

Cuándo se usa

Cuando piden "determine la función de distribución acumulada", "obtenga \(F(x)\) por tramos", o "resuelva usando la acumulada". Una vez que tenés \(F\), cualquier probabilidad sale con una resta, sin volver a integrar.

Fórmulas

\[ F(x) = P(X \leq x) = \int_{-\infty}^{x} f(t)\,dt \]

Si \(f\) no es 0 solo en \([a, b]\), por tramos:

\[ F(x) = \begin{cases} 0 & \text{si } x < a \\ \displaystyle\int_a^x f(t)\,dt & \text{si } a \leq x < b \\ 1 & \text{si } x \geq b \end{cases} \]

Para usarla:

\[ P(X \leq c) = F(c) \qquad P(c < X < d) = F(d) - F(c) \qquad P(X > c) = 1 - F(c) \]

Y el camino de vuelta: \[ f(x) = \frac{dF(x)}{dx} = F'(x) \]

Qué significa cada letra

SímboloQué esEjemplo
\(F(x)\)el área bajo \(f\) desde el principio hasta \(x\): la probabilidad de \(x\) o menos\(F(1) = P(X \leq 1)\)
\(t\)la letra de adentro de la integral. Se cambia porque la \(x\) ya está ocupada como límite de arriba\(\int_{-1}^{x} \frac{t^2}{3}\,dt\)
\(F'(x)\) o \(\frac{dF}{dx}\)la derivada de \(F\) (sección 4)\(\big(\tfrac{x^3 + 1}{9}\big)' = \tfrac{x^2}{3}\)

De dónde sale

Es la misma idea que en la discreta (sección 3), "lo juntado hasta \(x\)", pero en vez de sumar bastones se junta área. Antes de \(a\) no hay área (\(F = 0\)); después de \(b\) ya se juntó toda (\(F = 1\)); en el medio, el área desde \(a\) hasta \(x\), que es una integral con límite de arriba variable: el resultado es una fórmula con \(x\), no un número.

Como integrar y derivar se deshacen (sección 4), si \(F\) es la integral de \(f\), derivando \(F\) se vuelve a \(f\). Sirve para controlar que la \(F\) esté bien.

Cómo es el gráfico

  • Vale 0 a la izquierda de \(a\) y 1 desde \(b\) en adelante.
  • En el medio es una curva sin saltos (no una escalera como la discreta): sube de a poco.
  • Nunca baja. Sube más rápido donde \(f\) es más alta.

Dos controles que no fallan

  1. \(F(a) = 0\) y \(F(b) = 1\): reemplazando los extremos en la fórmula del medio.
  2. \(F'(x) = f(x)\): derivando se vuelve a la densidad.

Ejemplo 1 — La densidad \(x^2/3\) (de la cátedra)

Enunciado

Sea \(f(x) = \begin{cases} \dfrac{x^2}{3} & -1 < x < 2 \\ 0 & \text{en c.o.c.} \end{cases}\) Obtenga \(F(x)\), verifique que \(f = F'\) y calcule con ella \(P(X < 1{,}5)\).

Desarme del enunciado

FraseQué significaLa cuentaA dónde va
"\(-1 < x < 2\)"\(a = -1\), \(b = 2\)—los tres tramos
"verifique que \(f = F'\)"derivar la \(F\)—control
"\(P(X < 1{,}5)\)"en una continua, igual a \(P(X \leq 1{,}5)\)—\(F(1{,}5)\)

Paso 1 — El tramo del medio

Fórmula: \(\displaystyle F(x) = \int_{a}^{x} f(t)\,dt\) para \(a \leq x < b\).

\[ F(x) = \int_{-1}^{x} \frac{t^2}{3}\,dt = \left[\frac{t^3}{9}\right]_{-1}^{x} = \frac{x^3}{9} - \left(\frac{(-1)^3}{9}\right) = \frac{x^3}{9} + \frac{1}{9} = \frac{x^3 + 1}{9} \]

En Barrow, el límite de arriba ahora es la letra \(x\): se reemplaza \(t\) por \(x\) y queda una fórmula.

Paso 2 — Los tres tramos

\[ F(x) = \begin{cases} 0 & \text{si } x < -1 \\ \dfrac{x^3 + 1}{9} & \text{si } -1 \leq x < 2 \\ 1 & \text{si } x \geq 2 \end{cases} \]

Control 1: \(F(-1) = \dfrac{-1 + 1}{9} = 0\) y \(F(2) = \dfrac{8 + 1}{9} = 1\). ✔

Paso 3 — \(f = F'\)

\[ F'(x) = \left(\frac{x^3 + 1}{9}\right)' = \frac{1}{9}\,(3x^2 + 0) = \frac{3x^2}{9} = \frac{x^2}{3} = f(x) \quad\checkmark \]

Paso 4 — \(P(X < 1{,}5)\) con la acumulada

Fórmula: \(P(X \leq c) = F(c)\).

\[ P(X < 1{,}5) = F(1{,}5) = \frac{(3/2)^3 + 1}{9} = \frac{27/8 + 8/8}{9} = \frac{35/8}{9} = \frac{35}{72} = 0{,}4861 \]

Es el mismo resultado que con la integral directa (sección 5), sin volver a integrar.

La acumulada \((x^3 + 1)/9\): 0 hasta −1, curva hasta 2, 1 después. Los puntos son \(F(1)\) y \(F(1{,}5)\).

Respuesta

\(F(x)\) por tramos de arriba; \(F'(x) = x^2/3 = f(x)\); \(P(X < 1{,}5) = 35/72 = 0{,}4861\).

Ejemplo 2 — Tiempo de resolución de un ticket (Final 29/07/2026, ej. 1a a 1d)

Enunciado

El tiempo \(X\), medido en horas, que tarda un técnico de soporte en resolver un ticket de reclamo se modela mediante una variable aleatoria continua cuya función de densidad está dada por \(f(x) = \begin{cases} k(4 - x) & 0 \leq x \leq 4 \\ 0 & \text{en otro caso} \end{cases}\)

a) Determinar el valor de \(k\) para que \(f\) sea una función de densidad. Justificar verificando las condiciones necesarias. b) Representar gráficamente \(f\). c) Obtener la función de distribución acumulada \(F(x)\), expresándola por tramos. d) Calcular \(P(X \leq 1)\) y \(P(1 < X \leq 3)\) e interpretar los resultados en el contexto del problema.

Desarme del enunciado

FraseQué significaLa cuentaA dónde va
"\(0 \leq x \leq 4\)"\(a = 0\), \(b = 4\)—límites y tramos
"verificando las condiciones"\(f \geq 0\) y área 1—inciso a
"\(P(X \leq 1)\)"a lo sumo una hora—\(F(1)\)
"\(P(1 < X \leq 3)\)"entre una y tres horas—\(F(3) - F(1)\)

a) La constante

Fórmula: \(\displaystyle \int_a^b f(x)\,dx = 1\) (sección 6).

\[ k \int_0^4 (4 - x)\,dx = k\left[4x - \frac{x^2}{2}\right]_0^4 = k\left(16 - \frac{16}{2}\right) = k \cdot 8 = 1 \quad\Longrightarrow\quad k = \frac{1}{8} \]

Condiciones: con \(k = \tfrac{1}{8}\), \(f(x) = \tfrac{4 - x}{8}\) vale \(\tfrac{4}{8} = 0{,}5\) en 0 y 0 en 4: nunca negativa entre 0 y 4 ✔; y su área total es 1 ✔.

b) Gráfico de \(f\)

\(f(x) = (4 - x)/8\): una recta que baja de 0,5 a 0. Los tickets cortos son los más probables. Pintada, el área de 1 a 3.

c) La acumulada por tramos

Fórmula: \(\displaystyle F(x) = \int_{a}^{x} f(t)\,dt\) para \(a \leq x < b\).

\[ F(x) = \int_0^x \frac{4 - t}{8}\,dt = \frac{1}{8}\left[4t - \frac{t^2}{2}\right]_0^x = \frac{1}{8}\left(4x - \frac{x^2}{2}\right) = \frac{x}{2} - \frac{x^2}{16} \]

\[ F(x) = \begin{cases} 0 & \text{si } x < 0 \\ \dfrac{x}{2} - \dfrac{x^2}{16} & \text{si } 0 \leq x < 4 \\ 1 & \text{si } x \geq 4 \end{cases} \]

Controles: \(F(0) = 0\), \(F(4) = 2 - 1 = 1\) ✔. \(F'(x) = \tfrac{1}{2} - \tfrac{2x}{16} = \tfrac{1}{2} - \tfrac{x}{8} = \tfrac{4 - x}{8} = f(x)\) ✔.

d) Las dos probabilidades

Fórmula: \(P(X \leq c) = F(c)\).

\[ P(X \leq 1) = F(1) = \frac{1}{2} - \frac{1}{16} = \frac{8}{16} - \frac{1}{16} = \frac{7}{16} = 0{,}4375 \]

Fórmula: \(P(c < X \leq d) = F(d) - F(c)\).

\[ F(3) = \frac{3}{2} - \frac{9}{16} = \frac{24}{16} - \frac{9}{16} = \frac{15}{16} \]

\[ P(1 < X \leq 3) = F(3) - F(1) = \frac{15}{16} - \frac{7}{16} = \frac{8}{16} = 0{,}5 \]

La acumulada: la distancia vertical entre \(F(1)\) y \(F(3)\) es la probabilidad de estar entre 1 y 3 horas.

Respuesta

a) \(k = 1/8\). c) La \(F\) por tramos de arriba. d) \(P(X \leq 1) = 0{,}4375\): el 43,75 % de los tickets se resuelve en una hora o menos. \(P(1 < X \leq 3) = 0{,}5\): la mitad de los tickets tarda entre una y tres horas.

Errores y trampas

  • Escribir solo el tramo del medio: \(F\) se define para todo \(x\); faltan el 0 y el 1.
  • Dejar la \(t\) en el resultado: después de Barrow, la fórmula queda en \(x\).
  • Olvidar el \(-G(a)\) cuando \(a\) no es 0: con \(a = -1\) aparece el \(+\tfrac{1}{9}\) del Ejemplo 1; sin él, \(F(-1)\) no daría 0.

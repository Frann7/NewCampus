Clase 4 — JavaScript, DOM y API REST

Basado en la Presentación de la Clase 4 de la cátedra (18 diapositivas). Hasta la Clase 3 todo pasaba en el servidor: PHP armaba el HTML y el navegador lo mostraba quieto. Acá aparece el otro lado: JavaScript, el lenguaje que corre dentro del navegador y puede cambiar la página sin recargarla, validar un formulario antes de mandarlo a PHP y pedirle datos a otros sistemas por internet.

Antes de leer

Cómo leer esta clase

El Parcial PHP no tomó nada de esta clase: sus 20 preguntas son de PHP. Pero es parte de la materia, y el TP y los ejemplos de la cátedra la usan para validar formularios. Por eso los ejemplos siguen el estilo del parcial ("¿qué muestra?", "¿qué valor queda?"), para que leas JavaScript con la misma mirada con la que leés PHP.

Las diapositivas son cortas. Lo que dejan implícito (cómo se escribe una variable, una función flecha, un evento) está completado acá, sin salirse de sus temas. Conviene leer en este orden:

Si venís de PHP

JavaScript se parece bastante, pero tiene tres diferencias que confunden al principio: las variables no llevan $, los textos se unen con + (no con el punto) y el código no corre en el servidor sino en la computadora de quien mira la página. Las tres están explicadas en la sección 2.

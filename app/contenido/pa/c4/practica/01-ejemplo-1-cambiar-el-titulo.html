Cambiar el título con botones

Una página con un título vacío y cinco botones: cambiar el texto, ponerlo rojo, ponerle fondo verde, agrandar y achicar la letra. Todo lo hace una clase, IndexClass, en js/page1Class.js.

Paso 1 — El HTML: qué elementos hay 
<div style="text-align: center;">
    <h2>Ejemplo de uso de clases en Javascript</h2>
    <hr />
    <h1 id="titulo"></h1>
    <hr />
    <button id="btCambioTitulo">Cambiar Título</button>
    <button id="btCambioColor">Cambiar Color</button>
    <button id="btCambioFondo">Cambiar Fondo</button>
    <button id="btAumentoTamaño">+</button>
    <button id="btDisminuirTamaño">-</button>
    <hr />
</div>

<script src="js/page1Class.js" type="text/javascript"></script>
  • El <h1 id="titulo"> está vacío: el texto lo pone JavaScript al cargar.
  • Cada botón tiene un id distinto, que es lo que usa JavaScript para encontrarlo. El texto del botón ("+", "Cambiar Color") es solo lo que ve el usuario.
  • El <script> va al final del <body> y carga el archivo de la clase.
Paso 2 — El constructor: agarrar los elementos 
class IndexClass {

    constructor(){
        this.titulo = document.getElementById('titulo');

        this.btCambioTitulo = document.getElementById('btCambioTitulo');
        this.btCambioColor = document.getElementById('btCambioColor');
        this.btCambioFondo = document.getElementById('btCambioFondo');
        this.btAumentoTamaño = document.getElementById('btAumentoTamaño');
        this.btDisminuirTamaño = document.getElementById('btDisminuirTamaño');
    }
LíneaQué haceCómo quedan las propiedades
this.titulo = ...('titulo');Guarda el <h1> en una propiedad del objetothis.titulo = el h1
this.btCambioTitulo = ... y las otras cuatroGuarda cada botón en una propiedad con el mismo nombre que su id (es una costumbre, no una obligación)Cinco propiedades, una por botón

El constructor solo junta los elementos. Así, después, cualquier método los tiene a mano con this., sin volver a buscarlos.

Paso 4 — addEventListeners(): qué hace cada botón 
    addEventListeners() {
        this.btCambioTitulo.addEventListener('click', () => {
            this.titulo.innerHTML = "Nuevo Título de la pagina web";
        });

        this.btCambioColor.addEventListener('click', () => {
            this.titulo.style.color = "red";
        });

        this.btCambioFondo.addEventListener('click', () => {
            this.titulo.style.backgroundColor = "green";
        });

        this.btAumentoTamaño.addEventListener('click', () => {
            let currentSize = window.getComputedStyle(this.titulo).fontSize;
            this.titulo.style.fontSize = (parseFloat(currentSize) + 2) + "px";
        });

        this.btDisminuirTamaño.addEventListener('click', () => {
            let currentSize = window.getComputedStyle(this.titulo).fontSize;
            this.titulo.style.fontSize = (parseFloat(currentSize) - 2) + "px";
        });
    }
}
BotónQué hace al hacer clicQué se ve
Cambiar TítuloReemplaza el contenido del h1"Nuevo Título de la pagina web". Más clics no cambian nada: pone siempre el mismo texto
Cambiar Colorstyle.color = rojoLetras rojas
Cambiar Fondostyle.backgroundColor = verdeFranja verde detrás del título (el h1 ocupa todo el ancho)
+Lee el tamaño real con getComputedStyle, lo pasa a número con parseFloat, le suma 2 y lo vuelve a escribir con "px"La letra crece 2px por clic
-Lo mismo restando 2La letra se achica 2px por clic

Las cinco funciones son flechas: por eso adentro this.titulo sigue siendo el título (teoría, sección 6, ejemplo 3). La cuenta del tamaño es la de la sección 4, ejemplo 2: con la configuración de fábrica del navegador el h1 arranca en 32px, y tres clics en "+" lo dejan en 38px.

Qué se ve en la página

Al abrirla: el título "Titulo de la pagina web Programación Avanzada" entre dos líneas, y los cinco botones abajo. Cada botón cambia el título al instante, sin recargar. Si se recarga, todo vuelve a como estaba: los cambios eran del DOM, no del archivo.

La ñ en los nombres

btAumentoTamaño lleva ñ en el id y en la propiedad. JavaScript y HTML lo aceptan, y anda porque el archivo está guardado en UTF-8 (lo dice el <meta charset="UTF-8">). Igual, por costumbre, en el código conviene evitar ñ y tildes: si el archivo se guarda con otra codificación, el id del HTML y el del JavaScript dejan de coincidir.

Definiciones

4. Claves

Para escribir en la hoja

Una clave es un conjunto de uno o más atributos que identifica a cada fila de una tabla. Para serlo tiene que cumplir dos propiedades:

  • Unicidad: no hay dos filas con el mismo valor de la clave (y no puede quedar vacía).
  • Minimalidad: si la clave tiene varios atributos, no se le puede sacar ninguno sin perder la unicidad.
  • Clave candidata: cada conjunto de atributos que cumple unicidad y minimalidad. Una tabla puede tener varias.
  • Clave primaria (PK): la clave candidata que se elige para identificar las filas de la tabla. Hay una sola por tabla.
  • Clave secundaria (o alternativa): una clave candidata que no se eligió como primaria.
  • Clave foránea (FK): un atributo (o varios) de una tabla que es la clave primaria de otra tabla. Es lo que relaciona las dos tablas: su valor tiene que existir en la tabla a la que apunta.
  • Clave compuesta: una clave formada por más de un atributo, porque ninguno solo alcanza para identificar la fila.

Ejemplo 1: las cinco en una misma base

Propietario(Documento, Email, Nombre) · Animal(NumeroHC, Nombre, Documento) · ConsultaTratamiento(NumeroConsulta, CodigoTratamiento, Costo)

ClaveDónde estáPor qué
CandidatasEn Propietario: Documento y EmailCada una sola ya identifica a una persona: no hay dos con el mismo documento ni con el mismo email
PrimariaDocumentoEs la que se eligió de las dos candidatas
SecundariaEmailEs candidata, pero no se eligió
ForáneaDocumento, dentro de AnimalEs la PK de Propietario, guardada en Animal para saber de quién es cada animal
Compuesta(NumeroConsulta, CodigoTratamiento)Una consulta tiene varios tratamientos y un tratamiento se aplica en varias consultas: solo el par no se repite

Ejemplo 2: ¿es clave o no?

En una tabla Empleado(Legajo, DNI, Nombre, Telefono): ¿Nombre es candidata? ¿Y (Legajo, Nombre)?

  • Nombre: no. Puede haber dos empleados que se llamen igual: falla la unicidad.
  • (Legajo, Nombre): no se repite nunca, pero no es mínima: si le sacás Nombre, Legajo solo sigue identificando. Falla la minimalidad.
  • Las candidatas son Legajo y DNI. Si se elige Legajo como primaria, DNI queda como secundaria.
Errores y trampas
  • La clave primaria nunca puede quedar vacía (nula) ni repetirse. Una foránea sí se repite (muchos animales del mismo dueño).
  • Toda primaria es candidata, pero no toda candidata es primaria.
  • "Compuesta" habla de cuántos atributos tiene; "primaria" o "candidata" hablan de qué papel cumple. Una clave puede ser primaria y compuesta a la vez.
  • En el apunte de Archivos, "clave secundaria" también se usa para un campo por el que se busca aunque se repita (un índice extra). Si la pregunta es de bases de datos, va la definición de arriba.

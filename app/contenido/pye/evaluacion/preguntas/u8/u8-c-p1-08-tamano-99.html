Para estimar el tiempo medio de carga de un sitio con 99 % de confianza y un error de a lo sumo 2 ms, la fórmula del tamaño de muestra dio \(n = 106{,}17\). ¿Cuántas cargas hay que medir?

Tercer parcial — primera parte probable (inventada)

  • 106, porque 0,17 está por debajo de 0,5.
  • 107, porque el tamaño de muestra se redondea siempre para arriba.
  • 106,17, el valor exacto que dio la fórmula.
  • 106, porque con menos datos el error queda más chico.
  • No se puede medir una parte de una carga: \(n\) tiene que ser entero.
  • Se redondea siempre para arriba: con 107 el error queda en 2 ms o menos; con 106 queda un poco más grande que lo pedido.
  • Redondear como siempre (para abajo si es menos de 0,5) acá no vale.
  • Con menos datos el error queda más grande, no más chico.

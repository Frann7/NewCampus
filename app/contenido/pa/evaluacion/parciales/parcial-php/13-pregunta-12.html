¿El siguiente código Php es correcto y tiene como salida "INGRESA"?

<?php
$a=true;
if ($a) {
echo "INGRESA";
}
?>

Seleccione una:

  1. Si es correcto
  2. No, porque es falso por defecto .
  3. Emite un error, porque la estructura de control IF no posee condición para evaluar

a) Si es correcto

Qué evalúa

La sintaxis del if y qué puede ir como condición. Es de la Clase 1 (estructuras de control).

El concepto, desde cero

if (condición) { ... } ejecuta el bloque si la condición vale true. La condición puede ser una comparación ($x > 3) o cualquier valor: PHP lo convierte a booleano. Una variable que ya es booleana se usa tal cual.

Qué imprime y por qué

INGRESA

El código es correcto y la salida es INGRESA (comprobado corriéndolo).

Opción por opción

  • a) Si es correcto: correcta.
  • b) No, porque es falso por defecto: $a no tiene valor por defecto, se le asignó true en la línea anterior. (Una variable que nunca se asignó da un aviso Undefined variable y cuenta como false; no es este caso.)
  • c) Emite un error, porque el IF no posee condición: sí la tiene, $a. No hace falta escribir $a == true.
La trampa

Creer que la condición tiene que ser una comparación. if ($a) es lo mismo que if ($a == true).

Guia 2020 · Ejercicio 5 · Tamaño de muestra

Tiempo para perforar una placa: cuantas mediciones hacen falta

Un experto en eficiencia desea determinar el tiempo promedio que toma perforar una cierta placa metalica. a) ¿De que tamaño se necesita una muestra para tener 95% de confianza de que la media de la muestra este dentro de 12 segundos de la media real? Suponga que por estudios previos se sabe que el desvio estandar de la variable aleatoria considerada en la poblacion es de 40 segundos. b) Repita el inciso anterior contemplando que el error maximo de estimacion debe disminuir a la mitad.

Que metodo y por que
  • Todavia no hay muestra: se esta planificando cuantas perforaciones medir. Lo que se fija de antemano es la confianza (95 %) y cuanto se tolera errar.
  • "Que la media de la muestra este dentro de 12 segundos de la media real" es \(|\bar{x} - \mu| \leq 12\): el error maximo de estimacion (la mitad del ancho del futuro intervalo) es \(E = 12\).
  • El error es \(E = Z_{\alpha/2}\,\sigma/\sqrt{n}\). Como \(\sigma = 40\) es conocida ("por estudios previos se sabe que el desvio ... en la poblacion"), se puede despejar \(n\):

\[ E = Z_{\alpha/2}\,\frac{\sigma}{\sqrt{n}} \;\Longrightarrow\; \sqrt{n} = \frac{Z_{\alpha/2}\,\sigma}{E} \;\Longrightarrow\; n = \left( \frac{Z_{\alpha/2}\,\sigma}{E} \right)^{2} \]

Tamaño de muestra para estimar \(\mu\)

\[ n = \left( \frac{Z_{\alpha/2}\,\sigma}{E} \right)^{2} \]

Se redondea siempre hacia arriba: con menos datos el error se pasaria del maximo pedido.

Inciso a — Error maximo de 12 segundos

Formula:

\[ n = \left( \frac{Z_{\alpha/2}\,\sigma}{E} \right)^{2} \]

Pieza por pieza:

  • \(Z_{\alpha/2}\,\sigma = 1{,}96 \times 40 = 78{,}4\)
  • \(\dfrac{78{,}4}{E} = \dfrac{78{,}4}{12} = 6{,}5333\)

\[ n = 6{,}5333^{2} = 42{,}68 \;\Longrightarrow\; n = 43 \]

Comprobacion con \(E = 78{,}4/\sqrt{n}\):

  • \(n = 42\): \(E = \dfrac{78{,}4}{6{,}4807} = 12{,}10\) s → se pasa de 12, no alcanza.
  • \(n = 43\): \(E = \dfrac{78{,}4}{6{,}5574} = 11{,}96\) s → cumple.
Respuesta a

Hacen falta 43 perforaciones. Con 43 mediciones, con 95 % de confianza el tiempo promedio de la muestra queda a menos de 12 segundos del tiempo medio real.

Inciso b — Error maximo a la mitad (6 segundos)

Formula:

\[ n = \left( \frac{Z_{\alpha/2}\,\sigma}{E} \right)^{2} \]

  • \(Z_{\alpha/2}\,\sigma = 1{,}96 \times 40 = 78{,}4\) (no cambia)
  • \(\dfrac{78{,}4}{E} = \dfrac{78{,}4}{6} = 13{,}0667\)

\[ n = 13{,}0667^{2} = 170{,}74 \;\Longrightarrow\; n = 171 \]

Comprobacion: con \(n = 170\), \(E = 78{,}4/13{,}0384 = 6{,}01\) s (no alcanza); con \(n = 171\), \(E = 78{,}4/13{,}0767 = 5{,}995\) s (cumple).

Respuesta b

Hacen falta 171 perforaciones: para reducir el error a la mitad hubo que medir unas 4 veces mas.

Por que la mitad de error cuesta el cuadruple

En la formula \(E\) esta al cuadrado abajo: si \(E\) se divide por 2, \(E^{2}\) se divide por 4 y \(n\) se multiplica por 4. Sin redondear se ve exacto: \(42{,}68 \times 4 = 170{,}74\). Dicho con \(\sqrt{n}\): el error baja como \(1/\sqrt{n}\), y para que \(\sqrt{n}\) se duplique, \(n\) tiene que cuadruplicarse.

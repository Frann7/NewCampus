6. Error de estimación y tamaño de muestra

Una muestra · error E y tamaño n

Una fintech procesa cada noche un job de conciliación de pagos. Por los registros anteriores se sabe que el desvío estándar poblacional del tiempo de procesamiento es de 15 segundos. Se toma una muestra aleatoria de 50 ejecuciones del job para estimar el tiempo medio con un 95 % de confianza.

  1. ¿Cuál es el error máximo de estimación de ese intervalo?
  2. ¿Cuántas ejecuciones habría que registrar para que, con un 95 % de confianza, el error de estimación sea a lo sumo de 3 segundos?
✓ ResultadosSolo las respuestas, sin procedimiento
IncisoResultado
a) Error de estimación\(Z\) con \(\sigma\): \(z_{0{,}025} = 1{,}96\), \(\sigma/\sqrt{n} = 2{,}1213\)  ·  \(E = 4{,}158\) s
b) Tamaño de muestra\(n = (1{,}96 \cdot 15 / 3)^{2} = 96{,}04\) → \(n = 97\) ejecuciones
✎ Explicación detalladaDesde cero: qué caso es, fórmulas, desarme, tabla y resolución
El enunciado, otra vez

Tiempo de un job nocturno, con \(\sigma = 15\) s conocida. Muestra de 50 ejecuciones, confianza del 95 %. Piden: a) el error máximo de estimación; b) cuántas ejecuciones hacen falta para un error de a lo sumo 3 s.

¿Qué caso es?

PreguntaEn este enunciadoEntonces
¿Una muestra o dos?Un solo job.Una muestra.
¿Media o proporción?Se estima el “tiempo medio”.Media \(\mu\).
¿\(n \geq 30\)?\(n = 50\) (y en el inciso b va a salir más grande todavía).Sí.
¿\(\sigma\) conocida?“desvío estándar poblacional … 15 segundos”.Sí.

Caso: una media con \(Z\) y \(\sigma\). No piden el intervalo, sino dos piezas de él: el error \(E\) (inciso a) y, al revés, el \(n\) que hace falta para un \(E\) dado (inciso b).

La fórmula

Error de estimación y tamaño de muestra

\[ E = z_{\alpha/2}\,\frac{\sigma}{\sqrt{n}} \qquad\qquad n = \left(\frac{z_{\alpha/2}\,\sigma}{E}\right)^{2} \]

La segunda sale de despejar \(n\) de la primera: se pasa \(\sqrt{n}\) multiplicando y \(E\) dividiendo, \(\sqrt{n} = z_{\alpha/2}\,\sigma / E\), y se eleva todo al cuadrado.

El \(n\) se redondea siempre hacia arriba, aunque el decimal sea chico.

LetraQué es
\(E\)El error de estimación: lo máximo que, con esa confianza, el promedio de la muestra se aleja del verdadero \(\mu\). Es la mitad del ancho del intervalo.
\(\sigma\)El desvío de la población.
\(n\)Cuántos datos tiene la muestra. En el inciso b es la incógnita.
\(\sigma/\sqrt{n}\)El error estándar: cuánto cambia \(\bar{x}\) de una muestra a otra.
\(z_{\alpha/2}\)El valor de la tabla normal que deja \(\alpha/2\) en cada punta.

Desarme del enunciado

El valor de tabla, paso a paso

  1. \(1 - \alpha = 0{,}95\), así que \(\alpha = 1 - 0{,}95 = 0{,}05\).
  2. Se reparte entre las dos puntas: \(\alpha/2 = 0{,}025\).
  3. Se busca 0,025 adentro de la tabla Z: fila \(-1{,}9\), columna \(0{,}06\), \(z = -1{,}96\).
  4. En la fórmula va positivo: \(z_{0{,}025} = 1{,}96\).

Buscar \(1 - \alpha/2 = 0{,}975\) da \(1{,}96\) directo: es lo mismo.

Resolución

Inciso a — Error de estimación

Fórmula:

\[ E = z_{\alpha/2}\,\frac{\sigma}{\sqrt{n}} \]

Error estándar:

\[ \frac{\sigma}{\sqrt{n}} = \frac{15}{\sqrt{50}} = \frac{15}{7{,}0711} = 2{,}1213 \]

Error de estimación:

\[ E = 1{,}96 \times 2{,}1213 = 4{,}158 \]

Respuesta a

\(E = 4{,}158\) s.

Con un 95 % de confianza, el promedio de las 50 ejecuciones no se aleja del tiempo medio verdadero del job más de 4,158 segundos.

Inciso b — Tamaño de muestra para \(E \leq 3\) s

Ahora se conoce el error que se quiere (3 s) y falta \(n\). Un error más chico que 4,158 pide más datos que 50.

Fórmula:

\[ n = \left(\frac{z_{\alpha/2}\,\sigma}{E}\right)^{2} \]

Reemplazar:

\[ n = \left(\frac{1{,}96 \times 15}{3}\right)^{2} \]

Arriba:

\[ 1{,}96 \times 15 = 29{,}4 \]

Dividir:

\[ \frac{29{,}4}{3} = 9{,}8 \]

Al cuadrado:

\[ n = 9{,}8^{2} = 96{,}04 \]

Se redondea hacia arriba: \(n = 97\). Aunque el decimal sea 0,04, con 96 no alcanza. Control:

\[ 1{,}96 \cdot \frac{15}{\sqrt{97}} = 2{,}985 \leq 3 \ \checkmark \qquad\qquad 1{,}96 \cdot \frac{15}{\sqrt{96}} = 3{,}0006 > 3 \]

Respuesta b

Hay que registrar 97 ejecuciones del job.

Trampas

Las trampas de este caso
  1. Redondear 96,04 a 96. El \(n\) va siempre para arriba: con 96 el error queda apenas por encima de 3.
  2. Olvidarse del cuadrado. 9,8 no es la respuesta.
  3. Usar el \(n = 50\) en el inciso b. En b el \(n\) es la incógnita: el 50 era solo del inciso a.

Strings

12. Comparar strings: ==, ===, strcmp y strcasecmp

Para qué sirve

Saber si dos textos son iguales (una contraseña, un nombre de usuario) es de lo más común. Hay dos caminos:

  • Los operadores == y === de la Clase 1, que dan true o false.
  • Las funciones strcmp() y parientes, que además dicen cuál va primero en orden alfabético y permiten ignorar mayúsculas.

Sintaxis

Operadores y funciones 
$a == $b                    // ¿mismo valor? (puede convertir tipos)
$a === $b                   // ¿mismo valor y mismo tipo?
strcmp($a, $b)              // 0 si son idénticas
strcasecmp($a, $b)          // 0 si son iguales sin mirar mayúsculas
strncmp($a, $b, n)          // compara solo los primeros n caracteres
strncasecmp($a, $b, n)      // los primeros n, sin mirar mayúsculas

Qué es cada parte

Para usarlas en un if se pregunta si el resultado es == 0: 0 quiere decir "iguales" (al revés de lo que uno esperaría).

La cátedra dice true: era así antes de PHP 8

El apunte afirma que '123abc' == 123 es true, porque PHP convertía el string a número (123). Eso pasaba hasta PHP 7. Desde PHP 8 (el de XAMPP) da false. La conclusión de la cátedra sigue valiendo: para comparar sin sorpresas, ===.

La cátedra describe las dos funciones al revés

El apunte dice que strcmp() no diferencia mayúsculas y strcasecmp() sí. Es al revés, como muestra este ejemplo: strcmp distingue (da 1) y strcasecmp no (da 0). La pista está en el nombre: case es "mayúsculas/minúsculas", y la función que lo lleva es la que no les da importancia.

Ejemplo 3 — Solo los primeros n caracteres (formato "¿cuál es la salida?")

Enunciado

¿Cuál es la salida del siguiente script?

<?php
$cadena = 'Hola a todos';
if (strncasecmp($cadena, 'HolA  a todos', 3) == 0) {
    echo 'Iguales en 3 (sin mayúsculas)<br>';
}
if (strncmp($cadena, 'HolA a todos', 3) == 0) {
    echo 'Iguales en 3<br>';
}
if (strncmp($cadena, 'HolA a todos', 4) == 0) {
    echo 'Iguales en 4';
}
?>

La función se llama strncasecmp

El apunte la escribe strcasencmp(), que no existe en PHP (daría Call to undefined function). El nombre correcto es strncasecmp(): str + n + case + cmp.

Errores y trampas

if (strcmp(...)) entra cuando son distintas

Como "iguales" es 0 y 0 es falso, if (strcmp($a, $b)) entra justamente cuando no son iguales. Siempre se escribe == 0.

Ejercicio 3

20 puntos Unidad 8 · IC para la diferencia de medias (varianzas iguales)

Un equipo de desarrollo web compara el tiempo de carga (en segundos) de la página principal de un sitio construida con dos frameworks: el framework A renderiza la página en el navegador y el framework B la renderiza en el servidor. Con el framework A se midieron 14 cargas, con un tiempo medio de 2,84 s y un desvío estándar de 0,52 s. Con el framework B se midieron 12 cargas, con un tiempo medio de 2,31 s y un desvío estándar de 0,34 s. Suponga que con ambos frameworks el tiempo de carga se distribuye normalmente y que las muestras son independientes.

  1. ¿Pueden suponerse iguales las varianzas poblacionales? Justifique con la regla empírica.
  2. Construya un intervalo de confianza del 95 % para la diferencia de los tiempos medios de carga \(\mu_A - \mu_B\).
  3. ¿Hay una diferencia significativa entre los tiempos medios de carga? ¿Con qué framework carga más rápido la página?
✓ ResultadosSolo las respuestas, sin procedimiento
IncisoResultado
a) Regla empírica \(S_A^{2}/S_B^{2} = 0{,}2704 / 0{,}1156 = 2{,}34 \leq 3\) → sí se suponen iguales: pooled
b) IC 95 % para \(\mu_A - \mu_B\) \(S_p = 0{,}4466\), \(\nu = 24\), \(t_{(0{,}025;\ 24)} = 2{,}064\), \(E = 0{,}3626\)  ·  \(\text{IC}_{95\%}(\mu_A - \mu_B) = (0{,}167\ ;\ 0{,}893)\) s
c) Conclusión El intervalo no incluye el 0: hay diferencia significativa. Es todo positivo: \(\mu_A > \mu_B\), la página carga más rápido con el framework B (renderizado en el servidor), entre 0,167 y 0,893 s menos en promedio.

El enunciado, otra vez

Framework A (renderiza en el navegador): 14 cargas, media 2,84 s, desvío 0,52 s. Framework B (renderiza en el servidor): 12 cargas, media 2,31 s, desvío 0,34 s. Normales e independientes. Piden: a) si las varianzas pueden suponerse iguales (regla empírica); b) IC del 95 % para \(\mu_A - \mu_B\); c) si hay diferencia significativa y con qué framework carga más rápido.

¿De qué tema es?

Estimación, parte 2: intervalo de confianza para la diferencia de medias de dos poblaciones con muestras independientes y chicas.

Los conceptos que hacen falta, desde cero

1. Qué fórmula usar (diagrama de decisión de la cátedra)
  • ¿\(\sigma_1^{2}\) y \(\sigma_2^{2}\) conocidas? → \(Z\) con las \(\sigma^{2}\).
  • Desconocidas y \(n_1, n_2 \geq 30\) → \(Z\) con \(S_1^{2}\) y \(S_2^{2}\).
  • Desconocidas, muestras chicas y poblaciones normales → \(t\), y para saber cuál se usa la regla empírica:

\[ \frac{S^{2}_{\text{mayor}}}{S^{2}_{\text{menor}}} \leq 3 \;\Rightarrow\; \text{varianzas supuestas iguales (pooled)} \qquad\qquad \frac{S^{2}_{\text{mayor}}}{S^{2}_{\text{menor}}} > 3 \;\Rightarrow\; \text{no supuestas iguales (Welch)} \]

Si el enunciado ya dice “varianzas iguales” o “diferentes”, se usa eso sin la regla.

2. Pooled: varianzas supuestas iguales

Pooled quiere decir “juntado”. Si las dos poblaciones tienen la misma varianza, \(S_1^{2}\) y \(S_2^{2}\) son dos estimaciones del mismo número: se promedian en una sola, \(S_p^{2}\), dándole más peso a la muestra con más datos.

\[ S_p^{2} = \frac{(n_1-1)S_1^{2} + (n_2-1)S_2^{2}}{n_1+n_2-2} \qquad\qquad S_p = \sqrt{S_p^{2}} \]

\[ (\bar{x}_1 - \bar{x}_2) \pm t_{(\alpha/2;\ n_1+n_2-2)}\, S_p\sqrt{\frac{1}{n_1} + \frac{1}{n_2}} \]

  • \(n_1 + n_2 - 2\) son los grados de libertad: todos los datos juntos, menos 1 por cada media que se calculó.
  • \(S_p\) es un promedio de los dos desvíos: tiene que quedar entre \(S_1\) y \(S_2\) (sirve de control).
3. Welch, para comparar (cuando el cociente es \(> 3\))

\[ (\bar{x}_1 - \bar{x}_2) \pm t_{(\alpha/2;\ \nu)}\sqrt{\frac{S_1^{2}}{n_1} + \frac{S_2^{2}}{n_2}} \]

con \(\nu\) de Welch-Satterthwaite. Acá no se usa: está para que veas la diferencia.

4. Cómo se concluye con un IC para \(\mu_1 - \mu_2\)
  • Si el intervalo incluye el 0: puede que las medias sean iguales → no hay diferencia significativa.
  • Si no incluye el 0: hay diferencia significativa. Todo positivo → \(\mu_1 > \mu_2\); todo negativo → \(\mu_1 < \mu_2\).

Inciso a — ¿Varianzas iguales? Regla empírica

Primero se pasan los desvíos a varianzas:

\[ S_A^{2} = 0{,}52^{2} = 0{,}2704 \qquad\qquad S_B^{2} = 0{,}34^{2} = 0{,}1156 \]

Fórmula (la mayor arriba):

\[ \frac{S^{2}_{\text{mayor}}}{S^{2}_{\text{menor}}} = \frac{0{,}2704}{0{,}1156} = 2{,}34 \leq 3 \]

Respuesta a

Sí pueden suponerse iguales: el cociente de varianzas da 2,34, que no pasa de 3. Como además las muestras son chicas (\(14\) y \(12\), menos de 30) y las poblaciones normales, se usa la \(t\) con la varianza combinada: caso pooled.

La trampa del desvío

Con los desvíos el cociente da \(0{,}52 / 0{,}34 = 1{,}53\): acá la decisión sale igual, pero la regla es con varianzas. En el Ejercicio 4 el mismo error lleva al caso equivocado: siempre elevar al cuadrado primero.

Inciso b — Intervalo del 95 % para \(\mu_A - \mu_B\)

Fórmula (pooled):

\[ (\bar{x}_A - \bar{x}_B) \pm t_{(\alpha/2;\ n_A+n_B-2)}\, S_p\sqrt{\frac{1}{n_A} + \frac{1}{n_B}} \qquad S_p^{2} = \frac{(n_A-1)S_A^{2} + (n_B-1)S_B^{2}}{n_A+n_B-2} \]

La varianza combinada \(S_p^{2}\)

Fórmula:

\[ S_p^{2} = \frac{(n_A-1)S_A^{2} + (n_B-1)S_B^{2}}{n_A+n_B-2} \]

Cada varianza se multiplica por su \(n - 1\) (su peso):

\[ (n_A - 1)\,S_A^{2} = 13 \times 0{,}2704 = 3{,}5152 \qquad\qquad (n_B - 1)\,S_B^{2} = 11 \times 0{,}1156 = 1{,}2716 \]

\[ S_p^{2} = \frac{3{,}5152 + 1{,}2716}{14 + 12 - 2} = \frac{4{,}7868}{24} = 0{,}19945 \qquad\qquad S_p = \sqrt{0{,}19945} = 0{,}4466 \text{ s} \]

Control: \(0{,}34 < 0{,}4466 < 0{,}52\). Queda entre los dos desvíos, como tiene que ser.

La raíz de las fracciones

\[ \frac{1}{n_A} + \frac{1}{n_B} = \frac{1}{14} + \frac{1}{12} = 0{,}07143 + 0{,}08333 = 0{,}15476 \qquad\qquad \sqrt{0{,}15476} = 0{,}3934 \]

Los grados de libertad y la tabla

Fórmula:

\[ \nu = n_A + n_B - 2 = 14 + 12 - 2 = 24 \]

Valor de tabla (fila 24, área 0,025 a la derecha):

\[ t_{(0{,}025;\ 24)} = 2{,}064 \]

El intervalo

\[ \bar{x}_A - \bar{x}_B = 2{,}84 - 2{,}31 = 0{,}53 \]

\[ E = t_{(\alpha/2;\ n_A+n_B-2)}\, S_p\sqrt{\frac{1}{n_A} + \frac{1}{n_B}} = 2{,}064 \times 0{,}4466 \times 0{,}3934 = 0{,}3626 \]

\[ 0{,}53 - 0{,}3626 \;<\; \mu_A - \mu_B \;<\; 0{,}53 + 0{,}3626 \]

\[ 0{,}167 \;<\; \mu_A - \mu_B \;<\; 0{,}893 \]

Respuesta b

\(\text{IC}_{95\%}(\mu_A - \mu_B) = (0{,}167\ ;\ 0{,}893)\) s.

Inciso c — ¿Diferencia significativa? ¿Con cuál carga más rápido?
  • El intervalo \((0{,}167\ ;\ 0{,}893)\) no incluye el 0: hay diferencia significativa entre las medias.
  • Es todo positivo: \(\mu_A - \mu_B > 0\), o sea \(\mu_A > \mu_B\): con A la página tarda más.
  • Tiempo de carga menor = más rápido: el más rápido es B.
Respuesta c

Con un 95 % de confianza hay diferencia significativa: la página carga más rápido con el framework B, que renderiza en el servidor, entre 0,167 y 0,893 s menos en promedio que con el framework A.

Las trampas de este ejercicio
  1. Regla empírica con desvíos. Siempre con varianzas (desvío al cuadrado).
  2. Meter los desvíos en \(S_p^{2}\). La fórmula lleva \(S_A^{2} = 0{,}2704\) y \(S_B^{2} = 0{,}1156\), no 0,52 y 0,34.
  3. Olvidar la raíz de \(S_p^{2}\). En el intervalo va \(S_p = 0{,}4466\), no \(0{,}19945\).
  4. Usar \(n_A - 1\) o \(n_B - 1\) grados de libertad. En pooled son \(n_A + n_B - 2 = 24\).
  5. Leer “positivo” como “A es mejor”. Positivo quiere decir que A tarda más; en tiempos, menos es mejor: gana B.

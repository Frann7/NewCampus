Ejercicio 1

28 puntos Unidad 8 · IC para la media con Z, tamaño de muestra y estimadores

El equipo de infraestructura monitorea el tiempo de respuesta (en ms) de un endpoint de una API REST. Por el historial de monitoreo se sabe que el desvío estándar poblacional del tiempo de respuesta es \(\sigma = 18\) ms. Se registra una muestra aleatoria de 40 peticiones, que da un tiempo medio de respuesta de 126,4 ms.

  1. Construya un intervalo de confianza del 95 % para el tiempo medio de respuesta del endpoint. Concluya.
  2. El proveedor del servicio garantiza un tiempo medio de respuesta de 120 ms. Con el intervalo del inciso anterior, ¿es aceptable esa garantía? Justifique.
  3. ¿Cuántas peticiones habría que registrar para que, con un 95 % de confianza, el error de estimación sea a lo sumo de 4 ms?
  4. ¿Por qué se usa la media muestral para estimar \(\mu\)? Mencione las propiedades del mejor estimador.

El enunciado, otra vez

Tiempo de respuesta de un endpoint, con \(\sigma = 18\) ms conocida por el historial. Una muestra de 40 peticiones da \(\bar{x} = 126{,}4\) ms. Piden: a) IC del 95 % para la media y concluir; b) si la garantía de 120 ms es aceptable; c) cuántas peticiones hacen falta para un error de a lo sumo 4 ms; d) por qué \(\bar{x}\) y las propiedades del mejor estimador.

¿De qué tema es?

Estimación, parte 1: intervalo de confianza para \(\mu\) con \(Z\), usarlo para decidir si un valor es aceptable, error de estimación y tamaño de muestra, y la teoría de los estimadores. Es el mismo esquema que el Ejercicio 1 del Tercer Parcial 2025.

Los conceptos que hacen falta, desde cero

1. Intervalo de confianza para \(\mu\) con \(Z\)

\[ \bar{x} - z_{\alpha/2}\,\frac{\sigma}{\sqrt{n}} \;<\; \mu \;<\; \bar{x} + z_{\alpha/2}\,\frac{\sigma}{\sqrt{n}} \qquad\qquad E = z_{\alpha/2}\,\frac{\sigma}{\sqrt{n}} \]

  • \(\bar{x}\): promedio de la muestra, el centro del intervalo.
  • \(\sigma/\sqrt{n}\): error estándar, cuánto varía \(\bar{x}\) de muestra en muestra (Teorema Central del Límite).
  • \(z_{\alpha/2}\): valor de la normal estándar que deja \(\alpha/2\) a la derecha. 90 % → 1,645; 95 % → 1,96; 99 % → 2,576.
  • \(E\): error de estimación, la mitad del ancho del intervalo.

Se usa \(Z\) si \(n \geq 30\) (con \(\sigma\), o con \(S\) si no la dan) o si \(\sigma\) es conocida. Con \(n < 30\) y sin \(\sigma\), \(t\).

2. Decidir con el intervalo

El intervalo junta los valores creíbles de \(\mu\). Un valor que queda adentro es aceptable; uno que queda afuera, no.

3. Tamaño de muestra: despejar \(n\) del error

Se parte del error y se despeja \(n\):

\[ E = z_{\alpha/2}\,\frac{\sigma}{\sqrt{n}} \quad\Rightarrow\quad \sqrt{n} = \frac{z_{\alpha/2}\,\sigma}{E} \quad\Rightarrow\quad n = \left(\frac{z_{\alpha/2}\,\sigma}{E}\right)^{2} \]

El resultado se redondea siempre hacia arriba (al entero siguiente), aunque el decimal sea chico: con una petición menos, el error superaría el pedido.

Inciso a — Intervalo de confianza del 95 % para \(\mu\)

Por qué \(Z\) con \(\sigma\)

  • \(\sigma = 18\) ms es dato de la población: conocida.
  • \(n = 40 \geq 30\): muestra grande.

Fórmula:

\[ \bar{x} - z_{\alpha/2}\,\frac{\sigma}{\sqrt{n}} \;<\; \mu \;<\; \bar{x} + z_{\alpha/2}\,\frac{\sigma}{\sqrt{n}} \]

Error estándar:

\[ \frac{\sigma}{\sqrt{n}} = \frac{18}{\sqrt{40}} = \frac{18}{6{,}3246} = 2{,}8460 \]

Error de estimación:

\[ E = 1{,}96 \times 2{,}8460 = 5{,}578 \]

Intervalo:

\[ 126{,}4 - 5{,}578 \;<\; \mu \;<\; 126{,}4 + 5{,}578 \]

\[ 120{,}82 \;<\; \mu \;<\; 131{,}98 \]

Respuesta a

\(\text{IC}_{95\%}(\mu) = (120{,}82\ ;\ 131{,}98)\) ms.

Con un 95 % de confianza, el tiempo medio de respuesta de todas las peticiones al endpoint está entre 120,82 y 131,98 ms.

Inciso b — ¿Es aceptable la garantía de 120 ms?

\[ \mu_0 = 120 \qquad\qquad \text{IC}_{95\%}(\mu) = (120{,}82\ ;\ 131{,}98) \qquad\qquad 120 < 120{,}82 \]

  • 120 queda afuera del intervalo, por debajo (por poco, pero afuera).
  • Todos los valores creíbles para el tiempo medio son mayores que 120.
Respuesta b

No es aceptable. Con un 95 % de confianza, el tiempo medio de respuesta real es mayor que los 120 ms que garantiza el proveedor.

“Pero 120,82 está re cerca de 120”

No importa cuán cerca: la regla es adentro o afuera. Lo que sí conviene decir es que con otro nivel de confianza la respuesta puede cambiar: al 99 % (\(z = 2{,}576\)) el intervalo es \((119{,}07\ ;\ 133{,}73)\) y el 120 queda adentro. Por eso siempre se aclara con qué confianza se decide.

Inciso c — Tamaño de muestra para \(E \leq 4\) ms

Fórmula (el error despejado para \(n\)):

\[ n = \left(\frac{z_{\alpha/2}\,\sigma}{E}\right)^{2} \]

\[ n = \left(\frac{1{,}96 \times 18}{4}\right)^{2} = \left(\frac{35{,}28}{4}\right)^{2} = (8{,}82)^{2} = 77{,}79 \]

Se redondea hacia arriba: \(n = 78\).

Control: con 78 el error queda debajo de 4; con 77, no.

\[ 1{,}96 \cdot \frac{18}{\sqrt{78}} = 3{,}995 \leq 4 \ \checkmark \qquad\qquad 1{,}96 \cdot \frac{18}{\sqrt{77}} = 4{,}021 > 4 \]

Respuesta c

Hay que registrar 78 peticiones (bastante más que las 40, porque el error baja de 5,58 a 4).

Inciso d — Por qué \(\bar{x}\) y las propiedades del mejor estimador

Para estimar un parámetro se elige el estadístico que sea el mejor estimador. \(\bar{X}\) lo es para \(\mu\) porque cumple las cuatro propiedades:

PropiedadQué diceEn \(\bar{X}\)
InsesgadoEn promedio no sobreestima ni subestima: \(E(\hat{\theta}) = \theta\).\(E(\bar{X}) = \mu\)
EficienteTiene la menor varianza entre los estimadores insesgados.Entre los insesgados, es el que menos varía
ConsistenteAl aumentar \(n\), se acerca al verdadero parámetro.\(V(\bar{X}) = \sigma^{2}/n \to 0\)
SuficienteUsa toda la información de la muestra sobre el parámetro.Usa los \(n\) datos
Respuesta d

Se usa \(\bar{X}\) porque es el mejor estimador puntual de \(\mu\): es insesgado, eficiente, consistente y suficiente. Del mismo modo, \(S^{2}\) estima a \(\sigma^{2}\) y \(\hat{p}\) a \(\pi\).

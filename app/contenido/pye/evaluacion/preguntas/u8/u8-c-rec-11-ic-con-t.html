Para usar la \(t\) de Student con una muestra chica, hace falta suponer que la variable \(X\) tiene distribución normal.

Recuperatorio de la primera parte, probable (inventada)

Con muestra chica no se puede usar el TLC. Por eso la diapositiva pide que la variable \(X\) tenga distribución normal; entonces \(T = \dfrac{\bar{X} - \mu}{S/\sqrt{n}}\) tiene distribución \(t\) con \(\nu = n - 1\).

  • Por eso los enunciados con \(t\) dicen “suponga que se distribuye normalmente”.

De dónde sale: Estimación parte 1, pág. 11: “Si se tiene una muestra chica … y la variable X tiene distribución normal”.

Ejercicio 5 · Baja

Script para borrar comentarios

Modifique el script del punto 4 de manera tal que permita eliminar algún comentario en particular. Agregue para esto un botón o link a cada comentario listado que al presionarlo ejecute el script borrarComentario.php, el cual deberá contener el código necesario para realizar tal tarea.

Paso 1 — Cómo sabe el script qué comentario borrar

borrarComentario.php es un script aparte: no sabe nada del listado. Hay que mandarle el número del comentario. La forma más simple es ponerlo en el link, como parámetro GET (Clase 3): borrarComentario.php?id=2. Lo que va después del ? llega en $_GET['id']. Por eso el SELECT del ejercicio 4 ya traía id_comentario: ahora se usa.

Paso 3 — El código: borrarComentario.php 
<?php
if (!isset($_GET['id']) || !ctype_digit($_GET['id'])) {
    die("No se indicó qué comentario borrar");
}

require_once 'conexion.php';

$id = (int) $_GET['id'];

$stmt = $mysqli->prepare("DELETE FROM comentarios WHERE id_comentario = ?");
$stmt->bind_param("i", $id);
$stmt->execute();

if ($stmt->affected_rows > 0) {
    $mensaje = "Se borró el comentario número " . $id . ".";
} else {
    $mensaje = "No existe un comentario con el número " . $id . ".";
}

$stmt->close();
$mysqli->close();
?>
<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <title>Borrar comentario</title>
</head>
<body>
  <p><?php echo $mensaje; ?></p>
  <a href="listarComentarios.php">Volver al listado</a>
</body>
</html>

Verificado corriendo el script con la base reemplazada por una de ejemplo, en los tres casos:

Errores y trampas
  • Borrar por la clave primaria, no por el nombre: WHERE nombre = 'Ana' borraría todos los comentarios de todas las Ana.
  • Sin validar el id, y armando el SQL pegando $_GET['id'], la dirección ?id=2 OR 1=1 borraría la tabla entera (sección 6 de la teoría). Acá lo frenan dos cosas: ctype_digit y la consulta preparada.
  • La guía acepta "un botón o link". Un link funciona, pero cualquiera que conozca la dirección puede borrar con solo abrirla; en un sitio real el borrado va con un botón de un formulario post y pidiendo confirmación.
Resultado

Cada fila del listado lleva un link borrarComentario.php?id=N; ese script valida el número, ejecuta un DELETE preparado por id_comentario y avisa según affected_rows. La guía no tiene hoja de resultados.

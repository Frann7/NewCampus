Sobre la demostración de \(V(X) = E(X^{2}) - \mu^{2}\), con \(\mu = E(X)\), seleccione las afirmaciones correctas.

Tema del Segundo Parcial 2025, Ejercicio 1 c · formato 1ra etapa

  • Se parte de la definición \(V(X) = E\left[(X - \mu)^{2}\right]\) y se desarrolla el cuadrado: \(E\left(X^{2} - 2\mu X + \mu^{2}\right)\).
  • \(E(2\mu X) = 2\mu\,E(X) = 2\mu^{2}\), porque \(\mu\) es una constante.
  • \(E(\mu^{2}) = \mu^{2}\), porque la esperanza de una constante es la misma constante.
  • \(E\left[(X-\mu)^{2}\right] = \left[E(X - \mu)\right]^{2}\), porque la esperanza de un cuadrado es el cuadrado de la esperanza.
  • La demostración solo vale para variables discretas.
  • Ninguna opción es correcta

La demostración completa, usando que la esperanza es lineal:

\[ V(X) = E\left[(X-\mu)^{2}\right] = E\left(X^{2} - 2\mu X + \mu^{2}\right) = E(X^{2}) - 2\mu\,E(X) + \mu^{2} = E(X^{2}) - 2\mu^{2} + \mu^{2} = E(X^{2}) - \mu^{2} \]

Las tres primeras son los pasos de esa cadena. La cuarta es falsa: la esperanza de un cuadrado no es el cuadrado de la esperanza (de hecho \(E(X - \mu) = 0\), así que daría varianza 0 siempre). La quinta también: solo se usa la linealidad de \(E\), que vale igual para discretas (con sumas) y continuas (con integrales).

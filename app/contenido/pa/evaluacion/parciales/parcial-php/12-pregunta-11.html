Pregunta 11

5 puntos Clase 3 · input tipo text

El componente HTML "INPUT" tipo text:

Seleccione una:

  1. Nos permite el ingreso de una cadena de texto pero no vemos los caracteres que ingresamos.
  2. Nos permite ingresar una cadena de texto pero no es visible dentro del formulario.
  3. Nos permite ingresar una cadena de texto.
  4. Nos permite ingresar un archivo para ser enviado al servidor.
✓ ResultadosSolo la respuesta

c) Nos permite ingresar una cadena de texto.

✎ Explicación detalladaQué evalúa, el concepto desde cero, la traza y las trampas

Qué evalúa

Los tipos del elemento <input> de un formulario HTML. Es de la Clase 3 (HTML y formularios).

El concepto, desde cero

HTML es el lenguaje con el que se escriben las páginas web: el navegador lo lee y lo dibuja. Se escribe con etiquetas entre < >, como <form>; muchas se abren y se cierran (<form> … </form>, con la barra en la de cierre) y <input> va sola. Dentro de una etiqueta van los atributos, con la forma nombre="valor", que la configuran.

Un formulario (<form>) es la parte de la página donde el usuario carga datos para mandarlos al servidor (la computadora que tiene la página y ejecuta el PHP). <input> es un campo de ese formulario, y su atributo type dice qué clase de campo es. Cada opción del parcial describe un tipo distinto:

<form action="guardar.php" method="post">
  Nombre: <input type="text" name="nombre">
  Clave: <input type="password" name="clave">
  <input type="hidden" name="origen" value="campus">
  Foto: <input type="file" name="foto">
  <input type="submit" value="Enviar">
</form>
PiezaQué significa
action="guardar.php"A qué archivo PHP del servidor se mandan los datos al apretar Enviar.
method="post"Cómo viajan: post los manda ocultos en el pedido; get, pegados a la dirección (URL).
name="nombre"El nombre con que el dato llega al PHP (ahí se lee como $_POST['nombre']).
value="campus"El valor que lleva el campo.
type="submit"El botón que envía el formulario; su value es el texto del botón.
typeQué muestraOpción que lo describe
textUna caja de una línea donde se escribe y se ve lo que se escribe.c
passwordUna caja que muestra puntitos en lugar de los caracteres.a
hiddenNada: el campo no se ve, pero su value se envía igual.b
fileUn botón para elegir un archivo y subirlo al servidor.d

Respuesta

c) Nos permite ingresar una cadena de texto. (Cadena de texto = un texto cualquiera: letras, números, espacios.) Es el campo común, el que usan todos los formularios de la teoría (<input type="text" name="nombre">).

La trampa

Las otras tres también hablan de “ingresar una cadena”, pero agregan algo que es de otro tipo: no ver los caracteres (password), no ser visible (hidden) o enviar un archivo (file).

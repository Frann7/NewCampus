✓ ResultadosSolo la respuesta

Descripción: Singleton es un patrón creacional que se usa cuando una clase debe tener una única instancia disponible para todo el programa. La clase oculta su constructor y ofrece un método estático que crea el objeto la primera vez y devuelve siempre el mismo, dando un punto de acceso global.

Dos ejemplos: la conexión a la base de datos de un sistema y la configuración global de una aplicación.

✎ Explicación detalladaEl concepto desde cero, el desarme de la consigna, la respuesta y las trampas

Qué evalúa

Saber de memoria la estructura de un patrón, para qué sirve y dónde se usa. Tres cosas pedidas, tres cosas en la respuesta.

El concepto

Singleton resuelve dos problemas a la vez: garantiza que una clase tenga una única instancia y da un punto de acceso global a ella. Lo hace con dos movimientos: el constructor privado (nadie de afuera puede hacer new) y un método estático que crea el objeto la primera vez, lo guarda en un atributo estático y después devuelve siempre ese.

Una sola clase con tres cosas. Lo que no puede faltar: los dos subrayados y los dos signos menos.

Paso 2 — La descripción

"Usabilidad" es para qué se usa. Alcanza con decir cuándo se aplica y cómo lo logra (el texto de Resultados).

Paso 3 — Los ejemplos

Cualquiera de estos: la conexión a la base de datos, la configuración global, el registro de eventos (log), un gestor de usuarios o de seguridad. Conviene decirlos con el porqué: "la conexión a la base de datos, porque todo el sistema debe usar la misma".

Trampas

  • Olvidarse de que el constructor es privado: sin eso, nada impide crear más objetos.
  • No subrayar lo estático: es la marca que distingue al Singleton de una clase común.

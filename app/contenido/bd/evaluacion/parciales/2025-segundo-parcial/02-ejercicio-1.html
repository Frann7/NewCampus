Unidad 1 · Transacción

Ejercicio 1: Defina Transacción en base de datos. Definición y propiedades.

✓ ResultadosSolo la respuesta

Transacción: es una unidad de ejecución de un programa, que puede incluir varios accesos a la base (consultas, actualizaciones, procedimientos almacenados, vistas). Empieza con BEGIN TRAN y termina con COMMIT (se confirma) o ROLLBACK (se cancela).

Propiedades:

  • Atomicidad: la transacción se ejecuta completa (todas sus operaciones) o no se ejecuta ninguna.
  • Consistencia: una transacción ejecutada sola (sin otras al mismo tiempo) deja la base en un estado consistente.
  • Aislamiento: si se ejecutan varias transacciones al mismo tiempo, el SGBD las aísla para que no generen inconsistencias entre ellas. Los cambios de cada una se hacen efectivos recién con su COMMIT.

Qué evalúa

Dos cosas: la definición y las propiedades, cada una explicada. Las dos salen de las diapositivas "Transacciones y concurrencia" de la cátedra (clase del 15/09), que traen tres propiedades.

La idea, con un ejemplo

Cuando un turno de la clínica se atiende, hay que registrar la consulta y pasar el turno a "Atendido". Si se hace la primera y el sistema se cae antes de la segunda, queda una consulta para un turno que figura como pendiente. La transacción las convierte en una sola cosa: 

BEGIN TRAN;
INSERT INTO Consulta (Numero, Diagnostico, Observaciones, Fecha, NumeroTurno)
VALUES (501, 'Otitis', 'Control en 7 días', '2026-10-14', 3020);
UPDATE Turno SET Estado = 'Atendido' WHERE Numero = 3020;
COMMIT;

Las tres propiedades sobre ese ejemplo

PropiedadEn el ejemplo
AtomicidadSi el UPDATE falla, el INSERT se deshace: no queda la consulta suelta.
ConsistenciaTerminada, la base sigue siendo correcta: la consulta apunta a un turno que existe y el turno está "Atendido".
AislamientoSi en ese momento alguien lista los turnos pendientes, no ve el cambio a medias: se hace efectivo con el COMMIT.

Otros libros suman una cuarta, durabilidad (lo confirmado queda guardado aunque falle el sistema), y forman la sigla ACID. Se puede nombrar al final, pero la cátedra presenta las tres.

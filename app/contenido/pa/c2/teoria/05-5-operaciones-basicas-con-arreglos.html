Arreglos

5. Operaciones básicas: count, is_array, isset, in_array, unset

Para qué sirve

Cinco funciones para las preguntas más comunes sobre un arreglo:

  • ¿Cuántos elementos tiene? → count()
  • ¿Esta variable es un arreglo? → is_array()
  • ¿Existe esta clave? → array_key_exists() o isset()
  • ¿Está este valor? → in_array()
  • Borrar un elemento → unset()

Sintaxis

Las cinco 
count($arreglo)                     // devuelve un número
is_array($variable)                 // devuelve true o false
array_key_exists(clave, $arreglo)   // devuelve true o false
isset($arreglo[clave])              // devuelve true o false
in_array(valor, $arreglo)           // devuelve true o false
unset($arreglo[clave]);             // borra el elemento, no devuelve nada

Qué muestra echo con un true o un false

echo true; imprime 1, y echo false; no imprime nada. Por eso, para ver el resultado de estas funciones conviene var_dump() (sección 3), que muestra bool(true) o bool(false).

Errores y trampas

count() de algo que no es arreglo: en PHP 8 es un error

La cátedra dice que count(10) da 1. Eso era así en versiones viejas de PHP. En PHP 8 (el de XAMPP) el script se corta con Fatal error: Uncaught TypeError: count(): Argument #1 ($value) must be of type Countable|array, int given. La idea de fondo de la cátedra sigue valiendo: para saber si algo es un arreglo se usa is_array(), no count().

El ejemplo de isset de la cátedra no corre

El apunte escribe array_key_exists($a['a']), con un solo argumento: PHP 8 corta con ArgumentCountError: array_key_exists() expects exactly 2 arguments, 1 given. Se escribe array_key_exists('a', $a): la clave y el arreglo. Además, en ese ejemplo $a = array('a', 'b', 'c') tiene claves 0, 1 y 2: 'a' y 'b' son valores, no claves, así que isset($a['b']) da false.

El orden de los argumentos

array_key_exists(clave, $arreglo) e in_array(valor, $arreglo): en las dos, primero lo que buscás y después dónde.

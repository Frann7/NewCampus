4. Modificar y crear elementos

Para qué sirve

Una vez que tenés el elemento (sección 3), le cambiás lo que quieras a través de sus propiedades: el texto, el valor de un campo, el color, las clases de CSS. Y también podés crear elementos nuevos y colgarlos del árbol. Cada cambio se ve en la pantalla al instante, sin recargar.

Sintaxis

const titulo = document.getElementById('titulo');

titulo.textContent = "Nuevo título";           // cambia el texto
titulo.innerHTML = "Título <em>nuevo</em>";    // cambia el contenido, interpretando etiquetas
titulo.style.color = "red";                     // estilo en línea (CSS)
titulo.style.backgroundColor = "green";         // background-color se escribe en camelCase
titulo.classList.add('is-invalid');             // agrega una clase de CSS
titulo.classList.remove('is-valid');            // saca una clase de CSS

campo.value = '';                               // vacía un campo
campo.focus();                                  // pone el cursor en el campo

const p = document.createElement('p');          // crea un <p> suelto (todavía no se ve)
p.textContent = "Párrafo nuevo";
document.getElementById('parrafos').appendChild(p);   // lo cuelga adentro de #parrafos: ahora se ve

Ejemplo 1 — textContent contra innerHTML

Enunciado

La página tiene <h1 id="titulo"></h1>. ¿Qué se ve en el título después de cada línea?

const t = document.getElementById('titulo');
t.innerHTML = "Hola <em>mundo</em>";
t.textContent = "Hola <em>mundo</em>";
t.innerHTML = '';
LíneaQué haceQué se ve en el título
const t = ...('titulo');Agarra el <h1> vacío(nada)
t.innerHTML = "Hola <em>mundo</em>";Interpreta el <em> como etiqueta: crea un nodo em hijo del h1Hola mundo (con "mundo" en cursiva)
t.textContent = "Hola <em>mundo</em>";Reemplaza todo por texto; los < y > son caracteres comunesHola <em>mundo</em>, literal
t.innerHTML = '';Reemplaza el contenido por nada(vacío otra vez)

Por qué: innerHTML pasa el texto por el mismo lector de HTML que la página (sección 1) y arma nodos; textContent no lee nada, solo pone texto. Por eso, para mostrar algo que escribió el usuario, la cátedra usa textContent.

Ejemplo 2 — ¿Qué tamaño queda? (estilo calculado)

Enunciado

Un <h1> sin estilos propios mide 32px en un navegador con la configuración de fábrica (letra base de 16px; el h1 es el doble). Este código corre tres veces seguidas. ¿Qué tamaño queda? 

let currentSize = window.getComputedStyle(titulo).fontSize;
titulo.style.fontSize = (parseFloat(currentSize) + 2) + "px";
VezQué haceCómo quedan las variables
1raLee el tamaño real: "32px". parseFloat da 32; más 2, 34; con "px" pegado, "34px"currentSize = "32px"; letra = 34px
2daAhora el tamaño real es el que se puso reciéncurrentSize = "34px"; letra = 36px
3raIgualcurrentSize = "36px"; letra = 38px
Respuesta

38px (32 + 2 + 2 + 2). Con otra letra base en el navegador el punto de partida cambia, pero cada vez suma 2.

Por qué los paréntesis: (parseFloat(currentSize) + 2) + "px" hace primero la suma de números y después pega el texto. Sin parseFloat quedaría "32px" + 2, que concatena: "32px2", un valor que el CSS no entiende y descarta (la letra no cambia).

Ejemplo 3 — ¿Cuántos quedan? (crear y colgar)

Enunciado

La página tiene <ul id="lista"><li>A</li></ul>. Después de correr esto, ¿cuántos <li> tiene la lista y en qué orden?

const lista = document.getElementById('lista');
const letras = ['B', 'C'];
letras.forEach(letra => {
    const li = document.createElement('li');
    li.textContent = letra;
    lista.appendChild(li);
});
const suelto = document.createElement('li');
suelto.textContent = 'D';
LíneaQué haceCómo queda la lista
const lista = ...('lista');Agarra el <ul>A
const letras = ['B', 'C'];Array con dos textosA
forEach, 1ra vueltaCrea un li, le pone "B" y lo cuelga al finalA, B
forEach, 2da vueltaCrea otro li (uno nuevo por vuelta), "C", al finalA, B, C
const suelto = createElement('li');Crea un li...A, B, C
suelto.textContent = 'D';...y le pone texto, pero nunca se cuelga con appendChildA, B, C
Respuesta

3 elementos: A, B, C. La "D" existe en memoria pero no está en el árbol, así que no se ve.

Errores y trampas

Crear no es mostrar

createElement solo fabrica el elemento. Sin appendChild no aparece (ejemplo 3).

Nombres de CSS con guion

titulo.style.background-color = "green" es un error: JavaScript lo lee como titulo.style.background menos color. Se escribe backgroundColor.

innerHTML con datos del usuario

Si mostrás con innerHTML algo que escribió el usuario y escribió etiquetas, el navegador las ejecuta como HTML. Para mostrar datos, textContent.

Los cambios no viajan al servidor

Vaciar un campo con campo.value = '' o pintarlo de rojo cambia el DOM de esta pantalla y nada más. PHP no se entera hasta que se envía el formulario.

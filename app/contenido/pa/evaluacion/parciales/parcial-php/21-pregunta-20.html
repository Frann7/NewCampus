Qué evalúa

Qué muestra var_dump(). Aparece en la Clase 1 (“muestra el tipo y valor de una variable”) y se usa en la práctica de la Clase 2 para ver arrays.

El concepto, desde cero

var_dump($x) sirve para depurar: muestra el tipo y el valor, y si es un array, su estructura: cuántos elementos tiene y la clave, el tipo y el valor de cada uno.

<?php
var_dump(5);
var_dump("hola");
var_dump(true);
var_dump(array(1, 'a' => 2.5));
?>
int(5)
string(4) "hola"
bool(true)
array(2) {
  [0]=>
  int(1)
  ["a"]=>
  float(2.5)
}
LíneaQué muestra
var_dump(5);Tipo int (entero) y valor 5.
var_dump("hola");Tipo string, largo 4 y el valor.
var_dump(true);Tipo bool y valor true.
var_dump(array(1, 'a' => 2.5));Array de 2 elementos y, de cada uno, la clave, el tipo y el valor.

Para comparar: echo muestra solo el valor (y con un array no sirve: imprime la palabra Array y un aviso), y print_r muestra la estructura pero sin los tipos ([a] => 2.5). Salidas comprobadas en PHP 8.2.

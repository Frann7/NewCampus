Pregunta 15

5 puntos Clase 1 · Qué es PHP

Indique la definición más correcta para PHP (PHP HyperText PreProcessor).

Seleccione una:

  1. PHP es un lenguaje de programación compilado que se ejecuta del lado del cliente.
  2. PHP es un lenguaje de programación interpretado que se ejecuta del lado del cliente.
  3. PHP es un lenguaje de programación interpretado que se ejecuta del lado del servidor.
  4. PHP es un lenguaje de programación compilado que se ejecuta del lado del servidor.
✓ ResultadosSolo la respuesta

c) PHP es un lenguaje de programación interpretado que se ejecuta del lado del servidor.

✎ Explicación detalladaQué evalúa, el concepto desde cero, la traza y las trampas

Qué evalúa

La definición de PHP de la Clase 1: “PHP es un lenguaje de programación interpretado” y “sirve para la programación de scripts del lado del servidor”.

El concepto, desde cero

PalabraQué quiere decirEn PHP
CompiladoUn programa traduce todo el código a un ejecutable antes de usarlo (C, por ejemplo).No.
InterpretadoUn programa (el intérprete) lee el código y lo ejecuta en el momento, cada vez.Sí: el intérprete de PHP ejecuta el .php en cada pedido.
Lado del clienteSe ejecuta en el navegador del usuario (HTML, JavaScript).No.
Lado del servidorSe ejecuta en el servidor web, que le manda al navegador solo el resultado.Sí: el navegador recibe el HTML que generó PHP, nunca el código PHP.

Opción por opción

Las cuatro opciones combinan dos palabras; cada una se cae por la que está mal:

  • a) compilado y cliente: las dos mal.
  • b) interpretado bien, pero cliente mal (eso es JavaScript).
  • c) interpretado y servidor: correcta.
  • d) servidor bien, pero compilado mal.
La trampa

Las opciones solo cambian una o dos palabras: hay que chequear las dos (interpretado + servidor) antes de marcar.

6. Clases en JavaScript

Para qué sirve

Una clase es un molde: define qué datos (propiedades) y qué acciones (métodos) va a tener cada objeto que se fabrique con ella. La cátedra arma todos sus ejemplos así: una clase por página, que en el constructor agarra los elementos del DOM y en init() engancha los eventos. Todo lo de una pantalla queda junto y ordenado, en vez de suelto por el archivo.

Sintaxis (el esquema de la diapositiva 13)

class FormPersonas {

    constructor() {
        // se ejecuta solo, al hacer new: guarda los elementos en propiedades
        this.form = document.getElementById('formPersonas');
    }

    init() {
        // engancha los eventos
    }

}

window.addEventListener('DOMContentLoaded', () => {
    new FormPersonas().init();
});

Ejemplo 1 — Un contador como clase

Enunciado

¿Qué muestra la consola?

class Contador {
  constructor() { this.valor = 0; }
  sumar() { this.valor = this.valor + 1; }
  mostrar() { console.log(`Valor: ${this.valor}`); }
}
const c = new Contador();
c.sumar();
c.sumar();
c.mostrar();
LíneaQué haceCómo quedan las variables
class Contador { ... }Solo define el molde. No ejecuta nada—
const c = new Contador();Crea el objeto; corre el constructor, que crea la propiedad valorc.valor = 0
c.sumar();Adentro, this es c: c.valor = 0 + 1c.valor = 1
c.sumar();Otra vezc.valor = 2
c.mostrar();Imprime con un template literalc.valor = 2

Qué muestra (verificado con Node.js):

Valor: 2

Por qué: la propiedad valor vive en el objeto, así que los dos sumar() trabajan sobre el mismo número.

Ejemplo 2 — ¿Cuál es la salida? (dos objetos)

Enunciado

¿Qué muestra la consola?

class Persona {
  constructor(nombre, edad) { this.nombre = nombre; this.edad = edad; }
  cumplir() { this.edad++; return this.edad; }
  saludo() { return `Soy ${this.nombre} y tengo ${this.edad}`; }
}
const p1 = new Persona("Ana", 20);
const p2 = new Persona("Luis", 30);
p1.cumplir();
p1.cumplir();
console.log(p1.saludo());
console.log(p2.saludo());
console.log(p2.cumplir() + p1.edad);
LíneaQué haceCómo quedan las variables
const p1 = new Persona("Ana", 20);El constructor recibe los dos datos y los guarda en el objetop1: Ana, 20
const p2 = new Persona("Luis", 30);Otro objeto, con sus propias propiedadesp1: Ana, 20 · p2: Luis, 30
p1.cumplir();this.edad++ suma 1 a la edad de p1. Devuelve 21, pero nadie lo usap1: 21
p1.cumplir();Otra vezp1: 22
console.log(p1.saludo());saludo() devuelve el texto armado→ "Soy Ana y tengo 22"
console.log(p2.saludo());p2 no fue tocado→ "Soy Luis y tengo 30"
p2.cumplir() + p1.edadPrimero p2.cumplir(): p2 pasa a 31 y devuelve 31. Después suma la edad de p1: 31 + 22p2: 31 → 53

Qué muestra (verificado con Node.js):

Soy Ana y tengo 22
Soy Luis y tengo 30
53

Por qué: cada new fabrica un objeto independiente. Cambiar p1 no toca a p2. Y en la última línea los dos operandos son números (31 y 22), así que el + suma.

Ejemplo 3 — El esquema de la cátedra, y por qué usa flechas

Enunciado

La página tiene <button id="btSumar">. Con esta clase, el usuario hace un clic. ¿Qué muestra la consola cada escuchador? 

class Pagina {
    constructor() {
        this.boton = document.getElementById('btSumar');
        this.clics = 0;
    }
    init() {
        this.boton.addEventListener('click', () => {
            this.clics++;
            console.log("flecha:", this.clics);
        });
        this.boton.addEventListener('click', function () {
            console.log("function:", this.id, this.clics);
        });
    }
}
window.addEventListener('load', () => { new Pagina().init(); });
LíneaQué haceCómo quedan las variables
window.addEventListener('load', ...)Espera a que la página cargue—
new Pagina()Constructor: guarda el botón y el contadorthis.boton = el botón, this.clics = 0
.init()Registra dos escuchadores de click en el mismo botón (se pueden registrar varios; corren en orden)—
Clic → la flechaUna función flecha no tiene this propio: usa el de donde fue escrita, que es el objeto Paginathis.clics = 1 → "flecha: 1"
Clic → la functionUna function común llamada por un evento recibe como this el elemento que disparó el evento: el botónthis.id = "btSumar"; el botón no tiene clics → undefined

Qué muestra (verificado en Node.js con un botón simulado, que llama a cada escuchador como lo hace el navegador):

flecha: 1
function: btSumar undefined

Por qué: adentro de la function, this dejó de ser el objeto Pagina. Por eso la cátedra escribe todos los escuchadores con flechas: así this.titulo, this.txtNombre o this.validoDatos() siguen apuntando al objeto. undefined es el valor de JavaScript para "esto no existe / no tiene valor".

Errores y trampas

Olvidarse el this.

Adentro de un método, validoDatos() a secas busca una función suelta con ese nombre y falla: ReferenceError: validoDatos is not defined. Lo mismo con una propiedad: titulo en vez de this.titulo. Igual que en PHP con $this->.

Olvidarse el new

Persona("Ana", 20) sin new corta con TypeError: Class constructor Persona cannot be invoked without 'new'.

Comas o function entre métodos

Dentro de class { } los métodos van uno debajo del otro, sin coma y sin la palabra function. Cualquiera de las dos es un error de sintaxis y no corre nada del archivo.

Dos archivos con la misma clase

En los ejemplos de la práctica casi todas las clases se llaman IndexClass. No choca porque cada página carga un solo .js. Si una página cargara dos archivos que declaran la misma clase, el segundo daría error.

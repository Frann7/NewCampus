3. El DOM: seleccionar elementos

Para qué sirve

El DOM es la representación de la interfaz con un conjunto estándar de objetos. A través de él, JavaScript puede leer y modificar el contenido, la estructura y el estilo de la página. Pero antes de modificar algo hay que agarrarlo: conseguir, desde JavaScript, el objeto que representa a esa etiqueta. Eso es seleccionar.

Todo arranca en document: un objeto que el navegador crea solo y que representa la página entera (la raíz del árbol de la sección 1).

Sintaxis

// UN elemento, por su id
const campo = document.getElementById('nombre');

// TODOS los elementos de una etiqueta (colección)
const inputs = document.getElementsByTagName('input');

// la colección pasada a array, para poder recorrerla con forEach
const arrayDeNodos = Array.from(inputs);
arrayDeNodos.forEach(cadaInput => { console.log(cadaInput); });

// TODOS los que cumplen un selector de CSS (ya trae forEach)
const parrafos = document.querySelectorAll('p');

Qué es cada parte

PiezaQué devuelveDetalle
document.getElementById('x')Un elemento: el que tiene id="x"Si no hay ninguno, devuelve null. Si hay dos con el mismo id (no debería), devuelve el primero
document.getElementsByTagName('p')Una colección de objetos HTML (HTMLCollection) con todos los <p>, en el orden en que aparecenTiene .length y se accede con [0], [1]..., pero no tiene forEach. Es "viva": si después se agrega un <p> a la página, aparece sola en la colección
Array.from(coleccion)Un array con los mismos elementosEs una copia fija: lo que se agregue después a la página no aparece. A cambio, tiene forEach, push y todo lo de un array
document.querySelectorAll('p')Una lista (NodeList) con todos los que cumplen el selector de CSS ('p', '#id', '.clase')Ya tiene forEach. Es fija, como el array
elemento.valueLo que tiene escrito un campo (input, select, textarea)Siempre es un texto, aunque el campo sea de números
Cuál usar
  • ¿Necesitás un elemento puntual (un botón, un campo)? → getElementById. Por eso en los ejemplos todo lo importante tiene id.
  • ¿Necesitás varios para hacerles lo mismo (todos los párrafos)? → getElementsByTagName + Array.from, o querySelectorAll.

Errores y trampas

forEach sobre la colección

document.getElementsByTagName('p').forEach(...) da TypeError: ... .forEach is not a function. La colección no es un array: primero Array.from. (Con querySelectorAll sí se puede.)

Elements, en plural

getElementById va en singular (devuelve uno); getElementsByTagName va en plural (devuelve varios). Si escribís getElementByTagName, la función no existe y da error.

El id va sin #

getElementById('nombre'), no getElementById('#nombre'): este último busca un id que literalmente empieza con # y devuelve null. El # va solo en los selectores de CSS (querySelectorAll('#nombre')).

Las comillas de las diapositivas

En las diapositivas 11 y 12 las comillas salieron "tipográficas" (”, ‘), por el editor de la presentación. Si copiás ese código tal cual, no anda: en el código van comillas rectas (" o ').

Seleccionar antes de que exista

Si el script corre antes de que el navegador haya leído el elemento, getElementById devuelve null y lo que sigue falla. Por eso los <script> van al final del <body> y la cátedra arranca todo cuando la página terminó de cargar (sección 5).

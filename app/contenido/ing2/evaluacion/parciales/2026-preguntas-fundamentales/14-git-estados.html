El flujo básico

  1. Modificás archivos en el directorio de trabajo.
  2. Preparás los que querés guardar (git add).
  3. Confirmás: Git guarda esa foto de manera permanente en el repositorio local (git commit).
  4. Para compartirlo, lo subís al remoto (git push).

Por qué Git es distinto

Guarda fotos de todo el proyecto en cada confirmación, no listas de cambios, y casi todo se hace en local: por eso es rápido y se trabaja sin conexión.

Trampa

git commit no sube nada a GitHub: guarda en el repositorio local. Lo que sube es git push.

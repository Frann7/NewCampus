Formulario con captcha y el script que dibuja la imagen

Misma carpeta formularios: formCaptcha.php muestra el formulario con una imagen que genera includes/rdnimg.php, y procesoForm.php compara lo que escribió la persona con el código guardado en la sesión. El encabezado y el pie son los mismos includes/head.php e includes/footer.php del ejemplo anterior.

Archivo 2 — includes/rdnimg.php 
<?php
session_start();

if (!empty($_SESSION['rand_code'])) {
    unset($_SESSION['rand_code']);
}

if (empty($_SESSION['rand_code'])) {
    $str = "";
    $a = "0123456789abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ";
    for ($i = 0; $i <= 3; $i++) {
        $str .= $a[rand(0, 61)];
    }

    $_SESSION['rand_code'] = $str;
}
header('Content-Type: image/png');
$im = imagecreatetruecolor(120, 30);
$color_texto = imagecolorallocate($im, 233, 14, 91);
imagestring($im, 10, 5, 5, $str, $color_texto);
imagepng($im);
imagedestroy($im);
?>

Archivo 3 — procesoForm.php (la parte del captcha) 
    //---- PROCESO EL FORM-TOKEN ----

    if (!empty($_POST['rand_code'])) {
        if ($_POST['rand_code'] == $_SESSION['rand_code']) {
            echo "LOS DATOS PROVIENEN DE NUESTRO FORMULARIO CON CAPTCHA.";

            // proceso los datos restantes

            echo '<br>';
            echo 'Usuario: ' . $_POST['usuario'];
            echo '<br>';
            echo 'Contraseña: ' . $_POST['contrasenia'];
        } else {
            echo "LOS DATOS PROVIENEN DE OTRO ORIGEN.";
        }
    }

Va dentro del mismo if (!empty($_POST)), después de la parte del token. Es la misma estructura con rand_code en vez de token. (El comentario dice "FORM-TOKEN" porque se copió del bloque de arriba; este bloque es el del captcha.)

Qué problema de seguridad evita
  • Igual que el token, frena al programa que manda datos sin abrir el formulario: no tiene código en su sesión.
  • Además frena al programa que sí abre el formulario y lee el HTML: el código no está escrito en ningún lado del HTML, solo dibujado en la imagen. Para pasarlo, el programa tendría que leer la imagen.
  • Lo que no hace: borrar el código después de usarlo (caso 4). En el ejercicio 2 se agrega un unset($_SESSION['rand_code']) al procesar, para que cada código sirva una sola vez.
Si la imagen sale rota

Es la extensión GD apagada en el php.ini de XAMPP: rdnimg.php corta con Call to undefined function imagecreatetruecolor(). Se activa sacándole el ; a ;extension=gd y reiniciando Apache.

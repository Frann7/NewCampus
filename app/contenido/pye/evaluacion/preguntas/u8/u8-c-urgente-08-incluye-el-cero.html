Se compara el tiempo medio de despliegue de dos pipelines (1 y 2). ¿Cuáles conclusiones sobre el intervalo del 95 % para \(\mu_1 - \mu_2\) son correctas?

Estimación parte 2 de la cátedra, conclusiones de los Ejemplos 4 y 5 (entra en el 3er parcial)

  • Si el IC es \((-0{,}57\ ;\ 6{,}17)\) min, no hay diferencia significativa entre las medias.
  • Si el IC es \((4{,}39\ ;\ 20{,}01)\) min, hay diferencia significativa y el pipeline 1 tiene mayor tiempo medio.
  • Si el IC es \((-8{,}3\ ;\ -2{,}1)\) min, no hay diferencia significativa porque los límites son negativos.
  • Si el IC es \((-0{,}57\ ;\ 6{,}17)\) min, el pipeline 1 es más lento porque la mayor parte del intervalo es positiva.

Lo que se mira es si el intervalo incluye el 0 (\(\mu_1 - \mu_2 = 0\) es “medias iguales”):

  • Incluye el 0 → no se puede afirmar que haya diferencia significativa. Da igual cuánto del intervalo quede de cada lado.
  • No incluye el 0 → hay diferencia significativa, y el signo dice cuál es mayor: todo positivo → \(\mu_1 > \mu_2\); todo negativo → \(\mu_1 < \mu_2\).

\((-8{,}3\ ;\ -2{,}1)\) no incluye el 0: sí hay diferencia, con \(\mu_2\) mayor.

Indique con qué estructuras de control se pueden recorrer arreglos en PHP.(Seleccione dos respuestas)

Parcial PHP · preg. 14

  • else if
  • if
  • switch
  • var_dump
  • foreach
  • for
  • r_array
  • trim

Recorrer un array es repetir algo por cada elemento: hace falta un ciclo. Los dos que se ofrecen son foreach (pone cada elemento en una variable, uno por vuelta) y for (recorre con el índice, de 0 a count($a) - 1).

if, else if y switch deciden, no repiten; var_dump y trim son funciones (mostrar una variable y sacar espacios), y r_array no existe.

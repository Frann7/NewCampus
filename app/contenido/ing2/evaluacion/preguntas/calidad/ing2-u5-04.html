¿En qué nivel de madurez de CMMI está esta empresa?

  • Todos los equipos siguen el proceso estándar de la organización.
  • Se mide el tiempo real de cada tarea y los defectos por versión, y con esos datos se fijan rangos esperados y se predicen los desvíos.
  • Los datos se usan para controlar los proyectos, pero no hay un mecanismo para cambiar el proceso a partir de ellos.

Inventada · estilo Parcial 2025, Teoría 1

  • Nivel 1 — Inicial
  • Nivel 2 — Gestionado
  • Nivel 3 — Definido
  • Nivel 4 — Cuantitativamente gestionado
  • Nivel 5 — En optimización continua

Nivel 4 (Cuantitativamente gestionado): se usan métricas para gestionar los procesos y controlar la calidad ("se decide con números"). Lo que le falta para el 5 es el último punto: usar esos datos para mejorar e innovar de forma sistemática, no solo para controlar.

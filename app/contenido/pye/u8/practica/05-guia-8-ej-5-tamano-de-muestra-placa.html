Guía 8 · Ej. 5 · Tamaño de muestra

Tiempo para perforar una placa: cuántas mediciones hacen falta

Un experto en eficiencia desea determinar el tiempo promedio que toma perforar una cierta placa metálica.

a. ¿De qué tamaño se necesita una muestra para tener 95% de confianza de que la media de la muestra esté dentro de 12 segundos de la media real? Suponga que por estudios previos se sabe que el desvío estándar de la variable aleatoria considerada en la población es de 40 segundos.

b. Repita el inciso anterior contemplando que el error máximo de estimación debe disminuir a la mitad.

Qué método y por qué
  • Todavía no hay muestra: se está planificando cuántas perforaciones medir. Lo que se fija de antemano es la confianza (95 %) y cuánto se tolera errar.
  • "Que la media de la muestra esté dentro de 12 segundos de la media real" es \(|\bar{x} - \mu| \leq 12\): el error máximo de estimación (la mitad del ancho del futuro intervalo) es \(E = 12\).
  • El error es \(E = z_{\alpha/2}\,\sigma/\sqrt{n}\). Como \(\sigma = 40\) es conocida ("por estudios previos se sabe que el desvío ... en la población"), se puede despejar \(n\):

\[ E = z_{\alpha/2}\,\frac{\sigma}{\sqrt{n}} \;\Longrightarrow\; \sqrt{n} = \frac{z_{\alpha/2}\,\sigma}{E} \;\Longrightarrow\; n = \left( \frac{z_{\alpha/2}\,\sigma}{E} \right)^{2} \]

Tamaño de muestra para estimar \(\mu\)

\[ n = \left( \frac{z_{\alpha/2}\,\sigma}{E} \right)^{2} \]

Se redondea siempre hacia arriba: con menos datos el error se pasaría del máximo pedido.

Desarme del enunciado

Qué son \(\alpha\) y \(\alpha/2\), en criollo: el 95 % de confianza es qué tan seguido acierta el método: de cada 100 intervalos armados así, 95 atrapan la media real. \(\alpha = 1 - 0{,}95 = 0{,}05\) es lo contrario, la chance de que el intervalo no acierte. Esa parte se reparte mitad en cada punta de la campana (valores demasiado altos y demasiado bajos): \(\alpha/2 = 0{,}025\) de cada lado. El valor de tabla que se busca es el que deja justo 0,025 afuera a la derecha.

\(z_{\alpha/2}\) de la tabla

Área a la izquierda de \(z_{\alpha/2}\):

\[ 1 - \frac{\alpha}{2} = 1 - 0{,}025 = 0{,}975 \]

En la tabla A.3, fila 1,9, columna 0,06: 0,9750 exacto. \(z_{\alpha/2} = 1{,}96\).

Inciso a — Error máximo de 12 segundos

Fórmula:

\[ n = \left( \frac{z_{\alpha/2}\,\sigma}{E} \right)^{2} \]

Pieza por pieza:

  • \(z_{\alpha/2}\,\sigma = 1{,}96 \times 40 = 78{,}4\)
  • \(\dfrac{78{,}4}{E} = \dfrac{78{,}4}{12} = 6{,}5333\)

\[ n = 6{,}5333^{2} = 42{,}68 \;\Longrightarrow\; n = 43 \]

Comprobación con \(E = 78{,}4/\sqrt{n}\):

  • \(n = 42\): \(E = \dfrac{78{,}4}{6{,}4807} = 12{,}10\) s → se pasa de 12, no alcanza.
  • \(n = 43\): \(E = \dfrac{78{,}4}{6{,}5574} = 11{,}96\) s → cumple.
Respuesta a

Hacen falta 43 perforaciones. Con 43 mediciones, con 95 % de confianza el tiempo promedio de la muestra queda a menos de 12 segundos del tiempo medio real.

Inciso b — Error máximo a la mitad (6 segundos)

Fórmula:

\[ n = \left( \frac{z_{\alpha/2}\,\sigma}{E} \right)^{2} \]

  • \(z_{\alpha/2}\,\sigma = 1{,}96 \times 40 = 78{,}4\) (no cambia)
  • \(\dfrac{78{,}4}{E} = \dfrac{78{,}4}{6} = 13{,}0667\)

\[ n = 13{,}0667^{2} = 170{,}74 \;\Longrightarrow\; n = 171 \]

Comprobación: con \(n = 170\), \(E = 78{,}4/13{,}0384 = 6{,}01\) s (no alcanza); con \(n = 171\), \(E = 78{,}4/13{,}0767 = 5{,}995\) s (cumple).

Respuesta b

Hacen falta 171 perforaciones: para reducir el error a la mitad hubo que medir unas 4 veces más.

Por qué la mitad de error cuesta el cuádruple

En la fórmula \(E\) está al cuadrado abajo: si \(E\) se divide por 2, \(E^{2}\) se divide por 4 y \(n\) se multiplica por 4. Sin redondear se ve exacto: \(42{,}68 \times 4 = 170{,}74\). Dicho con \(\sqrt{n}\): el error baja como \(1/\sqrt{n}\), y para que \(\sqrt{n}\) se duplique, \(n\) tiene que cuadruplicarse.

Resolución 2023 de la cátedra

a) \(n = 43\); b) \(n = 171\). Coincide.

1. SELECT, WHERE y ORDER BY

La forma de una consulta 
SELECT columnas          -- qué se muestra
FROM tabla               -- de dónde
WHERE condición          -- qué filas (opcional)
ORDER BY columna;        -- en qué orden (opcional)

Se escriben en ese orden, siempre. El resultado es otra tabla, con las columnas del SELECT y solo las filas que cumplen el WHERE.

Los textos y las fechas van entre comillas simples ('León', '2026-10-01'); los números, sin comillas.

Ejemplo 1: filtrar y ordenar

Con la tabla Especie (Codigo (PK), Nombre, NombreCientifico, Descripcion, CodigoZona (FK)), listar nombre y nombre científico de las especies de la zona 2, en orden alfabético.

Ejemplo 2: TOP con ORDER BY ("el mayor")

Con la tabla Zona (Codigo (PK), Nombre, Extension), el nombre de la zona de mayor extensión (Guía 9, consulta 11).

Zona
CodigoNombreExtension
1Selva5000.00
2Sabana12000.00
3Acuario800.00
SELECT TOP 1 Nombre
FROM Zona
ORDER BY Extension DESC;

Se ordena de mayor a menor y se queda con la primera: Sabana. Para "los 10 más..." es lo mismo con TOP 10.

Errores y trampas
  • El orden de las cláusulas no se cambia: WHERE va antes que ORDER BY.
  • TOP sin ORDER BY trae filas cualquiera: "los primeros" no significa nada si no se dice por qué orden.
  • Para ordenar por varias columnas se separan con coma: ORDER BY Provincia, Ciudad, Nombre (desempata por la segunda, después por la tercera).
  • Un texto con comillas dobles ("León") da error en SQL Server: van simples.

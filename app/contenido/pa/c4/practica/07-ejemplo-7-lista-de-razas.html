Consumir una API: la lista de razas

Misma API que el ejemplo 6, otra dirección: la que devuelve todas las razas. La página muestra un párrafo por raza. Clase IndexClass en js/pgConsultoApi1Class.js.

Paso 2 — Qué contesta la API

https://dog.ceo/api/breeds/list/all devuelve (principio de una respuesta real, pedida al escribir esto):

{"message":{"affenpinscher":[],"african":["wild"],"airedale":[],"akita":[],"appenzeller":[],"australian":["kelpie","shepherd"], ... },"status":"success"}
ParteQué es
messageAhora no es un texto: es un objeto. Cada clave es una raza
"african": ["wild"]El valor de cada raza es un array con sus sub-razas (vacío si no tiene)

Las razas no vienen en un array sino como claves de un objeto. Por eso hace falta Object.keys (teoría, sección 2) para sacar la lista de nombres.

Paso 3 — El JavaScript 
class IndexClass {

    constructor() {
        this.divDatos = document.getElementById('divDatos');
        this.btConsultoApi = document.getElementById('btConsultoApi');
    }

    init() {
        this.addEventListeners();
    }

    addEventListeners() {
        this.btConsultoApi.addEventListener('click', () => {

            const url = "https://dog.ceo/api/breeds/list/all";

            fetch(url)
                .then(response => response.json())
                .then(data => {

                    const datos = Array.from(Object.keys(data.message));

                    this.divDatos.innerHTML = '';

                    datos.forEach(dato => {
                        const p = document.createElement('p');
                        p.textContent = dato;
                        this.divDatos.appendChild(p);
                    });
                })
                .catch(error => {
                    console.error('Error al consultar la API:', error);
                });
        });
    }
}

window.addEventListener('load',() => {
    new IndexClass().init();
})

Probado en Node.js con un recorte de la respuesta ({affenpinscher: [], african: ["wild"], airedale: []}): Array.from(Object.keys(...)) da [ 'affenpinscher', 'african', 'airedale' ].

Por qué se vacía antes

Sin el innerHTML = '', cada clic agregaría la lista entera de nuevo debajo de la anterior. Acá se vacía con innerHTML; en el ejemplo 6 el mismo efecto lo daba asignar innerText.

Las sub-razas no aparecen

Object.keys solo toma las claves. El "wild" de african o el "kelpie" de australian quedan afuera: para mostrarlos habría que leer también el valor de cada clave.

Qué se ve en la página

Al apretar el botón, debajo de la línea aparece una lista larga de párrafos, uno por raza: affenpinscher, african, airedale, akita, appenzeller... (al escribir esto eran 108; la cantidad la decide la API). Apretar otra vez muestra la misma lista, no la duplica.

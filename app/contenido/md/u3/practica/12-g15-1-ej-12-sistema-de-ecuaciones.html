Grimaldi 15.1 · Ej. 12 · Sistema de ecuaciones booleanas

Resolver un sistema de tres ecuaciones en w, x, y, z

Encuentre los valores de las variables booleanas \(w, x, y, z\) que satisfagan el siguiente sistema de ecuaciones (booleanas) simultáneas.

\[x + \overline{x}y = 0 \qquad \overline{x}y = \overline{x}z \qquad \overline{x}y + \overline{x}\,\overline{z} + zw = \overline{z}w\]
Qué tema es y por qué
  • Un sistema booleano: los valores tienen que cumplir las tres ecuaciones a la vez.
  • El método: arrancar por la ecuación que fija valores (una suma igualada a 0 o un producto igualado a 1) y reemplazar lo que se sabe en las siguientes.
  • Las dos propiedades que fijan valores (observaciones de la teoría de esta unidad):
    • \(a + b = 0 \iff a = 0 \text{ y } b = 0\).
    • \(ab = 1 \iff a = 1 \text{ y } b = 1\).

Paso 1 — Primera ecuación: \(x + \overline{x}y = 0\)

Regla: una suma vale 0 solo si todos los sumandos valen 0.

  • \(x = 0\), entonces \(\overline{x} = 1\).
  • \(\overline{x}y = 0\), o sea \(1 \cdot y = 0\), entonces \(y = 0\) (identidad: \(1 \cdot y = y\)).
Paso 2 — Segunda ecuación: \(\overline{x}y = \overline{x}z\)

Se reemplaza \(\overline{x} = 1\) y \(y = 0\):

\[1 \cdot 0 = 1 \cdot z \;\Rightarrow\; 0 = z\]

Entonces \(z = 0\) y \(\overline{z} = 1\).

Paso 3 — Tercera ecuación: \(\overline{x}y + \overline{x}\,\overline{z} + zw = \overline{z}w\)

Se reemplaza \(\overline{x} = 1\), \(y = 0\), \(z = 0\), \(\overline{z} = 1\):

\[1 \cdot 0 + 1 \cdot 1 + 0 \cdot w = 1 \cdot w\] \[0 + 1 + 0 = w \;\Rightarrow\; w = 1\] Paso 4 — Control

Con \(w = 1, x = 0, y = 0, z = 0\):

  • \(x + \overline{x}y = 0 + 1 \cdot 0 = 0\). ✔
  • \(\overline{x}y = 0\) y \(\overline{x}z = 1 \cdot 0 = 0\). ✔
  • \(\overline{x}y + \overline{x}\,\overline{z} + zw = 0 + 1 + 0 = 1\) y \(\overline{z}w = 1 \cdot 1 = 1\). ✔

Cada paso obligó un valor, así que es la única solución (y probando las 16 entradas se confirma que no hay otra).

Respuesta

\(w = 1,\ x = 0,\ y = 0,\ z = 0\) (solución única).

Solución del libro

Es par: no está en las soluciones en castellano. El manual del profesor sigue el mismo orden (\(x = y = 0\), después \(z = 0\), después \(w = 1\)). Coincide.

Para armar un intervalo del 98 % de confianza para el tiempo medio de respuesta de una API, con una muestra de 50 peticiones, ¿qué valor de \(z_{\alpha/2}\) se usa?

Tercer parcial — primera parte probable (inventada)

  • 1,96
  • 2,05
  • 2,33
  • 2,576
  1. \(n = 50 \geq 30\) → se usa \(Z\).
  2. Confianza \(1 - \alpha = 0{,}98\) → \(\alpha = 0{,}02\) → \(\alpha/2 = 0{,}01\) (lo que queda afuera en cada cola).
  3. En la tabla normal se busca 0,01 adentro (área a la izquierda). El más cercano es 0,0099, en \(z = -2{,}33\).
  4. Es negativo porque es la cola izquierda; por simetría se toma el valor absoluto: \(z_{0{,}01} = 2{,}33\).
  • 2,05 deja 0,02 en una sola cola: se olvidó dividir \(\alpha\) por 2.
  • 1,96 es del 95 % y 2,576 del 99 %.

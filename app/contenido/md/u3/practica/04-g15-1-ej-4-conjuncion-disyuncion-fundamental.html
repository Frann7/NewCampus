Grimaldi 15.1 · Ej. 4 · Mintérmino y maxtérmino de un punto

La conjunción que vale 1 y la disyunción que vale 0 en un solo punto

a) Encuentre la conjunción fundamental formada con las variables \(w, x, y, z\) o sus complementos, de modo que el valor de la conjunción sea 1 exactamente cuando

i) \(w = x = 0,\ y = z = 1\).    ii) \(w = 0,\ x = 1,\ y = 1,\ z = 0\).
iii) \(w = 0,\ x = y = z = 1\).    iv) \(w = x = y = z = 0\).

b) Responda la parte (a), esta vez para las disyunciones fundamentales en vez de las conjunciones fundamentales, donde el valor de cada disyunción fundamental es 0 precisamente para los valores dados de \(w, x, y, z\).

Qué tema es y por qué
  • Una conjunción fundamental (mintérmino) es un producto con las cuatro variables, cada una con o sin barra: \(\overline{w}x\overline{y}z\), por ejemplo.
  • Una disyunción fundamental (maxtérmino) es una suma con las cuatro variables, cada una con o sin barra: \(w + \overline{x} + y + \overline{z}\).
  • Las dos son las piezas de la f.n.d. y de la f.n.c. (en la teoría de esta unidad). Este ejercicio enseña a armarlas a partir del punto.
Inciso a) — La regla del mintérmino
Conjunción fundamental que vale 1 solo en un punto

Variable que vale 1 → va sin barra. Variable que vale 0 → va con barra.

Por qué: un producto vale 1 solo si cada factor vale 1. Si \(w = 0\), el factor que vale 1 es \(\overline{w}\); si \(x = 1\), el factor que vale 1 es \(x\). En cualquier otro punto alguna variable cambió, su factor pasa a 0 y el producto entero se hace 0.

Punto\(w\ x\ y\ z\)Cada variableConjunción
i)0 0 1 1\(\overline{w},\ \overline{x},\ y,\ z\)\(\overline{w}\,\overline{x}yz\)
ii)0 1 1 0\(\overline{w},\ x,\ y,\ \overline{z}\)\(\overline{w}xy\overline{z}\)
iii)0 1 1 1\(\overline{w},\ x,\ y,\ z\)\(\overline{w}xyz\)
iv)0 0 0 0\(\overline{w},\ \overline{x},\ \overline{y},\ \overline{z}\)\(\overline{w}\,\overline{x}\,\overline{y}\,\overline{z}\)

Control del i): en \(0011\), \(\overline{w}\,\overline{x}yz = 1 \cdot 1 \cdot 1 \cdot 1 = 1\).

Inciso b) — La regla del maxtérmino
Disyunción fundamental que vale 0 solo en un punto

Variable que vale 0 → va sin barra. Variable que vale 1 → va con barra. (Es al revés que en el mintérmino.)

Por qué: una suma vale 0 solo si cada sumando vale 0. Si \(w = 0\), el sumando que vale 0 es \(w\); si \(y = 1\), el sumando que vale 0 es \(\overline{y}\). En cualquier otro punto algún sumando pasa a 1 y la suma entera se hace 1.

Punto\(w\ x\ y\ z\)Cada variableDisyunción
i)0 0 1 1\(w,\ x,\ \overline{y},\ \overline{z}\)\(w + x + \overline{y} + \overline{z}\)
ii)0 1 1 0\(w,\ \overline{x},\ \overline{y},\ z\)\(w + \overline{x} + \overline{y} + z\)
iii)0 1 1 1\(w,\ \overline{x},\ \overline{y},\ \overline{z}\)\(w + \overline{x} + \overline{y} + \overline{z}\)
iv)0 0 0 0\(w,\ x,\ y,\ z\)\(w + x + y + z\)

Control del i): en \(0011\), \(w + x + \overline{y} + \overline{z} = 0 + 0 + 0 + 0 = 0\).

Para qué sirve en el parcial

Como cada maxtérmino vale 0 en un solo punto, un producto de maxtérminos \(\prod M(\dots)\) vale 0 exactamente en los puntos de la lista y 1 en todos los demás. Para evaluar \(\prod M(1, 3, 5, 6, 10, 12, 13)\) en \((1, 0, 1, 1)\) alcanza con pasar \(1011\) a decimal (\(8 + 2 + 1 = 11\)): 11 no está en la lista, así que ningún factor se anula y \(f(1, 0, 1, 1) = 1\). Sin tabla.

Respuesta

a) i) \(\overline{w}\,\overline{x}yz\)   ii) \(\overline{w}xy\overline{z}\)   iii) \(\overline{w}xyz\)   iv) \(\overline{w}\,\overline{x}\,\overline{y}\,\overline{z}\)

b) i) \(w + x + \overline{y} + \overline{z}\)   ii) \(w + \overline{x} + \overline{y} + z\)   iii) \(w + \overline{x} + \overline{y} + \overline{z}\)   iv) \(w + x + y + z\)

Variables que se miden

5. Función de densidad de una variable continua

Cuándo se usa

Cuando la variable es continua (un tiempo, una temperatura) y el enunciado da una fórmula \(f(x)\) llamada "función de densidad de probabilidad" (fdp). Piden "verificar que \(f\) es una función de densidad", "la probabilidad de que el tiempo esté entre…", "la probabilidad de que sea exactamente…".

Por qué no sirve una tabla

Una continua puede tomar infinitos valores (entre 0 y 1 están 0,5; 0,51; 0,511…). Si a cada valor le tocara una probabilidad positiva, al sumar infinitas se pasaría de 1. La cátedra lo dice así: la probabilidad de un valor exacto sería "casos favorables sobre casos totales", \(1/N\), con \(N \to \infty\), y eso tiende a 0.

Conclusión: en una continua, un valor exacto tiene probabilidad 0, y solo los intervalos tienen probabilidad. En vez de tabla se usa una curva \(f(x)\), la densidad, y la probabilidad de un intervalo es el área bajo la curva en ese tramo.

Fórmulas

\[ P(a < X < b) = \int_a^b f(x)\,dx \]

Propiedades de una función de densidad (lo que hay que verificar):

  1. \(f(x) \geq 0\) para todo \(x \in \mathbb{R}\): la curva nunca baja del eje.
  2. \(\displaystyle \int_{-\infty}^{+\infty} f(x)\,dx = 1\): el área total vale 1.
  3. \(\displaystyle P(a < X < b) = \int_a^b f(x)\,dx\).

Y por eso: \(P(X = a) = 0\), y da lo mismo \(<\) que \(\leq\).

Qué significa cada letra

SímboloQué esEjemplo
\(f(x)\)la densidad: la altura de la curva. No es una probabilidad\(f(x) = x^2/3\)
\(\int_a^b f(x)\,dx\)el área bajo la curva entre \(a\) y \(b\) (sección 4): eso sí es una probabilidad\(P(-1 < X < 1) = 2/9\)
"en c.o.c.""en cualquier otro caso": afuera del intervalo, \(f\) vale 0\(f(x) = 0\) si \(x < -1\) o \(x > 2\)
\(-\infty\), \(+\infty\)"desde lo más a la izquierda hasta lo más a la derecha"en la práctica, desde donde empieza \(f\) hasta donde termina

De dónde sale

Si se miden muchísimos datos y se arma un histograma (Unidad 2) con barras cada vez más finas, las barras van dibujando una curva. El área de las barras de un tramo es la proporción de datos que cayeron ahí; en el límite, esa área es la probabilidad. Y como todos los datos caen en algún lado, el área total es 1 (la cátedra lo llama distribución empírica: de las mediciones se infiere la forma de la curva).

Cómo se verifica que es densidad

  1. \(f(x) \geq 0\): mirar la fórmula en su intervalo. \(x^2/3\) es un cuadrado dividido 3: nunca negativo. Con una recta, alcanza con mirar los dos extremos (si los dos dan positivo, todo el medio también).
  2. Área total igual a 1: la integral se hace solo donde \(f\) no es 0. Afuera vale 0 y su área es 0, así que \(\int_{-\infty}^{+\infty}\) se reduce a \(\int_a^b\).
La densidad puede valer más que 1

\(f(x)\) es una altura, no una probabilidad. En el Ejemplo 2, \(f(2) = 1{,}5\), y está bien: lo que tiene que valer 1 es el área total, no la altura.

\(P(X = a) = 0\) no quiere decir "imposible"

Que el tiempo dure exactamente 1,000000… segundos tiene probabilidad 0 (un punto no tiene ancho, y un área sin ancho es 0), pero el valor existe. Por eso, en una continua, \(P(X < 1) = P(X \leq 1)\): agregar o sacar un punto no cambia el área. En el examen se justifica así: "es 0 porque \(X\) es continua y la probabilidad de un valor puntual es nula".

Ejemplo 1 — La densidad \(x^2/3\) (de la cátedra)

Enunciado

Sea \(f(x) = \begin{cases} \dfrac{x^2}{3} & -1 < x < 2 \\ 0 & \text{en cualquier otro caso} \end{cases}\)

a) Compruebe que \(f\) es una función de densidad. b) Obtenga \(P(-1 < X < 1)\). c) Obtenga \(P(X < 1{,}5)\).

Desarme del enunciado

FraseQué significaLa cuentaA dónde va
"\(-1 < x < 2\)"donde \(f\) no es 0—los límites del área total
"compruebe que es densidad"las propiedades 1 y 2\(\int_{-1}^{2} f = 1\)inciso a
"\(X < 1{,}5\)"desde donde empieza \(f\) hasta 1,5\(1{,}5 = 3/2\)\(\int_{-1}^{3/2}\)

La curva \(x^2/3\) entre −1 y 2; pintada, el área entre −1 y 1. Afuera, \(f = 0\).

a) Comprobar que es densidad

Propiedad 1. \(x^2/3 \geq 0\) siempre (un cuadrado no es negativo), y afuera \(f = 0\). ✔

Propiedad 2. Fórmula: \(\displaystyle \int_{-\infty}^{+\infty} f(x)\,dx = 1\). Como \(f\) es 0 afuera, se integra de \(-1\) a 2:

\[ \int_{-1}^{2} \frac{x^2}{3}\,dx = \left[\frac{x^3}{9}\right]_{-1}^{2} = \frac{8}{9} - \left(-\frac{1}{9}\right) = \frac{9}{9} = 1 \quad\checkmark \]

La primitiva: el \(\tfrac{1}{3}\) sale afuera y \(\int x^2\,dx = x^3/3\), así que queda \(x^3/9\) (sección 4).

b) \(P(-1 < X < 1)\)

Fórmula: \(\displaystyle P(a < X < b) = \int_a^b f(x)\,dx\).

\[ P(-1 < X < 1) = \int_{-1}^{1} \frac{x^2}{3}\,dx = \left[\frac{x^3}{9}\right]_{-1}^{1} = \frac{1}{9} - \left(-\frac{1}{9}\right) = \frac{2}{9} = 0{,}2222 \]

c) \(P(X < 1{,}5)\)

Fórmula: \(\displaystyle P(X < b) = \int_{-\infty}^{b} f(x)\,dx\). Antes de \(-1\) el área es 0, así que se arranca en \(-1\):

\[ P(X < 1{,}5) = \int_{-1}^{3/2} \frac{x^2}{3}\,dx = \left[\frac{x^3}{9}\right]_{-1}^{3/2} = \frac{(3/2)^3}{9} - \left(-\frac{1}{9}\right) \]

\((3/2)^3 = \dfrac{3^3}{2^3} = \dfrac{27}{8}\), y dividido 9 queda \(\dfrac{27}{72}\). Con denominador 72, \(\dfrac{1}{9} = \dfrac{8}{72}\):

\[ P(X < 1{,}5) = \frac{27}{72} + \frac{8}{72} = \frac{35}{72} = 0{,}4861 \]

Respuesta

a) Es densidad: no es negativa y su área total es 1. b) \(2/9 = 0{,}2222\). c) \(35/72 = 0{,}4861\).

Ejemplo 2 — Tiempo de compilación (con formato de examen)

Enunciado

El tiempo, en minutos, que tarda en compilar un proyecto es una variable aleatoria \(X\) con función de densidad \(f(x) = \begin{cases} \dfrac{3}{8}x^2 & 0 \leq x \leq 2 \\ 0 & \text{en c.o.c.} \end{cases}\)

a) ¿\(X\) es discreta o continua? Justifique. b) Verifique que \(f\) es una función de densidad. c) ¿Cuál es la probabilidad de que la compilación tarde entre medio minuto y un minuto y medio? d) ¿Cuál es la probabilidad de que tarde exactamente 1 minuto? e) ¿Y de que tarde a lo sumo 1 minuto?

Desarme del enunciado

FraseQué significaLa cuentaA dónde va
"tiempo, en minutos"se mide—continua
"entre medio minuto y un minuto y medio"un intervalo—\(P(0{,}5 < X < 1{,}5)\)
"exactamente 1 minuto"un punto—\(P(X = 1) = 0\)
"a lo sumo 1 minuto"1 o menos—\(P(X \leq 1)\)

La densidad \(3x^2/8\): sube hasta 1,5 en \(x = 2\). Pintada, el área entre 0,5 y 1,5.

a) Discreta o continua

\(X\): tiempo de compilación del proyecto, en minutos → v.a. continua, porque se mide: puede tomar cualquier valor real entre 0 y 2.

b) Verificar

Propiedad 1. \(\tfrac{3}{8}x^2 \geq 0\) para todo \(x\) (número positivo por un cuadrado). ✔

Propiedad 2. Fórmula: \(\displaystyle \int_{-\infty}^{+\infty} f(x)\,dx = 1\).

\[ \int_0^2 \frac{3}{8}x^2\,dx = \frac{3}{8}\left[\frac{x^3}{3}\right]_0^2 = \left[\frac{x^3}{8}\right]_0^2 = \frac{8}{8} - 0 = 1 \quad\checkmark \]

El \(\tfrac{3}{8}\) sale afuera; \(\tfrac{3}{8} \cdot \tfrac{x^3}{3} = \tfrac{x^3}{8}\) (el 3 se simplifica).

c) Entre 0,5 y 1,5

Fórmula: \(\displaystyle P(a < X < b) = \int_a^b f(x)\,dx\).

\[ P(0{,}5 < X < 1{,}5) = \int_{1/2}^{3/2} \frac{3}{8}x^2\,dx = \left[\frac{x^3}{8}\right]_{1/2}^{3/2} = \frac{27/8}{8} - \frac{1/8}{8} = \frac{27}{64} - \frac{1}{64} = \frac{26}{64} = \frac{13}{32} = 0{,}4063 \]

\((1/2)^3 = 1/8\) y \((3/2)^3 = 27/8\); dividir por 8 otra vez da denominador 64.

d) Exactamente 1 minuto

Fórmula: \(P(X = a) = 0\) en una continua.

\[ P(X = 1) = \int_1^1 f(x)\,dx = 0 \]

Un área de ancho cero vale 0 (en Barrow: \(G(1) - G(1) = 0\)).

e) A lo sumo 1 minuto

Fórmula: \(\displaystyle P(X \leq b) = \int_{-\infty}^{b} f(x)\,dx\); desde 0, que es donde empieza \(f\):

\[ P(X \leq 1) = \int_0^1 \frac{3}{8}x^2\,dx = \left[\frac{x^3}{8}\right]_0^1 = \frac{1}{8} = 0{,}125 \]

Respuesta

a) Continua. b) Es densidad. c) La probabilidad de que la compilación tarde entre medio minuto y un minuto y medio es 0,4063. d) 0, porque \(X\) es continua y un valor puntual tiene probabilidad nula. e) La probabilidad de que tarde a lo sumo un minuto es 0,125.

Errores y trampas

  • Integrar desde \(-\infty\) con la fórmula de adentro: afuera del intervalo \(f\) vale 0. Se arranca donde empieza \(f\).
  • Decir que \(f(2) = 1{,}5\) "no puede ser": la densidad no es una probabilidad.
  • Calcular \(P(X = 1)\) reemplazando en \(f\): \(f(1) = 3/8\) es una altura, no la probabilidad. La probabilidad de un punto es 0.

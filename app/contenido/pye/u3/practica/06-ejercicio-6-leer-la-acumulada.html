Ejercicio 6 · Leer la acumulada

Probabilidades a partir del gráfico de \(F(x)\)

Sea la variable aleatoria discreta \(X\), cuya distribución acumulada de probabilidad se encuentra graficada a continuación. Determine: a) \(P(X \leq 3)\). b) \(P(X = 3)\). c) \(P(X > 3)\). d) \(P(X \geq 3)\). e) \(P(X < 3)\). f) \(P(X = 2)\). g) \(P(2 < X \leq 3)\).

El gráfico de la guía, redibujado con los mismos valores: escalones en 1, 2, 3 y 4.

Desarme del enunciado

Qué se veQué significaA dónde va
escalones en \(x = 1, 2, 3, 4\)los valores de \(X\)\(X\) toma 1, 2, 3 o 4
altura de cada escalón\(F\) desde ese valor\(F(1) = 0{,}1\), \(F(2) = 0{,}5\), \(F(3) = 0{,}7\), \(F(4) = 1\)
punto lleno a la izquierdaen el valor, \(F\) ya incluye el salto\(F(3) = 0{,}7\), no 0,5
Paso 0 — Pasar el gráfico a una tabla

La altura de cada escalón es \(F\); el tamaño de cada salto es \(f(x) = F(x) - F(\text{anterior})\):

\(x\)1234
\(F(x)\)0,10,50,71
\(f(x)\) (salto)0,10,5 − 0,1 = 0,40,7 − 0,5 = 0,21 − 0,7 = 0,3
Inciso a — \(P(X \leq 3)\)

Fórmula: \(P(X \leq a) = F(a)\).

\[ P(X \leq 3) = F(3) = 0{,}7 \]

Inciso b — \(P(X = 3)\)

Fórmula: \(P(X = a) = F(a) - F(\text{anterior})\): el salto en 3.

\[ P(X = 3) = P(X \leq 3) - P(X \leq 2) = F(3) - F(2) = 0{,}7 - 0{,}5 = 0{,}2 \]

Inciso c — \(P(X > 3)\)

Fórmula: \(P(X > a) = 1 - F(a)\) (lo contrario de "más de 3" es "3 o menos").

\[ P(X > 3) = 1 - P(X \leq 3) = 1 - F(3) = 1 - 0{,}7 = 0{,}3 \]

Inciso d — \(P(X \geq 3)\)

Fórmula: \(P(X \geq a) = 1 - F(\text{anterior})\) (lo contrario de "3 o más" es "menos de 3", o sea "2 o menos").

\[ P(X \geq 3) = 1 - P(X < 3) = 1 - P(X \leq 2) = 1 - F(2) = 1 - 0{,}5 = 0{,}5 \]

Compará con el c: la diferencia entre \(\geq\) y \(>\) es justo \(P(X = 3) = 0{,}2\). En una discreta importa.

Inciso e — \(P(X < 3)\)

Fórmula: \(P(X < a) = F(\text{anterior})\).

\[ P(X < 3) = P(X \leq 2) = F(2) = 0{,}5 \]

Inciso f — \(P(X = 2)\)

Fórmula: \(P(X = a) = F(a) - F(\text{anterior})\).

\[ P(X = 2) = P(X \leq 2) - P(X \leq 1) = F(2) - F(1) = 0{,}5 - 0{,}1 = 0{,}4 \]

Inciso g — \(P(2 < X \leq 3)\)

Fórmula: \(P(a < X \leq b) = F(b) - F(a)\). "Más de 2 y hasta 3" deja solo al 3:

\[ P(2 < X \leq 3) = P(X \leq 3) - P(X \leq 2) = F(3) - F(2) = 0{,}7 - 0{,}5 = 0{,}2 \]

Da lo mismo que el inciso b, porque entre 2 (sin incluir) y 3 (incluido) el único valor posible es el 3.

Respuesta

a) 0,7. b) 0,2. c) 0,3. d) 0,5. e) 0,5. f) 0,4. g) 0,2.

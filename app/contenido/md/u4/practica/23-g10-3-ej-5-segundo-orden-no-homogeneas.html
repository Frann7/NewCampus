Grimaldi 10.3 · Ej. 5(a, b) · Segundo orden no homogénea

Dos relaciones de segundo orden no homogéneas

Resuelva las siguientes relaciones de recurrencia.

a) \(a_{n+2} + 3a_{n+1} + 2a_n = 3^{n},\ n \geq 0,\ a_0 = 0,\ a_1 = 1\)

b) \(a_{n+2} + 4a_{n+1} + 4a_n = 7,\ n \geq 0,\ a_0 = 1,\ a_1 = 2\)

Qué tema es y por qué
  • Orden 2 (subíndices \(n+2\) a \(n\)) con un término que no depende de los \(a\): no homogéneas.
  • Método de coeficientes indeterminados de la cátedra (en la teoría de esta unidad).
El método (se repite en cada inciso)

1. \(a_n = a_n^{(h)} + a_n^{(p)}\).

2. \(a_n^{(h)}\): ecuación característica de la homogénea asociada; raíces distintas \(\to C_1 r_1^{\,n} + C_2 r_2^{\,n}\); raíz doble \(\to (C_1 + C_2 n)\,r^{n}\). \(C_1, C_2\) quedan para el final.

3. \(a_n^{(p)}\): constante \(\to A\); \(k \cdot s^{n} \to A\,s^{n}\). Si choca con un término de \(a_n^{(h)}\), se multiplica por \(n\) (por \(n^{2}\) si la raíz es doble).

4. Se reemplaza \(a_n^{(p)}\) en la relación para hallar \(A\).

5. Con la solución completa y \(a_0, a_1\) se hallan \(C_1, C_2\).

Paso 1 — Inciso a)

2. Homogénea: \(r^{2} + 3r + 2 = 0 \Rightarrow (r + 1)(r + 2) = 0 \Rightarrow r = -1,\ r = -2\). \(\ a_n^{(h)} = C_1(-1)^{n} + C_2(-2)^{n}\).

3. \(g(n) = 3^{n}\) \(\to a_n^{(p)} = A\,3^{n}\). No choca (3 no es raíz).

4. Reemplazando: \(A\,3^{n+2} + 3A\,3^{n+1} + 2A\,3^{n} = 3^{n}\). Dividiendo por \(3^{n}\): \(9A + 9A + 2A = 20A = 1 \Rightarrow A = \tfrac{1}{20}\).

5. \(a_n = C_1(-1)^{n} + C_2(-2)^{n} + \tfrac{1}{20}3^{n}\):

\[ \left\{\begin{array}{l} n = 0:\ C_1 + C_2 + \tfrac{1}{20} = 0 \\ n = 1:\ -C_1 - 2C_2 + \tfrac{3}{20} = 1 \end{array}\right. \]

Sumando: \(-C_2 + \tfrac{4}{20} = 1 \Rightarrow C_2 = -\tfrac45\); entonces \(C_1 = \tfrac45 - \tfrac1{20} = \tfrac34\).

\[ a_n = \tfrac34(-1)^{n} - \tfrac45(-2)^{n} + \tfrac{1}{20}\,3^{n},\ \forall n \geq 0 \]

Comprobación: con la relación, \(a_2 = 3^{0} - 3 \cdot 1 - 2 \cdot 0 = -2\), \(a_3 = 3 - 3(-2) - 2 \cdot 1 = 7\). Con la fórmula, \(a_2 = \tfrac34 - \tfrac{16}{5} + \tfrac{9}{20} = -2\), \(a_3 = -\tfrac34 + \tfrac{32}{5} + \tfrac{27}{20} = 7\). Coinciden.

Paso 2 — Inciso b)

2. Homogénea: \(r^{2} + 4r + 4 = 0 \Rightarrow (r + 2)^{2} = 0\): raíz doble \(r = -2\). \(\ a_n^{(h)} = (C_1 + C_2 n)(-2)^{n}\).

3. \(g(n) = 7\), constante \(\to a_n^{(p)} = A\). No choca: 1 no es raíz (una constante es \(A \cdot 1^{n}\), y choca solo si \(r = 1\) es raíz).

4. Reemplazando: \(A + 4A + 4A = 9A = 7 \Rightarrow A = \tfrac79\).

5. \(a_n = (C_1 + C_2 n)(-2)^{n} + \tfrac79\):

\[ \left\{\begin{array}{l} n = 0:\ C_1 + \tfrac79 = 1 \Rightarrow C_1 = \tfrac29 \\ n = 1:\ -2(C_1 + C_2) + \tfrac79 = 2 \Rightarrow C_1 + C_2 = -\tfrac{11}{18} \Rightarrow C_2 = -\tfrac{11}{18} - \tfrac{4}{18} = -\tfrac56 \end{array}\right. \]

\[ a_n = \tfrac29(-2)^{n} - \tfrac56\,n\,(-2)^{n} + \tfrac79,\ \forall n \geq 0 \]

Comprobación: con la relación, \(a_2 = 7 - 4 \cdot 2 - 4 \cdot 1 = -5\), \(a_3 = 7 - 4(-5) - 4 \cdot 2 = 19\). Con la fórmula, \(a_2 = \tfrac89 - \tfrac{20}{6} + \tfrac79 = -5\), \(a_3 = -\tfrac{16}{9} + 20 + \tfrac79 = 19\). Coinciden.

La constante y la raíz 1

Antes de proponer \(a_n^{(p)} = A\) para una constante, mirá si \(r = 1\) es raíz de la característica. En el Parcial 2 2026, \(r^{2} + 8r - 9 = (r - 1)(r + 9)\): como 1 es raíz, \(A\) choca y la particular es \(A\,n\). Si se usa \(A\), al reemplazar queda \(0 = 100\).

Respuesta

a) \(a_n = \tfrac34(-1)^{n} - \tfrac45(-2)^{n} + \tfrac1{20}3^{n}\)   b) \(a_n = \tfrac29(-2)^{n} - \tfrac56 n(-2)^{n} + \tfrac79\), para \(n \geq 0\).

Solución del libro

El libro da a) \((3/4)(-1)^{n} + (-4/5)(-2)^{n} + (1/20)(3)^{n}\) y b) \((2/9)(-2)^{n} - (5/6)(n)(-2)^{n} + (7/9)\). Coinciden los dos.

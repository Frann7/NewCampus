Ejercicio 7 · Facade

Reconocer el patrón en un código en otro lenguaje

Guía N°2, ejercicio 3. Dado el siguiente código identifique el lenguaje de programación en que se está implementado, qué tipo de patrón se implementa y realice el diagrama correspondiente. 

using System;

namespace git.QQQQ.Conceptual
{

    public class Pantalla
    {
        protected Subsystem1 _subsystem1;
        protected Subsystem2 _subsystem2;

        public pantalla(Subsystem1 subsystem1, Subsystem2 subsystem2)
        {
            this._subsystem1 = subsystem1;
            this._subsystem2 = subsystem2;
        }

        public string Operation()
        {
            string result = "pantallainitializes subsystems:\n";
            result += this._subsystem1.operation1();
            result += this._subsystem2.operation1();
            result += "pantallaorders subsystems to perform the action:\n";
            result += this._subsystem1.operationN();
            result += this._subsystem2.operationZ();
            return result;
        }
    }

    public class Subsystem1
    {
        public string operation1()
        {
            return "Subsystem1: Ready!\n";
        }

        public string operationN()
        {
            return "Subsystem1: Go!\n";
        }
    }

    public class Subsystem2
    {
        public string operation1()
        {
            return "Subsystem2: Get ready!\n";
        }

        public string operationZ()
        {
            return "Subsystem2: Fire!\n";
        }
    }

    class Client
    {
        public static void ClientCode(pantallapantalla)
        {
            Console.Write(pantalla.Operation());
        }
    }

    class Program
    {
        static void Main(string[] args)
        {
            Subsystem1 subsystem1 = new Subsystem1();
            Subsystem2 subsystem2 = new Subsystem2();
            pantallapantalla= new pantalla(subsystem1, subsystem2);
            Client.ClientCode(pantalla);
        }
    }
}
Paso 1 — El lenguaje

Es C#: using System;, namespace con llaves, Console.Write, static void Main(string[] args), y los métodos se llaman con punto (this._subsystem1.operation1()) y no con flecha.

Los pantallapantalla y pantallainitializes pegados son restos de haber reemplazado la palabra Facade por pantalla; se leen como pantalla pantalla (una variable pantalla de tipo Pantalla).

Paso 2 — Listar las clases y quién hereda de quién
Clase¿Hereda?Qué tiene
Subsystem1NoDos métodos propios: operation1() y operationN()
Subsystem2NoDos métodos propios: operation1() y operationZ()
PantallaNoDos atributos, uno de cada subsistema, y un solo método Operation()
ClientNoRecibe una Pantalla y llama a Operation()

Nadie hereda de nadie. Esa sola observación ya apunta a Facade.

Paso 3 — Las dos preguntas sobre la clase que guarda a otras
  • ¿De quién hereda Pantalla? De nadie.
  • ¿Qué guarda? Un objeto de cada una de dos clases sueltas y distintas.

Y su único método, Operation(), llama en orden a cuatro métodos de los subsistemas y junta todo en un solo resultado. El cliente hace una sola llamada.

Paso 4 — El diagrama
Respuesta

Lenguaje: C#. Patrón: Facade (estructural). Pantalla es la fachada: guarda una referencia a Subsystem1 y otra a Subsystem2, y su método Operation() llama en el orden correcto a las operaciones de los dos subsistemas. El cliente usa solo Pantalla.Operation() y no necesita conocer el subsistema. Las clases del subsistema no heredan de nada en común ni conocen a la fachada.

Es el mismo código de los parciales

Comparalo con el del parcial 2024 (Teoría, sección 3, ejemplo 2): Pantalla es Operador, Subsystem1 es Facturacion y Subsystem2 es Compras, con los mismos Operation1, OperationN y OperationZ. La única diferencia es que acá los subsistemas se le pasan a la fachada desde afuera, y en el parcial la fachada los crea si no se los pasan.

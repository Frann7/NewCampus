1. PHP y las bases de datos

Para qué sirve

Cada vez que alguien pide una página, PHP corre el script desde cero y, al terminar, se olvida de todo: las variables no sobreviven de un pedido al siguiente. Si un comentario tiene que seguir ahí mañana, hay que guardarlo afuera de PHP, en un programa hecho para eso: un Sistema Gestor de Base de Datos (SGBD).

La cátedra lo dice así: PHP es un lenguaje del lado servidor y, como tal, puede conectarse a los distintos SGBD del mercado. En la materia se usa uno solo, MySQL/MariaDB, a través de la extensión mysqli.

El recorrido de un pedido

Cuando alguien entra a una página que lista datos, pasa esto:

Navegador --pide listado.php--> Apache --> PHP corre listado.php
                                             |
                                             | 1. abre la conexión (socket)
                                             | 2. manda el SQL
                                             v
                                       MySQL / MariaDB
                                             |
                                             | 3. devuelve las filas
                                             v
Navegador <--recibe el HTML-- Apache <-- PHP arma el HTML con las filas
                                          y 4. cierra la conexión

El navegador nunca habla con la base: solo recibe el HTML terminado. Por eso las credenciales de la base (usuario y contraseña) pueden estar en el código PHP: ese código no le llega a quien mira la página.

Sintaxis: dos formas de escribir lo mismo

mysqli se puede usar de dos maneras. La teoría de la cátedra usa la primera; la tabla de funciones de la guía y el parcial usan los nombres de la segunda. Hacen exactamente lo mismo: 

// Estilo objetos (el de la teoría)
$mysqli = new mysqli('127.0.0.1', 'root', '', 'Personal');
$resultado = $mysqli->query('SELECT * FROM personas');

// Estilo procedural (el de la guía y el parcial)
$conexion = mysqli_connect('127.0.0.1', 'root', '', 'Personal');
$resultado = mysqli_query($conexion, 'SELECT * FROM personas');
ParteQué es
new mysqli(...)new crea un objeto de la clase mysqli (las clases de PHP se vieron en la Clase 5). Ese objeto es la conexión
$mysqli->query(...)La flecha -> llama a un método (una función que pertenece al objeto). Como el objeto ya es la conexión, no hace falta decirle cuál
mysqli_connect(...)Una función común que abre la conexión y la devuelve
mysqli_query($conexion, ...)Una función común: como no pertenece a ningún objeto, hay que pasarle la conexión como primer parámetro

La regla para pasar de uno a otro: $mysqli->algo(x) se escribe mysqli_algo($mysqli, x). La tabla completa está en la sección 8.

Ejemplo 2 — Verdadero o falso (formato del parcial)

Enunciado

Indicar si cada afirmación es verdadera o falsa.

  1. Una conexión abierta en index.php se puede usar después en listado.php.
  2. La extensión mysqli sirve tanto para MySQL como para MariaDB.
  3. El navegador se conecta a la base de datos para traer las filas.
  4. $mysqli->query($sql) y mysqli_query($mysqli, $sql) hacen lo mismo.
  1. Falso. Cada script corre desde cero y al terminar se pierde todo. Por eso la cátedra dice que la conexión hay que hacerla en cada script que consulte la base.
  2. Verdadero. MariaDB se maneja igual que MySQL.
  3. Falso. La conexión la abre PHP, en el servidor. El navegador solo recibe HTML.
  4. Verdadero. Es el mismo pedido en los dos estilos: en el procedural la conexión va como primer parámetro.
mysqli no es mysql

En internet todavía aparecen ejemplos con mysql_connect() o mysql_query() (sin la i). Esa extensión vieja ya no existe en PHP 7 ni en PHP 8: en el XAMPP actual esas funciones dan "Call to undefined function". Siempre mysqli_.

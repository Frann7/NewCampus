Una empresa tiene dos servidores en centros de datos distintos, uno en Paraná y otro en Santa Fe. Sean \(X\) = “cantidad de caídas del servidor de Paraná en una semana” e \(Y\) = “cantidad de caídas del servidor de Santa Fe en la misma semana”. La función de probabilidad conjunta de \((X, Y)\) es:

\(X \backslash Y\)01
00,300,20
10,180,12
20,120,08

Además, en un servicio con autoescalado se registra cada hora \(U\) = “cambio en la cantidad de réplicas” (\(-1\) si se apaga una, \(0\) si queda igual, \(+1\) si se agrega una) y \(W\) = “1 si el autoescalado actuó en esa hora, 0 si no”. Su distribución conjunta es:

\(U \backslash W\)01
\(-1\)00,25
00,500
100,25
  1. Encuentre las distribuciones marginales de \(X\) y de \(Y\).
  2. ¿Son \(X\) e \(Y\) independientes? Justifique utilizando probabilidades.
  3. Calcule \(E(X)\), \(E(Y)\), \(E(XY)\) y \(Cov(X, Y)\). ¿Qué relación hay entre \(E(XY)\) y \(E(X)\,E(Y)\)?
  4. Encuentre la varianza del total semanal de caídas, \(T = X + Y\).
  5. Para \((U, W)\): calcule \(Cov(U, W)\). ¿Son \(U\) y \(W\) independientes? ¿Qué muestra este caso?

Fundamental · basado en el Segundo Parcial 2023, Ejercicio 1 c, el Segundo Parcial 2025, Ejercicio 1 d y la Guía integradora para el segundo parcial, Ejercicio 2 f y h

La marginal de \(X\) es \(g(0) = 0{,}5\), \(g(1) = 0{,}3\), \(g(2) = 0{,}2\), y la de \(Y\) es \(h(0) = 0{,}6\), \(h(1) = 0{,}4\).

Sí son independientes: en las 6 casillas la conjunta es igual al producto de las marginales, \(f(x,y) = g(x)\,h(y)\) (por ejemplo \(f(1,1) = 0{,}12 = 0{,}3 \cdot 0{,}4\)).

\(E(X) = 0{,}7\) y \(E(Y) = 0{,}4\) caídas por semana; \(E(XY) = 0{,}28\), que es exactamente \(E(X)\,E(Y) = 0{,}7 \cdot 0{,}4\), como pasa con variables independientes, así que \(Cov(X,Y) = 0\).

Como \(Cov(X,Y) = 0\), \(V(T) = V(X) + V(Y) = 0{,}61 + 0{,}24 = 0{,}85\).

\(Cov(U,W) = E(UW) - E(U)\,E(W) = 0 - 0 \cdot 0{,}5 = 0\), pero \(U\) y \(W\) no son independientes porque \(f(0,1) = 0 \neq P(U=0)\,P(W=1) = 0{,}25\). Muestra que una covarianza nula no implica independencia: la covarianza solo mide relación lineal, y acá \(W = U^{2}\).

Variable del inciso d: \(T = X + Y\) = total de caídas en la semana.

Variables del inciso e: \(U\) = cambio en la cantidad de réplicas (\(-1, 0, 1\)); \(W\) = 1 si actuó el autoescalado, 0 si no.

  1. La marginal de \(X\) suma cada fila: \(g(x) = \sum_{y} f(x,y)\). ¿Cuánto vale \(g(0)\)?

    \(g(0) = 0{,}30 + 0{,}20 = 0{,}5\)

    Fila \(x = 0\): \(0{,}30 + 0{,}20\).

    \(g(0) = 0{,}5\). Las otras filas: \(g(1) = 0{,}18 + 0{,}12 = 0{,}3\) y \(g(2) = 0{,}12 + 0{,}08 = 0{,}2\).

    Qué se pide: \(g(0) = P(X = 0)\), la probabilidad de que el servidor de Paraná no se caiga en la semana.

    1. La fórmula. \(X = 0\) puede darse con \(Y = 0\) o con \(Y = 1\); son casos que no se pisan y se suman: \(g(x) = \sum_{y} f(x,y)\), la suma de la fila.
    2. La cuenta. \[ g(0) = f(0,0) + f(0,1) = 0{,}30 + 0{,}20 = 0{,}5 \]
    3. Las otras filas. \(g(1) = 0{,}18 + 0{,}12 = 0{,}3\); \(g(2) = 0{,}12 + 0{,}08 = 0{,}2\).

    Qué significa: la mitad de las semanas el servidor de Paraná no se cae. Control: \(0{,}5 + 0{,}3 + 0{,}2 = 1\).

  2. La marginal de \(Y\) suma cada columna: \(h(y) = \sum_{x} f(x,y)\). ¿Cuánto vale \(h(0)\)?

    \(h(0) = 0{,}30 + 0{,}18 + 0{,}12 = 0{,}6\)

    Columna \(y = 0\): \(0{,}30 + 0{,}18 + 0{,}12\).

    \(h(0) = 0{,}6\) y \(h(1) = 0{,}20 + 0{,}12 + 0{,}08 = 0{,}4\).

    Qué se pide: \(h(0) = P(Y = 0)\), la probabilidad de que el de Santa Fe no se caiga.

    1. La fórmula. \(h(y) = \sum_{x} f(x,y)\): se suma la columna de ese \(y\).
    2. La cuenta. \[ h(0) = 0{,}30 + 0{,}18 + 0{,}12 = 0{,}6 \]
    3. La otra. \(h(1) = 0{,}20 + 0{,}12 + 0{,}08 = 0{,}4\).

    Qué significa: el 60 % de las semanas el de Santa Fe no se cae. Control: \(0{,}6 + 0{,}4 = 1\).

  3. ¿Cuáles son las marginales de \(X\) y de \(Y\)?

    \(g(x) = 0{,}5;\ 0{,}3;\ 0{,}2\ (x = 0, 1, 2); \quad h(y) = 0{,}6;\ 0{,}4\ (y = 0, 1)\)
    • \(g(x)\): \(0{,}5;\ 0{,}3;\ 0{,}2\) · \(h(y)\): \(0{,}6;\ 0{,}4\)
    • \(g(x)\): \(0{,}6;\ 0{,}4\) · \(h(y)\): \(0{,}5;\ 0{,}3;\ 0{,}2\)
    • \(g(x)\): \(0{,}30;\ 0{,}18;\ 0{,}12\) · \(h(y)\): \(0{,}30;\ 0{,}20\)
    • \(g(x)\): \(\frac{1}{3}\) cada una · \(h(y)\): \(\frac{1}{2}\) cada una

    Filas para \(X\), columnas para \(Y\).

    Filas: \(0{,}5;\ 0{,}3;\ 0{,}2\). Columnas: \(0{,}6;\ 0{,}4\). Cada marginal suma 1.

    Qué se pide: las dos marginales, \(g(x) = P(X = x)\) y \(h(y) = P(Y = y)\).

    1. Las fórmulas. \(g(x) = \sum_{y} f(x,y)\) (filas) y \(h(y) = \sum_{x} f(x,y)\) (columnas).
    2. Filas. \(0{,}30 + 0{,}20 = 0{,}5\); \(0{,}18 + 0{,}12 = 0{,}3\); \(0{,}12 + 0{,}08 = 0{,}2\).
    3. Columnas. \(0{,}30 + 0{,}18 + 0{,}12 = 0{,}6\); \(0{,}20 + 0{,}12 + 0{,}08 = 0{,}4\).
    4. Las opciones que no. La segunda cruza las marginales. La tercera toma solo la primera columna y la primera fila, sin sumar. La cuarta supone valores igual de probables.

    Qué significa: ya están las dos tablitas; con ellas se prueba la independencia.

  4. Para probar que \(X\) e \(Y\) son independientes con la tabla, ¿qué hay que verificar?

    Independientes \(\iff f(x,y) = g(x)\,h(y)\) en las 6 casillas
    • Que \(f(x,y) = g(x)\,h(y)\) en todas las casillas (acá, las 6)
    • Que \(f(x,y) = g(x)\,h(y)\) en una casilla cualquiera
    • Que \(Cov(X,Y) = 0\)
    • Que las marginales sumen 1

    Para negar alcanza una casilla que falle; para afirmar, no puede fallar ninguna.

    La definición pide la igualdad para todo par \((x,y)\). Una sola casilla que cumpla no prueba nada; una sola que falle alcanza para negarla.

    Qué se pide: qué tarea hace falta para afirmar la independencia.

    1. La definición. \(X\) e \(Y\) son independientes si la conjunta se factoriza como producto de las marginales para todos los pares: \[ f(x,y) = g(x)\,h(y) \quad \forall (x,y) \]
    2. Probar vs. refutar. Para probar hay que revisar todas las casillas (acá \(3 \times 2 = 6\)). Para refutar alcanza una sola que falle.
    3. Las opciones que no. Una casilla que cumple puede ser casualidad. \(Cov = 0\) no alcanza: la independencia implica covarianza 0, pero no al revés (se ve en el inciso e). Y las marginales suman 1 siempre.

    Qué significa: hay que multiplicar marginal por marginal en las 6 casillas y comparar con la tabla.

  5. Hay independencia si \(f(x,y) = g(x)\,h(y)\) en todas las casillas. Probá en la casilla \((1,1)\): ¿cuánto vale \(g(1) \cdot h(1)\)?

    \(g(1)\,h(1) = 0{,}3 \cdot 0{,}4 = 0{,}12 = f(1,1)\) (coincide)

    \(g(1) = 0{,}3\) (fila 1) y \(h(1) = 0{,}4\) (columna 1).

    \(0{,}3 \cdot 0{,}4 = 0{,}12\), igual a \(f(1,1) = 0{,}12\). Esta casilla cumple.

    Qué se pide: el producto de las marginales en \((1,1)\), para compararlo con la casilla de la tabla.

    1. Las marginales. \(g(1) = 0{,}18 + 0{,}12 = 0{,}3\) (fila \(x = 1\)); \(h(1) = 0{,}20 + 0{,}12 + 0{,}08 = 0{,}4\) (columna \(y = 1\)).
    2. El producto. \[ g(1)\,h(1) = 0{,}3 \cdot 0{,}4 = 0{,}12 \]
    3. La comparación. En la tabla, \(f(1,1) = 0{,}12\). Coinciden.

    Qué significa: una casilla que cumple todavía no prueba nada: hay que seguir con las demás.

  6. Hay independencia si \(f(x,y) = g(x)\,h(y)\) en todas las casillas. En la casilla \((2,0)\), ¿cuánto vale \(g(2) \cdot h(0)\)?

    \(g(2)\,h(0) = 0{,}2 \cdot 0{,}6 = 0{,}12 = f(2,0)\) (coincide)

    \(g(2) = 0{,}2\) y \(h(0) = 0{,}6\).

    \(0{,}2 \cdot 0{,}6 = 0{,}12 = f(2,0)\). Las 6 casillas: \(0{,}5 \cdot 0{,}6 = 0{,}30\); \(0{,}5 \cdot 0{,}4 = 0{,}20\); \(0{,}3 \cdot 0{,}6 = 0{,}18\); \(0{,}3 \cdot 0{,}4 = 0{,}12\); \(0{,}2 \cdot 0{,}6 = 0{,}12\); \(0{,}2 \cdot 0{,}4 = 0{,}08\). Todas coinciden.

    Qué se pide: otra casilla de la verificación, la \((2,0)\).

    1. El producto. \(g(2) = 0{,}12 + 0{,}08 = 0{,}2\) y \(h(0) = 0{,}6\): \(g(2)\,h(0) = 0{,}12\). En la tabla \(f(2,0) = 0{,}12\).
    2. La tabla de productos completa.
      \(g(x)\,h(y)\)\(y = 0\) (\(0{,}6\))\(y = 1\) (\(0{,}4\))
      \(x = 0\) (\(0{,}5\))0,300,20
      \(x = 1\) (\(0{,}3\))0,180,12
      \(x = 2\) (\(0{,}2\))0,120,08
      Es exactamente la tabla del enunciado.

    Qué significa: la igualdad vale en las 6 casillas. En la hoja conviene escribir esta tabla de productos al lado de la conjunta.

  7. ¿Son independientes \(X\) e \(Y\)?

    \(f(x,y) = g(x)\,h(y)\) en las 6 casillas \(\Rightarrow\) son independientes
    • Sí: \(f(x,y) = g(x)\,h(y)\) en las 6 casillas
    • Sí: porque \(f(1,1) = g(1)\,h(1)\)
    • No: porque \(f(0,0) = 0{,}30\) es distinta de \(f(0,1) = 0{,}20\)
    • No se puede saber sin la covarianza

    Multiplicá \(g(x)\,h(y)\) en cada casilla y compará con la tabla.

    Los 6 productos \(g(x)\,h(y)\) reproducen la tabla: son independientes. Tiene sentido: son servidores en centros de datos distintos.

    Qué se pide: decidir y justificar con probabilidades.

    1. El criterio. Independientes si \(f(x,y) = g(x)\,h(y)\) para todos los pares, con \(g = 0{,}5;\ 0{,}3;\ 0{,}2\) y \(h = 0{,}6;\ 0{,}4\).
    2. Las 6 verificaciones. \(0{,}5 \cdot 0{,}6 = 0{,}30\) (coincide), \(0{,}5 \cdot 0{,}4 = 0{,}20\) (coincide), \(0{,}3 \cdot 0{,}6 = 0{,}18\) (coincide), \(0{,}3 \cdot 0{,}4 = 0{,}12\) (coincide), \(0{,}2 \cdot 0{,}6 = 0{,}12\) (coincide), \(0{,}2 \cdot 0{,}4 = 0{,}08\) (coincide).
    3. Las opciones que no. Una casilla sola no alcanza para afirmar. Comparar casillas entre sí no es el criterio. Y la covarianza no decide la independencia.

    Qué significa: son independientes: saber cuántas veces se cayó el de Paraná no cambia las chances del de Santa Fe.

  8. ¿Cuánto vale \(E(X)\)?

    \(E(X) = \sum x\,g(x) = 0 \cdot 0{,}5 + 1 \cdot 0{,}3 + 2 \cdot 0{,}2 = 0{,}7\) caídas

    \(E(X) = \sum x \cdot g(x)\), con \(g = 0{,}5;\ 0{,}3;\ 0{,}2\).

    \(E(X) = 0 + 0{,}3 + 0{,}4 = 0{,}7\) caídas por semana.

    Qué se pide: la cantidad promedio de caídas semanales del servidor de Paraná.

    1. La fórmula. \(E(X) = \sum_{x} x \cdot g(x)\), con la marginal de \(X\).
    2. La cuenta. \[ E(X) = 0 \cdot 0{,}5 + 1 \cdot 0{,}3 + 2 \cdot 0{,}2 = 0{,}7 \]

    Qué significa: en promedio se cae 0,7 veces por semana.

  9. ¿Cuánto vale \(E(Y)\)?

    \(E(Y) = \sum y\,h(y) = 0 \cdot 0{,}6 + 1 \cdot 0{,}4 = 0{,}4\) caídas

    \(E(Y) = \sum y \cdot h(y)\), con \(h = 0{,}6;\ 0{,}4\).

    \(E(Y) = 0{,}4\) caídas por semana.

    Qué se pide: la cantidad promedio de caídas semanales del de Santa Fe.

    1. La fórmula. \(E(Y) = \sum_{y} y \cdot h(y)\).
    2. La cuenta. \[ E(Y) = 0 \cdot 0{,}6 + 1 \cdot 0{,}4 = 0{,}4 \]

    Qué significa: el de Santa Fe se cae menos: 0,4 veces por semana en promedio.

  10. Para \(Cov(X,Y) = E(XY) - E(X)\,E(Y)\) hace falta \(E(XY) = \sum_x \sum_y x \cdot y \cdot f(x,y)\), con la tabla conjunta. ¿Cuánto vale \(E(XY)\)?

    \(E(XY) = 1 \cdot 1 \cdot 0{,}12 + 2 \cdot 1 \cdot 0{,}08 = 0{,}28\)

    Solo aportan las casillas con \(x \neq 0\) e \(y \neq 0\): \((1,1)\) y \((2,1)\).

    \(E(XY) = 0{,}12 + 0{,}16 = 0{,}28\).

    Qué se pide: el promedio del producto \(X \cdot Y\), calculado con la tabla (sin usar todavía la independencia).

    1. La fórmula. \[ E(XY) = \sum_{x}\sum_{y} x \cdot y \cdot f(x,y) \]
    2. Las que aportan. Con \(x = 0\) o \(y = 0\) el producto es 0. Quedan \((1,1)\): \(1 \cdot 1 \cdot 0{,}12 = 0{,}12\) y \((2,1)\): \(2 \cdot 1 \cdot 0{,}08 = 0{,}16\).
    3. La suma. \(E(XY) = 0{,}12 + 0{,}16 = 0{,}28\).

    Qué significa: fijate que \(E(X)\,E(Y) = 0{,}7 \cdot 0{,}4 = 0{,}28\): da lo mismo.

  11. ¿Cuánto vale \(Cov(X,Y)\)?

    \(Cov(X,Y) = E(XY) - E(X)\,E(Y) = 0{,}28 - 0{,}7 \cdot 0{,}4 = 0\)

    \(Cov(X,Y) = E(XY) - E(X)\,E(Y)\).

    \(Cov = 0{,}28 - 0{,}28 = 0\).

    Qué se pide: la covarianza entre las caídas de los dos servidores.

    1. La fórmula. \(Cov(X,Y) = E(XY) - E(X)\,E(Y)\).
    2. Los ingredientes. \(E(XY) = 0{,}28\) (tabla), \(E(X) = 0{,}7\), \(E(Y) = 0{,}4\) (marginales).
    3. La cuenta. \[ Cov(X,Y) = 0{,}28 - 0{,}7 \cdot 0{,}4 = 0{,}28 - 0{,}28 = 0 \]

    Qué significa: no hay relación lineal entre las caídas. Es lo esperable: si son independientes, la covarianza es 0.

  12. En este ejercicio \(E(XY) = 0{,}28\) es igual a \(E(X)\,E(Y) = 0{,}7 \cdot 0{,}4\). ¿Por qué pasa?

    Independientes \(\Rightarrow E(XY) = E(X)\,E(Y) \Rightarrow Cov(X,Y) = 0\)
    • Porque \(X\) e \(Y\) son independientes: con \(f(x,y) = g(x)\,h(y)\), la doble suma se separa en \(\sum x\,g(x) \cdot \sum y\,h(y)\)
    • Porque \(E(XY) = E(X)\,E(Y)\) vale siempre
    • Por casualidad: no tiene que ver con la independencia
    • Porque \(Y\) solo toma los valores 0 y 1

    Reemplazá \(f(x,y)\) por \(g(x)\,h(y)\) en \(\sum\sum x\,y\,f(x,y)\).

    Con independencia, \(\sum_x\sum_y x\,y\,g(x)\,h(y) = \sum_x x\,g(x) \cdot \sum_y y\,h(y) = E(X)\,E(Y)\). Por eso la covarianza da 0.

    Qué se pide: explicar la igualdad \(E(XY) = E(X)\,E(Y)\) que salió en las cuentas.

    1. La demostración de la teoría. Si son independientes, \(f(x,y) = g(x)\,h(y)\). Entonces \[ E(XY) = \sum_{x}\sum_{y} x\,y\,g(x)\,h(y) = \Big(\sum_{x} x\,g(x)\Big)\Big(\sum_{y} y\,h(y)\Big) = E(X)\,E(Y) \] (en el caso continuo es igual, con integrales).
    2. La consecuencia. \(Cov(X,Y) = E(XY) - E(X)\,E(Y) = 0\).
    3. Las opciones que no. No vale siempre: en el Parcial 2025 o en el ejercicio de los tickets, \(E(XY) \neq E(X)\,E(Y)\). No es casualidad: sale de la factorización. Y que \(Y\) sea 0 o 1 no tiene nada que ver.

    Qué significa: independencia \(\Rightarrow\) covarianza 0. La vuelta no vale, y el inciso e lo muestra.

  13. ¿Qué fórmula da \(V(T) = V(X + Y)\) en este caso?

    \(V(X + Y) = V(X) + V(Y) + 2\,Cov(X,Y) = V(X) + V(Y)\) (porque \(Cov = 0\))
    • \(V(X + Y) = V(X) + V(Y)\), porque \(Cov(X,Y) = 0\)
    • \(V(X + Y) = V(X) + V(Y) + 2\,E(X)\,E(Y)\)
    • \(V(X + Y) = [V(X) + V(Y)]^{2}\)
    • \(V(X + Y) = V(X)\,V(Y)\)

    En general \(V(X + Y) = V(X) + V(Y) + 2\,Cov(X,Y)\). ¿Cuánto vale acá la covarianza?

    La fórmula general tiene \(2\,Cov(X,Y)\); con independencia ese término es 0.

    Qué se pide: la fórmula de la varianza de la suma, sabiendo que son independientes.

    1. La fórmula general. \(V(aX + bY + c) = a^{2}V(X) + b^{2}V(Y) + 2ab\,Cov(X,Y)\). Con \(a = b = 1\), \(c = 0\): \(V(X + Y) = V(X) + V(Y) + 2\,Cov(X,Y)\).
    2. Con \(Cov = 0\). El último término se va: \(V(X + Y) = V(X) + V(Y)\).
    3. Las opciones que no. El término cruzado es la covarianza, no \(E(X)\,E(Y)\). Las varianzas se suman, no se elevan ni se multiplican.

    Qué significa: hacen falta \(V(X)\) y \(V(Y)\).

  14. Para \(V(X) = E(X^{2}) - [E(X)]^{2}\) hace falta \(E(X^{2}) = \sum x^{2}\,g(x)\), con \(g = 0{,}5;\ 0{,}3;\ 0{,}2\). ¿Cuánto vale \(E(X^{2})\)?

    \(E(X^{2}) = 0 \cdot 0{,}5 + 1 \cdot 0{,}3 + 4 \cdot 0{,}2 = 1{,}1\)

    Los cuadrados son \(0, 1, 4\).

    \(E(X^{2}) = 0 + 0{,}3 + 0{,}8 = 1{,}1\).

    Qué se pide: el promedio de los cuadrados de \(X\).

    1. La fórmula. \(E(X^{2}) = \sum_{x} x^{2} \cdot g(x)\): el valor al cuadrado, la probabilidad no.
    2. La cuenta. \[ E(X^{2}) = 0^{2} \cdot 0{,}5 + 1^{2} \cdot 0{,}3 + 2^{2} \cdot 0{,}2 = 0 + 0{,}3 + 0{,}8 = 1{,}1 \]

    Qué significa: control: \(1{,}1 \geq 0{,}7^{2} = 0{,}49\).

  15. Para \(V(T) = V(X) + V(Y)\), ¿cuánto vale \(V(X) = E(X^{2}) - [E(X)]^{2}\)?

    \(V(X) = 1{,}1 - 0{,}7^{2} = 1{,}1 - 0{,}49 = 0{,}61\)

    \(E(X^{2}) = 1{,}1\) y \(E(X) = 0{,}7\).

    \(V(X) = 1{,}1 - 0{,}49 = 0{,}61\).

    Qué se pide: la varianza de las caídas de Paraná.

    1. Los ingredientes. \(E(X) = 0{,}7\) y \(E(X^{2}) = 0 \cdot 0{,}5 + 1 \cdot 0{,}3 + 4 \cdot 0{,}2 = 1{,}1\).
    2. La fórmula y la cuenta. \[ V(X) = E(X^{2}) - [E(X)]^{2} = 1{,}1 - 0{,}49 = 0{,}61 \]

    Qué significa: el desvío es \(\sqrt{0{,}61} \approx 0{,}78\) caídas.

  16. Para \(V(T) = V(X) + V(Y)\), ¿cuánto vale \(V(Y) = E(Y^{2}) - [E(Y)]^{2}\)?

    \(E(Y^{2}) = 0 \cdot 0{,}6 + 1 \cdot 0{,}4 = 0{,}4\); \(V(Y) = 0{,}4 - 0{,}4^{2} = 0{,}24\)

    Como \(Y\) vale 0 o 1, \(Y^{2} = Y\) y \(E(Y^{2}) = 0{,}4\).

    \(V(Y) = 0{,}4 - 0{,}16 = 0{,}24\).

    Qué se pide: la varianza de las caídas de Santa Fe.

    1. \(E(Y^{2})\). \(0^{2} \cdot 0{,}6 + 1^{2} \cdot 0{,}4 = 0{,}4\).
    2. La fórmula y la cuenta. \[ V(Y) = E(Y^{2}) - [E(Y)]^{2} = 0{,}4 - 0{,}4^{2} = 0{,}24 \]

    Qué significa: control: no es negativa.

  17. ¿Cuánto vale \(V(T)\), la varianza del total semanal de caídas?

    \(V(T) = V(X) + V(Y) + 2\,Cov(X,Y) = 0{,}61 + 0{,}24 + 0 = 0{,}85\)

    Independencia \(\Rightarrow\) \(Cov = 0\). ¿Vale la vuelta? Mirá la casilla \((0,1)\).

    \(W\) depende totalmente de \(U\) (\(W = U^{2}\)), pero no de forma lineal, y la covarianza solo detecta relaciones lineales. Por eso da 0 sin que haya independencia.

    Qué se pide: decidir la independencia de \((U, W)\) y sacar la conclusión teórica.

    1. La covarianza. \(Cov(U,W) = E(UW) - E(U)\,E(W) = 0 - 0 \cdot 0{,}5 = 0\).
    2. La independencia. En \((0,1)\): \(f(0,1) = 0\) y \(P(U=0)\,P(W=1) = 0{,}25\). Falla en una casilla: no son independientes.

    4. Las opciones que no. Covarianza 0, o \(E(UW) = E(U)\,E(W)\), es lo mismo dicho de dos formas, y ninguna alcanza para afirmar independencia. Y no hay nada que obligue a una covarianza negativa.

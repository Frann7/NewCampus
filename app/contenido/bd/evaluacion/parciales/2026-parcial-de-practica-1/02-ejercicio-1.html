Ejercicio 1: ¿Qué es el lenguaje SQL y para qué se utiliza? Escriba las sentencias específicas que tiene el lenguaje para DDL y para DML.

✓ ResultadosSolo la respuesta

SQL (Structured Query Language) es el lenguaje que usan casi todos los sistemas de bases de datos relacionales para definir la base (tablas, claves y restricciones) y manipular sus datos (consultar, agregar, modificar y borrar). Es no procedimental (se dice qué se quiere, no cómo obtenerlo), trabaja sobre conjuntos de registros y tiene propiedad dual: se usa solo (autocontenido) o embebido en otro lenguaje (huésped).

  • DDL (definición de la estructura): CREATE, ALTER, DROP.
  • DML (manipulación de los datos): SELECT, INSERT, UPDATE, DELETE.

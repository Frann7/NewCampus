Formulario de Personas: validar con una clase y recibir en PHP

La segunda página de sitePoo (ejemplo 9): un formulario con nombre y apellido, correo y documento. Antes de enviarlo, la clase FormPersonas (la de la diapositiva 13) revisa los tres campos y los marca en verde o rojo con mensajes de Bootstrap. Si están bien, los recibe procesoFormulario.php y los muestra en una tabla. Archivos: formPersonas.php, js/formPersonas.js y procesoFormulario.php.

Paso 2 — La expresión regular del correo

            if (nombreyape.value.trim() === '') {
                nombreyape.classList.add('is-invalid');
                nombreyape.classList.remove('is-valid');

            } else {
                nombreyape.classList.add('is-valid');

            }

        const correo = document.getElementById('correo');
        const correoValido = /^[\w-\.]+@([\w-]+\.)+[\w-]{2,4}$/.test(correo.value.trim());

        if (correo.value.trim() === '' || !correoValido) {
            correo.classList.add('is-invalid');
            correo.classList.remove('is-valid');
            formValido = false;
        } else {
            correo.classList.add('is-valid');
            correo.classList.remove('is-invalid');

            documento.classList.add('is-invalid');

            formValido = false;
        } else {
            documento.classList.add('is-valid');
            documento.classList.remove('is-invalid');
        }
        return formValido;
    }

Paso 4 — validoInputsArray() y cambiarEstiloInput() 
    validoInputsArray(){
        this.inputs = Array.from(this.form.elements).filter(element => element.tagName === 'INPUT');
        let formValido = true;
        this.inputs.forEach(input => {
            let esValido = true;
            if (input.id === 'correo') {
                const correoValido = /^[\w-\.]+@([\w-]+\.)+[\w-]{2,4}$/.test(input.value.trim());
                if (input.value.trim() === '' || !correoValido) {
                    esValido = false;
                }
            } else if (input.id === 'nombreyape') {
                if (input.value.trim() === '' || input.value.trim().length < 3) {
                    esValido = false;
                }
            } else if (input.id === 'documento') {
                if (input.value.trim() === '' || input.value.trim().length < 6) {
                    esValido = false;
                }
            } else {
                if (input.value.trim() === '') {
                    esValido = false;
                }
            }
            this.cambiarEstiloInput(input, esValido);
            if (!esValido) {
                formValido = false;
            }
        });
        return formValido;
    }

    cambiarEstiloInput(elemento, esValido) {
        if (esValido) {
            elemento.classList.add('is-valid');
            elemento.classList.remove('is-invalid');
        } else {
            elemento.classList.add('is-invalid');
            elemento.classList.remove('is-valid');
        }
    }

"$_POST" se ve escrito tal cual

El subtítulo dice literalmente "Se reciben los datos desde el array $_POST": está entre comillas simples, y en PHP las simples no reemplazan variables. Con comillas dobles, PHP habría intentado meter el array ahí.

Entrar directo a procesoFormulario.php

Si se abre la dirección sin enviar el formulario, $_POST está vacío, el if no entra y $filas nunca se crea. Al usarla en $body, PHP 8 avisa Warning: Undefined variable $filas (verificado con php.exe) y la tabla sale sin filas. Se evita creando $filas = ""; antes del if.

El navegador valida antes que JavaScript

Como el correo es type="email", si se escribe algo sin arroba (por ejemplo ana), el propio navegador frena el envío con su cartel y el evento submit ni llega a JavaScript. Con ana@mail el navegador lo acepta (para él es un correo válido), pero la expresión regular no, y lo marca en rojo JavaScript.

Qué se ve

En "Formulario de Personas": los tres campos y el botón. Al enviar con errores, la página no cambia: cada campo mal queda con borde rojo y su mensaje ("El campo Correo no puede estar vacío."), y los bien, en verde con "Buen dato!" o "Bien!". Con todo bien, se pasa a "Datos Recibidos del Formulario": una tabla rayada con dos columnas, Indice y Valor, y una fila por campo.

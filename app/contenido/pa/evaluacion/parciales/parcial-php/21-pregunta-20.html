Qué evalúa

Qué muestra var_dump(). Aparece en la Clase 1 (“muestra el tipo y valor de una variable”) y se usa en la práctica de la Clase 2 para ver arrays.

El concepto, desde cero

Una variable es una caja con nombre que guarda un valor, y todo valor tiene un tipo: qué clase de dato es.

TipoQué esEjemplo
intNúmero entero.5
floatNúmero con decimales (se escriben con punto).2.5
stringTexto (cadena de caracteres), entre comillas."hola"
boolBooleano: solo true (verdadero) o false (falso).true
arrayVarios valores juntos, cada uno con su clave.array(1, 'a' => 2.5)

Una función es una instrucción con nombre que ya viene hecha en PHP; se la usa escribiendo el nombre y, entre paréntesis, el dato con el que tiene que trabajar. var_dump($x) (dump = volcar) sirve para depurar (buscar errores mirando qué tiene cada variable): muestra el tipo y el valor, y si es un array, su estructura: cuántos elementos tiene y la clave, el tipo y el valor de cada uno.

Un ejemplo

<?php
var_dump(5);
var_dump("hola");
var_dump(true);
var_dump(array(1, 'a' => 2.5));
?>
int(5)
string(4) "hola"
bool(true)
array(2) {
  [0]=>
  int(1)
  ["a"]=>
  float(2.5)
}
LíneaQué muestraCómo se lee
var_dump(5);int(5)Tipo int (entero), valor 5.
var_dump("hola");string(4) "hola"Tipo string; el 4 es el largo (cantidad de caracteres); después, el valor.
var_dump(true);bool(true)Tipo bool, valor true.
var_dump(array(1, 'a' => 2.5));array(2) { … }Un array de 2 elementos. Entre las llaves, cada elemento: su clave entre corchetes ([0], puesta sola porque el 1 no tenía clave; ["a"], escrita en el código), =>, y abajo su tipo y valor (int(1), float(2.5)).

Para comparar: echo muestra solo el valor (y con un array no sirve: imprime la palabra Array y un aviso Array to string conversion), y print_r muestra la estructura pero sin los tipos ([a] => 2.5). Salidas comprobadas en PHP 8.2.

Respuesta

Verdadero. La afirmación nombra justo las tres cosas que muestra: estructura, tipo y valor.

La trampa

Confundirla con print_r, que también muestra la estructura pero no dice el tipo de cada valor.

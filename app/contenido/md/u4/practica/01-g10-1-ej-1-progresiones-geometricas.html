Grimaldi 10.1 · Ej. 1 · RR de una progresión geométrica

Una relación de recurrencia para cada progresión geométrica

Encuentre una relación de recurrencia, con una condición inicial, que determine de manera única cada una de las siguientes progresiones geométricas.

a) \(2, 10, 50, 250, \dots\)    b) \(6, -18, 54, -162, \dots\)    c) \(1, 1/3, 1/9, 1/27, \dots\)    d) \(7, 14/5, 28/25, 56/125, \dots\)

Qué tema es y por qué
  • Una progresión geométrica es una lista donde cada término sale de multiplicar el anterior siempre por el mismo número, la razón \(d\).
  • Eso, escrito como regla, es la relación de recurrencia lineal homogénea de primer orden (en la teoría de esta unidad): cada término depende solo del anterior.
  • "Con una condición inicial" pide además el primer término: sin él, la misma regla genera infinitas listas distintas.
La regla que se usa en los cuatro incisos

\[ a_n = d\,a_{n-1},\ \forall n \geq 1,\qquad a_0 = A \qquad\Longrightarrow\qquad a_n = A\,d^{\,n},\ \forall n \geq 0 \]

La razón se saca dividiendo un término por el anterior: \(d = \dfrac{a_1}{a_0}\). Se controla con otro par: \(\dfrac{a_2}{a_1}\) tiene que dar lo mismo.

Se numera desde \(a_0\): el primer número de la lista es \(a_0\), el segundo \(a_1\), y así.

Paso 1 — Inciso a): \(2, 10, 50, 250, \dots\)
  • Razón: \(d = \dfrac{10}{2} = 5\). Control: \(\dfrac{50}{10} = 5\), \(\dfrac{250}{50} = 5\). Es geométrica.
  • Regla \(a_n = d\,a_{n-1}\) con \(d = 5\) y \(a_0 = 2\):

\[ a_n = 5\,a_{n-1},\ \forall n \geq 1,\quad a_0 = 2 \]

Paso 2 — Inciso b): \(6, -18, 54, -162, \dots\)
  • Razón: \(d = \dfrac{-18}{6} = -3\). Control: \(\dfrac{54}{-18} = -3\). El signo que alterna es la señal de una razón negativa.
  • Regla \(a_n = d\,a_{n-1}\) con \(d = -3\) y \(a_0 = 6\):

\[ a_n = -3\,a_{n-1},\ \forall n \geq 1,\quad a_0 = 6 \]

Paso 3 — Inciso c): \(1, 1/3, 1/9, 1/27, \dots\)
  • Razón: \(d = \dfrac{1/3}{1} = \dfrac{1}{3}\). Control: \(\dfrac{1/9}{1/3} = \dfrac{1}{9} \cdot 3 = \dfrac{1}{3}\).
  • Regla \(a_n = d\,a_{n-1}\) con \(d = 1/3\) y \(a_0 = 1\):

\[ a_n = \tfrac{1}{3}\,a_{n-1},\ \forall n \geq 1,\quad a_0 = 1 \qquad(\text{o también } 3a_n = a_{n-1}) \]

Paso 4 — Inciso d): \(7, 14/5, 28/25, 56/125, \dots\)
  • Razón: \(d = \dfrac{14/5}{7} = \dfrac{14}{35} = \dfrac{2}{5}\). Control: \(\dfrac{28/25}{14/5} = \dfrac{28}{25} \cdot \dfrac{5}{14} = \dfrac{2}{5}\).
  • Regla \(a_n = d\,a_{n-1}\) con \(d = 2/5\) y \(a_0 = 7\):

\[ a_n = \tfrac{2}{5}\,a_{n-1},\ \forall n \geq 1,\quad a_0 = 7 \]

Paso 5 — Comprobación con la fórmula

Con \(a_n = A\,d^{\,n}\) salen las listas del enunciado:

IncisoFórmula\(n = 0, 1, 2, 3\)
a\(a_n = 2 \cdot 5^{n}\)\(2,\ 10,\ 50,\ 250\)
b\(a_n = 6\,(-3)^{n}\)\(6,\ -18,\ 54,\ -162\)
c\(a_n = (1/3)^{n}\)\(1,\ 1/3,\ 1/9,\ 1/27\)
d\(a_n = 7\,(2/5)^{n}\)\(7,\ 14/5,\ 28/25,\ 56/125\)
Respuesta

a) \(a_n = 5a_{n-1},\ n \geq 1,\ a_0 = 2\).   b) \(a_n = -3a_{n-1},\ n \geq 1,\ a_0 = 6\).

c) \(a_n = \tfrac13 a_{n-1},\ n \geq 1,\ a_0 = 1\).   d) \(a_n = \tfrac25 a_{n-1},\ n \geq 1,\ a_0 = 7\).

Solución del libro

El libro da a) \(a_n = 5a_{n-1},\ a_0 = 2\) y b) \(a_n = -3a_{n-1},\ a_0 = 6\), que coinciden. Lo que rotula "(c)" es \(a_n = (2/5)a_{n-1},\ a_0 = 7\): es la respuesta del inciso d) (coincide). La del inciso c) no la da; queda la verificación de la tabla.

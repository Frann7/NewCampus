Ejercicio 3 · print_r

Agregar print_r() para ver la estructura

Edite el script del punto 2 y agregue la función print_r() para ver el contenido y la estructura del arreglo $dias_semana.

Paso 1 — Qué pide

Al script del ejercicio 2 se le agrega al final un print_r($dias_semana), que muestra cada clave con su valor (teoría, sección 3).

Paso 2 — El código 
<?php
$dias_semana = array('Domingo', 'Lunes', 'Martes', 'Miércoles', 'Jueves', 'Viernes', 'Sábado');
foreach ($dias_semana as $un_dia) {
    echo $un_dia . "<br />";
}
print_r($dias_semana);
?>
Paso 3 — Qué hace cada línea
LíneaQué haceCómo quedan las variables
$dias_semana = array(...);El arreglo de siempre0 => Domingo … 6 => Sábado
foreach (...) { echo ...; }Igual que el ejercicio 2: un día por línea$un_dia toma los 7 valores
print_r($dias_semana);Imprime Array y cada [clave] => valor(no cambia nada)

Por qué la última línea sale así: print_r genera varias líneas con sangría, pero sin <br />; el navegador junta esos saltos en espacios y lo muestra todo seguido (teoría, sección 3). Generado por PHP, el texto es:

Ejercicio 5

20 puntos Unidad 3 · Distribución conjunta continua, marginales e independencia

En un análisis sobre el uso de recursos en algoritmos de procesamiento de imágenes, se estudian dos variables aleatorias: \(X\): uso promedio de CPU durante el procesamiento (en núcleos), \(Y\): cantidad de memoria RAM utilizada (en GB). La función de densidad de probabilidad conjunta es:

\[ f(x,y) = \begin{cases} c\,(x + 2y) & \text{si } 0 \leq x \leq 2;\ 1 \leq y \leq 3 \\ 0 & \text{en o.c.} \end{cases} \]

  1. Obtener el valor de la constante \(c\) para que \(f\) sea una función de densidad de probabilidad conjunta.
  2. Determinar las funciones marginales de probabilidad de las variables. ¿Son independientes \(X\) e \(Y\)? Justifique.
  3. ¿Cuál es la probabilidad de que el uso de CPU supere los 2 núcleos y la memoria utilizada sea menor a 1 GB?
  4. Hallar \(P(Y < 1)\). Interprete en el contexto del problema.

El enunciado, otra vez

\(X\): uso de CPU (núcleos); \(Y\): memoria RAM (GB). Densidad conjunta \(f(x,y) = c\,(x + 2y)\) para \(0 \leq x \leq 2\), \(1 \leq y \leq 3\), y 0 fuera de ahí. Piden \(c\), las marginales, si son independientes, \(P(X > 2,\ Y < 1)\) y \(P(Y < 1)\).

¿De qué tema es?

Unidad 3: distribución conjunta de dos variables continuas. Se resuelve con integrales dobles. Los incisos c y d tienen trampa: las dos dan 0 sin hacer ninguna integral.

Los conceptos que hacen falta, desde cero

1. Propiedades de una densidad conjunta

\[ f(x,y) \geq 0 \qquad\text{y}\qquad \int_{-\infty}^{\infty}\int_{-\infty}^{\infty} f(x,y)\,dy\,dx = 1 \]

Fuera de la zona indicada \(f = 0\), así que la integral se hace solo sobre el rectángulo \(0 \leq x \leq 2\), \(1 \leq y \leq 3\). La constante \(c\) es el número que hace que esa integral dé 1.

2. Marginales

\[ g(x) = \int f(x,y)\,dy \qquad\qquad h(y) = \int f(x,y)\,dx \]

Para quedarte con la distribución de una sola variable, “borrás” la otra integrando sobre todo su recorrido. Para \(g(x)\) se integra en \(y\) (y la \(x\) se trata como un número fijo).

3. Independencia

\[ X \text{ e } Y \text{ son independientes} \iff f(x,y) = g(x)\,h(y) \text{ para todo } (x,y) \]

Si falla en un solo punto, no son independientes.

4. Las dos reglas de integración que se usan
  • Potencia: \(\displaystyle\int t^{k}\,dt = \frac{t^{k+1}}{k+1}\). Por ejemplo \(\int y\,dy = \dfrac{y^2}{2}\) y \(\int 1\,dy = y\).
  • Barrow: \(\displaystyle\int_a^b F'(t)\,dt = F(b) - F(a)\): se reemplaza el límite de arriba, el de abajo, y se restan.

Las constantes (como \(c\), o la \(x\) cuando se integra en \(y\)) salen afuera de la integral.

El rectángulo donde \(f\) es positiva, y las zonas que preguntan los incisos c y d:

Inciso a — La constante \(c\)

Fórmula (la integral total tiene que dar 1):

\[ \int_{0}^{2}\int_{1}^{3} c\,(x + 2y)\,dy\,dx = 1 \]

Paso 1 — La integral de adentro, en \(y\) (la \(x\) es un número fijo):

\[ \int_{1}^{3} (x + 2y)\,dy = \Big[\,x\,y + y^2\,\Big]_{1}^{3} = (3x + 9) - (x + 1) = 2x + 8 \]

Por qué: \(\int x\,dy = x\,y\) (la \(x\) es constante) y \(\int 2y\,dy = 2 \cdot \tfrac{y^2}{2} = y^2\). Después Barrow: con \(y = 3\) queda \(3x + 9\); con \(y = 1\), \(x + 1\); se restan.

Paso 2 — La integral de afuera, en \(x\):

\[ \int_{0}^{2} (2x + 8)\,dx = \Big[\,x^2 + 8x\,\Big]_{0}^{2} = (4 + 16) - 0 = 20 \]

Paso 3 — Despejar:

\[ c \cdot 20 = 1 \quad\Longrightarrow\quad c = \frac{1}{20} = 0{,}05 \]

Además \(x + 2y > 0\) en todo el rectángulo, así que \(f \geq 0\). ✓

Respuesta a

\(c = \dfrac{1}{20}\), y queda \(f(x,y) = \dfrac{x + 2y}{20}\) en el rectángulo.

Inciso b — Marginales e independencia

Fórmula de la marginal de \(X\):

\[ g(x) = \int_{1}^{3} f(x,y)\,dy \]

Es la misma integral en \(y\) del inciso a, dividida por 20:

\[ g(x) = \frac{1}{20}\int_{1}^{3} (x + 2y)\,dy = \frac{2x + 8}{20} = \frac{x + 4}{10} \qquad 0 \leq x \leq 2 \]

Fórmula de la marginal de \(Y\):

\[ h(y) = \int_{0}^{2} f(x,y)\,dx \]

Ahora la \(y\) es la constante: \(\int x\,dx = \tfrac{x^2}{2}\) y \(\int 2y\,dx = 2y\,x\).

\[ h(y) = \frac{1}{20}\Big[\,\frac{x^2}{2} + 2y\,x\,\Big]_{0}^{2} = \frac{1}{20}\,(2 + 4y) = \frac{1 + 2y}{10} \qquad 1 \leq y \leq 3 \]

Control: cada marginal integra 1. \(\int_0^2 \frac{x+4}{10}dx = \frac{2 + 8}{10} = 1\) ✓ y \(\int_1^3 \frac{1+2y}{10}dy = \frac{(3 + 9) - (1 + 1)}{10} = 1\) ✓

Independencia. Se multiplica \(g(x)\,h(y)\) y se compara con \(f(x,y)\):

\[ g(x)\,h(y) = \frac{(x + 4)(1 + 2y)}{100} \qquad\text{vs.}\qquad f(x,y) = \frac{x + 2y}{20} \]

No son la misma función. Alcanza con un punto, por ejemplo \((x, y) = (0, 1)\):

\[ g(0)\,h(1) = \frac{4}{10} \cdot \frac{3}{10} = 0{,}12 \qquad\qquad f(0, 1) = \frac{0 + 2}{20} = 0{,}10 \]

Respuesta b

\(g(x) = \dfrac{x + 4}{10}\) para \(0 \leq x \leq 2\) y \(h(y) = \dfrac{1 + 2y}{10}\) para \(1 \leq y \leq 3\) (0 fuera de esos intervalos). \(X\) e \(Y\) no son independientes, porque \(f(x,y) \neq g(x)\,h(y)\): en \((0, 1)\) da 0,10 contra 0,12.

Inciso c — CPU mayor a 2 núcleos y RAM menor a 1 GB

Fórmula: la probabilidad de una zona es la integral de \(f\) sobre esa zona.

\[ P(X > 2,\ Y < 1) = \int_{2}^{\infty}\int_{-\infty}^{1} f(x,y)\,dy\,dx \]

Mirá el gráfico: \(f\) es positiva solo con \(x \leq 2\) e \(y \geq 1\). La zona pedida (\(x > 2\) y \(y < 1\)) no toca el rectángulo: ahí \(f = 0\) y la integral da 0.

Respuesta c

\(P(X > 2,\ Y < 1) = 0\): es imposible, el uso de CPU nunca supera los 2 núcleos ni la memoria baja de 1 GB.

Inciso d — \(P(Y < 1)\) e interpretación

Con la marginal de \(Y\). Fórmula:

\[ P(Y < 1) = \int_{-\infty}^{1} h(y)\,dy \]

\(h(y)\) es positiva solo entre 1 y 3; debajo de 1 vale 0. Entonces \(P(Y < 1) = 0\).

Respuesta d

\(P(Y < 1) = 0\). Interpretación: es imposible que un algoritmo de procesamiento de imágenes use menos de 1 GB de memoria RAM; según el modelo, siempre usa entre 1 y 3 GB.

Las trampas de este ejercicio
  1. Integrar sin mirar los límites: en c y d no hay nada que integrar; lo primero es ubicar la zona respecto del rectángulo.
  2. En la marginal, integrar en la variable equivocada: \(g(x)\) se obtiene integrando en \(y\).
  3. Olvidar el recorrido de cada marginal (\(0 \leq x \leq 2\), \(1 \leq y \leq 3\)).
  4. Justificar la independencia con una frase sin cuentas: hay que mostrar que el producto no da \(f\).

Palabras con una cantidad par de letras a

Sea el alfabeto \(\Sigma = \{a, b, c\}\) y sea \(S_n\) el conjunto de palabras de longitud \(n\), formadas con las letras de \(\Sigma\), en las que todas las veces que aparece la letra \(a\) lo hace un número par de veces. Encontrar una relación de recurrencia para calcular \(S_n\) y resolverla.

Qué tema es y por qué
  • Se cuentan palabras con una condición: plantear mirando la última letra.
  • "La \(a\) aparece un número par de veces" incluye 0 veces (0 es par): \(bcb\) sirve, \(aab\) sirve, \(abc\) no.
  • \(S_n\) es un conjunto; lo que se cuenta es su cantidad de elementos. Se llama \(s_n = |S_n|\).
  • Sale una relación de primer orden no homogénea.
Desarme del enunciado
FraseQué significaLa cuentaA dónde va

Paso 1 — Mirar la última letra
  • Termina en \(b\) o en \(c\) (2 opciones). No agrega \(a\): lo anterior tiene que tener cantidad par. \(2\,s_{n-1}\).
  • Termina en \(a\). Agrega una \(a\): lo anterior tiene que tener cantidad impar, para que al sumar una quede par. Las de largo \(n - 1\) con impar son todas menos las de par: \(3^{n-1} - s_{n-1}\).

\[ s_n = 2s_{n-1} + \left(3^{n-1} - s_{n-1}\right) = s_{n-1} + 3^{n-1},\ \forall n \geq 1,\qquad s_0 = 1 \]

(\(s_0 = 1\): la palabra vacía tiene 0 letras \(a\). Control: \(s_1 = 1 + 1 = 2\), las palabras \(b\) y \(c\).)

Paso 2 — Resolver

\(s_n = s_n^{(h)} + s_n^{(p)}\); para \(k \cdot r^{n}\) se propone \(A\,r^{n}\) (por \(n\) si choca con la homogénea).

  • Homogénea \(s_n = s_{n-1}\): \(s_n^{(h)} = C\).
  • \(g(n) = 3^{n-1} = \tfrac13\,3^{n}\) \(\to s_n^{(p)} = A\,3^{n}\) (no choca: 3 no es raíz).
  • Reemplazando: \(A\,3^{n} - A\,3^{n-1} = 3^{n-1}\). Dividiendo por \(3^{n-1}\): \(3A - A = 1 \Rightarrow A = \tfrac12\).
  • Completa: \(s_n = C + \tfrac12 3^{n}\). Con \(s_0 = 1\): \(C + \tfrac12 = 1 \Rightarrow C = \tfrac12\).

\[ s_n = |S_n| = \frac{3^{n} + 1}{2},\ \forall n \geq 0 \]

Paso 3 — Comprobación

Contando todas las palabras con un programa: \(1, 2, 5, 14, 41, 122, 365\) para \(n = 0, \dots, 6\). La relación y la fórmula dan lo mismo (por ejemplo, \(n = 2\): \(\tfrac{9 + 1}{2} = 5\): \(aa, bb, bc, cb, cc\)).

Respuesta

\(s_n = s_{n-1} + 3^{n-1},\ n \geq 1,\ s_0 = 1\), con solución \(s_n = \dfrac{3^{n} + 1}{2}\).

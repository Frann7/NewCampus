Pregunta 12

Unidad 8 · Conclusión del IC de una diferencia

Seleccione una:

Se compara el tiempo medio de respuesta del servidor A y del servidor B. El intervalo del 95 % para \(\mu_A - \mu_B\) dio \((-7{,}4\ ;\ -1{,}8)\) ms. ¿Qué se concluye?

  1. Hay diferencia significativa: el servidor A tiene menor tiempo medio de respuesta que el B.
  2. Hay diferencia significativa: el servidor A tiene mayor tiempo medio de respuesta que el B.
  3. No hay diferencia significativa, porque los dos límites son negativos.
  4. No se puede concluir nada sin conocer las medias muestrales.
✓ ResultadosSolo la respuesta

Correcta: a — Hay diferencia significativa: el servidor A tiene menor tiempo medio de respuesta que el B.

✎ Explicación detalladaDe dónde sale, la cuenta y las trampas

Qué evalúa

Leer la conclusión de un intervalo para \(\mu_1 - \mu_2\) mirando el 0 y el signo.

Por qué

  • El grupo 1 es el que se nombra primero: acá A. El intervalo es para \(\mu_A - \mu_B\).
  • ¿Incluye el 0? No: va de \(-7{,}4\) a \(-1{,}8\). Entonces hay diferencia significativa.
  • Todo negativo → \(\mu_A - \mu_B < 0\) → \(\mu_A < \mu_B\): A tiene menor tiempo medio.

Trampas

  • Negativo no quiere decir “no hay diferencia”: lo que dice “no hay diferencia” es que el intervalo incluya el 0.
  • El intervalo ya alcanza para concluir; las medias muestrales no hacen falta.

Qué evalúa

Qué es un motor de JavaScript y cuáles son los de los navegadores grandes.

La idea

Un motor de JavaScript es el programa que lee el código JS y lo ejecuta. Cada navegador trae el suyo:

MotorDónde está
V8Google Chrome, Edge y Node.js
SpiderMonkeyFirefox (el primer motor de JS, de Netscape)
JavaScriptCore (Nitro)Safari

Opción por opción

Opción¿Va?Por qué
PyPyNoEs un intérprete de Python, no de JavaScript.
V8SíEl de Chrome y Node.js.
SpiderMonkeySíEl de Firefox.
JVMNoLa Java Virtual Machine ejecuta Java (Java y JavaScript son lenguajes distintos).
JavaScriptCore (Nitro)SíEl de Safari.

Trampas

  • Son tres correctas. En el Aula Virtual cada correcta marcada suma un tercio y cada incorrecta resta lo mismo: marcar JVM “por las dudas” cuesta puntos.
  • JVM tienta por el nombre “Java”, pero Java no es JavaScript.

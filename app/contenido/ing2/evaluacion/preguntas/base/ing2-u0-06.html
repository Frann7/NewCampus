¿Qué imprime este programa?

#include <iostream>
#include <string>

class Animal {
public:
    virtual ~Animal() {}
    virtual std::string hablar() const { return "..."; }
};

class Perro : public Animal {
public:
    std::string hablar() const override { return "Guau"; }
};

int main() {
    Animal* a = new Perro();
    std::cout << a->hablar() << "\n";
    delete a;
    return 0;
}

Inventada · Base, sección 4

  • ...
  • Guau
  • No compila: un Animal* no puede apuntar a un Perro.
  • ...Guau

El puntero es de tipo Animal*, pero el objeto que se creó es un Perro. Como hablar() es virtual, se ejecuta la versión de la clase real del objeto: imprime Guau. Eso es el polimorfismo, y todos los patrones se apoyan en él: se trabaja con un puntero a la clase base o a la interfaz sin saber qué clase concreta hay detrás.

Ejemplo 5 · pForm3.html + procesoFormulario.php

Validar con JavaScript y enviar a PHP

El ejemplo 4 terminado: si falta algo, avisa; si está todo, envía el formulario a PHP, que muestra lo que recibió. Es el primer ejemplo donde se conectan las tres partes: HTML (los campos), JavaScript (la validación, en el navegador) y PHP (el proceso, en el servidor). Archivos: pForm3.html, js/pForm3Class.js y php/procesoFormulario.php.

Paso 2 — El JavaScript: validar y enviar 
class IndexClass {

    constructor() {
        this.formulario = document.getElementById('formulario');
        this.txtNombre = document.getElementById('txtNombre');
        this.txtApellido = document.getElementById('txtApellido');
        this.txtEdad = document.getElementById('txtEdad');
        this.txtDireccion = document.getElementById('txtDireccion');
        this.btEnvioFormulario = document.getElementById('btEnvioFormulario');
    }

    init() {
        this.addEventListeners();
    }

    addEventListeners() {
        this.btEnvioFormulario.addEventListener('click', () => {
            const datosValidos = this.validoDatos();
            if (datosValidos===true) {
                this.formulario.action='php/procesoFormulario.php';
                this.formulario.method='POST';
                this.formulario.submit();
            }
        });
    }

    validoDatos() {
        let nombre = this.txtNombre.value;
        let apellido = this.txtApellido.value;
        let edad = this.txtEdad.value;
        let direccion = this.txtDireccion.value;

        let datosValidos=true;

        if (nombre === '') {
            alert('El nombre es obligatorio');
            this.txtNombre.focus();
            return false;
        }

        if (apellido === '') {
            alert('El apellido es obligatorio');
            this.txtApellido.style.borderColor = 'red';
            this.txtApellido.focus();
            return false;
        }

        if (edad === '') {
            alert('La edad es obligatoria');
            this.txtEdad.style.borderColor = 'red';
            this.txtEdad.focus();
            return false;
        }

        if (direccion === '') {
            alert('La dirección es obligatoria');
            this.txtDireccion.style.borderColor = 'red';
            this.txtDireccion.focus();
            return false;
        }

        return datosValidos;
    }
}

window.addEventListener('load',() => {
    new IndexClass().init();
})

LíneaQué haceCómo quedan las variables
echo "<h1>Datos recibidos</h1>";Imprime el título—
foreach ($_POST as $clave => $valor)Recorre todo lo que llegó por POST. Las claves son los name de los campos, en el orden del formulario1ra vuelta: $clave = 'nombre', $valor = 'Ana'...
echo "<p>$clave: $valor</p>";Comillas dobles: PHP reemplaza las dos variables. Un párrafo por campo—

Si el usuario envió Ana, Paz, 20 y Urquiza 100, el PHP imprime (verificado con php.exe, cargando esos datos en $_POST):

<h1>Datos recibidos</h1><p>nombre: Ana</p><p>apellido: Paz</p><p>edad: 20</p><p>direccion: Urquiza 100</p>

En el navegador se ve el título grande "Datos recibidos" y abajo un párrafo por campo: "nombre: Ana", "apellido: Paz", "edad: 20", "direccion: Urquiza 100". Fijate que dice direccion sin tilde: es el name del campo, no el placeholder.

Paso 4 — El recorrido completo
  1. El navegador pide pForm3.html y su .js. Al cargar, la clase engancha el botón.
  2. El usuario completa los campos y aprieta "Envío Datos". JavaScript, en su computadora, valida.
  3. Si falta algo: cartel y cursor en el campo. No se envía nada y el servidor no se entera.
  4. Si está todo: JavaScript pone action y method y llama a submit(). El navegador manda los cuatro name = valor por POST.
  5. PHP, en el servidor, recorre $_POST y devuelve el HTML del paso 3, que reemplaza a la página.
Validar en JavaScript no alcanza

La validación de JavaScript es una comodidad para el usuario, no una protección: corre en su navegador, y cualquiera puede desactivarla o mandar datos a procesoFormulario.php sin pasar por esta página. Este PHP imprime lo que llega sin revisarlo.

Hace falta Apache

Abriendo pForm3.html con doble clic la validación anda, pero el envío no: el .php solo se ejecuta si lo sirve Apache (XAMPP, por http://localhost/...).

Qué se ve

Con algún campo vacío, lo mismo que el ejemplo 4. Con todo completo, la página cambia a "Datos recibidos" con un renglón name: valor por campo.

11. while y do...while

Para qué sirve

Las estructuras iterativas (o bucles, o ciclos) ejecutan una o más líneas de código varias veces. Cada repetición se llama vuelta o iteración. Las de PHP son while, do...while, for y foreach (esta última se ve con los arrays, en la clase 2).

while y do...while repiten mientras la condición sea verdadera. La única diferencia es cuándo se pregunta.

Sintaxis

while (condición) {
    sentencia_1;
    sentencia_2;
}

do {
    sentencia_1;
    sentencia_2;
} while (condición);

Qué es cada parte

ParteQué es
while (condición) { }Pregunta antes de cada vuelta. Si la condición es falsa desde el principio, no ejecuta ni una vez.
do { } while (condición);Ejecuta la vuelta y pregunta al final. Por eso siempre se ejecuta al menos una vez. Lleva ; después del paréntesis.
la condiciónIgual que en el if. Mientras dé true, sigue; cuando da false, sale.
el incrementoAlguna línea de adentro tiene que cambiar la variable de la condición (por ejemplo $i++;). Si no, la condición nunca se vuelve falsa: bucle infinito.

Ejemplo 1 — Contar del 1 al 3 con while

<?php
$i = 1;
while ($i <= 3) {
    echo $i . " ";
    $i++;
}
echo "Fin: " . $i;
?>

Al salir, $i vale 4, no 3: el bucle termina justamente porque $i pasó el límite.

El ejemplo del apunte es igual, con $i de 0 a 9 y echo "Esta es la línea ".$i;. Como no imprime ni un espacio ni un <br>, sale todo pegado: Esta es la línea 0Esta es la línea 1Esta es la línea 2... hasta la 9.

Ejemplo 2 — Con formato del Parcial PHP: while contra do...while

<?php
$i = 10;
while ($i < 10) {
    echo "while ";
    $i++;
}
do {
    echo "do-while ";
    $i++;
} while ($i < 10);
echo $i;
?>

Con la misma condición falsa, el while no hizo nada y el do...while hizo una vuelta.

a. Bucle infinito.

Errores y trampas

"Hasta que" o "mientras"

El apunte dice que estos bucles ejecutan "hasta que la condición se evalúe como verdadera". Es al revés: repiten mientras la condición sea verdadera, y salen cuando se vuelve falsa.

do...while con paréntesis

El apunte escribe }while{condicion}, con llaves. Así da Parse error: syntax error, unexpected token "{", expecting "(". La condición va entre paréntesis y con punto y coma: } while ($i < 10);.

Contar las vueltas en el borde

$i < 10 empezando en 0 da 10 vueltas (0 a 9); $i <= 10 da 11 (0 a 10). Siempre probá a mano la primera y la última vuelta.

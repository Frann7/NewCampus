Arreglos

1. Qué es un arreglo y cómo se crea

Para qué sirve

Una variable común guarda un dato: $dia = 'Lunes';. Si tenés que guardar los siete días de la semana, con variables comunes necesitarías siete ($dia1, $dia2…). Un arreglo (en inglés array, la palabra que usa la cátedra y PHP) guarda muchos datos bajo un solo nombre.

La definición de la cátedra, desarmada:

  • Un arreglo es una colección ordenada de elementos.
  • Cada elemento tiene un valor (el dato guardado)…
  • …y una clave única que lo identifica dentro del arreglo (su "dirección").

Se lo puede imaginar como una tabla de dos columnas:

ClaveValor
0'Domingo'
1'Lunes'
2'Martes'

Lo que tienen de particular los arreglos de PHP

  • No se declara ni el tipo ni el tamaño. El arreglo crece solo a medida que le agregás elementos.
  • Puede mezclar tipos: en el mismo arreglo puede haber números, textos, booleanos y hasta otros arreglos.
  • La clave puede ser un número entero o un texto. Si no la ponés, PHP usa números automáticos que empiezan en 0.
  • Puede tener una dimensión (un vector), dos (una matriz) o las que hagan falta (sección 4).

Dos nombres que vas a ver mucho

NombreQué claves tieneEjemplo
Arreglo indexadoNúmeros (0, 1, 2…), casi siempre puestos por PHParray('rojo', 'azul')
Arreglo asociativoTextos elegidos por vos, que asocian un nombre a cada datoarray('apellido' => 'Gomez')

Sintaxis

Hay dos formas de crear un arreglo.

Forma 1: con array() (o con corchetes, que es lo mismo) 
$arreglo = array(valor1, valor2, valor3);
$arreglo = array(clave1 => valor1, clave2 => valor2);
$arreglo = array();
$arreglo = ['rojo', 'azul'];
Forma 2: agregando de a un elemento con [] 
$arreglo[] = valor;          // PHP elige la clave
$arreglo['clave'] = valor;   // la clave la elegís vos

Qué es cada parte

ParteQué es
array( ... )El constructor: crea el arreglo con los elementos que van entre paréntesis, separados por comas
[ ... ]Forma corta de array( ... ): ['rojo', 'azul'] es igual a array('rojo', 'azul')
clave => valorUn elemento con su clave elegida. La flecha => se lee "apunta a"
array() vacíoUn arreglo sin elementos, listo para irle agregando
$arreglo[] = valor;Agrega valor al final, con la clave numérica siguiente. Si la variable no existía, la crea como arreglo
$arreglo['c'] = valor;Guarda valor en la clave 'c'. Si la clave ya existía, pisa el valor anterior
Cómo elige PHP la clave automática

Cuando no ponés clave, PHP usa el entero más grande que ya haya en el arreglo, más uno. Si todavía no hay ninguna clave entera, usa 0. Las claves de texto no cuentan para esta cuenta.

Para ver un arreglo entero hace falta print_r(), que se explica en la sección 3. Por ahora, en cada ejemplo se muestra cómo queda el arreglo por dentro (las tablas se comprobaron imprimiendo cada arreglo con print_r()).

Ejemplo 1 — Las cuatro formas de la cátedra

<?php
$valores1 = array(10, 20, 30);
$valores2 = array('a' => 10, 'b' => 20, 'cee' => 30);
$valores3 = array(5 => 1, 3 => 2, 1 => 3);
$valores4 = array();
?>

Qué hace cada línea

LíneaQué haceCómo queda el arreglo (clave => valor)
$valores1 = array(10, 20, 30);Solo valores: PHP pone las claves 0, 1, 20 => 10  ·  1 => 20  ·  2 => 30
$valores2 = array('a' => 10, ...);Claves de texto elegidas: es un arreglo asociativoa => 10  ·  b => 20  ·  cee => 30
$valores3 = array(5 => 1, ...);Claves numéricas puestas a mano y desordenadas. PHP las respeta y guarda los elementos en el orden en que se escribieron5 => 1  ·  3 => 2  ·  1 => 3
$valores4 = array();Arreglo vacío(sin elementos)

Qué imprime: nada, porque no hay ningún echo. El script solo crea los cuatro arreglos en memoria.

Ejemplo 2 — Agregando con [] (formato "¿qué claves quedan?")

Enunciado

Después de ejecutar este script, ¿qué clave tiene cada elemento de $m?

<?php
$m = array('a', 'b');
$m[] = 'c';
$m['z'] = 'd';
$m[] = 'e';
?>

Qué hace cada línea

LíneaQué haceCómo queda $m
$m = array('a', 'b');Dos valores sin clave: PHP usa 0 y 10 => a  ·  1 => b
$m[] = 'c';Sin clave: el entero más grande es 1, entonces usa 2… 2 => c
$m['z'] = 'd';Clave de texto elegida… z => d
$m[] = 'e';Sin clave: el entero más grande sigue siendo 2 (la 'z' no cuenta), entonces usa 30 => a · 1 => b · 2 => c · z => d · 3 => e
Respuesta

a en la 0, b en la 1, c en la 2, d en la 'z' y e en la 3. Una clave de texto en el medio no corta la numeración automática.

Ejemplo 3 — Claves mezcladas (presentación de la cátedra)

<?php
$cosas = array(
    0 => 22444555,
    'apellido' => 'Gomez',
    1 => 'Martín'
);
$tres = array(5 => 'a', 'b', 'c');
?>

Qué hace cada línea

LíneaQué haceCómo queda el arreglo
$cosas = array(...);Un mismo arreglo con claves numéricas y de texto, y con valores de distinto tipo (un número y dos textos)0 => 22444555 · apellido => Gomez · 1 => Martín
$tres = array(5 => 'a', 'b', 'c');El primero tiene clave 5; los siguientes no tienen clave, así que siguen desde el 55 => a · 6 => b · 7 => c

Qué imprime: nada; solo crea los arreglos.

Errores y trampas

Las claves automáticas empiezan en 0, no en 1

En array('Domingo', 'Lunes', 'Martes'), 'Domingo' está en la clave 0 y 'Lunes' en la 1. Es la trampa de la pregunta 8 del parcial (sección 2).

Repetir una clave pisa el valor

Una clave es única: si escribís $a['x'] = 1; y después $a['x'] = 2;, el arreglo tiene un solo elemento x => 2. No se agrega otro.

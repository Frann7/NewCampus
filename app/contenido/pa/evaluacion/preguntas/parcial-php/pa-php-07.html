Es un array asociativo que contiene variables de sesión disponibles para el script actual. $_GET$_POST$_SESSION

ES un array asociativo de variables pasado al script actual vía parámetros URL. $_GET$_POST$_SESSION

Es un array asociativo de variables pasadas al script actual a través del método HTTP POST. $_GET$_POST$_SESSION

Parcial PHP · preg. 7

$_GET trae los parámetros de la URL (lo que va después del ?, o un formulario con method="get"); $_POST, lo que manda un formulario con method="post"; $_SESSION, las variables de sesión que el servidor guarda para ese usuario entre página y página (con session_start()).

“Parámetros URL” es GET aunque no lo diga: GET manda los datos en la URL y POST en el cuerpo del pedido.

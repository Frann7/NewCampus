Los ? no son PHP: son el hueco que hay que completar (así como está, PHP daría Parse error). Cada opción pone un booleano en cada variable, en orden: $a, $b, $c valen true (verdadero) o false (falso).

Lo que hay que saber: if (cond) { … } else { … } ejecuta una sola de las dos ramas (la primera si la condición es true, el else si es false); if ($a) pregunta “¿$a es true?”; ! da vuelta el valor (!false = true); && da true solo si los dos lados son true. Los if están anidados (uno adentro de otro): qué está adentro de qué lo dicen las llaves { }, no la sangría.

Se va de la salida hacia atrás, nivel por nivel, hasta el único echo "Hola, mundo!":

  • Nivel 1, if ($a): el echo está en su else ⇒ $a = false.
  • Nivel 2, if (!$b): el echo está adentro (su else imprime “No exactamente”) ⇒ !$b true ⇒ $b = false.
  • Nivel 3, if (!$a && (!$b && $c)): queda true && (true && $c), que es true solo si $c = true.

Resultado: False, False, True. Corriendo las otras: False, True, True y False, True, False van al else del nivel 1 y después al else de if (!$b) (porque !true = false): imprimen “No exactamente”. True, True, False entra a if ($a) y ahí $b && !$c = true && true: imprime “Adios mundo cruel!”.

Ojo: el enunciado dice “Hola, Mundo!” y el script imprime “Hola, mundo!” (minúscula); es un descuido del enunciado. Y $string no se usa: está para distraer.

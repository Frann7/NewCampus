¿En qué estado queda el cambio de un archivo después de cada acción?

  • Guardé el archivo en el editor y no hice nada más: Confirmado (committed)Modificado (modified)Preparado (staged)
  • Hice git add del archivo: Confirmado (committed)Modificado (modified)Preparado (staged)
  • Hice git commit: Confirmado (committed)Modificado (modified)Preparado (staged)

Inventada · Unidad 6, los tres estados

A cada estado le corresponde un lugar: modificado en el directorio de trabajo, preparado en el área de preparación (lo que va a entrar en el próximo commit) y confirmado en el directorio de Git, el repositorio local.

Ejercicio 3 · Densidad, acumulada y valor exacto

Temperatura de una reacción química

Sea \(X\) la temperatura a la cual ocurre una reacción química en grados Celsius. Suponga que \(X\) tiene una función de densidad de probabilidad como la siguiente: \(f(x) = \begin{cases} \frac{1}{9}(4 - x^2) & \text{con } -1 \leq x \leq 2 \\ 0 & \text{en c.o.c.} \end{cases}\)

a) ¿La variable aleatoria \(X\) es discreta o continua? Justifique. b) Verifique que \(f\) es una función de densidad de probabilidad. c) Determine la función de distribución acumulada de probabilidad. d) ¿Cuál es la probabilidad de que la reacción química ocurra a temperaturas que no excedan los 0 °C? e) Resuelva el inciso anterior nuevamente empleando la función de distribución acumulada de probabilidad. f) ¿Cuál es la probabilidad de que la reacción química ocurra exactamente a 0 °C? g) ¿Cuál es la probabilidad de que la reacción se produzca a menos de 1 °C pero a más de 0 °C? Resuelva de dos maneras diferentes.

Inciso a — Discreta o continua

\(X\): temperatura, en °C, a la que ocurre la reacción → v.a. continua, porque se mide: puede tomar cualquier valor real del intervalo \([-1;\ 2]\).

Inciso b — Verificar que es densidad

Propiedad 1, \(f(x) \geq 0\): \(4 - x^2 \geq 0\) cuando \(x^2 \leq 4\), o sea entre \(-2\) y 2. El intervalo \([-1;\ 2]\) está adentro, así que \(f \geq 0\) ✔ (en \(x = 2\) vale justo 0).

Propiedad 2. Fórmula: \(\displaystyle \int_{-\infty}^{+\infty} f(x)\,dx = 1\).

Primitiva (sección 4): el \(\tfrac{1}{9}\) sale afuera, \(\int 4\,dx = 4x\) y \(\int x^2\,dx = \tfrac{x^3}{3}\).

\[ \int_{-1}^{2} \frac{1}{9}(4 - x^2)\,dx = \frac{1}{9}\left[4x - \frac{x^3}{3}\right]_{-1}^{2} = \frac{1}{9}\left[\left(8 - \frac{8}{3}\right) - \left(-4 + \frac{1}{3}\right)\right] \]

\((-1)^3 = -1\), así que \(-\tfrac{(-1)^3}{3} = +\tfrac{1}{3}\). Las dos cuentas: \(8 - \tfrac{8}{3} = \tfrac{16}{3}\) y \(-4 + \tfrac{1}{3} = -\tfrac{11}{3}\).

\[ = \frac{1}{9}\left[\frac{16}{3} + \frac{11}{3}\right] = \frac{1}{9} \cdot \frac{27}{3} = \frac{1}{9} \cdot 9 = 1 \quad\checkmark \]

La densidad es una parábola "boca abajo" entre −1 y 2. Pintada, el área hasta 0 (inciso d).

Inciso c — La acumulada

Fórmula: \(\displaystyle F(x) = \int_{a}^{x} f(t)\,dt\) para \(a \leq x < b\); 0 antes y 1 después.

\[ F(x) = \int_{-1}^{x} \frac{1}{9}(4 - t^2)\,dt = \frac{1}{9}\left[4t - \frac{t^3}{3}\right]_{-1}^{x} = \frac{1}{9}\left[\left(4x - \frac{x^3}{3}\right) - \left(-\frac{11}{3}\right)\right] \]

(el \(-\tfrac{11}{3}\) es el mismo \(G(-1)\) del inciso b). Distribuyendo el \(\tfrac{1}{9}\):

\[ F(x) = \frac{4x}{9} - \frac{x^3}{27} + \frac{11}{27} \]

\[ F(x) = \begin{cases} 0 & \text{si } x < -1 \\ -\dfrac{1}{27}x^3 + \dfrac{4}{9}x + \dfrac{11}{27} & \text{si } -1 \leq x < 2 \\ 1 & \text{si } x \geq 2 \end{cases} \]

Controles: \(F(-1) = \tfrac{1}{27} - \tfrac{4}{9} + \tfrac{11}{27} = \tfrac{1 - 12 + 11}{27} = 0\) ✔; \(F(2) = -\tfrac{8}{27} + \tfrac{8}{9} + \tfrac{11}{27} = \tfrac{-8 + 24 + 11}{27} = 1\) ✔.

Inciso d — No exceder 0 °C, con la integral

Fórmula: \(\displaystyle P(X \leq b) = \int_{-\infty}^{b} f(x)\,dx\), desde donde empieza \(f\).

\[ P(X \leq 0) = \frac{1}{9}\int_{-1}^{0} (4 - x^2)\,dx = \frac{1}{9}\left[4x - \frac{x^3}{3}\right]_{-1}^{0} = \frac{1}{9}\left[0 - \left(-\frac{11}{3}\right)\right] = \frac{11}{27} = 0{,}4074 \]

Inciso e — Lo mismo con la acumulada

Fórmula: \(P(X \leq c) = F(c)\).

\[ P(X \leq 0) = F(0) = -0 + 0 + \frac{11}{27} = 0{,}4074 \]

Inciso f — Exactamente 0 °C

Fórmula: \(P(X = a) = 0\) en una continua.

\[ P(X = 0) = 0 \]

Al ser \(X\) continua, la probabilidad de que tome un valor puntual es nula.

Inciso g — Entre 0 y 1 °C, de dos maneras

El área entre 0 y 1: casualmente vale lo mismo que la del inciso d.

Manera 1, integrando. Fórmula: \(\displaystyle P(a < X < b) = \int_a^b f(x)\,dx\).

\[ P(0 < X < 1) = \frac{1}{9}\left[4x - \frac{x^3}{3}\right]_0^1 = \frac{1}{9}\left(4 - \frac{1}{3}\right) = \frac{1}{9} \cdot \frac{11}{3} = \frac{11}{27} = 0{,}4074 \]

Manera 2, con la acumulada. Fórmula: \(P(a < X < b) = F(b) - F(a)\).

\[ F(1) = -\frac{1}{27} + \frac{4}{9} + \frac{11}{27} = \frac{-1 + 12 + 11}{27} = \frac{22}{27} \]

\[ P(0 < X < 1) = F(1) - F(0) = \frac{22}{27} - \frac{11}{27} = \frac{11}{27} = 0{,}4074 \]

Respuesta

a) Continua. b) Es densidad. c) La \(F\) por tramos de arriba. d) y e) La probabilidad de que la reacción ocurra a 0 °C o menos es 0,4074. f) 0. g) 11/27 = 0,4074.

Resultados oficiales de la cátedra

a) Continua; c) \(F(x) = -\frac{1}{27}x^3 + \frac{4}{9}x + \frac{11}{27}\) si \(-1 \leq x < 2\); d) y e) 0,4074; f) 0; g) \(11/27\)  ✓

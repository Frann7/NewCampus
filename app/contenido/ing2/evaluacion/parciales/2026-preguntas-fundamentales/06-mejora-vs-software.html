Unidad 5 · Mejora de procesos

Realice un cuadro comparativo entre un proyecto de mejora de procesos y un proyecto de desarrollo de software que contemple objetivo, resultado, enfoque, etapas y un ejemplo.

✓ RespuestaPara aprender y escribir en la hoja
Proyecto de mejora de procesosProyecto de desarrollo de software
ObjetivoOptimizar un proceso que ya existeCrear o actualizar un sistema
ResultadoUn proceso rediseñado, mejor documentado y con mejor rendimientoUn producto de software que funciona
EnfoqueProcesos: personas, tareas, flujosTecnología: software, código
EtapasDiagnóstico (AS-IS) → objetivos → rediseño (TO-BE) → implementación → seguimientoRequisitos → análisis y diseño → desarrollo → pruebas → implementación → mantenimiento
EjemploBajar de 10 días a 3 el tiempo para aprobar un créditoCrear una app para pedir créditos en línea

Están relacionados: conviene mejorar el proceso antes de programarlo, para no automatizar ineficiencias.

Trampa

El mismo tema puede dar los dos proyectos: "aprobar créditos más rápido" es mejora de procesos; "una app para pedir créditos" es desarrollo de software. La diferencia está en el resultado: un proceso o un producto.

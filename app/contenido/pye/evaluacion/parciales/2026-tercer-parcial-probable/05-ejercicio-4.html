Ejercicio 4

26 puntos Unidad 8 · IC para la diferencia de medias (muestras chicas)

Se comparan los tiempos de respuesta (en ms) de un servicio de consultas instalado en dos servidores: el servidor A usa caché Redis y el servidor B no usa caché. En el servidor A se midieron 12 peticiones, con un tiempo medio de 85,3 ms y un desvío estándar de 6,2 ms. En el servidor B se midieron 10 peticiones, con un tiempo medio de 97,8 ms y un desvío estándar de 14,5 ms. Suponga que en ambos servidores el tiempo de respuesta se distribuye normalmente y que las muestras son independientes.

  1. ¿Pueden suponerse iguales las varianzas poblacionales? Justifique con la regla empírica.
  2. Construya un intervalo de confianza del 95 % para la diferencia de los tiempos medios \(\mu_A - \mu_B\).
  3. ¿Hay una diferencia significativa entre los tiempos medios de respuesta? ¿Qué servidor responde más rápido?
✓ ResultadosSolo las respuestas, sin procedimiento
IncisoResultado
a) Regla empírica \(S_B^{2}/S_A^{2} = 210{,}25 / 38{,}44 = 5{,}47 > 3\) → no se suponen iguales: Welch
b) IC 95 % para \(\mu_A - \mu_B\) \(\nu = 11{,}73 \approx 12\), \(t_{(0{,}025;\ 12)} = 2{,}179\), \(E = 10{,}73\)  ·  \(\text{IC}_{95\%}(\mu_A - \mu_B) = (-23{,}23\ ;\ -1{,}77)\) ms
c) Conclusión El intervalo no incluye el 0: hay diferencia significativa. Es todo negativo: \(\mu_A < \mu_B\), el servidor A (con caché) responde más rápido, entre 1,77 y 23,23 ms menos en promedio.

El enunciado, otra vez

Servidor A (con caché Redis): 12 peticiones, media 85,3 ms, desvío 6,2 ms. Servidor B (sin caché): 10 peticiones, media 97,8 ms, desvío 14,5 ms. Normales e independientes. Piden: a) si las varianzas pueden suponerse iguales (regla empírica); b) IC del 95 % para \(\mu_A - \mu_B\); c) si hay diferencia significativa y qué servidor es más rápido.

¿De qué tema es?

Estimación, parte 2: intervalo de confianza para la diferencia de medias de dos poblaciones con muestras independientes y chicas.

Los conceptos que hacen falta, desde cero

1. Qué fórmula usar (diagrama de decisión de la cátedra)
  • ¿\(\sigma_1^{2}\) y \(\sigma_2^{2}\) conocidas? → \(Z\) con las \(\sigma^{2}\).
  • Desconocidas y \(n_1, n_2 \geq 30\) → \(Z\) con \(S_1^{2}\) y \(S_2^{2}\).
  • Desconocidas, muestras chicas y poblaciones normales → \(t\), y para saber cuál se usa la regla empírica:

\[ \frac{S^{2}_{\text{mayor}}}{S^{2}_{\text{menor}}} \leq 3 \;\Rightarrow\; \text{varianzas supuestas iguales (pooled)} \qquad\qquad \frac{S^{2}_{\text{mayor}}}{S^{2}_{\text{menor}}} > 3 \;\Rightarrow\; \text{no supuestas iguales (Welch)} \]

Si el enunciado ya dice “varianzas iguales” o “diferentes”, se usa eso sin la regla.

2. Welch: varianzas no supuestas iguales

\[ (\bar{x}_1 - \bar{x}_2) \pm t_{(\alpha/2;\ \nu)}\sqrt{\frac{S_1^{2}}{n_1} + \frac{S_2^{2}}{n_2}} \]

con los grados de libertad de Welch-Satterthwaite:

\[ \nu = \frac{\left(\dfrac{S_1^{2}}{n_1} + \dfrac{S_2^{2}}{n_2}\right)^{2}}{\dfrac{\left(S_1^{2}/n_1\right)^{2}}{n_1 - 1} + \dfrac{\left(S_2^{2}/n_2\right)^{2}}{n_2 - 1}} \]

\(\nu\) casi nunca da entero: se redondea al entero más cercano (truncar hacia abajo es lo más conservador; en este ejercicio da la misma conclusión).

3. Pooled, para comparar (cuando el cociente es \(\leq 3\))

\[ (\bar{x}_1 - \bar{x}_2) \pm t_{(\alpha/2;\ n_1+n_2-2)}\, S_p\sqrt{\frac{1}{n_1} + \frac{1}{n_2}} \qquad S_p^{2} = \frac{(n_1-1)S_1^{2} + (n_2-1)S_2^{2}}{n_1+n_2-2} \]

Acá no se usa: está para que veas la diferencia.

4. Cómo se concluye con un IC para \(\mu_1 - \mu_2\)
  • Si el intervalo incluye el 0: puede que las medias sean iguales → no hay diferencia significativa.
  • Si no incluye el 0: hay diferencia significativa. Todo positivo → \(\mu_1 > \mu_2\); todo negativo → \(\mu_1 < \mu_2\).

Inciso a — ¿Varianzas iguales? Regla empírica

Primero se pasan los desvíos a varianzas:

\[ S_A^{2} = 6{,}2^{2} = 38{,}44 \qquad\qquad S_B^{2} = 14{,}5^{2} = 210{,}25 \]

Fórmula (la mayor arriba):

\[ \frac{S^{2}_{\text{mayor}}}{S^{2}_{\text{menor}}} = \frac{210{,}25}{38{,}44} = 5{,}47 > 3 \]

Respuesta a

No pueden suponerse iguales: el cociente de varianzas da 5,47, mayor que 3. Como además las muestras son chicas (\(12\) y \(10\), menos de 30) y las poblaciones normales, se usa la \(t\) de Welch.

La trampa del desvío

Con los desvíos el cociente da \(14{,}5 / 6{,}2 = 2{,}34 \leq 3\), y uno se iría a pooled por error. La regla es con varianzas: siempre elevar al cuadrado primero.

Inciso b — Intervalo del 95 % para \(\mu_A - \mu_B\)

Fórmula (Welch):

\[ (\bar{x}_A - \bar{x}_B) \pm t_{(\alpha/2;\ \nu)}\sqrt{\frac{S_A^{2}}{n_A} + \frac{S_B^{2}}{n_B}} \]

Las dos fracciones (se usan dos veces: conviene sacarlas primero)

\[ \frac{S_A^{2}}{n_A} = \frac{38{,}44}{12} = 3{,}2033 \qquad\qquad \frac{S_B^{2}}{n_B} = \frac{210{,}25}{10} = 21{,}025 \]

\[ \frac{S_A^{2}}{n_A} + \frac{S_B^{2}}{n_B} = 3{,}2033 + 21{,}025 = 24{,}2283 \qquad\qquad \sqrt{24{,}2283} = 4{,}9222 \]

Los grados de libertad

Fórmula:

\[ \nu = \frac{\left(\dfrac{S_A^{2}}{n_A} + \dfrac{S_B^{2}}{n_B}\right)^{2}}{\dfrac{\left(S_A^{2}/n_A\right)^{2}}{n_A - 1} + \dfrac{\left(S_B^{2}/n_B\right)^{2}}{n_B - 1}} \]

Numerador: \(24{,}2283^{2} = 587{,}01\). Denominador, término por término:

\[ \frac{3{,}2033^{2}}{11} = \frac{10{,}2613}{11} = 0{,}9328 \qquad\qquad \frac{21{,}025^{2}}{9} = \frac{442{,}05}{9} = 49{,}1167 \]

\[ \nu = \frac{587{,}01}{0{,}9328 + 49{,}1167} = \frac{587{,}01}{50{,}0496} = 11{,}73 \;\approx\; 12 \]

Valor de tabla (fila 12, área 0,025 a la derecha):

\[ t_{(0{,}025;\ 12)} = 2{,}179 \]

El intervalo

\[ \bar{x}_A - \bar{x}_B = 85{,}3 - 97{,}8 = -12{,}5 \]

\[ E = 2{,}179 \times 4{,}9222 = 10{,}73 \]

\[ -12{,}5 - 10{,}73 \;<\; \mu_A - \mu_B \;<\; -12{,}5 + 10{,}73 \]

\[ -23{,}23 \;<\; \mu_A - \mu_B \;<\; -1{,}77 \]

Respuesta b

\(\text{IC}_{95\%}(\mu_A - \mu_B) = (-23{,}23\ ;\ -1{,}77)\) ms.

Si truncás \(\nu\) a 11

\(t_{(0{,}025;\ 11)} = 2{,}201\), \(E = 10{,}83\) y el intervalo queda \((-23{,}33\ ;\ -1{,}67)\). Apenas más ancho, y la conclusión es la misma. Cualquiera de los dos criterios está bien si se dice cuál se usó.

Inciso c — ¿Diferencia significativa? ¿Cuál es más rápido?
  • El intervalo \((-23{,}23\ ;\ -1{,}77)\) no incluye el 0: hay diferencia significativa entre las medias.
  • Es todo negativo: \(\mu_A - \mu_B < 0\), o sea \(\mu_A < \mu_B\).
  • Tiempo de respuesta menor = más rápido.
Respuesta c

Con un 95 % de confianza hay diferencia significativa: el servidor A, con caché Redis, responde más rápido, entre 1,77 y 23,23 ms menos en promedio que el servidor B.

Las trampas de este ejercicio
  1. Regla empírica con desvíos. Siempre con varianzas (desvío al cuadrado).
  2. Restar al revés. Piden \(\mu_A - \mu_B\): \(85{,}3 - 97{,}8 = -12{,}5\). Si restás al revés, el intervalo sale con los signos cambiados y la conclusión se lee al revés.
  3. Usar \(n_A + n_B - 2 = 20\) grados de libertad. Esos son los de pooled; en Welch se calcula \(\nu\).
  4. Concluir solo “no incluye el 0”. Piden además cuál es más rápido: lo dice el signo.

¿El siguiente código Php es correcto y tiene como salida "INGRESA"?

<?php
$a=true;

}
?>

✓ ResultadosSolo la respuesta

a) Si es correcto

✎ Explicación detalladaQué evalúa, el concepto desde cero, la traza y las trampas

Qué evalúa

La sintaxis del if y qué puede ir como condición. Es de la Clase 1 (estructuras de control).

El concepto, desde cero

Un booleano es un valor que solo puede ser true (verdadero) o false (falso). Las condiciones de PHP siempre terminan dando uno de esos dos valores.

if (condición) {
    // se ejecuta solo si la condición es true
}

if (“si”) mira la condición que va entre paréntesis: si es true, ejecuta lo que está entre las llaves { }; si es false, lo saltea y sigue con lo que haya después de la }. Este if no tiene else, así que con false no haría nada. (Las líneas con // son comentarios: notas que PHP ignora.)

La condición puede ser una comparación ($x > 3) o cualquier valor, incluida una variable sola. Si la variable ya es booleana, se usa tal cual: if ($a) pregunta “¿$a es true?”, igual que if ($a == true).

Qué imprime y por qué

INGRESA

El código es correcto y la salida es INGRESA. Para comparar, con $a=false; el mismo script no imprime nada: el if saltea su bloque y no hay else. (Las dos cosas comprobadas en PHP 8.2.)

Opción por opción

  • a) Si es correcto: correcta.
  • b) No, porque es falso por defecto: $a no tiene valor por defecto, se le asignó true en la línea anterior. (Una variable que nunca se asignó da un aviso Warning: Undefined variable y cuenta como false; no es este caso.)
  • c) Emite un error, porque el IF no posee condición: sí la tiene, $a. No hace falta escribir $a == true.
La trampa

Creer que la condición tiene que ser una comparación. if ($a) es lo mismo que if ($a == true).

¿Qué patrón de diseño aplica este código?

#include <iostream>
#include <string>

class Inventario {
public:
    bool hayStock(const std::string& producto) const {
        std::cout << "Verificando stock de " << producto << "\n";
        return true;
    }
};

class Pagos {
public:
    void cobrar(int monto) const { std::cout << "Cobrando $" << monto << "\n"; }
};

class Envios {
public:
    void despachar(const std::string& producto) const {
        std::cout << "Despachando " << producto << "\n";
    }
};

class Tienda {
private:
    Inventario inventario_;
    Pagos pagos_;
    Envios envios_;

public:
    void comprar(const std::string& producto, int monto) const {
        if (inventario_.hayStock(producto)) {
            pagos_.cobrar(monto);
            envios_.despachar(producto);
        }
    }
};

int main() {
    Tienda tienda;
    tienda.comprar("teclado", 15000);
    return 0;
}

Inventada · estilo Parcial 2024, Ej. 4

  • Facade
  • Adapter
  • Observer
  • Abstract Factory

Tienda tiene adentro un objeto de cada clase del subsistema (Inventario, Pagos, Envios) y ofrece un solo método, comprar(), que los llama en el orden correcto. El main usa una línea y no conoce a ninguna de las tres. Es Facade. No es Adapter: no se está haciendo encajar una clase en una interfaz que ya existía, se está dando una entrada nueva y más simple a varias.

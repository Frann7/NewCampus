Formularios en HTML

4. Los controles: tipos de input

Para qué sirve

El <input> es un solo elemento que se convierte en controles muy distintos según su atributo type: un cuadro de texto, un campo de contraseña, un botón, un selector de archivo. La cátedra los menciona como las "formas que pueden ir desde líneas de texto a subida de archivos, pasando por opciones, fechas, contraseñas y otras más".

Sintaxis

<input type="tipo" name="nombreDelDato" value="valor inicial">

Qué es cada tipo

Los cuatro primeros son los que aparecen en la pregunta 11 del parcial:

typeQué control esQué ve el usuario
textUna línea de texto. El usuario escribe y ve lo que escribe. Es el tipo por defecto: un <input> sin type es un textUn cuadro con lo que va escribiendo
passwordUna línea de texto oculta: cada carácter se muestra como un punto o un asterisco••••••
hiddenUn dato invisible: no aparece en la página, pero viaja con el formulario. Su valor lo pone el programador en value, no el usuarioNada
filePara elegir un archivo de la computadora y mandarlo al servidorUn botón "Seleccionar archivo"
submitEl botón que envía el formulario. value es su textoUn botón

dateUna fecha. Llega al servidor como año-mes-día (2001-05-09)Un cuadro con calendario

Otros controles que no son input

ElementoQué es
<textarea name="..." rows="8" cols="30"></textarea>Texto de varias líneas (un comentario). Sí tiene cierre; lo que va entre las etiquetas es el texto inicial. rows y cols: alto en renglones y ancho en caracteres
<select name="..."> con <option value="...">Una lista desplegable. Viaja el value de la opción elegida, no el texto que se ve
<button type="submit">Enviar</button>Otra forma de hacer el botón de enviar, con el texto entre las etiquetas
<label for="id">El rótulo de un control. Si su for coincide con el id del control, hacer clic en el rótulo pone el cursor en el control

Y un atributo que vas a ver en el sitio de la práctica: required, que marca un control como obligatorio. Si está vacío, el navegador no deja enviar.

Ejemplo 1 — Un formulario de ingreso

<form action="ingreso.php" method="post">
Usuario: <input type="text" name="usuario">
Clave: <input type="password" name="clave">
<input type="hidden" name="origen" value="inicio">
<input type="submit" value="Ingresar">
</form>

El usuario escribe fran y la clave secreta123.

Qué llega al servidor

Tres pares: usuario=fran, clave=secreta123 y origen=inicio. La clave llega escrita normal: el tipo password solo la tapa en la pantalla. Y el hidden llega aunque el usuario nunca lo haya visto. Lo comprobamos corriendo PHP en la sección 8.

Ejemplo 2 — La pregunta 11 del parcial

Enunciado (Parcial PHP, preg. 11)

El componente HTML "INPUT" tipo text:

  1. Nos permite el ingreso de una cadena de texto pero no vemos los caracteres que ingresamos.
  2. Nos permite ingresar una cadena de texto pero no es visible dentro del formulario.
  3. Nos permite ingresar una cadena de texto.
  4. Nos permite ingresar un archivo para ser enviado al servidor.

Cada opción incorrecta describe otro tipo de la tabla:

OpciónQué tipo describe¿Es text?
a. "no vemos los caracteres"passwordNo
b. "no es visible dentro del formulario"hiddenNo
c. "ingresar una cadena de texto"textSí
d. "ingresar un archivo"fileNo
Respuesta

c. El input tipo text permite ingresar una cadena de texto (de una línea), y el usuario ve lo que escribe.

Errores y trampas

Lo que suele salir mal
  • password no es seguridad. Solo tapa los caracteres en la pantalla. Si el formulario va por GET, la clave aparece escrita en la URL (sección 5).
  • hidden no es secreto. No se ve en la página, pero está en el código HTML (clic derecho → "Ver código fuente") y el usuario lo puede cambiar.
  • file necesita más. Para que el archivo viaje, el <form> tiene que ser method="post" y llevar enctype="multipart/form-data"; si no, solo viaja el nombre del archivo. En esta clase no se desarrolla.
  • Una casilla (checkbox) sin tildar no se envía. No llega vacía: directamente no llega.
  • reset no envía. Solo vacía el formulario en el navegador; al servidor no le llega nada.

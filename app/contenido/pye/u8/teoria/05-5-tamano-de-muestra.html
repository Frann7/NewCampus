5. Tamaño de muestra a partir del error

Cuándo se usa

Cuando el enunciado da el error y pregunta por \(n\): "¿de qué tamaño debe ser la muestra para que el error de estimación no supere 0,5 ms con un 95 % de confianza?", "¿cuántas mediciones hay que tomar para estimar la media con un error máximo de…?". Es la misma fórmula del error de la sección 2, pero despejando \(n\).

Fórmula

Tamaño de muestra para estimar \(\mu\)

\[ n = \left(\frac{z_{\alpha/2}\cdot\sigma}{E}\right)^{2} \qquad\text{y se redondea siempre para arriba} \]

Qué significa cada letra

SímboloQué esCómo lo reconocés
\(E\)el error máximo que se acepta (la mitad del ancho del intervalo)"que el error no supere", "con un error máximo de", "a menos de 0,5 ms de la media real"
\(\sigma\)el desvío (de la población, o el de una muestra anterior)"se sabe que el desvío es"
\(z_{\alpha/2}\)el valor de la tabla \(Z\) para esa confianza95 % → 1,96; 90 % → 1,645
\(n\)lo que se busca"¿de qué tamaño debe ser la muestra?"

De dónde sale

Del error de la media (sección 2), despejando \(n\) paso a paso:

\[ E = z_{\alpha/2}\,\frac{\sigma}{\sqrt{n}} \;\Longrightarrow\; \sqrt{n} = \frac{z_{\alpha/2}\,\sigma}{E} \;\Longrightarrow\; n = \left(\frac{z_{\alpha/2}\,\sigma}{E}\right)^{2} \]

(se pasa \(\sqrt{n}\) multiplicando y \(E\) dividiendo, y después se eleva al cuadrado para sacar la raíz).

Por qué siempre para arriba

\(n\) es una cantidad de datos: tiene que ser entero. Si da 245,86 y tomás 245, el error queda apenas más grande que el pedido (no se cumple). Con 246 queda apenas más chico (sí se cumple). Por eso se redondea para arriba aunque el decimal sea chico (152,21 → 153).

Ejemplo 1 — El microservicio, con un error de 0,5 ms

Enunciado

El tiempo de respuesta de un microservicio de autenticación tiene un desvío de 4 ms. ¿Cuántas peticiones hay que medir para estimar el tiempo medio de respuesta con un error de estimación de, a lo sumo, 0,5 ms, con un 95 % de confianza?

Por qué este modelo

  • Dan el error y preguntan cuántos datos: es tamaño de muestra para una media.
  • Se usa \(z\): el resultado va a ser grande (\(n \geq 30\)), así que la \(z\) vale.

Desarme del enunciado

FraseQué significaLa cuentaA dónde va
"tiene un desvío de 4 ms"desvío—\(\sigma = 4\)
"error de estimación de, a lo sumo, 0,5 ms"error máximo—\(E = 0{,}5\)
"95 %"confianza\(F(z) = 0{,}975\)\(z_{\alpha/2} = 1{,}96\)
"¿cuántas peticiones?"lo que se busca—\(n\)

Paso 1 — Fórmula.

\[ n = \left(\frac{z_{\alpha/2}\cdot\sigma}{E}\right)^{2} \]

Paso 2 — Reemplazar (primero lo de adentro del paréntesis, después al cuadrado):

\[ n = \left(\frac{1{,}96 \cdot 4}{0{,}5}\right)^{2} = \left(\frac{7{,}84}{0{,}5}\right)^{2} = 15{,}68^{2} = 245{,}86 \]

Paso 3 — Redondear para arriba: \(n = 246\).

Paso 4 — Comprobar (opcional): con 246, \(E = 1{,}96 \cdot \dfrac{4}{\sqrt{246}} = 1{,}96 \cdot 0{,}2550 = 0{,}49986\), apenas menos que 0,5. Cumple.

Respuesta

Hay que medir 246 peticiones para que, con un 95 % de confianza, el error al estimar el tiempo medio de respuesta no supere 0,5 ms.

Ejemplo 2 — La máquina de refrescos, al 90 %

Enunciado

Una máquina de refrescos despacha un contenido que se distribuye normal con desviación estándar de 0,15 litros. ¿Cuántos refrescos hay que medir para estimar el contenido medio con un error máximo de 0,02 litros y un 90 % de confianza?

Por qué este modelo

  • Dan el error máximo y preguntan cuántos datos: tamaño de muestra.
  • \(\sigma\) es conocida (de la población) y la población es normal: \(z\).

Desarme del enunciado

FraseQué significaLa cuentaA dónde va
"desviación estándar de 0,15 litros"desvío de la población—\(\sigma = 0{,}15\)
"error máximo de 0,02 litros"error—\(E = 0{,}02\)
"90 %"confianza\(\alpha/2 = 0{,}05\), \(F(z) = 0{,}95\)\(z_{\alpha/2} = 1{,}645\)

Paso 1 — Fórmula.

\[ n = \left(\frac{z_{\alpha/2}\cdot\sigma}{E}\right)^{2} \]

Paso 2 — Reemplazar:

\[ n = \left(\frac{1{,}645 \cdot 0{,}15}{0{,}02}\right)^{2} = \left(\frac{0{,}24675}{0{,}02}\right)^{2} = 12{,}3375^{2} = 152{,}21 \]

Paso 3 — Redondear para arriba: 152,21 → \(n = 153\) (aunque el decimal sea ,21: con 152 el error pasaría de 0,02).

Respuesta

Hay que medir 153 refrescos para estimar el contenido medio con un error de a lo sumo 0,02 litros, con un 90 % de confianza.

Errores típicos
  • Olvidarse del cuadrado (daría 12,34 refrescos).
  • Si dan la varianza, sacarle la raíz antes: en la fórmula va el desvío.
  • Redondear para abajo.

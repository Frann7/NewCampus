Definiciones

1. ¿Qué es SQL?

Para escribir en la hoja

SQL (Structured Query Language, lenguaje de consulta estructurado) es el lenguaje que usan casi todos los sistemas de bases de datos relacionales para definir la base (crear tablas, claves y restricciones) y para manipular los datos (consultar, agregar, modificar y borrar).

  • Es un lenguaje no procedimental (de 4ta generación): se dice qué datos se quieren, no cómo buscarlos.
  • Trabaja sobre conjuntos de registros: una sola sentencia recupera o modifica todos los que cumplen la condición.
  • Tiene propiedad dual: se puede usar solo, en forma interactiva (autocontenido), o embebido dentro de otro lenguaje de programación (huésped).
  • Sus sentencias se dividen en DDL (definición) y DML (manipulación).

Ejemplo: procedimental contra no procedimental

Se quiere la lista de los animales de raza "Caniche".

  • Con un lenguaje procedimental: abrir el archivo, leer un registro, preguntar si la raza es Caniche, mostrarlo, pasar al siguiente, repetir hasta el final del archivo.
  • Con SQL: una sola sentencia que dice qué se quiere (la forma se explica en la Unidad 4):
SELECT Nombre FROM Animal WHERE Raza = 'Caniche';

El SGBD decide cómo buscarlos. Por eso se dice que SQL trabaja sobre un conjunto de registros.

Errores y trampas
  • SQL no es un SGBD ni una base de datos: es el lenguaje con el que se le habla al SGBD.
  • No es solo para consultar (aunque se llame "de consulta"): también crea tablas y modifica datos.
  • Si la pregunta sigue con "escriba las sentencias para DDL y DML", la respuesta es la de la sección 2.

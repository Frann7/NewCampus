Pregunta 25

1 pt Interbloqueos · Definición

Seleccione una:

Para muchas aplicaciones, un proceso necesita acceso exclusivo no sólo a un recurso, sino a varios. Si tenemos dos procesos, A y B, y el proceso A esta usando el recurso W y el proceso B esta usando el recurso X; Posteriormente, el proceso A solicita permiso al SO para usar el recurso X y el proceso B pide permisos para usar el recurso V.
En este punto ambos procesos están bloqueados y permanecerán así para siempre. A esta situación se le conoce como interbloqueo.

Qué evalúa

Qué es un interbloqueo, con el ejemplo de Tanenbaum (en el libro, un escáner y una grabadora de CD).

Por qué es falso

En el ejemplo del libro, cada proceso pide el recurso que tiene el otro: A tiene W y pide X; B tiene X y pide W. Eso cierra un ciclo y los dos esperan para siempre.

Acá B pide V, un recurso que no tiene A. Entonces no hay ciclo:

ProcesoTienePide¿Quién se lo retiene?
AWXB
BXVNadie de los dos

B recibe V, termina, libera X, y entonces A también puede seguir. No se cumple la espera circular (pregunta 11), así que no es un interbloqueo.

Trampas

  • En el parcial 2025 esta misma frase decía "el recurso W" y era verdadera. El cambio es una sola letra.

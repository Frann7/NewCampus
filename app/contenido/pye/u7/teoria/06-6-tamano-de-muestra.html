La formula del error, al reves

6. Tamano de muestra

Cuando se usa

Cuando preguntan cuantos datos hacen falta: "¿de que tamano se necesita la muestra para que el error sea a lo sumo 10 horas?", "tamano minimo de muestra para un margen de error de 1 ml".

Formula

\[ n = \left( \frac{z_{\alpha/2} \cdot \sigma}{e} \right)^{2} \]

Y el resultado se redondea siempre para arriba.

Que significa cada letra

SimboloQue esComo lo reconoces
\(e\)el error maximo que se acepta"error a lo sumo 10 horas", "margen de error de 1 ml", "dentro de 12 segundos de la media real"
\(\sigma\)desvio de la poblaciontiene que ser conocido ("por estudios previos…")
\(z_{\alpha/2}\)el de la confianza pedida95 % → 1,96

De donde sale

Es la formula del error (seccion 4) despejando \(n\):

\[ e = z_{\alpha/2} \frac{\sigma}{\sqrt{n}} \;\Longrightarrow\; \sqrt{n} = \frac{z_{\alpha/2}\,\sigma}{e} \;\Longrightarrow\; n = \left( \frac{z_{\alpha/2}\,\sigma}{e} \right)^{2} \]

Por que para arriba: \(n\) es una cantidad de datos, tiene que ser entero. Si da 61,47 y se toman 61, el error queda un poco mas grande que el pedido; con 62 queda por debajo. Por eso aunque de 24,01 se toma 25.

Ejemplo 1 — Botellas (final 29/07)

Enunciado

El contenido de las botellas es normal con desvio \(\sigma = 4\) ml. Determinar el tamano minimo de muestra para estimar la media con un margen de error maximo de 1 ml y un nivel de confianza del 95 %.

Desarme del enunciado

FraseTraduccionA donde va
"tamano minimo de muestra"piden \(n\)formula de tamano
"margen de error maximo de 1 ml"el error aceptado\(e = 1\)
"desvio 4 ml" (poblacion)\(\sigma\) conocida\(\sigma = 4\)
"95 %"\(F(z) = 0{,}975\)\(z_{\alpha/2} = 1{,}96\)

Paso 1 — Reemplazar. Formula:

\[ n = \left( \frac{z_{\alpha/2} \cdot \sigma}{e} \right)^{2} \]

\[ n = \left( \frac{1{,}96 \cdot 4}{1} \right)^{2} = (7{,}84)^{2} = 61{,}47 \]

Paso 2 — Redondear para arriba: 61,47 → 62.

Respuesta

Hacen falta al menos 62 botellas para que, con 95 % de confianza, el promedio no se aleje mas de 1 ml de la media real.

Ejemplo 2 — Cuando da casi entero

Enunciado

Las piezas tienen desvio 0,5 mm. ¿Cuantas hay que medir para que, con 95 % de confianza, el error sea a lo sumo 0,2 mm?

Datos: \(\sigma = 0{,}5\), \(e = 0{,}2\), \(z_{\alpha/2} = 1{,}96\).

\[ n = \left( \frac{z_{\alpha/2} \cdot \sigma}{e} \right)^{2} = \left( \frac{1{,}96 \cdot 0{,}5}{0{,}2} \right)^{2} = (4{,}9)^{2} = 24{,}01 \]

Respuesta

25 piezas. Aunque 24,01 este casi en 24, con 24 el error pasaria apenas de 0,2: se redondea para arriba igual.

Si piden el error a la mitad

Como \(e\) esta al cuadrado abajo, dividir el error por 2 multiplica \(n\) por 4. Precision cuesta cara.

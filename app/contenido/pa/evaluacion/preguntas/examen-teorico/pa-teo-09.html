Si quisieras descargar el código del Kernel de Linux desde el repositorio de GitHub de Linus Torvalds, ¿cuál de los siguientes comandos sería el correcto?

Examen teórico 2025 · preg. 9

  • git init https://github.com/torvalds/linux.git
  • git fetch https://github.com/torvalds/linux.git
  • git pull https://github.com/torvalds/linux.git
  • git clone https://github.com/torvalds/linux.git

Qué evalúa

Qué comando de Git copia un repositorio remoto que todavía no tenés.

La idea

ComandoQué hace
git clone URLCrea una carpeta nueva con una copia completa del repositorio (archivos e historial). Es el que se usa la primera vez.
git initCrea un repositorio vacío en la carpeta actual. No descarga nada.
git fetchTrae los cambios nuevos del remoto a un repositorio que ya tenés, sin mezclarlos.
git pullEs fetch + merge: trae y mezcla en tu rama. También es para un repositorio que ya existe.

Opción por opción

Opción¿Va?Por qué
git init …NoNo recibe una URL para descargar: crea un repositorio vacío.
git fetch …NoActualiza un repositorio que ya tenés; no crea la copia.
git pull …NoIgual que fetch, más el merge: supone que ya clonaste.
git clone …SíDescarga el repositorio entero en una carpeta nueva (linux/).

Trampas

  • pull suena a “bajar”, pero baja cambios a algo que ya tenés. Para traerlo por primera vez es clone.

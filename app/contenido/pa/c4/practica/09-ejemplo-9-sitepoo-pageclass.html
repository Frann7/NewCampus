Ejemplo 9 · sitePoo: PageClass.php

Un sitio armado con una clase de PHP

sitePoo ("sitio con POO", programación orientada a objetos) es un sitio chico de dos páginas: Inicio y un Formulario de Personas. Todas las páginas comparten el mismo encabezado, menú y pie, y en vez de copiarlos en cada archivo, los arma una clase de PHP, PageClass. Cada página solo escribe su contenido propio. Este ejemplo explica esa clase; el 10, el formulario y su validación.

Paso 3 — PageClass.php 
<?php

class PageClass
{
    private $header;
    private $navbar;
    private $body;
    private $js;
    private $footer;

    function __construct()
    {
       $this->setHeader();
       $this->setNavBar();
       $this->setJs();
       $this->setFooter();
    }

    private function setHeader()
    {
        $this->header='<!DOCTYPE html>
                <html lang="es">
                 <head>
                    <meta charset="UTF-8">
                    <meta name="viewport" content="width=device-width, initial-scale=1, shrink-to-fit=no">
                    <title>Programación Avanzada</title>
                    <link rel="icon" href="/imgs/favicon.ico" type="image/x-icon">
                    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.0.2/dist/css/bootstrap.min.css" rel="stylesheet" ...>
                </head>
                <body class="bg-light">
                    <div class="container">';
    }

    private function setNavBar()
    {
        $this->navbar='<nav class="navbar navbar-expand-lg navbar-light bg-light">
                    <div class="container-fluid">
                        <a class="navbar-brand" href="index.php">
                            <img src="imgs/desarrollo-web.svg" width="30" height="30" class="d-inline-block align-top">
                            Programación Avanzada
                        </a>
                        <button class="navbar-toggler" type="button" data-toggle="collapse" data-target="#navbarNav" ...>
                            <span class="navbar-toggler-icon"></span>
                        </button>
                        <div class="collapse navbar-collapse" id="navbarSupportedContent">
                            <ul class="navbar-nav me-auto mb-2 mb-lg-0">
                                <li class="nav-item">
                                    <a class="nav-link active" aria-current="page" href="index.php">Inicio</a>
                                </li>
                                <li class="nav-item">
                                    <a class="nav-link" aria-current="page" href="formPersonas.php">Formulario de Personas</a>
                                </li>
                            </ul>
                        </div>
                    </div>
                </nav>';
    }

    public function setBody($body)
    {
        $this->body=$body;
        $this->body.='</div>';
    }

    private function setJs()
    {
        $this->js='<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.7/dist/js/bootstrap.bundle.min.js" ...></script>
                   <script src="js/formPersonas.js"></script>';
    }

    private function setFooter()
    {
        $this->footer='</body></html>';
    }

    public function getHtml()
    {
        $Pagina=$this->header;
        $Pagina.=$this->navbar;
        $Pagina.=$this->body;
        $Pagina.=$this->js;
        $Pagina.=$this->footer;
        return $Pagina;
    }
}

(Los ... son los atributos integrity/crossorigin de Bootstrap y los aria-* del botón, que no cambian nada de lo que se explica.)

MétodoQué haceQué guarda
__construct()Al crear el objeto, llama a los cuatro set... privados. No llama a setBody: el contenido lo pone cada página—
setHeader()Arma el principio del documento: <head> con Bootstrap, apertura del <body> y de un <div class="container">$this->header = un string largo. Va entre comillas simples, que en PHP pueden ocupar varias líneas
setNavBar()Arma el menú de arriba: logo, "Programación Avanzada" y dos enlaces (Inicio y Formulario de Personas)$this->navbar
setBody($body)Público: lo llama cada página con su contenido. Le agrega al final </div>, que cierra el container abierto en el header$this->body = contenido + </div>
setJs()Los dos <script>: el JavaScript de Bootstrap y js/formPersonas.js$this->js
setFooter()Cierra </body></html>$this->footer
getHtml()Público: pega las cinco partes en orden y devuelve la página entera como un solo stringDevuelve header + navbar + body + js + footer

LíneaQué haceCómo quedan las variables
require_once __DIR__.'\includes\PageClass.php';Trae el archivo de la clase. __DIR__ es la carpeta donde está index.php; se le pega la ruta relativa. require_once corta con error si no lo encuentra, y no lo trae dos vecesLa clase PageClass ya existe

echo $oPage->getHtml();Imprime la página entera: eso es lo que le llega al navegador—

Lo que imprime index.php (verificado con php.exe; se juntaron los espacios de sangría y se recortó el medio):

 ...

 <script src="js/formPersonas.js"></script></body></html>

Por qué así: las partes quedan pegadas una tras otra sin salto de línea entre ellas (</nav><h4, </h4></div><script) porque getHtml() las concatena tal cual. El </div> que agregó setBody cierra el container justo antes de los scripts.

La ruta con barras invertidas

'\includes\PageClass.php' usa \, el separador de Windows: en XAMPP sobre Windows anda (verificado). En un servidor Linux no lo encontraría y require_once cortaría la página. La barra común '/includes/PageClass.php' anda en los dos.

formPersonas.js se carga en todas las páginas

setJs() es el mismo para todas, así que index.php también carga la validación del formulario, aunque no tenga formulario. Por eso el JavaScript, antes de arrancar, pregunta si el formulario existe (ejemplo 10).

El menú en pantallas chicas

En una ventana angosta Bootstrap esconde los enlaces del menú y muestra el botón de tres rayitas. Ese botón apunta a #navbarNav con atributos de Bootstrap 4 (data-toggle), pero el menú se llama navbarSupportedContent y la página usa Bootstrap 5 (data-bs-toggle): el botón no abre nada. En una ventana ancha no se nota.

Qué se ve en la página

Fondo gris claro; arriba, el menú con el logo (una pantalla con </>), "Programación Avanzada" y los enlaces Inicio y Formulario de Personas; abajo, centrado, "Página de Inicio". Cualquier página nueva del sitio tendría el mismo menú escribiendo solo su $body.

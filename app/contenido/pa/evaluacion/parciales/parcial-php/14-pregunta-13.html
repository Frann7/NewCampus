Verdadero

✎ Explicación detalladaQué evalúa, el concepto desde cero, la traza y las trampas

Qué evalúa

El número opcional de break. Es de la Clase 1, “Detener y continuar”, que muestra un break 2 dentro de dos for.

El concepto, desde cero

Un ciclo (for, while, foreach) repite un bloque de código; cada repetición es una vuelta. Las estructuras están anidadas cuando una está adentro de otra: un for adentro de otro for, por ejemplo. Por cada vuelta del de afuera, el de adentro da todas sus vueltas.

break corta el ciclo (o el switch) en el que está y PHP sigue con lo que viene después de él. Un argumento es un dato que se le agrega a una instrucción para decirle cómo trabajar; el de break es un número y es opcional (se puede no poner): break n sale de n estructuras anidadas de una vez. break 1 es lo mismo que break solo; break 2 sale del ciclo de adentro y también del de afuera.

Un ejemplo

<?php
for ($i = 1; $i <= 3; $i++) {
  for ($j = 1; $j <= 3; $j++) {
    if ($j == 2) break 2;
    echo "$i-$j ";
  }
}
echo "fin";
?>

$jOtra variable contadora, la del for de adentro.
$j == 2Comparación: “¿$j es igual a 2?”. Con dos = compara; con uno solo, asignaría.
if (…) break 2;Un if sin llaves: afecta solo a la instrucción que le sigue. Si la condición es true, ejecuta break 2.
echo "$i-$j ";Dentro de comillas dobles, PHP reemplaza cada variable por su valor: con $i = 1 y $j = 1 imprime 1-1 . (Con comillas simples imprimiría literalmente $i-$j.)

Respuesta

Verdadero. La afirmación dice exactamente esto: el número es opcional e indica de cuántas estructuras anidadas se sale.

La trampa

break 2 no quiere decir “saltear 2 vueltas”: el número cuenta estructuras de las que salir. (continue también acepta un número.)

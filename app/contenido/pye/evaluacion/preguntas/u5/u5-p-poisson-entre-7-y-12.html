Mismo servidor: 0,2 mensajes por minuto, o sea \(\lambda t = 12\) en una hora.

Segundo Parcial 2023, Ejercicio 5 c

Probabilidad de recibir entre siete y doce mensajes en una hora, ambos extremos incluidos.

  • \(0{,}5302\)
  • \(0{,}4427\)
  • \(0{,}5760\)
  • \(0{,}6218\)

Con una tabla acumulada, un “entre \(a\) y \(b\) inclusive” es \(F(b) - F(a-1)\). El \(-1\) es lo que hace que el extremo izquierdo quede adentro.

\[ P(7 \leq X \leq 12) = P(X \leq 12) - P(X \leq 6) = 0{,}5760 - 0{,}0458 = \mathbf{0{,}5302} \]

El error típico es restar \(P(X \leq 7)\) en vez de \(P(X \leq 6)\): eso deja el 7 afuera y da 0,4427, que está puesta como opción a propósito.

  1. ¿Qué resta hay que hacer?

    • \(P(X \leq 12) - P(X \leq 6)\)
    • \(P(X \leq 12) - P(X \leq 7)\)
    • \(P(X \leq 11) - P(X \leq 6)\)
    • \(P(X \leq 12) + P(X \leq 6)\)

    Los dos extremos entran. Restá hasta el anterior al primero.

    \(F(12) - F(6)\).

  2. Buscá \(P(X \leq 12)\) con \(\lambda t = 12\).

    \(P(X \leq 12) = 0{,}5760\)

    Fila \(r = 12\).

    \(0{,}5760\). Tiene sentido que ronde 0,5: 12 es la media.

  3. Buscá \(P(X \leq 6)\).

    \(P(X \leq 6) = 0{,}0458\)

    Fila \(r = 6\).

    \(0{,}0458\).

  4. Restá.

    \(P(7 \leq X \leq 12) = P(X \leq 12) - P(X \leq 6) = 0{,}5760 - 0{,}0458 = 0{,}5302\)

    \(0{,}5760 - 0{,}0458\).

    \(0{,}5302\).

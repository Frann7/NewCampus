2. Algo de JavaScript

Para qué sirve

JavaScript (JS) es el lenguaje que entiende el navegador. PHP corre en el servidor y lo que le llega al navegador es solo el HTML que PHP imprimió; JavaScript, en cambio, viaja al navegador y corre ahí, en la computadora de quien mira la página. Por eso puede reaccionar a un clic o a lo que se escribe en un campo sin volver a pedirle nada al servidor.

La diapositiva 8 solo dice "Algo de JavaScript". Acá va lo mínimo para poder leer los ejemplos de la cátedra, todo lo que usan y nada más.

Sintaxis

El código va en un archivo .js que el HTML carga con <script>, normalmente al final del <body>:

<script src="js/page1Class.js" type="text/javascript"></script>

Y adentro de ese archivo:

let nombre = "Fede";              // variable que puede cambiar
const edad = 20;                  // constante: no se puede reasignar
let saludo = `Hola ${nombre}`;    // template literal: mete variables en el texto
console.log(saludo);              // escribe en la consola del navegador (F12)
alert("Cuidado");                 // muestra un cartel en la página

const sumar = (a, b) => a + b;    // función flecha
const notas = [7, 4, 9];          // array
notas.forEach(nota => { console.log(nota); });   // recorre el array
const persona = { nombre: "Juan", edad: 30 };     // objeto

Ejemplo 1 — Variables y template literals

Enunciado

¿Qué muestra la consola?

let nombre = "Fede";
const edad = 20;
nombre = "Ana";
console.log(`Hola ${nombre}, tenés ${edad + 1} años`);
LíneaQué haceCómo quedan las variables
let nombre = "Fede";Crea la variable nombre con let, así que se puede cambiarnombre = "Fede"
const edad = 20;Crea la constante edadnombre = "Fede", edad = 20
nombre = "Ana";Reasigna nombre. Ya no lleva let: la variable existenombre = "Ana", edad = 20
console.log(`...`);Arma el texto reemplazando ${nombre} por Ana y ${edad + 1} por el resultado de la cuenta, 21Sin cambios: edad + 1 no modifica edad

Qué muestra (verificado con Node.js, que corre JavaScript fuera del navegador):

Hola Ana, tenés 21 años

Por qué: el template literal resuelve cada ${...} en el momento de armar el texto, con el valor que la variable tiene en ese momento ("Ana", no "Fede"). Y la cuenta adentro de ${ } se calcula, pero el resultado no se guarda en ninguna variable.

Ejemplo 2 — ¿Qué muestra? (texto contra número)

Enunciado

¿Cuál es la salida del siguiente código?

let a = "5";
let b = 5;
console.log(a == b);
console.log(a === b);
console.log(a + b);
console.log(parseFloat("32px") + 2 + "px");
LíneaQué haceCómo quedan las variables
let a = "5";Guarda el texto "5" (está entre comillas)a = "5" (string)
let b = 5;Guarda el número 5a = "5", b = 5 (number)
a == b== convierte el texto "5" en el número 5 y recién compara: 5 es igual a 5→ true
a === b=== no convierte: uno es texto y el otro número, así que ya son distintos→ false
a + bComo a es texto, el + une: "5" pegado a 5→ "55"
parseFloat("32px") + 2 + "px"Se resuelve de izquierda a derecha: parseFloat("32px") da el número 32; 32 + 2 son dos números, suma: 34; 34 + "px" tiene un texto, une: "34px"→ "34px"

Qué muestra (verificado con Node.js):

true
false
55
34px

Por qué: el + de JavaScript hace dos trabajos. Mira los dos lados: si hay algún texto, concatena; si son todos números, suma. La última línea es exactamente la cuenta que usan los ejemplos de la cátedra para agrandar la letra (práctica, ejemplo 1).

Ejemplo 3 — Recorrer un array con forEach

Enunciado

¿Qué muestra la consola y qué valor queda en suma?

const notas = [7, 4, 9];
let suma = 0;
notas.forEach((nota, i) => {
  console.log(`Nota ${i + 1}: ${nota}`);
  suma = suma + nota;
});
console.log(suma / notas.length);
LíneaQué haceCómo quedan las variables
const notas = [7, 4, 9];Crea el array. Posiciones: 0 → 7, 1 → 4, 2 → 9notas = [7, 4, 9]
let suma = 0;Acumulador en cerosuma = 0
forEach, 1ra vueltanota = 7, i = 0. Imprime "Nota 1: 7" (i + 1 para que no empiece en 0) y sumasuma = 0 + 7 = 7
forEach, 2da vueltanota = 4, i = 1. Imprime "Nota 2: 4"suma = 7 + 4 = 11
forEach, 3ra vueltanota = 9, i = 2. Imprime "Nota 3: 9"suma = 11 + 9 = 20
console.log(suma / notas.length);notas.length es 3; divide 20 entre 3→ 6.666666666666667

Qué muestra (verificado con Node.js):

Nota 1: 7
Nota 2: 4
Nota 3: 9
6.666666666666667

Por qué: forEach llama a la función flecha tres veces, una por elemento, pasándole el elemento y su posición. El decimal sale con punto y sin redondear porque console.log muestra el número tal cual.

¿Por qué notas es const si el array se usa?

const impide reasignar la variable (notas = [1] daría error), no impide cambiar lo de adentro: notas.push(10) funciona. Por eso la cátedra declara con const los elementos y arrays que después modifica.

Errores y trampas

Lo que viene de un campo de formulario es texto

Aunque el campo sea de edad, lo que se lee de él es un string: "20", no 20. Si hacés edad + 1 te da "201". Hay que pasarlo a número con parseFloat antes de sumar.

isNaN("") da false

El texto vacío se lee como el número 0, así que isNaN("") dice "sí es un número" (verificado: false). Por eso la cátedra, para ver si una edad es válida, pregunta las dos cosas: edad === '' || isNaN(edad) (|| es "o", como en PHP).

Reasignar una const

const x = 1; x = 2; corta el programa con TypeError: Assignment to constant variable. Si la variable va a cambiar (un contador, un acumulador), va con let.

Acento grave, no comilla

"Hola ${nombre}" con comillas comunes imprime literalmente Hola ${nombre}. El reemplazo solo funciona con `acentos graves`. Al revés que en PHP, donde las comillas dobles sí reemplazan.

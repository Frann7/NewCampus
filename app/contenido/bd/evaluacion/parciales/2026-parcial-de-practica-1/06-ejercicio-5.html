Unidad 4 · Consultas

Ejercicio 5: Utilizando sentencias SQL, realice los scripts correspondientes para generar cada uno de los siguientes listados:

  1. Listado de reservas pendientes, ordenado por fecha y hora (más antiguas primero), mostrando número de reserva, fecha, hora, nombre del socio, nombre de la clase y nombre del profesor.
  2. Listado de cantidad de reservas pendientes por socio, ordenado por país, provincia, ciudad y nombre del socio. Se debe mostrar: País, Provincia, Ciudad, Nombre del Socio, Cantidad de Reservas Pendientes.
  3. Listado de socios ordenados por total pagado durante los últimos 12 meses, agrupado por año y mes. Mostrar: Año, Mes, Nombre del Socio, Total Pagado.
  4. Listado de clases con la cantidad de reservas que tiene cada una, incluyendo las clases que no tienen ninguna.
✓ ResultadosSolo la respuesta

a)

SELECT r.Numero AS NroReserva,
       CAST(r.FechaHora AS DATE) AS Fecha,
       CAST(r.FechaHora AS TIME) AS Hora,
       s.Nombre AS Socio,
       c.Nombre AS Clase,
       pr.Nombre AS Profesor
FROM Reserva r
INNER JOIN Socio s ON s.DNI = r.DNI
INNER JOIN Clase c ON c.Codigo = r.CodigoClase
INNER JOIN Profesor pr ON pr.Legajo = c.Legajo
WHERE r.Estado = 'Pendiente'
ORDER BY r.FechaHora ASC;

b)

SELECT pa.Nombre AS Pais,
       pv.Nombre AS Provincia,
       ci.Nombre AS Ciudad,
       s.Nombre AS Socio,
       COUNT(r.Numero) AS CantidadReservasPendientes
FROM Socio s
INNER JOIN Ciudad ci ON ci.IdCiudad = s.IdCiudad
INNER JOIN Provincia pv ON pv.IdProvincia = ci.IdProvincia
INNER JOIN Pais pa ON pa.IdPais = pv.IdPais
INNER JOIN Reserva r ON r.DNI = s.DNI
WHERE r.Estado = 'Pendiente'
GROUP BY pa.Nombre, pv.Nombre, ci.Nombre, s.DNI, s.Nombre
ORDER BY pa.Nombre, pv.Nombre, ci.Nombre, s.Nombre;

c)

SELECT YEAR(p.Fecha) AS Anio,
       MONTH(p.Fecha) AS Mes,
       s.Nombre AS Socio,
       SUM(pc.Importe) AS TotalPagado
FROM Socio s
INNER JOIN Pago p ON p.DNI = s.DNI
INNER JOIN Pago_Concepto pc ON pc.NumeroPago = p.Numero
WHERE p.Fecha >= DATEADD(MONTH, -12, GETDATE())
GROUP BY YEAR(p.Fecha), MONTH(p.Fecha), s.DNI, s.Nombre
ORDER BY TotalPagado DESC;

d)

SELECT c.Codigo, c.Nombre, COUNT(r.Numero) AS CantidadReservas
FROM Clase c
LEFT JOIN Reserva r ON r.CodigoClase = c.Codigo
GROUP BY c.Codigo, c.Nombre;

a) Reservas pendientes

  • Columnas: número, fecha y hora (Reserva, con CAST), socio (Socio), clase (Clase) y profesor (Profesor).
  • Camino: Reserva → Socio; Reserva → Clase → Profesor. El profesor no está en la reserva: se llega por la clase.
  • Filtro: r.Estado = 'Pendiente'. Orden: r.FechaHora ASC.
SELECT r.Numero AS NroReserva,
       CAST(r.FechaHora AS DATE) AS Fecha,
       CAST(r.FechaHora AS TIME) AS Hora,
       s.Nombre AS Socio,
       c.Nombre AS Clase,
       pr.Nombre AS Profesor
FROM Reserva r
INNER JOIN Socio s ON s.DNI = r.DNI
INNER JOIN Clase c ON c.Codigo = r.CodigoClase
INNER JOIN Profesor pr ON pr.Legajo = c.Legajo
WHERE r.Estado = 'Pendiente'
ORDER BY r.FechaHora ASC;

b) Cantidad por socio

  • Camino: Pais ← Provincia ← Ciudad ← Socio → Reserva. Acá el socio reserva directo (en la veterinaria había que pasar por el animal).
  • Filtro en el WHERE; COUNT(r.Numero); al GROUP BY todo lo demás más el DNI.
  • Orden: esta vez la consigna incluye el país: ORDER BY país, provincia, ciudad y nombre.
SELECT pa.Nombre AS Pais,
       pv.Nombre AS Provincia,
       ci.Nombre AS Ciudad,
       s.Nombre AS Socio,
       COUNT(r.Numero) AS CantidadReservasPendientes
FROM Socio s
INNER JOIN Ciudad ci ON ci.IdCiudad = s.IdCiudad
INNER JOIN Provincia pv ON pv.IdProvincia = ci.IdProvincia
INNER JOIN Pais pa ON pa.IdPais = pv.IdPais
INNER JOIN Reserva r ON r.DNI = s.DNI
WHERE r.Estado = 'Pendiente'
GROUP BY pa.Nombre, pv.Nombre, ci.Nombre, s.DNI, s.Nombre
ORDER BY pa.Nombre, pv.Nombre, ci.Nombre, s.Nombre;

c) Total pagado por año y mes

  • Camino: Socio → Pago → Pago_Concepto (donde está el Importe).
  • Filtro: p.Fecha >= DATEADD(MONTH, -12, GETDATE()).
  • SUM(pc.Importe), y GROUP BY el año, el mes y el socio. Orden: por total, de mayor a menor.
SELECT YEAR(p.Fecha) AS Anio,
       MONTH(p.Fecha) AS Mes,
       s.Nombre AS Socio,
       SUM(pc.Importe) AS TotalPagado
FROM Socio s
INNER JOIN Pago p ON p.DNI = s.DNI
INNER JOIN Pago_Concepto pc ON pc.NumeroPago = p.Numero
WHERE p.Fecha >= DATEADD(MONTH, -12, GETDATE())
GROUP BY YEAR(p.Fecha), MONTH(p.Fecha), s.DNI, s.Nombre
ORDER BY TotalPagado DESC;

d) La consulta con LEFT JOIN

  • "Incluyendo las clases que no tienen ninguna": LEFT JOIN desde Clase (Unidad 4, sección 2). Los profes avisaron que probablemente haya una así.
  • COUNT(r.Numero), de la tabla de la derecha: la clase sin reservas da 0. Con COUNT(*) daría 1.
SELECT c.Codigo, c.Nombre, COUNT(r.Numero) AS CantidadReservas
FROM Clase c
LEFT JOIN Reserva r ON r.CodigoClase = c.Codigo
GROUP BY c.Codigo, c.Nombre;

Trampas

  • En a), el profesor se trae pasando por Clase: no hay FK de Reserva a Profesor.
  • En c), el total de un pago no está guardado: se suma el detalle (Pago_Concepto).

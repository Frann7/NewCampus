5. Variables

Para qué sirve

Una variable es un contenedor donde se guarda un dato por un rato, para usarlo después. Puede guardar cualquiera de los tipos de la sección 4, y lo que tiene adentro puede cambiar mientras corre el programa.

Sintaxis

$nombre = valor;

Qué es cada parte

ParteQué es
$Toda variable empieza con el signo pesos. Es lo que le dice a PHP "esto es una variable".
nombreEl identificador. Puede tener letras (a-z, A-Z), números y guion bajo _. Tiene que empezar con una letra o con _, nunca con un número.
=Asignación: guarda el valor de la derecha en la variable de la izquierda.
valorEl dato a guardar: 5, 'rojo', true...

Tres reglas más

  • No se declara el tipo. En PHP las variables no se "tipan" antes de usarlas: se crean en el momento en que se les asigna un valor, y el tipo sale del valor.
  • Distingue mayúsculas de minúsculas. $nombre y $Nombre son dos variables distintas.
  • Ámbito. Cada variable vale en una parte del programa: una variable global vale en todo el script; una local, solo dentro de la función donde se creó (las funciones se ven más adelante).

Qué nombres valen

Nombre¿Válido?Por qué
$valorSíEmpieza con letra.
$_valorSíEmpieza con guion bajo.

Variables predefinidas (superglobales)

PHP trae variables especiales ya creadas, que sirven para recuperar datos que vienen de afuera del script (lo que mandó un formulario, datos del servidor, la sesión del usuario):

$GLOBALS · $_SERVER · $_GET · $_POST · $_COOKIE · $_FILES · $_ENV · $_REQUEST · $_SESSION

Se usan en las clases de formularios y de sesiones.

Variables variables

Una variable variable es una variable cuyo nombre sale del valor de otra. Se escribe con dos $: si $saludar vale "saludo_es", entonces $$saludar es la variable $saludo_es.

Ejemplo 1 — Crear y usar variables (el de la presentación)

El punto . pega dos textos uno detrás del otro (se llama concatenar; sección 8).

<?php
$color = 'rojo';
$numero = 5;
echo 'Mi color favorito es el:  '.$color;
echo 'Mi número favorito es el: '.$numero;
?>

Qué hace cada línea

LíneaQué haceCómo quedan las variables
$color = 'rojo';Crea $color con un string. No hizo falta decir "es texto".$color = 'rojo'
$numero = 5;Crea $numero con un entero.$color = 'rojo', $numero = 5
echo '...el: '.$color;Pega el texto con el valor de $color y lo muestra.sin cambios
echo '...el: '.$numero;Pega el texto con el 5 y lo muestra.sin cambios

Qué imprime y por qué

Mi color favorito es el:  rojoMi número favorito es el: 5

Las dos frases salen pegadas: ningún echo imprimió un <br> ni un espacio entre "rojo" y "Mi". PHP muestra exactamente lo que se le pide, ni un carácter más.

Ejemplo 3 — Variables variables (el de la cátedra)

<?php
$idioma = "es";
$saludo_es = "Hola!!!";
$saludo_en = "Hello!!!";
$saludar = "saludo_" . $idioma;
print $$saludar;
?>

Qué hace cada línea

LíneaQué haceCómo quedan las variables
$idioma = "es";Elige el idioma.$idioma = "es"
$saludo_es = "Hola!!!";El saludo en español.$saludo_es = "Hola!!!"
$saludo_en = "Hello!!!";El saludo en inglés.$saludo_en = "Hello!!!"
$saludar = "saludo_" . $idioma;Pega "saludo_" con "es".$saludar = "saludo_es"
print $$saludar;Primero se reemplaza el $saludar de adentro por su valor: queda $saludo_es. Después se muestra esa variable.sin cambios

Qué imprime y por qué

Hola!!!

Si la primera línea fuera $idioma = "en";, $saludar valdría "saludo_en", $$saludar sería $saludo_en y saldría Hello!!!. El mismo print muestra una variable u otra según un dato.

Errores y trampas

Una mayúscula es otra variable 
<?php
$nombre = "Fran";
echo "Hola " . $Nombre;
?>

$Nombre nunca se creó (la que existe es $nombre). PHP avisa y la toma como vacía:

Warning: Undefined variable $Nombre in ... on line 3
Hola
$_COOKIES no existe

El apunte la escribe $_COOKIES, pero el nombre real es $_COOKIE, sin S.

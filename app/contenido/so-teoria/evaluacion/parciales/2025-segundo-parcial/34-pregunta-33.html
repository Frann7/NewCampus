Pregunta 33

2 pts Cliente/servidor · Terminología

Seleccione una:

Cuando nos referimos a computación distribuida, los siguientes son terminologías de cliente/servidor (responda la mas completa):

  1. API, Cliente, Middleware, base de datos, servidor y Lenguaje Estructurado de Consultas
  2. API, cliente, Firmware, base de datos, servidor y Lenguaje Estructurado de Consultas
  3. API, Firmware, base de datos, cliente, servidor y Lenguaje Estructurado de Consultas
  4. API, Firmware, base de datos, servidor y Lenguaje Estructurado de Consultas
✓ ResultadosSolo la respuesta

Correcta: a — API, Cliente, Middleware, base de datos, servidor y Lenguaje Estructurado de Consultas.

✎ Explicación detalladaDe dónde sale, opción por opción y las trampas

Qué evalúa

La tabla de terminología cliente/servidor de Stallings.

La idea

TérminoQué es
APIInterfaz de programa de aplicación: funciones que un programa llama para usar los servicios de otro.
ClienteQuien pide información o servicios (PC o estación de trabajo).
MiddlewareControladores, API y software que mejoran la conexión entre cliente y servidor (pregunta 38).
Base de datos (relacional)Donde el servidor guarda la información, con acceso restringido.
ServidorLa computadora que guarda la información para los clientes (pregunta 37).
Lenguaje Estructurado de Consultas (SQL)El lenguaje para consultar y actualizar la base de datos.

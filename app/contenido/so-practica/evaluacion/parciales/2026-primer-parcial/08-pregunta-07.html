Pregunta 7

5 pts Clase 7 · Procesos y señales

Si quiero enviarle una señal SIGKILL con el comando kill para detener solamente el programa htop, como seria el comando.

Respuesta: ______________________

✓ ResultadosSolo la respuesta

kill -9 22846 (también vale kill -SIGKILL 22846).

✎ Explicación detalladaDe dónde sale, opción por opción y las trampas

Qué evalúa

Encontrar el PID del proceso en htop y escribir kill con la señal SIGKILL.

Paso a paso

  1. Buscar la fila cuya columna Command es htop: 1768 22846 exequiel … htop.
  2. Las dos primeras columnas son PPID (1768, el padre) y PID (22846, el proceso). kill va con el PID.
  3. SIGKILL es la señal 9: kill -9 22846.

Las señales de la clase 7

N.ºSeñalQué hace
15SIGTERMPide la terminación (el proceso puede cerrar ordenado). Es la que manda kill sin número
9SIGKILLTermina el proceso en forma inmediata
2SIGINTLo mismo que Ctrl + C
20SIGTSTPLo mismo que Ctrl + Z (lo detiene)
19SIGCONTReanuda un proceso detenido

Trampas

  • Usar el PPID (1768) mataría al padre (la terminal), no solo a htop.
  • killall -9 htop también lo mata, pero la consigna pide kill (con PID).

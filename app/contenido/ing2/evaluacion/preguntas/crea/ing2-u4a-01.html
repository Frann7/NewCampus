¿Qué patrón de diseño aplica este código?

#include <iostream>
#include <string>

class Registro {
private:
    static Registro* instancia_;
    Registro() {}

public:
    static Registro* obtener() {
        if (instancia_ == nullptr) {
            instancia_ = new Registro();
        }
        return instancia_;
    }
    void anotar(const std::string& texto) const {
        std::cout << "[log] " << texto << "\n";
    }
};

Registro* Registro::instancia_ = nullptr;

int main() {
    Registro::obtener()->anotar("inicio");
    Registro::obtener()->anotar("fin");
    return 0;
}

Inventada · estilo Parcial 2025, Práctica 2

  • Facade
  • Factory Method
  • Singleton
  • Strategy

Están las tres señales del Singleton: el constructor privado (nadie puede hacer new Registro() desde afuera), un atributo estático que guarda la única instancia, y un método estático público que la crea la primera vez y después devuelve siempre la misma. En el main nunca aparece un new: se pide el objeto a la clase.

El componente HTML "INPUT" tipo text:

Parcial PHP · preg. 11

  • Nos permite el ingreso de una cadena de texto pero no vemos los caracteres que ingresamos.
  • Nos permite ingresar una cadena de texto pero no es visible dentro del formulario.
  • Nos permite ingresar una cadena de texto.
  • Nos permite ingresar un archivo para ser enviado al servidor.

<input type="text"> es la caja de una línea para escribir texto, y lo que se escribe se ve: nos permite ingresar una cadena de texto.

Las otras opciones describen otros tipos: no ver los caracteres es type="password"; no ser visible, type="hidden"; enviar un archivo, type="file".

2. XAMPP: qué es y cómo se instala

Para qué sirve

Para programar en PHP hace falta un servidor web que lo ejecute (sección 1). XAMPP instala todo lo necesario en tu propia PC, en un solo paso: el servidor web, PHP y una base de datos. Así podés probar tu aplicación sin internet, en un servidor local, al que se entra con la dirección http://localhost/ ("localhost" = esta misma computadora).

Qué significa cada letra

XAMPP = X + Apache + MySQL + PHP + Perl
LetraQué esPara qué está
XCualquier sistema operativoIndica que funciona en diferentes sistemas operativos (hay versión para Windows, Linux, Mac OS X y Solaris). No es una herramienta: es "la incógnita".
AApacheEl servidor web: recibe los pedidos del navegador y responde.
MMySQL / MariaDBLa base de datos. Las versiones nuevas de XAMPP traen MariaDB, que es un derivado de MySQL.
PPHPEl lenguaje de programación que vamos a usar.
PPerlOtro lenguaje de programación, que viene incluido.

Además trae otras herramientas, por ejemplo phpMyAdmin (para manejar la base de datos desde el navegador). Es gratuito: la compilación de XAMPP se publica bajo la licencia GNU GPL, y cada programa que incluye tiene su propia licencia.

La instalación, en pasos

  1. Descargar el instalador del sitio oficial: https://www.apachefriends.org.
  2. Ejecutarlo y avanzar con OK / Next en la bienvenida.
  3. Carpeta de instalación: por defecto C:\xampp. Conviene dejarla así.
  4. Componentes: marcar al menos Apache y MySQL.
  5. Install y, al terminar, Finish.
  6. Abrir el Panel de control de XAMPP (el ícono naranja junto al reloj de Windows) y apretar Start en Apache y en MySQL.
  7. Verificar que los dos estén corriendo: cada uno tiene que mostrar un PID (número de proceso, cambia en cada inicio) y sus puertos: Apache 80 y 443, MySQL 3306 (los de por defecto).
  8. Probar el servidor: en el navegador, entrar a http://localhost/. Tiene que aparecer la página de bienvenida de XAMPP.

Dónde van tus archivos: htdocs

La carpeta C:\xampp\htdocs es el directorio público: lo que pongas ahí es lo que Apache sirve. La regla para pasar de archivo a dirección es reemplazar C:\xampp\htdocs por http://localhost:

Archivo en el discoDirección en el navegador
C:\xampp\htdocs\index.phphttp://localhost/index.php
C:\xampp\htdocs\prueba\hola.phphttp://localhost/prueba/hola.php

Ejemplo 1 — El primer script

Enunciado

Crear la carpeta prueba dentro de htdocs, guardar ahí hola.php con este código y abrirlo en el navegador.

<?php
echo "Hola desde XAMPP";
?>

Qué hace cada línea

LíneaQué hace
<?phpAbre el código PHP.
echo "Hola desde XAMPP";Escribe ese texto en la respuesta.
?>Cierra el código PHP.

Qué se ve y por qué

Con Apache encendido, en http://localhost/prueba/hola.php:

Hola desde XAMPP

Apache encontró el archivo en htdocs\prueba, se lo pasó a PHP, PHP ejecutó el echo y Apache le devolvió al navegador solo el texto.

Errores y trampas

La X no es "Windows"

Hay versiones para cada sistema operativo justamente porque la X es "cualquiera". Tampoco hay que confundir las dos P: una es PHP y la otra es Perl (no "Python").

Dos errores de tipeo de la guía

En los pasos finales la guía dice C:\wamp\ y http://localhost/wampp. Son restos de otra guía (WAMP es un programa parecido). Con XAMPP, la carpeta es C:\xampp y la página de bienvenida queda en http://localhost/dashboard/, como se ve en la captura de la misma guía.

Si la página no carga

Lo primero es mirar el panel: Apache tiene que estar en verde, con PID y puertos. Si está apagado, http://localhost/ no responde. Y el archivo tiene que estar dentro de htdocs: fuera de esa carpeta Apache no lo encuentra.

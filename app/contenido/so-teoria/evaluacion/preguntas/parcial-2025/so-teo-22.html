SUN Clusters
La implementación de Sun Cluster está orientada a objetos. Se utiliza el modelo de objetos de KarBon para definir los objetos y las llamadas a procedimiento remoto (RPC). Se utiliza el Lenguaje de Definición de Interfaces (IDL) de KarBon para especificar los interfaces entre los componentes MC de los diferentes nodos. Los objetos de MC se implementan en el lenguaje orientado a objetos C++.

Qué evalúa

El ejemplo de Sun Cluster de Stallings (un cluster hecho como extensión de Solaris).

Por qué es falso

La devolución del Aula Virtual lo dice: la implementación de Sun Cluster está orientada a objetos y se utiliza el modelo de objetos de CORBA para definir los objetos y las llamadas a procedimiento remoto (RPC).

Todo lo demás está bien: también se usa el IDL de CORBA para las interfaces entre los componentes MC (de Solaris MC, el proyecto del que salió) y los objetos se programan en C++. "KarBon" es inventado.

CORBA es un estándar para que objetos en distintas máquinas se llamen entre sí; su IDL describe esas interfaces sin depender del lenguaje.

Arreglos

8. Funciones entre arreglos: array_diff y array_intersect

Para qué sirve

Dos operaciones comunes cuando se trabaja con dos arreglos:

  • Diferencia (array_diff): los valores del primero que no están en el segundo.
  • Intersección (array_intersect): los valores del primero que también están en el segundo.

Es la diferencia y la intersección de conjuntos, mirando solo los valores.

Sintaxis

Las dos funciones 
$resultado = array_diff($a, $b);
$resultado = array_intersect($a, $b);

Qué es cada parte

ParteQué es
$aEl arreglo de donde salen los resultados. El orden importa: el resultado siempre son elementos de $a
$bEl arreglo contra el que se compara
$resultadoUn arreglo nuevo (los originales no cambian). Cada elemento conserva la clave que tenía en $a

Ejemplo 1 — Diferencia (teoría de la cátedra)

<?php
$a = array(1, 2, 3);
$b = array(1, 3, 6);
print_r(array_diff($a, $b));
?>
LíneaQué haceCómo quedan las variables
$a = array(1, 2, 3);Primer arreglo$a: 0 => 1 · 1 => 2 · 2 => 3
$b = array(1, 3, 6);Segundo arreglo$b: 0 => 1 · 1 => 3 · 2 => 6
array_diff($a, $b)Recorre $a: el 1 está en $b (afuera), el 2 no está (queda), el 3 está (afuera). El 2 conserva su clave 1resultado: 1 => 2
print_r(...)Muestra el resultado—
Array
(
    [1] => 2
)

El 6 no aparece aunque tampoco esté en los dos: array_diff solo devuelve elementos del primer arreglo.

Ejemplo 2 — Intersección (teoría de la cátedra)

<?php
$a = array(1, 2, 3);
$b = array(1, 3, 6);
print_r(array_intersect($a, $b));
?>
LíneaQué haceCómo quedan las variables
array_intersect($a, $b)Recorre $a: el 1 está en $b (queda, clave 0), el 2 no (afuera), el 3 sí (queda, clave 2)resultado: 0 => 1 · 2 => 3
Array
(
    [0] => 1
    [2] => 3
)
Las salidas del apunte de la cátedra están mal
  • Para la diferencia muestra [0] => 2: el valor está bien pero la clave es [1], porque se conserva la que el 2 tenía en $a.
  • Para la intersección muestra [0] => 2 y [1] => 3: el 2 no está en $b. Lo que coincide es el 1 y el 3, con claves 0 y 2.
  • Además, los códigos del apunte no corren tal cual: a $b = array(1,3,6) le falta el ;, y la función está escrita array_intersec (le falta la t).

Errores y trampas

Las claves quedan con huecos

Igual que con unset() (sección 5), el resultado puede quedar con claves salteadas (0 y 2). Un for de 0 a count()-1 pediría la clave 1, que no existe; para recorrerlo, foreach (sección 6).

El orden de los argumentos cambia el resultado

array_diff($b, $a) con los arreglos del ejemplo 1 da [2] => 6: lo que está en $b y no en $a.

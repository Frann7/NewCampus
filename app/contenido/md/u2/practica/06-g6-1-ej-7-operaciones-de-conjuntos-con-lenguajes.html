Grimaldi 6.1 · Ej. 7 · Operaciones de conjuntos

Intersección, diferencia, diferencia simétrica y complemento de tres lenguajes

Para el alfabeto \(\Sigma = \{0, 1\}\), sean \(A, B, C \subseteq \Sigma^*\) los siguientes lenguajes:

\(A = \{0, 1, 00, 11, 000, 111, 0000, 1111\}\), \(B = \{w \in \Sigma^* \mid 2 \leq \|w\|\}\), \(C = \{w \in \Sigma^* \mid 2 \geq \|w\|\}\).

Determine los siguientes subconjuntos (lenguajes) de \(\Sigma^*\).

a) \(A \cap B\)   b) \(A - B\)   c) \(A \triangle B\)   d) \(A \cap C\)   e) \(B \cap C\)   f) \(B \cup C\)   g) \(\overline{A \cap C}\)   h) \(\overline{A} \cap \overline{C}\)   i) \(\overline{A} \cap B\)

Qué tema es y por qué
  • Un lenguaje es un conjunto de cadenas (en la teoría, "Lenguajes y concatenación"), así que se le aplican las operaciones de conjuntos de siempre. El conjunto universal es \(\Sigma^*\).

\(X \cap Y\): las que están en los dos. \(X \cup Y\): las que están en alguno. \(X - Y\): las de \(X\) que no están en \(Y\).

\(X \triangle Y = (X - Y) \cup (Y - X)\): las que están en uno solo. \(\overline{X} = \Sigma^* - X\): todas las cadenas que no están en \(X\).

Desarme del enunciado
LenguajeQué significaCómo es
\(A\)8 cadenas: dos de cada largo 1, 2, 3, 4 (todo ceros o todo unos)finito

\(C\): "\(2 \geq \|w\|\)"largo 0, 1 o 2: \(\{\lambda, 0, 1, 00, 01, 10, 11\}\)finito, 7 cadenas

Truco para todo el ejercicio: \(A\), \(B\) y \(C\) se describen por largo, así que conviene preguntarse qué largo tiene cada cadena.

Paso 1 — a), b), c): \(A\) contra \(B\)

De \(A\), las de largo \(\geq 2\) están en \(B\); las de largo 1 (\(0\) y \(1\)) no.

  • a) \(A \cap B = \{00, 11, 000, 111, 0000, 1111\}\).
  • b) \(A - B = \{0, 1\}\).
  • c) Con \(X \triangle Y = (X - Y) \cup (Y - X)\): \(A - B = \{0, 1\}\) y \(B - A\) son las cadenas de largo \(\geq 2\) que no están en \(A\). Juntas: todas las cadenas salvo \(\lambda\) (no está en ninguno) y salvo las de \(A \cap B\) (están en los dos): \[A \triangle B = \Sigma^* - \{\lambda, 00, 11, 000, 111, 0000, 1111\}\]
Paso 2 — d), e), f): con \(C\)
  • d) De \(A\), las de largo \(\leq 2\): \(A \cap C = \{0, 1, 00, 11\}\).
  • e) Largo \(\geq 2\) y \(\leq 2\) a la vez: largo exactamente 2. \(B \cap C = \{00, 01, 10, 11\} = \{w \mid \|w\| = 2\}\).
  • f) Toda cadena tiene largo \(\geq 2\) o \(\leq 2\): \(B \cup C = \Sigma^*\).
Paso 3 — g), h), i): complementos
  • g) Con \(\overline{X} = \Sigma^* - X\) y d): \(\overline{A \cap C} = \Sigma^* - \{0, 1, 00, 11\}\). Dicho de otra forma: \(\{\lambda, 01, 10\} \cup \{w \mid \|w\| \geq 3\}\).
  • h) Por De Morgan, \(\overline{A} \cap \overline{C} = \overline{A \cup C}\): lo que no está ni en \(A\) ni en \(C\). \(A \cup C = \{\lambda, 0, 1, 00, 01, 10, 11, 000, 111, 0000, 1111\}\), así que \[\overline{A} \cap \overline{C} = \Sigma^* - \{\lambda, 0, 1, 00, 01, 10, 11, 000, 111, 0000, 1111\}\]
  • i) Las de largo \(\geq 2\) que no están en \(A\): \(\overline{A} \cap B = B - A = \Sigma^* - \{\lambda, 0, 1, 00, 11, 000, 111, 0000, 1111\}\).
Respuesta

a) \(\{00, 11, 000, 111, 0000, 1111\}\)   b) \(\{0, 1\}\)   c) \(\Sigma^* - \{\lambda, 00, 11, 000, 111, 0000, 1111\}\)

d) \(\{0, 1, 00, 11\}\)   e) \(\{00, 01, 10, 11\}\)   f) \(\Sigma^*\)

g) \(\Sigma^* - \{0, 1, 00, 11\}\)   h) \(\Sigma^* - \{\lambda, 0, 1, 00, 01, 10, 11, 000, 111, 0000, 1111\}\)   i) \(\Sigma^* - \{\lambda, 0, 1, 00, 11, 000, 111, 0000, 1111\}\)

Solución del libro

Da exactamente estos nueve conjuntos (en g escribe además \(\{\lambda, 01, 10\} \cup \{w \mid \|w\| \geq 3\}\)). Coincide; se comprobó con Python sobre todas las cadenas de largo hasta 5.

Sin importar que una CPU tenga o no E/S por asignación de memoria, necesita direccionar los controladores de dispositivos para intercambiar datos con ellos. La CPU puede solicitar datos de un controlador de E/S un bit a la vez, pero al hacerlo se desperdicia el tiempo de la CPU, por lo que a menudo se utiliza un esquema distinto, conocido como IMA (Acceso Indirecto a Memoria).

Falso.

Qué evalúa

El acceso directo a memoria (Tanenbaum, Principios del hardware de E/S).

Por qué es falso

Todo está bien menos el nombre: el esquema se llama DMA, Acceso Directo a Memoria (Direct Memory Access). "IMA, Acceso Indirecto a Memoria" no existe.

Con DMA la CPU programa un controlador DMA (qué dispositivo, cuántos bytes, a qué dirección de memoria) y se va a hacer otra cosa. El controlador DMA pasa el bloque entero entre el dispositivo y la memoria sin la CPU, y al final la avisa con una interrupción.

Trampas

  • El cambio de una palabra (directo por indirecto) es la trampa. En la pregunta 44 las opciones falsas usan el mismo "Indirect Memory Access".

En el patrón Strategy, ¿quién decide qué estrategia concreta se usa?

Inventada · Unidad 4C, Strategy

  • El Contexto, con un if o un switch por cada estrategia.
  • El Cliente: crea la estrategia concreta y se la pasa al Contexto, que la usa sin saber cuál es.
  • La interfaz Estrategia.
  • Cada estrategia concreta decide cuál es la siguiente.

El Cliente elige y se la pasa al Contexto (por el constructor o con un método para cambiarla). El contexto solo conoce la interfaz Estrategia. Si el contexto tuviera un if por cada variante, sería justo el código que el patrón viene a sacar.

Resolver (x + y)z = 1, x + z = 1, y + z̄ = x

Resolver las ecuaciones simultáneas: \((x + y) \cdot z = 1\) ; \(x + z = 1\) ; \(y + \overline{z} = x\).

Qué tema es y por qué
  • Sistema de ecuaciones booleanas: valores de \(x, y, z\) que cumplan las tres a la vez.
  • Método: empezar por la ecuación que fija valores y reemplazar en las demás. Las propiedades que fijan valores:
    • \(ab = 1 \iff a = 1 \text{ y } b = 1\).
    • \(a + b = 0 \iff a = 0 \text{ y } b = 0\).

Paso 1 — Primera ecuación: \((x + y) \cdot z = 1\)

Regla: un producto vale 1 solo si todos los factores valen 1.

  • \(z = 1\) (entonces \(\overline{z} = 0\)).
  • \(x + y = 1\): al menos una de las dos vale 1.
Paso 2 — Segunda ecuación: \(x + z = 1\)

Con \(z = 1\): \(x + 1 = 1\) (dominación), que se cumple para cualquier \(x\). No agrega información.

Paso 3 — Tercera ecuación: \(y + \overline{z} = x\)

Con \(\overline{z} = 0\): \(y + 0 = x\), y por identidad \(y = x\).

Paso 4 — Juntar
  • \(y = x\) y \(x + y = 1\), entonces \(x + x = 1\).
  • Idempotencia: \(x + x = x\), así que \(x = 1\), y por lo tanto \(y = 1\).

Control con \(x = y = z = 1\): \((1 + 1) \cdot 1 = 1\) ✔; \(1 + 1 = 1\) ✔; \(1 + \overline{1} = 1 + 0 = 1 = x\) ✔.

Respuesta

\(x = 1,\ y = 1,\ z = 1\) (solución única).

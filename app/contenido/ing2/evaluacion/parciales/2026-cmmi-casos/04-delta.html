Caso 3 — Delta Logic

Unidad 5 · CMMI · Identificar el nivel

La empresa Delta Logic desarrolla sistemas para bancos. Presenta estas características:

  • Trabaja con un proceso documentado y común a todos los equipos.
  • Guarda datos históricos de todos sus proyectos: defectos por versión y tiempos reales.
  • Estableció rangos esperados: si un proyecto se sale del rango, el sistema de seguimiento genera una alerta.
  • Cuando salta una alerta, el equipo corrige el desvío para volver a lo habitual; el proceso no se modifica.

¿En qué nivel de madurez del modelo CMMI se encuentra Delta Logic? Justifique brevemente. ¿Qué riesgos o limitaciones enfrenta si no avanza al siguiente nivel?

✓ RespuestaPara aprender y escribir en la hoja

Está en el Nivel 4 (Cuantitativamente gestionado).

  • Qué define al Nivel 4: los procesos se miden y los números se usan para controlar y predecir.
  • Lo que tiene la empresa: junta datos de todos sus proyectos, fijó rangos de lo normal y recibe una alerta cuando algo se desvía ("guarda datos históricos de todos sus proyectos", "rangos esperados").
  • Por qué no es Nivel 5: en el Nivel 5, los datos se usan para mejorar el proceso todo el tiempo. Delta usa los datos solo para corregir el desvío y volver a lo de siempre, sin cambiar el proceso ("el proceso no se modifica").
  • Riesgo si no avanza: como usa los datos solo para corregir desvíos, el proceso no mejora: vuelve siempre al mismo punto y pierde competitividad frente a quien innova.

Paso 1 — Las cuatro preguntas

Se contestan en orden; el nivel es el del primer "no".

Pregunta, en ordenEn este caso
1. ¿Los proyectos se planifican y se siguen?Sí: el proceso común lo incluye
2. ¿Hay un proceso común, documentado, que usan todos los equipos?Sí: "común a todos los equipos"
3. ¿Los procesos se miden y los números se usan para controlar y predecir?Sí: datos históricos, rangos esperados y alertas
4. ¿Los datos se usan para mejorar el proceso?No: "el proceso no se modifica" → Nivel 4

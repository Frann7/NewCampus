La ecuación \(x^3 - x + 1 = 0\) en \(\mathbb{Z}_4\)

Hallar el conjunto solución de la ecuación \(x^3 - x + 1 = 0\) en \(\mathbb{Z}_4\).

Qué tema es y por qué
  • Es una ecuación en un anillo finito: \(\mathbb{Z}_4 = \{0, 1, 2, 3\}\) tiene solo cuatro elementos.
  • No hay fórmula para "despejar" una cúbica, pero no hace falta: se prueban los cuatro valores, reduciendo cada cuenta módulo 4.
  • "\(= 0\) en \(\mathbb{Z}_4\)" quiere decir \(x^3 - x + 1 \equiv 0 \pmod{4}\): que el resultado sea múltiplo de 4.

La regla

En \(\mathbb{Z}_n\) se puede operar con enteros comunes y reducir módulo \(n\) al final (o en el medio): si \(a \equiv b\) y \(c \equiv d \pmod{n}\), entonces \(a + c \equiv b + d\) y \(ac \equiv bd \pmod{n}\).

Respuesta

\(S = \emptyset\): la ecuación no tiene solución en \(\mathbb{Z}_4\).

Por qué no podía tener solución
  • \(x^3 - x = (x - 1) \cdot x \cdot (x + 1)\): es el producto de tres enteros consecutivos.
  • Entre dos consecutivos siempre hay un par, así que ese producto es par.
  • Entonces \(x^3 - x + 1\) es par + 1 = impar, y un impar nunca es múltiplo de 4.

El razonamiento sirve para cualquier entero \(x\), no solo para 0, 1, 2 y 3: confirma la tabla.

Verificación (la guía no trae resultados)

Con Python: los valores de \(x^3 - x + 1\) módulo 4 para \(x = 0, 1, 2, 3\) son \(1, 1, 3, 1\). Ninguno es 0.

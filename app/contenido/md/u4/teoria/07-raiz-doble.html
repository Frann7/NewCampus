Segundo orden homogénea · Caso 2

7. Raíz doble

Para qué sirve

Cuando el discriminante da 0 (sección 5) la ecuación característica tiene una sola raíz, repetida: \(r_1 = r_2 = r\). Con la fórmula del caso 1 quedaría \(A_1 r^n + A_2 r^n = (A_1 + A_2) r^n\), que en realidad tiene una sola constante y no alcanza para las dos condiciones iniciales. Hace falta otra solución distinta.

Solución

Caso 2: \(r_1 = r_2 = r\)

\[ a_n = A_1 r^{\,n} + A_2\, n\, r^{\,n}, \quad \forall n \geq 0 \]

Las constantes \(A_1\) y \(A_2\) salen de las condiciones iniciales.

SímboloQué es
\(r\)la raíz doble: \(r = \frac{-b}{2a}\) (la resolvente con la raíz cuadrada igual a 0)
\(n\, r^n\)la segunda solución: la misma potencia multiplicada por \(n\)

De dónde sale

Hay que ver que \(n\,r^n\) también cumple la RR. Que \(r\) sea raíz doble de \(C_0 x^2 + C_1 x + C_2\) significa que ese polinomio es \(C_0 (x - r)^2 = C_0 x^2 - 2C_0 r\,x + C_0 r^2\). Comparando coeficientes: \(C_1 = -2C_0 r\) y \(C_2 = C_0 r^2\). Se reemplaza \(a_n = n r^n\) en el lado izquierdo de la RR:

  • \(C_0\, n r^n + C_1 (n-1) r^{n-1} + C_2 (n-2) r^{n-2}\) — cada \(a_k\) se cambió por \(k r^k\).
  • \(= C_0\, n r^n - 2C_0 r (n-1) r^{n-1} + C_0 r^2 (n-2) r^{n-2}\) — se usó \(C_1 = -2C_0 r\), \(C_2 = C_0 r^2\).
  • \(= C_0 r^n \left[\, n - 2(n-1) + (n-2) \,\right]\) — las potencias de \(r\) suman siempre \(n\): factor común \(C_0 r^n\).
  • \(= C_0 r^n \left[\, n - 2n + 2 + n - 2 \,\right] = C_0 r^n \cdot 0 = 0\) ✓

Entonces \(r^n\) y \(n r^n\) son dos soluciones distintas, y su combinación tiene las dos constantes que hacen falta.

Enunciado

Resolver \(a_{n+2} = 4a_{n+1} - 4a_n\), \(\forall n \geq 0\), con \(a_0 = 7\), \(a_1 = 8\).

\[ r^2 - 4r + 4 = 0, \quad \Delta = 16 - 16 = 0 \;\Rightarrow\; r = \frac{4}{2} = 2 \text{ (doble)} \]

Se puede ver también como cuadrado perfecto: \(r^2 - 4r + 4 = (r - 2)^2\).

Paso 2 — Forma

Fórmula: \(a_n = A_1 r^{\,n} + A_2\, n\, r^{\,n}\)

\[ a_n = A_1 2^n + A_2\, n\, 2^n \]

Paso 3 — Constantes

\[ \begin{cases} A_1 2^0 + A_2 \cdot 0 \cdot 2^0 = 7 \\ A_1 2^1 + A_2 \cdot 1 \cdot 2^1 = 8 \end{cases} \;\Leftrightarrow\; \begin{cases} A_1 = 7 \\ 2A_1 + 2A_2 = 8 \end{cases} \;\Leftrightarrow\; \begin{cases} A_1 = 7 \\ A_2 = -3 \end{cases} \]

Con \(n = 0\) el término \(A_2 \cdot 0 \cdot 2^0\) se anula: por eso \(A_1\) sale directo.

Base negativa en la calculadora

Se escribe con paréntesis: (−3)^10. Sin paréntesis, −3^10 la calculadora lo toma como \(-(3^{10})\) y da negativo.

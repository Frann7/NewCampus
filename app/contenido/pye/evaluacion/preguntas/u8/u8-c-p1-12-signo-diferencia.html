Se compara el tiempo medio de respuesta del servidor A y del servidor B. El intervalo del 95 % para \(\mu_A - \mu_B\) dio \((-7{,}4\ ;\ -1{,}8)\) ms. ¿Qué se concluye?

Tercer parcial — primera parte probable (inventada)

  • Hay diferencia significativa: el servidor A tiene menor tiempo medio de respuesta que el B.
  • Hay diferencia significativa: el servidor A tiene mayor tiempo medio de respuesta que el B.
  • No hay diferencia significativa, porque los dos límites son negativos.
  • No se puede concluir nada sin conocer las medias muestrales.
  • El grupo 1 es el que se nombra primero: acá A. El intervalo es para \(\mu_A - \mu_B\).
  • ¿Incluye el 0? No: va de \(-7{,}4\) a \(-1{,}8\). Entonces hay diferencia significativa.
  • Todo negativo → \(\mu_A - \mu_B < 0\) → \(\mu_A < \mu_B\): A tiene menor tiempo medio.
  • Negativo no quiere decir “no hay diferencia”: lo que dice “no hay diferencia” es que el intervalo incluya el 0.
  • El intervalo ya alcanza para concluir; las medias muestrales no hacen falta.

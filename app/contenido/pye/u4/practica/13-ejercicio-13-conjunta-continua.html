Ejercicio 13 · Conjunta continua

Covarianza con densidad conjunta \(f(x,y) = x + y\)

Encuentre la covarianza y el coeficiente de correlacion de las variables aleatorias \(X\) e \(Y\), cuya funcion de densidad de probabilidad conjunta es \(f(x,y) = x + y\) para \(0 < x < 1\) y \(0 < y < 1\).

Es el mismo esquema del ejercicio 11, pero en vez de sumar celdas hay que integrar. Como los limites de ambas variables van de 0 a 1, todas las integrales son dobles de 0 a 1.

Paso 1 — \(E(X)\)

Formula:

\[ E(X) = \int_{0}^{1}\!\!\int_{0}^{1} x \cdot f(x,y)\, dx\, dy \]

\[ E(X) = \int_{0}^{1}\!\!\int_{0}^{1} x(x+y)\, dx\, dy = \int_{0}^{1}\!\!\int_{0}^{1} (x^{2} + xy)\, dx\, dy \]

Resolvemos primero la integral de adentro (respecto de \(x\)), tratando a \(y\) como si fuera un numero fijo:

\[ \int_{0}^{1} (x^{2} + xy)\, dx = \left[ \frac{x^{3}}{3} + \frac{x^{2}y}{2} \right]_{0}^{1} = \frac{1}{3} + \frac{y}{2} \]

Ahora integramos ese resultado respecto de \(y\):

\[ E(X) = \int_{0}^{1} \left( \frac{1}{3} + \frac{y}{2} \right) dy = \left[ \frac{y}{3} + \frac{y^{2}}{4} \right]_{0}^{1} = \frac{1}{3} + \frac{1}{4} = \mathbf{\frac{7}{12}} \]

Por simetria (la funcion \(x+y\) trata igual a las dos variables, y los limites son iguales), sin hacer cuentas:

\[ E(Y) = \frac{7}{12} \]

Paso 2 — \(E(XY)\)

Formula:

\[ E(XY) = \int_{0}^{1}\!\!\int_{0}^{1} x\,y \cdot f(x,y)\, dx\, dy \]

\[ E(XY) = \int_{0}^{1}\!\!\int_{0}^{1} xy(x+y)\, dx\, dy = \int_{0}^{1}\!\!\int_{0}^{1} (x^{2}y + xy^{2})\, dx\, dy \]

Integral interna respecto de \(x\):

\[ \left[ \frac{x^{3}y}{3} + \frac{x^{2}y^{2}}{2} \right]_{0}^{1} = \frac{y}{3} + \frac{y^{2}}{2} \]

Integral externa respecto de \(y\):

\[ \int_{0}^{1} \left( \frac{y}{3} + \frac{y^{2}}{2} \right) dy = \left[ \frac{y^{2}}{6} + \frac{y^{3}}{6} \right]_{0}^{1} = \frac{1}{6} + \frac{1}{6} = \mathbf{\frac{1}{3}} \]

Paso 3 — Covarianza

Formula:

\[ Cov(X,Y) = E(XY) - E(X)\cdot E(Y) \]

\[ Cov(X,Y) = \frac{1}{3} - \left(\frac{7}{12}\right)\left(\frac{7}{12}\right) = \frac{1}{3} - \frac{49}{144} \]

Denominador comun 144 (porque \(\frac{1}{3} = \frac{48}{144}\)):

\[ Cov(X,Y) = \frac{48}{144} - \frac{49}{144} = \mathbf{-\frac{1}{144}} \approx -0{,}00694 \]

Paso 4 — Varianzas

Formula:

\[ E(X^{2}) = \int_{0}^{1}\!\!\int_{0}^{1} x^{2}(x+y)\, dx\, dy \]

Integral interna:

\[ \int_{0}^{1} (x^{3} + x^{2}y)\, dx = \left[ \frac{x^{4}}{4} + \frac{x^{3}y}{3} \right]_{0}^{1} = \frac{1}{4} + \frac{y}{3} \]

Integral externa:

\[ E(X^{2}) = \int_{0}^{1} \left( \frac{1}{4} + \frac{y}{3} \right) dy = \frac{1}{4} + \frac{1}{6} = \frac{5}{12} \]

Formula:

\[ V(X) = E(X^{2}) - \big[E(X)\big]^{2} \]

\[ V(X) = \frac{5}{12} - \frac{49}{144} = \frac{60}{144} - \frac{49}{144} = \frac{11}{144} \]

Y por simetria, \(V(Y) = \frac{11}{144}\) tambien.

Paso 5 — Coeficiente de correlacion

Formula:

\[ \rho = \frac{Cov(X,Y)}{\sigma_X \sigma_Y} \]

Como \(\sigma_X = \sigma_Y = \sqrt{\frac{11}{144}}\), el producto de los dos desvios es justamente \(\frac{11}{144}\) (raiz por raiz del mismo numero = el numero):

\[ \rho = \frac{-\frac{1}{144}}{\frac{11}{144}} = -\frac{1}{11} = \mathbf{-0{,}0909} \]

Resultado oficial de la catedra

\(Cov(X,Y) = -\frac{1}{144}\);   \(\rho = -\frac{1}{11} = -0{,}09\)  ✓

Interpretacion: hay una relacion negativa, pero debilisima (esta casi pegada al cero). Practicamente no se influyen.

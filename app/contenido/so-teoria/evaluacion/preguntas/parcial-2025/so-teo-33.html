Qué evalúa

La tabla de terminología cliente/servidor de Stallings.

La idea

TérminoQué es
APIInterfaz de programa de aplicación: funciones que un programa llama para usar los servicios de otro.
ClienteQuien pide información o servicios (PC o estación de trabajo).
MiddlewareControladores, API y software que mejoran la conexión entre cliente y servidor (pregunta 38).
Base de datos (relacional)Donde el servidor guarda la información, con acceso restringido.
ServidorLa computadora que guarda la información para los clientes (pregunta 37).
Lenguaje Estructurado de Consultas (SQL)El lenguaje para consultar y actualizar la base de datos.

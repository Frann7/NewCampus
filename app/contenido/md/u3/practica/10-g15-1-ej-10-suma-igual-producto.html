Grimaldi 15.1 · Ej. 10 · Ecuación booleana

Si x + y + z = xyz, las tres variables valen lo mismo

Si \(x\), \(y\) y \(z\) son variables booleanas y \(x + y + z = xyz\), demuestre que las tres tienen el mismo valor.

Qué tema es y por qué
  • Es una ecuación booleana: hay que ver qué valores de \(x, y, z\) la cumplen.
  • Herramientas (observaciones de la teoría de esta unidad):
    • \(a + b + c = 0 \iff a = b = c = 0\) (una suma vale 0 solo si todos los sumandos valen 0).
    • \(abc = 1 \iff a = b = c = 1\) (un producto vale 1 solo si todos los factores valen 1).
  • Como \(x\) solo puede valer 0 o 1, se separa en esos dos casos.
Paso 1 — Caso \(x = 0\)
  1. El lado derecho: \(xyz = 0 \cdot y \cdot z = 0\) (dominación: \(0 \cdot a = 0\)).
  2. Por la ecuación, el lado izquierdo también vale 0: \(x + y + z = 0\).
  3. Una suma vale 0 solo si todos los sumandos valen 0: \(y = 0\) y \(z = 0\).
  4. Las tres valen 0.
Paso 2 — Caso \(x = 1\)
  1. El lado izquierdo: \(x + y + z = 1 + y + z = 1\) (dominación: \(1 + a = 1\)).
  2. Por la ecuación, el lado derecho también vale 1: \(xyz = 1\).
  3. Un producto vale 1 solo si todos los factores valen 1: \(y = 1\) y \(z = 1\).
  4. Las tres valen 1.
Paso 3 — Conclusión

En los dos casos posibles las tres variables terminan con el mismo valor. Además, las dos soluciones sirven: en \(000\) los dos lados valen 0, y en \(111\) los dos valen 1.

Respuesta

Las únicas soluciones son \(x = y = z = 0\) y \(x = y = z = 1\): las tres variables tienen el mismo valor.

Solución del libro

Es par: no está en las soluciones en castellano. El manual del profesor hace los mismos dos casos (\(x = 0\) obliga \(y = z = 0\); \(x = 1\) obliga \(y = z = 1\)). Coincide; además se probaron las 8 entradas.

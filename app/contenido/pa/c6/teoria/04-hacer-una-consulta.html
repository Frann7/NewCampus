4. Hacer una consulta

Para qué sirve

Con la conexión abierta, una consulta (en inglés, query) es mandarle al SGBD una instrucción SQL para que la ejecute. La cátedra lo describe en tres pasos: escribir la instrucción SQL, enviársela al gestor, y obtener el resultado por la misma conexión.

Lo mínimo de SQL para leer datos

InstrucciónQué pide
SELECT * FROM personasTodas las columnas (*) de todas las filas de la tabla personas
SELECT apellido, nombres FROM personasSolo esas dos columnas
... WHERE apellido = 'Bonnet'Solo las filas que cumplen la condición. El texto va entre comillas simples; los números, sin comillas
... WHERE documento > 20000000Comparaciones como en PHP: = (uno solo), <> (distinto), >, <
... ORDER BY apellidoOrdena las filas por esa columna

Las instrucciones que modifican datos (INSERT, UPDATE, DELETE) están en la sección 6.

Sintaxis

$sql = 'SELECT * FROM personas';

if ($resultado = $mysqli->query($sql))
{
    // acá se usa $resultado
}

En estilo procedural: $resultado = mysqli_query($conexion, $sql);

Qué es cada parte

ParteQué es
$sqlUn string común de PHP con la instrucción SQL. Para PHP es solo texto: quien lo entiende es la base
$mysqli->query($sql)Manda ese texto por la conexión y espera la respuesta
$resultadoLo que devolvió la base (tabla de abajo)
if ($resultado = ...)Un solo =: no compara, asigna. Primero guarda en $resultado lo que devolvió query(), y después el if mira si eso cuenta como verdadero. Si la consulta falló, devolvió false y no entra
$resultado->num_rowsCuántas filas trajo la consulta (una propiedad, sin paréntesis)

Qué devuelve query()

Si la consulta es…Devuelve
un SELECT que anduvoun objeto de la clase mysqli_result, aunque no haya encontrado ninguna fila (en ese caso, con num_rows = 0)
un INSERT, UPDATE o DELETE que anduvotrue
cualquiera que fallófalse en el PHP viejo; en PHP 8.1 o más, una excepción (sección 7)
$resultado no tiene los datos

La cátedra lo remarca: $resultado no tiene almacenados los datos, es un apuntador al socket desde donde se van a leer. Para tener las filas en algo que PHP pueda usar (un arreglo), hay que sacarlas una por una: eso es la sección 5.

Errores y trampas
  • echo $resultado; no muestra las filas: da error, porque es un objeto, no un texto. Las filas se sacan con fetch (sección 5).
  • En SQL la igualdad es un solo =, al revés que en PHP. Y en PHP, el = dentro del if de la cátedra es a propósito: asigna y después evalúa.
  • Comillas anidadas: si el SQL lleva texto entre comillas simples, el string de PHP va entre dobles (o al revés). Mezclarlas iguales corta el string antes de tiempo.
  • El espacio que tiene la cátedra al principio (' SELECT * FROM personas') no molesta: SQL ignora los espacios de más.

Pregunta 20

Unidad 8 · Conclusión con el IC de la diferencia

Tilde la correcta:

Un intervalo de confianza del 95 % para \(\mu_1 - \mu_2\) dio \((-9{,}74\ ;\ -2{,}15)\). Se concluye que:

  1. No hay diferencia significativa entre las medias.
  2. \(\mu_1 > \mu_2\).
  3. \(\mu_1 < \mu_2\).
  4. Las medias son iguales.
✓ ResultadosSolo la respuesta

Correcta: c — \(\mu_1 < \mu_2\).

✎ Explicación detalladaDe dónde sale y las trampas

Qué evalúa

Leer el signo del intervalo.

Por qué

Los dos límites son negativos: no incluye el 0 y \(\mu_1 - \mu_2 < 0\), o sea \(\mu_1 < \mu_2\). Hay diferencia significativa y la población 1 tiene la media más chica.

IntervaloConclusión
incluye el 0no hay diferencia significativa
todo positivo\(\mu_1 > \mu_2\)
todo negativo\(\mu_1 < \mu_2\)

Trampas

  • d nunca es la respuesta: un intervalo no prueba que las medias sean iguales.

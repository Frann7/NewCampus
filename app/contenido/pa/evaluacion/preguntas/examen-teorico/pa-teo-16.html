El código de estado HTTP (Status Code) 400 (Success) pertenece a la clase de respuestas satisfactorias y es enviado por el servidor para confirmar que la solicitud del cliente ha sido procesada correctamente y el recurso solicitado está disponible.

Falso.

Qué evalúa

Las clases de códigos de estado de HTTP.

La idea

Cada respuesta HTTP trae un código de tres cifras; la primera cifra dice la clase:

ClaseSignificaEjemplo
1xxInformativa100 Continue
2xxÉxito200 OK
3xxRedirección301 Moved Permanently
4xxError del cliente400 Bad Request, 404 Not Found
5xxError del servidor500 Internal Server Error

El 400 es Bad Request: el servidor no entiende el pedido porque está mal armado. Lo que describe la frase es el 200 OK.

Trampas

  • El “(Success)” entre paréntesis está puesto para confundir: todos los 4xx son errores.

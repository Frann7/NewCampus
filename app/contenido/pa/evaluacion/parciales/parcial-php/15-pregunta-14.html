Qué evalúa

Qué estructuras sirven para recorrer un array (pasar por cada elemento). Es de la Clase 2 (arreglos), con las estructuras de la Clase 1.

El concepto, desde cero

Un array (arreglo) es una variable que guarda varios valores, cada uno con su clave; si no se escriben claves, PHP los numera desde 0 (índices 0, 1, 2…). Recorrerlo es hacer algo con cada elemento, uno por uno: mostrarlo, sumarlo, compararlo.

Las estructuras de control son las instrucciones que deciden qué se ejecuta y cuántas veces. Hay dos familias:

  • De decisión (if, else if, switch): eligen un camino según una condición, una sola vez.
  • De repetición o ciclos (for, foreach, while, do...while): repiten un bloque varias veces; cada repetición es una vuelta.

Recorrer es repetir algo para cada elemento, así que hace falta un ciclo. De los cuatro, la pregunta ofrece dos: for y foreach.

Un ejemplo con los dos

<?php
$letras = array('x', 'y', 'z');
for ($i = 0; $i < count($letras); $i++) echo $letras[$i]." ";
foreach ($letras as $v) echo $v." ";
?>

Los dos recorren el mismo array (comprobado en PHP 8.2): el for usando el índice, el foreach sin él.

Opción por opción

  • a) else if, b) if, c) switch: son de decisión, eligen un camino una sola vez; no repiten.
  • d) var_dump: es una función que muestra el contenido de una variable, no una estructura de control.
  • e) foreach: correcta, está hecha para recorrer arrays.
  • f) for: correcta, recorre usando el índice.
  • g) r_array: no existe en PHP (se parece a print_r).
  • h) trim: función de cadenas que saca los espacios del principio y del final.

3. Etiquetas, punto y coma y comentarios

Para qué sirve

PHP nació como un procesador de texto: un archivo .php es, casi siempre, una página HTML con pedazos de código metidos adentro. Las etiquetas le dicen a PHP dónde empieza y dónde termina el código. Lo que está fuera de las etiquetas se manda tal cual; lo que está dentro se ejecuta.

Sintaxis

<?php
    instrucción_1;
    instrucción_2;  instrucción_3;
    // comentario de una línea
    # otro comentario de una línea
    /* comentario
       de varias líneas */
?>

Qué es cada parte

ParteQué es
<?phpEtiqueta de apertura. Es la etiqueta estándar, la recomendada y la que se usa en toda la materia.
?>Etiqueta de cierre. Después de ella vuelve a ser HTML.
;Separa una instrucción de la otra. Puede haber una instrucción por renglón o varias en el mismo renglón: lo que las separa es el punto y coma, no el salto de línea.
// y #Comentario de una línea: desde ahí hasta el final del renglón, PHP no lee nada.
/* ... */Comentario de bloque: todo lo que está entre /* y */ se ignora, aunque ocupe varios renglones.

Las dos instrucciones para mostrar: echo y print

  • echo "texto"; escribe el texto en la respuesta (lo que recibe el navegador).
  • print "texto"; hace lo mismo. La cátedra usa las dos; a veces con paréntesis: print ("texto");, que es igual.
  • El texto va entre comillas: "así" o 'así'. Un texto entre comillas se llama string (sección 4).

Cómo se ve en el navegador: <br>

Lo que imprime PHP lo lee el navegador como HTML. En HTML, un salto de línea del texto no se ve: para bajar de renglón hay que imprimir la etiqueta <br> (también escrita <br/>). Por eso en los ejemplos aparece echo "<br>"; entre una salida y otra.

Ejemplo 1 — HTML y PHP en el mismo archivo

<p>Antes del PHP</p>
<?php
echo "Primera línea";
echo "<br>";
print "Segunda línea";
?>
<p>Después del PHP</p>

Qué imprime y por qué

Uno Dos Siete

Se ejecutan solo las tres instrucciones que no están comentadas, y no hay error por el ; que falta al final.

Errores y trampas

Olvidarse el punto y coma en el medio

El cierre ?> solo perdona el ; de la última instrucción. Si falta entre dos instrucciones:

<?php
echo "Hola"
echo "Chau";
?>

PHP no ejecuta nada y muestra un error de sintaxis que apunta a la línea siguiente (donde se dio cuenta):

Parse error: syntax error, unexpected token "echo", expecting "," or ";" in ... on line 3
Las comillas de los PDF no sirven para programar

En los apuntes de la cátedra el código aparece con comillas tipográficas (“así”). PHP solo entiende las comillas rectas del teclado ("así"). Si copiás y pegás desde el PDF, salta un error como Undefined constant "“Hola”": hay que reescribir las comillas.

"Cuatro tipos de etiquetas"

El apunte dice que hay cuatro tipos de etiquetas, pero muestra una sola: la estándar, <?php ... ?>. Es la única que se usa en la materia.

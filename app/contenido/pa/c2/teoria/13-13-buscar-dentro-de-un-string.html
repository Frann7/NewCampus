13. Buscar dentro de un string: strpos, strstr, strspn y parientes

Para qué sirve

Para saber si un texto contiene a otro, dónde, o para quedarse con un pedazo a partir de una marca:

  • ¿En qué posición está? → strpos() (y stripos() sin mirar mayúsculas).
  • Dame el texto desde ahí → strstr() (y stristr() sin mirar mayúsculas).
  • ¿Cuántos caracteres del principio son "permitidos"? → strspn() y strcspn().

strpos y strstr son case-sensitive (distinguen mayúsculas); las versiones con i (insensitive) no.

Sintaxis

Las funciones de búsqueda 
strpos($cadena, $buscar)            // posición (número) o false
strpos($cadena, $buscar, $desde)    // empezando a buscar en $desde
stripos($cadena, $buscar)           // igual, sin mirar mayúsculas
strstr($cadena, $buscar)            // el texto desde $buscar hasta el final, o false
strstr($cadena, $buscar, true)      // el texto de ANTES de $buscar
stristr($cadena, $buscar)           // como strstr, sin mirar mayúsculas
strspn($cadena, $mascara)           // largo del principio hecho solo con caracteres de $mascara
strcspn($cadena, $mascara)          // largo del principio SIN ningún carácter de $mascara

Qué es cada parte

ParteQué es
$cadenaEl texto donde se busca (el "pajar")
$buscarLo que se busca (la "aguja")
$desde(strpos) Posición desde donde empezar a buscar
true(strstr) En vez de lo que sigue, devuelve lo que está antes
$mascara(strspn, strcspn) Una lista de caracteres sueltos: una "lista blanca" para strspn y una "lista negra" para strcspn
Dos números más(strspn, strcspn) Opcionales: posición de inicio y cuántos caracteres analizar

Ejemplo 1 — strpos y el !== false (teoría de la cátedra)

<?php
$cadena = 'Hola a todos. Dentro de esta cadena realizaremos la búsqueda.';
var_dump(strpos($cadena, 'realizaremos'));
var_dump(strpos($cadena, 'Hola'));
var_dump(strpos($cadena, 'xyz'));
if (strpos($cadena, 'Hola')) {
    echo 'if simple: encontrada';
} else {
    echo 'if simple: NO encontrada';
}
echo "\n";
if (strpos($cadena, 'Hola') !== false) {
    echo 'con !== false: encontrada';
}
?>

Si no la encuentra devuelve false, no 0

El apunte dice que strpos devuelve "el valor 0 (falso) si no es encontrada". Devuelve false; el 0 es la posición cuando está al principio. Por eso la cátedra (bien) pide comparar con !== false: es la única forma de no confundir "está en la posición 0" con "no está".

Errores de tipeo del apunte en este ejemplo

El apunte presenta la función como strtr() (que es otra: reemplaza caracteres) cuando el código usa strstr(). Además guarda en $dominio y $cuenta pero hace echo $domain y echo $user, variables que no existen. Arriba está corregido.

Ejemplo 4 — strspn y strcspn: lista blanca y lista negra

<?php
echo strspn('1334455abcdef', '12345') . '<br>';
echo strcspn('1334455abcdef', 'abc') . '<br>';
echo strspn('1abc234', 'abc', 1, 4) . '<br>';
echo strcspn('Hola mundo', ' ');

La cátedra dice 6, pero son 7

Para strspn('1334455abcdef', '12345') el apunte anota 6. Los siete primeros caracteres (1334455) son todos de la máscara, así que da 7. También dice que estas funciones "aceptan dos parámetros": son dos parámetros más (inicio y largo), además de la cadena y la máscara.

Errores y trampas

strpos devuelve un número, strstr devuelve texto

strpos('123456789', '45') da 3 (dónde está); strstr('123456789', '45') da 456789 (lo que sigue). Las dos dan false si no encuentran nada.
